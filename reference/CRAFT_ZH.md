## 1. 情节结构

### Save the Cat 节拍表（百分比标记）

| 节拍 | % 位置 | 功能 |
|------|--------|------|
| 开幕画面 | 0-1% | 故事开始前的状态快照 |
| 主题陈述 | ~5% | 某个角色（非主角）暗示核心主题 |
| 铺垫 | 1-10% | 正常世界、建立角色、埋下种子 |
| 激励事件 | ~11% | 发生在主角身上的事件（非主角主动选择） |
| 犹豫/辩论 | 11-23% | 主角抗拒召唤，衡量选择 |
| 跨入第二幕 | ~23% | 主角主动选择进入新世界 |
| B 故事 | ~27% | 承载主题的新角色/关系 |
| 玩乐与游戏 | 26-50% | 兑现核心前提的承诺 |
| 中点 | ~50% | 假胜利或假失败，赌注提升 |
| 反派逼近 | 50-68% | 墙壁逼近、盟友分裂、压力升级 |
| 一切尽失 | ~68% | 最低点。死亡的影子（文字或象征） |
| 灵魂黑夜 | 68-77% | 主角内化主题 |
| 跨入第三幕 | ~77% | 新信息（常来自 B 故事）改变一切 |
| 终局 | 77-97% | 五段子节拍（集结→执行→高塔惊喜→深挖→新计划执行） |
| 终局画面 | ~99% | 与开幕画面形成镜像，展示转变 |

**可检查项**: 开幕/终局画面必须镜像。激励事件必须来自外部。跨入第二幕必须是选择。中点必须逆转轨迹。一切尽失必须包含某种死亡。

### Dan Harmon 故事圈（8 步骤，每步约 12.5%）

1. **你** — 角色在舒适区
2. **需要** — 角色渴望某物
3. **出发** — 跨越门槛，进入陌生领域
4. **搜寻** — 适应、挣扎、学习
5. **找到** — 得到渴望之物（6 点钟方向，最深之处）
6. **付出代价** — 为此付出沉重代价
7. **返回** — 回到熟悉领域
8. **改变** — 与第 1 步在本质上不同

**关键**: 此圈是分形的——适用于整部小说、每一幕、每一个章节。
上半圈 = 秩序/舒适。下半圈 = 混沌/未知。

### 许诺、进展、回报（Sanderson）

**许诺（前 10-20%）**: 开篇建立的隐性契约
- 调性许诺：开篇情绪 = 读者预期的情绪
- 角色许诺：这是谁的故事、TA 想要什么、缺乏什么
- 情节许诺：将面对何种冲突？
- 设定许诺：类型惯例已建立

**进展（中段 60%）**: 通过 try-fail 循环产生有意义的前进
- "是的，但是..." — 目标达成，新问题出现（最常用）
- "不，而且..." — 目标失败，情况更糟（最常用）
- "不，但是..." — 目标失败，一线希望（偶用）
- "是的，而且..." — 目标达成，持续向好（稀少，留给高潮）

**规则**: 中段 60%+ 的场景应为 "是的，但是" 或 "不，而且"

**回报（最后 20%）**: 每个许诺都被兑现——获得性的且令人意外，但回顾时又觉得必然。
- 有许诺无回报 = 契诃夫之枪违规
- 有回报无许诺 = 天降机械神

### MICE 商数 (Orson Scott Card / Sanderson)

每个故事是四种线索类型的组合：
- **环境** (Milieu): 对地点/世界的探索 (进入→离开)
- **探询** (Inquiry): 由问题/谜团驱动 (提出→回答)
- **角色** (Character): 由内在状态驱动 (不满→改变)
- **事件** (Event): 对常态的破坏 (破坏→新平衡)

**规则**: 线索按打开的反序关闭（像 HTML 标签一样嵌套）。
打开 M-I-C，关闭 C-I-M。

## 2. 角色技艺

### 三滑块 (Sanderson)

每个角色有三个独立刻度（0-10）：

- **主动性** — 推动情节还是被动反应？
- **讨喜度** — 读者会共情吗？
- **能力值** — 在某方面擅长吗？

**规则**: 令人信服的角色 = 至少两项高，或一项极高且有清晰成长。
三项全低 = 无聊。三项全高且无成长 = 玛丽苏。

经典组合:
- 高能力 + 高主动性 + 低讨喜度 = 反英雄
- 高讨喜度 + 低能力 + 低主动性 = 普通人
- 高主动性 + 高讨喜度 + 低能力 = 励志小人物

### 创伤/欲望/需求/谎言 因果链

一条因果链，每项导致下一项：

**创伤事件** (过去发生了什么？)
→ **伤口** (持续的情感伤害)
→ **谎言** (为应对伤口而采纳的错误信念)
→ **欲望** (由谎言驱动的外部目标——错误解药)
→ **需求** (真正能治愈的内在真相——与谎言对立)

**规则**:
- 创伤/伤口在第一幕（前 25%）暗示
- 欲望在第一幕结束时明确陈述
- 欲望与需求必须互相对立
- 中点（~50%）: 第一次瞥见欲望不奏效
- 一切尽失（~75%）: 谎言的最坏后果暴露
- 高潮: 角色在欲望和需求之间做出抉择
  - 正向弧: 选择需求，拒绝谎言
  - 负向弧: 选择欲望，加深谎言
  - 平弧: 已知真理，去改变世界而非自己

**可检查项**: 能否用一句话陈述谎言？真相是否是其直接对立面？创伤是否因果性地解释了谎言？

### 对话独特性（8 维度）

1. 词汇量级（音节数/用词复杂度）
2. 句子长度和结构（简短 vs 冗长）
3. 口语化程度（"不行" vs "不可以"）
4. 口头禅和语言习惯（每个角色独有）
5. 提问 vs 陈述比例（好奇型 vs 权威型）
6. 打断与被断模式（主导型 vs 顺从型）
7. 比喻域（士兵用军事比喻，农民用土地比喻）
8. 直接度 vs 委婉度（"滚。" vs "天不早了……"）

**测试**: 去掉所有对话标签。还能分辨是谁在说话吗？
若能，对话就是独特的。若不能，角色需要差异化。

## 3. 世界构建

### Sanderson 魔法三定律

**第零定律**: "永远偏向「酷」的方向。"
惊奇感有内在价值，哪怕略微打破其他规则。

**第一定律**: "作者用魔法解决冲突的能力，与读者对该魔法的理解程度成正比。"
- 硬魔法（规则清晰）→ 可以解决冲突
- 软魔法（神秘莫测）→ 应该制造问题，而非解决问题
- 高潮用未解释的魔法解决冲突 = 天降机械神
- **评估**: 每次用魔法解决的冲突，该能力是否在解决之前就已经被建立了？

**第二定律**: "限制 > 力量"
- 限制: 硬边界（什么不能做）
- 代价: 使用者支付什么（体力、生命力、资源）
- 弱点: 产生的脆弱性（对敌人可见等）
- **规则**: 限制的叙事比重应 ≥ 力量的叙事比重
- **规则**: 代价应驱动情节决策

**第三定律**: "在添加新东西之前，先拓展现有内容。"
- 更少的能力 + 更多应用 = 深度
- 更多能力 + 各少应用 = 杂货铺
- 最后 25% 不得出现未伏笔的新能力

## 4. 伏笔与回报

### 伏笔账本

| 编号 | 线索 | 种植章 | 强化章 | 回收章 | 类型 |
|------|------|--------|--------|--------|------|

**类型**: 物品 / 对话 / 行动 / 象征 / 结构

**规则**:
- 种植到回收间距 ≥ 3 章
- 每条线索在回收前至少被强化 1 次
- 不可有种植无回收（契诃夫之枪）
- 回收时应让读者有 "啊！原来如此！" 的感觉
- 回收方式应「意料之外、情理之中」

## 5. 文字品质

### 展示 vs 说教

- **展示**: 感官细节 → 读者自己得出情感结论
- **说教**: 叙述者直接告知情感状态 → 剥夺读者的主动参与

**禁止的说教模式**:
- "他感到愤怒/悲伤/害怕/……"
- "她心里一阵……"
- "气氛变得紧张/压抑/……"
- 副词标签化: "愤怒地说"、"悲伤地走"

**替代方案**: 行为、生理反应、环境互动
- "他把杯子攥出了裂纹。" 而非 "他感到愤怒。"
- "她数了三遍才把钥匙对准锁孔。" 而非 "她紧张不安。"

### 段落设计

- 段落长度有意变化，不可连续 3 段以上长度相近
- 每章至少 1 段 1-2 句的短段落（制造冲击）
- 每章至少 1 段 6+ 句的长段落（营造氛围）
- 短段落最适合: 发现、决定、反转
- 长段落最适合: 描写、回忆、渐进的领悟

### 句子节奏

- 短句（3-8 字）：动作、冲击、强调
- 中句（15-25 字）：推进、叙述、过渡
- 长句（30+ 字）：氛围、沉思、复杂情感
- 好章节的句子长度应该像呼吸一样有自然的快慢变化
