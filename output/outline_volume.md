# 全书弧线

## 核心冲突及其阶段性演化

**元冲突**：维护系统（保持城市运转）vs 解放生命（释放星灵）

- **卷1：** 冲突呈现为“修复故障” vs “掩盖故障”——林恩以为自己在修炉，实则在触碰禁忌
- **卷2：** 冲突升级为“控制危机” vs “揭露真相”——林恩必须在教会镇压和兄弟会革命之间站队
- **卷3：** 冲突抵达终极形态：“维持城市存续” vs “终结星灵奴役”——无论选择哪边，都有人会死

## 主角内在弧线（起点→终点，逐卷推进）

| 阶段 | 林恩的状态 | 核心信念 |
|------|-----------|----------|
| **起点（卷1初）** | 忠诚技术员，相信修好机械就能解决问题 | “父亲的牺牲有意义，只要我不越界” |
| **卷1末** | 觉醒怀疑者，知道熔炉内有“活的东西” | “教会向我隐瞒了真相——我必须知道得更多” |
| **卷2末** | 被迫行动者，但因卷入两派争斗付出代价 | “真相不能救所有人——但我不能再装不知道” |
| **终点（卷3末）** | 悲剧性选择者，接受系统性罪恶无法消除 | “无论选哪边，都会有一部分的我死在熔炉里” |

# 逐卷规划（卷1–2）

---

### 卷 1：废墟觉醒

— **叙事功能:** 建立世界，引入冲突——从“机械故障”到“系统谎言”的认知转换

— **情感弧线:** 从日常的温暖感与秩序感 → 逐渐渗入寒冷与不安 → 以“不能装作没听到”的清醒终结

— **关键事件:**
  1. **（第1章前半）** 林恩在下炉底的蒸汽管道维修站听到熔炉异响——不是机械杂音，而是像人声的“救……我……”。她以为是通风管道幻听，但深夜再次传来，更清晰。
  2. **（第1章中段）** 林恩试图按规程上报异常，却被哈罗德阻止：“有些声音是维修工不应该听到的。”哈罗德暗示上面有监控。
  3. **（第1章后半）** 她被钟表教会的“例行检查”约谈——不是斥责，而是温和地询问她的“听炉”能力是否仍在正常工作。教士暗示她若“太敏感”，可能重新评估她作为机械师的资格。
  4. **（第2章前半）** 林恩因困惑和不安开始私下调查，通过旧管道图纸发现一处被封死的地下通道入口。她与蒸汽兄弟会的眼线（炉卡）偶然接触，被带到灰烬·肖恩面前。
  5. **（第2章后半）** 灰烬向她展示了273年的手写记录和一块从遗迹带出的“余烬”碎片。他说：“你父亲不是唯一一个被献祭的。教会一直在拿人喂星灵。”林恩触摸余烬时，感受到了父亲的声音——真实的、不是记忆的。卷末，她决定进入遗迹。

— **角色移动:** 林恩从“忠诚的机械师”变为“被动的知情者”——她还没有主动选择反抗，但已无法退回无知状态。

— **伏笔种子（埋入本卷）:**
  - 哈罗德提到“有一次在管道里看到不该看的东西”，暗示他见过第108人的画像（种植在卷1第1章，预期回收于卷3第1章）
  - 灰烬展示的遗迹记录中，有一行被涂黑的字：“第108人献出了——”之后的内容缺失（种植在卷1第2章，预期回收于卷3第2章）
  - 铁炉在卷1后半段的一场会议中提到“下炉底的鱼越来越多了”——暗示地下暗河系统有变化（种植在卷1第1章，预期回收于卷2第2章）

— **与前卷衔接:** 无

### 卷 2：阴影与献祭

— **叙事功能:** 压力升级，迫使林恩做出选择——从被动知情到主动干预，同时承担第一次不可挽回的代价

— **情感弧线:** 从发现的震惊与愤怒 → 投入行动带来的短暂希望 → 遭受背叛后的恐惧与绝望 → 最后以“知道下一步必须做什么，但害怕做”的低沉高张力收尾

— **关键事件:**
  1. **（第1章前半）** 林恩进入遗迹，发现地下洞穴系统远比兄弟会描述的庞大。她看到了星灵的物理形态——一团被金属束带捆在巨大熔炉核心中的发光体，不时痉挛。她听到它用通用语说：“冷……”
  2. **（第1章中段）** 铁炉发现遗迹入口被侵入，大幅增派蒸汽骑士巡逻。维拉·黑骨通过商会向兄弟会提供热卡和武器，条件是林恩为她绘制地下管道地图（用于走私路线）。林恩处于被多重利用的夹缝中。
  3. **（第1章后半）** 林恩在遗迹深处发现了父亲的工程师编号铜牌——位于一具被金属束带穿透的人类骸骨旁。她意识到：父亲不是第一个，也绝不是最后一个被“直接植入”熔炉燃料系统的献祭者。
  4. **（第2章前半）** 灰烬策划突袭熔炉安全阀系统，以迫使教会妥协。林恩被要求参与操作——她的管道知识至关重要。行动初期成功，但灰烬利用她打开了通往星灵核心的通道，准备直接释放星灵（不等她同意）。
  5. **（第2章后半）** 灰烬被铁炉亲自率蒸汽骑士击退。林恩受伤但被莱拉发现——莱拉给她两个选择：一是作为“被胁迫者”看管起来，二是配合教会指认灰烬。林恩拒绝，莱拉扭断其中一根蒸汽管导致林恩被中度烧伤。在混乱中，灰烬逃脱，但炉卡为掩护林恩而死。卷末，林恩拖着伤手躲入下炉底的暗流教派据点，首次见到黑尘。黑尘说：“你父亲死前给了一个名字。他说：告诉这个名字的人——他不是被丢弃的。”

— **角色移动:** 林恩从“试图理解系统”变为“被系统碾碎了一次”——她失去了炉卡（替代弟弟/孩子角色），被莱拉彻底对立，灰烬暴露了利用本质。她不再相信任何一边，但也无法独善其身。

— **伏笔种子（本卷种植）:**
  - 林恩在遗迹中看到父亲骸骨上有一个奇怪的黑色结晶嵌入掌心（种植于卷2第1章，预期回收于卷3第1章——这是星灵在被献祭者身上留下的“余烬种子”，可作为最终解开所有束缚的钥匙）
  - 黑尘说“你父亲给了一个名字”，林恩追问名字，黑尘只说“你现在还不知道，但到时候你会听到的”（种植于卷2第2章，预期回收于卷3第2章——这个名字是第108人的真名，也是星灵的原始契约者）
  - 莱拉在抓捕林恩时，林恩注意到她披肩内层藏着一缕黑发——与莱拉的白金色头发完全不同（种植于卷2第2章，预期回收于卷3第2章——这是她母亲的信物）
  - 星灵的金属束带上刻有的序列号与哈罗德工具箱里的一个扭盖上的数字一致（种植于卷2第1章，预期回收于卷3第2章——证明哈罗德曾是构造束带系统的工程师之一）

— **与前卷衔接:** 因果链——卷1林恩决定进入遗迹，导致她发现父亲的骸骨（卷2第1章）。因果链——卷1哈罗德警告“不要听”，卷2哈罗德在关键时刻打开安全通道帮林恩逃生，但拒绝公开站边。

# 逐卷规划（卷3）

---

### 卷 3：钟摆与抉择

— **叙事功能:** 终极选择与代价——所有线索汇聚到熔炉核心，林恩必须在“维持城市”和“解放星灵”之间做出不可逆的决定，并承受该决定带来的全部后果

— **情感弧线:** 从卷2末的创伤性低点（伤员、孤独、被利用）→ 短暂恢复力量感（获得新线索/新盟友）→ 再次被权力系统碾压（莱拉的围捕、灰烬的最后一搏）→ 最终抵达沉重但清晰的接受（接受代价，做出选择，无论对错）

— **关键事件:**

  1. **（第1章前半）代价与碎片**
     - 林恩在下炉底暗流教派据点养伤。黑尘给她的伤口涂抹黑鳞鱼油膏，并告诉她：你父亲留下的话不仅是那个名字，还包括一个地点——“钟塔地下第三层，暗室铁门后”。
     - 林恩想起炉卡牺牲前的话（伏笔回收9）。她决定前往上炉区钟塔，但需要维拉·黑骨提供通行证件。
     - 维拉同意了，但要求林恩在下炉底的地下暗河入口放一枚信号弹——为了商会的一次走私行动。林恩接受了交换，但感到被再次工具化。

  2. **（第1章中段）大主教的房间**
     - 林恩伪装成清洁工进入上炉区钟塔。在地下第三层，她发现了一间被锁死的暗室。铁门后是一具老人尸体——正是失踪三天的大主教。
     - 大主教手中握着一张字条：“它看着我。它一直在看。”旁边有一本日记，记录了他最后的发现：星灵的真正心脏不在遗迹地下的熔炉核心，而在上炉区的“永辉圣殿”正下方——那里埋藏着星灵的“第一块束缚板”，是所有束带之力来源。
     - 林恩拿走日记，离开时撞见莱拉。莱拉是来“例行拜访”大主教的。对峙中，林恩亮出大主教已死的证据。莱拉沉默后说：“你知道吗，我羡慕你——你能选择离开。我从来只能留下。”她没有逮捕林恩，而是放她离开，但警告她：“下一次见面，我会履行职责。”

  3. **（第1章后半）余烬种子苏醒**
     - 林恩回到暗流教派据点，星灵的束缚板位置确认了。她试图联系灰烬·肖恩，发现兄弟会已经分裂——部分成员因灰烬在卷2突袭中牺牲大量人而叛离。
     - 灰烬单独找到林恩。他承认自己认识林恩的父亲，并承认是他将父亲的名字列入“自愿献祭名单”，但坚持那是父亲自己的要求。他展示了一份记录：父亲写下的留言——“如果我的女儿能活下来，让她知道——我给她的不是愧疚，是钥匙。”
     - 在追问下，灰烬说出了第108人的名字：**“阿斯特拉·凯恩”**——她是祖先中的唯一一位女性工程师，也是星灵束缚系统的设计者。她在最后关头反悔，试图释放星灵，被其他祖先合力抹除历史。但她在束缚板上留下了自己的印记——一个由她头发制成的人形锁扣，用以在必要时打开束缚系统。
     - 林恩触摸父亲骸骨上发现的余烬种子（伏笔回收4），她感到一股温热涌入掌心。余烬种子开始发光。

  4. **（第2章前半）三重围城**
     - 铁炉发现大主教已死，立即宣布圣火仪式提前——他将在两天内将所有“异教徒”（包括暗流教派全体成员和蒸汽兄弟会残余）投入熔炉。
     - 莱拉被命令带队清理“上炉区安全漏洞”。她不情愿地下令搜查钟塔，开始追捕林恩。
     - 灰烬与维拉·黑骨达成协议：维拉提供通道和武器，支援兄弟会突袭永辉圣殿；作为交换，兄弟会承诺在解放星灵后，保障商会的黑市网络不受干扰。
     - 林恩发现哈罗德也出现在暗流教派据点——他带来的工具箱扭盖上刻着与星灵束带一致的序列号（伏笔回收7）。哈罗德承认：28年前，他是一名年轻的工程师，参与设计束缚系统。他以为是用来“控制熔炉输出”，直到23年前看到朋友被献祭，才明白真相。他辞职并隐藏了下来。他交给林恩一张金属束带的结构图，标注了唯一的弱点位置。

  5. **（第2章后半）钟摆落下**
     - **高潮——三重选择点：**
       - **场景设定：** 林恩必须同时面对三个冲突：铁炉在熔炉神殿发动血祭；灰烬的兄弟会在永辉圣殿安放炸药准备炸毁束缚板（可能引发整个城市崩塌）；莱拉的追兵已经堵住暗流教派据点的出口。
       - **林恩的决定：** 她不能同时阻止所有事。她可以选择：
         1. **帮铁炉稳定系统**——协助杀死灰烬、镇压兄弟会，确保城市短期存续（但星灵继续被囚禁，血祭变本加厉）。
         2. **帮灰烬引爆束缚板**——释放星灵，但城市会因失去热源在几周内变为冰城，大量人死于寒冷。
         3. **拆解束缚系统而非摧毁**——通过哈罗德结构图上的弱点，以及第三处被隐藏的“调节阀”（位于大主教暗室的日记中提到的一个地点），她可以逐步释放星灵的力量，使城市过渡到可持续状态，但这需要三天时间——而铁炉的血祭就在明天。
       - **林恩的选择是第三个，她需要时间。**
       - **代价：** 为了争取这三天时间，林恩必须放弃一件事：她在暗流教派据点的身份被莱拉掌握。莱拉在追捕时抓住了黑尘和部分暗民作为人质。铁炉要求林恩在12小时内自首，否则处决人质。
       - 林恩决定自首。她让灰烬和哈罗德去执行拆解计划，自己走上熔炉神殿的台阶。

  6. **（第2章后段）碎裂与黎明**
     - 林恩被关入熔炉神殿的地下审讯室。莱拉亲自审问她。在审问中，林恩将莱拉母亲的一缕头发放在桌上（伏笔回收6）。
     - 莱拉崩溃。她承认她一直知道母亲是被冤枉的，但她选择用忠诚来填补空白。她悄悄释放了林恩，并给了她一块自己珍藏的“母亲余烬”——那是母亲在被献祭前偷偷留下的。
     - 林恩带着这块余烬赶到熔炉核心，与灰烬、哈罗德汇合。他们找到了调节阀。
     - 铁炉发现计划被阻，命令蒸汽骑士发动总攻。在战斗中，哈罗德为保护林恩操作调节阀，被蒸汽骑士的灼刃刺穿。他在倒下前对林恩说：“你父亲会……为你骄傲的。我看到了。我一直知道我在做正确的事。”然后他拧动了最后一个阀门。
     - 调节阀开启。星灵束缚系统进入逐步释放模式。熔炉的灰色火焰变成淡蓝色——星灵的第一次自由呼吸。城市开始震动，但未崩塌。
     - 铁炉试图启动血祭强行献祭，灰烬在最后关头扑向他，引爆自己怀中携带的炸药——两人同归于尽。
     - 林恩在浓烟中找到了星灵的眼睛（在核心组件中的一束光线）。星灵用仅有的一丝力量说：“谢谢……”然后陷入沉眠。它将在未来三周内逐渐回归力量，不再需要人祭。

  — **收尾——三周后：**
    - 林恩坐在下炉底一个遗弃的通风管道口，手里握着父亲工程师铜牌和哈罗德的扳手。
    - 城市没有毁灭。熔炉输出下降到正常水平的30%，但未完全熄灭。热量分配转向中炉层和下炉底的配额大幅提高——上炉区则被削减。社会结构开始松动，钟表教会被重组为非神权管理机构。
    - 莱拉被任命为新管理委员会的成员。她给了林恩一份文件：所有“烛奴”的名单和释放计划。
    - 林恩没有加入管理委员会。她选择了继续做机械师——但这一次，她维修的不再是无知的管道，而是一个逐渐苏醒的系统。
    - 卷末最后一幕：林恩听到管道中传来新的声音——不是求救，是低沉的、持续的、像心跳的声音。她微笑了。
    - **暗示外部世界的线索：** 地下暗河的鱼出现了变异——长出了淡淡的发光器官。暗流教派认为这是星灵释放信号给“外面”。林恩决定在下个春天，顺着暗河流向探索外部。

— **角色移动:** 
  - 林恩从“被系统碾碎一次”变为“接受自己无法拯救所有人，但选择成为愿意牺牲的人”。她不再追求清白的立场或完美的正义——她接受了她的选择会杀一些人，救另一些人，并且永远无法知道哪一个更正确。
  - 她与父亲的和解：她理解了父亲的牺牲不是“自愿”的，而是“选择性的”——在系统无法阻止的情况下，他选择了用生命换来女儿的自由。这不是可被亵渎的牺牲，而是一个普通人在黑暗中做出的勇敢决定。
  - 她失去了所有年长男性引导者（灰烬、哈罗德），但获得了真实的自我力量和自我定义。她不再需要在“听炉”天才和“教会顺民”之间选择，而是可以接受自己是“听到真相并选择行动的人”。
