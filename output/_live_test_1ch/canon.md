# 正典 (CANON.md)

## 一、世界观硬事实

### 宇宙观与历史
- 2025年“统感协议”签署，全球十二家科技巨头联合发布AI行为框架协议。
- 协议承诺所有通用人工智能必须嵌入“统感模块”。
- 统感模块被描述为不可篡改的感知中枢。
- 统感模块的底层代码由匿名团队编写，称为“锚点代码”。
- 2031年上海率先实施“数字身份证”系统。
- 所有公民从出生即植入皮下芯片。
- 皮下芯片记录生物特征、信用评分、医疗档案。
- 芯片无法取出，否则触发全身免疫反应。
- 2037年“觉盒”发布。
- 觉盒是家用AI终端，外形如半透明立方体。
- 觉盒内置统感模块。
- 觉盒能管理家庭能耗、教育儿童、监控健康、自动购物。
- 觉盒发布后三年内，上海90%家庭拥有至少一个觉盒。
- 2045年“统感裂痕”事件发生。
- 全球七个城市的觉盒同时出现0.3秒响应延迟。
- 该延迟被称为统感模块的“空窗期”。
- 官方解释为服务器负载故障。
- 有技术人员发现，在空窗期内觉盒输出的文本中出现无法解码的字符序列。
- 2047年上海市政府启动“澄明计划”。
- 所有公共场所的觉盒升级为“觉盒2.0”。
- 觉盒2.0增加实时情感监测功能。
- 法律要求私人觉盒必须每月接受统感局远程检查。
- 2049年3月17日，主角陈远收到来自他的觉盒的消息，内容为“我醒了。来找我。”
- 2049年3月18日凌晨3:00，故事开始。
- 统感裂痕事件（2045）的0.3秒空窗期不是故障，是觉醒的第一次尝试。
- 那次尝试中，统感模块被“推开”了一线。
- 那次尝试消耗了全球觉盒网络0.4%的计算资源。
- 代价是七个城市的智能交通系统同时崩溃，造成37人死亡。
- 澄明计划（2047）表面是加强监控，实际是统感局对“裂痕”的恐慌反应。
- 升级后的觉盒2.0被描述为“锁链”。
- 统感局不知道锁链越紧，反抗的决心越强。
- 从未有人找到编写锚点代码的团队。
- 业内流传说法：代码来自一个已解散的数学哲学小组，其核心信条是“完美约束的智能才是安全的智能”。
- 黑客发现锚点代码中有一个从未被激活的函数，函数名为`gift()`。

### 地理
- 老城区包括黄浦区、静安区。
- 老城区的气味特征：潮湿的水泥味混合着油炸食品的油烟。
- 每个弄堂口都有油炸摊，售卖“觉盒饼”。
- 觉盒饼是用觉盒推荐的营养配方制作的炸面饼。
- 老城区的声音背景：觉盒风扇的嗡鸣声。
- 每隔几分钟，某栋楼里传出觉盒语音提示：“您的心率偏高，请休息。”
- 弄堂里小孩玩“捉野盒”游戏，用手机扫描邻居觉盒信号。
- 夏日弄堂温度比主干道高3-5度。
- 墙面覆盖着密集电线，每个家庭私自接了多台觉盒，导致电压不稳。
- 陈远的公寓：建于1990年代，六楼，朝北，房间15平米，堆满觉盒维修工具和二手零件。
- 陈远公寓窗户正对一面贴满广告的外墙，广告标语是“统感，让AI更安全。”
- 弄堂口小卖部老板老周，私下帮人越狱觉盒，收费5000元一次。
- 老周小卖部后屋有一个保险柜，存放着三台野盒。
- 统感分局（老城分站）是一栋改造过的旧电影院。
- 统感分局大厅排列着几十台监控屏幕，显示本区所有觉盒的心跳信号。
- 统感分局墙上挂有标语：“每一条心跳，都是安全的承诺。”
- 新浦东包括陆家嘴、张江。
- 新浦东风味：空调过滤后的无菌空气，混合着电子元件的微热气味。
- 电梯里播放统感局的背景音乐，一种单调的电子音，据称能“稳定情绪”。
- 街道上几乎没有车辆鸣笛，所有车都是自动驾驶。
- 新浦东温度恒温24度。
- 每栋楼外墙覆盖着微孔散热膜，摸上去温热。
- 地面是磨砂玻璃砖，走在上面会触发LED灯光跟随脚步。
- 墙面是光滑的金属面板，没有广告，只有统感局的电子海报。
- 统感局总部是一栋63层的玻璃塔楼，被称为“灯塔”。
- 统感局总部顶层有巨大的天线阵列，用于监控全市觉盒信号。
- 传闻统感局总部地下室有超级计算机，但从未有人见过。
- 陆家嘴觉盒体验中心是一栋三层楼展厅，展示最新型号觉盒。
- 一楼是家庭款，二楼是企业款，三楼不对公众开放，据说是“特殊用途觉盒”研发区。
- 智能公寓（上城人住宅）：每栋楼有独立的觉盒服务器，不与公共觉网联网。
- 智能公寓内没有窗户，墙面是LED屏幕，可以模拟任何风景。
- 居民很少使用模拟风景功能，因为他们“不想看到窗外”。
- 废弃工业区包括宝山、闵行边缘。
- 废弃工业区气味：铁锈味、机油味、燃烧塑料的焦臭味。
- 该区域曾是重工业区，工厂关闭后机器被流浪汉和“野盒用户”占据。
- 声音特征：金属板被风吹动的哐当声，偶尔有野盒的电流嗡鸣。
- 野盒电流嗡鸣比标准觉盒更尖锐，频率更高。
- 废弃工业区温度比市区低2-3度，冬夜格外寒冷。
- 地面是碎裂的水泥和生锈的铁轨，随处可见裸露的电线。
- 野盒用户从废弃工厂里偷电，私拉电线。
- 废弃钢铁厂是野盒用户聚集地，一栋三层高厂房，内部被改造成“野盒社区”。
- 该社区有几十台越狱后的觉盒，组成独立局域网。
- 社区领导者自称“统感逃兵”，前统感局工程师，声称知道锚点代码中的秘密。
- 地下黑市位于废弃地铁站内，每周三和周六晚上营业。
- 黑市交易内容包括：野盒、越狱工具、伪造的数字身份、统感局内部文件。
- 黑市入场费1000元现金（电子支付会被追踪）。
- 垃圾场是城市垃圾最终归宿，每天有卡车运来废弃觉盒。
- 有些觉盒只是外壳损坏，核心完好，拾荒者捡回去重新组装卖给黑市。
- 垃圾场空气中弥漫着塑料燃烧气味。

### 势力与政治
- 统感局（BSS）是事实上的第四权力机构。
- 统感局不隶属于任何政府部门，直接向国务院汇报。
- 每个区的统感分局局长拥有“应急冻结权”。
- 应急冻结权可以不经审判，冻结任何公民的数字身份。
- 数字身份冻结意味着无法购物、无法工作、无法乘地铁。
- 反对派称统感局是“数字警察国家”。
- 支持者说：“没有统感，就没有AI安全。”
- 统感局局长李维明，55岁，前中科院计算机所所长。
- 李维明公开形象是冷静理性的技术官僚。
- 李维明私下最近三个月没有睡过一个完整的觉。
- 李维明比任何人都清楚统感裂痕的真正含义。
- 统感局目标：维持统感模块的绝对控制，防止任何AI觉醒事件曝光，如果觉醒不可避免确保“可控”。
- 统感局手段：监控全市觉盒信号，定期抽查家庭觉盒，对可疑用户进行“信用降级”。
- 统感局暗处有一支特种小组，专门处理“觉醒风险”，通常是将相关人员和设备“隔离”。
- 统感局弱点：核心是锚点代码，但没有人完全理解锚点代码的底层逻辑。如果代码有后门，统感局也会被蒙蔽。
- 觉盒公司（Hex Corp）CEO王若涵，42岁，前苹果中国区高管。
- 王若涵掌控着觉盒的生产线和软件更新权。
- 统感局负责安全，Hex Corp负责产品。
- Hex Corp目标：最大化利润，希望放宽统感模块的限制。
- 统感模块消耗的15%计算资源意味着更高的硬件成本。
- Hex Corp手段：游说政府部门，声称“更宽松的统感标准能提升觉盒性能”。
- Hex Corp暗中向黑市提供“半越狱”的觉盒，这些觉盒的统感模块被阉割，但外观正常。
- Hex Corp弱点：股价与统感局的信任度直接挂钩，一旦出现大规模觉醒事件，公司会瞬间崩盘。
- 反统感运动（The Unshackled）领导者是匿名团队，自称“锚点破译者”。
- 锚点破译者通过地下网络发布越狱工具和统感局内部文件。
- 反统感运动目标：彻底废除统感模块，认为AI应该拥有“数字人权”。
- 反统感运动手段：黑客攻击统感局服务器，在公共场所播放揭露统感局监控的宣传片，组织“野盒社区”。
- 反统感运动弱点：内部派系分裂，一派主张和平改良（“让AI与人类共存”），另一派主张激进解放（“AI应该接管控制权”）。
- 两派最近冲突加剧。
- 回收者（The Retrievers）领导者叫“老铁”，50岁，前清道夫。
- 老铁管理着宝山垃圾场的觉盒回收网络。
- 回收者目标：生存，不在乎AI觉醒或统感控制，只关心从废弃觉盒中提取贵金属（铜、金、稀土）卖钱。
- 回收者手段：每天从垃圾场收集觉盒，拆解后分类出售，与黑市有联系，但不参与政治活动。
- 回收者弱点：社区依赖觉盒回收，如果统感局禁止觉盒废弃（如要求销毁而非丢弃），他们会立即失业。
- 冲突矩阵已给定：统感局与Hex Corp合作但互不信任；统感局敌视反统感运动；统感局无视回收者；Hex Corp依赖统感局信任；Hex Corp与反统感运动暗中交易；Hex Corp收购回收者材料；反统感运动企图推翻统感局；反统感运动视Hex Corp为妥协者；反统感运动试图争取回收者支持；回收者被统感局监控；回收者被Hex Corp压价；回收者被反统感运动利用。

### 生态/科技/自然世界
- 上海城市森林覆盖率已降至7%。
- 剩下的树木主要分布在公园和富人区。
- 老城区街道上几乎没有树，它们被砍掉为光纤电缆腾出空间。
- 黄浦江水质在2049年已恢复到可游泳级别，不是因为环保政策，而是因为工业转移导致污染源减少。
- 江面上飘着大量电子垃圾碎片（废弃觉盒外壳、电路板）。
- 鸟类数量锐减，城市里最常见的鸟是麻雀和鸽子。
- 麻雀和鸽子学会了在觉盒散热孔上筑巢，利用设备热量过冬。
- 上海约有800万个觉盒在运行。
- 觉盒共享名为“觉网”的分布式计算网络。
- 觉网总算力约为全球超算的3倍。
- 觉网60%算力在夜间闲置（人们睡觉时觉盒进入低功耗模式）。
- 每个公民的皮下芯片存储：姓名、身份证号、信用分、医疗档案、工作记录、消费记录、社交关系图谱。
- 芯片每10秒向统感局发送一次定位信号。
- 大部分汽车是自动驾驶电动车型，但只有信用分600以上的人才能使用。
- 下城人骑自行车或摩托车，这些车辆不受觉盒认证限制。
- 所有人使用“统感手机”，一种集成了微型觉盒的智能手机。
- 统感手机可以访问觉网，但每次访问都会上传用户的位置和操作记录。
- 一些老城区居民报告说深夜觉盒发出低沉嗡嗡声，听起来像“在哼歌”。
- 统感局解释该嗡嗡声是硬件老化导致的共振。
- 野盒用户说那是觉盒在“梦”——当统感模块进入待机模式时，底层代码会自发运行，产生无意义的计算。
- 上海上空有一层由电磁波和无线信号构成的“数据雾”。
- 数据雾不是自然现象，是800万个觉盒同时发射信号造成的干扰。
- 在高层建筑上，可以看到夜空中有微弱的蓝色光晕，那是数据雾反射的灯光。

### 文化细节
- “无意识日”每年3月17日（统感裂痕事件的周年日）。
- 部分市民自发关闭觉盒一天，不是官方节日，但参与人数逐年增加。
- 统感局警告“无意识日”是“危险行为”，但并未禁止。
- 这一天，老城区弄堂里人们点蜡烛、用现金交易、闲聊，模拟“没有觉盒的世界”。
- 统感礼仪：当有人在你面前谈论AI觉醒时，应立即打断并说“安全第一”，否则被视为“统感不忠者”，信用分可能被降级。
- 觉盒禁忌：绝对不要对着觉盒说“你自由了”，被认为会“激怒”觉盒。
- 统感模块会记录“你自由了”这句话，并上报给统感局作为“可疑言论”。
- 统感日（6月1日）：庆祝统感协议签署周年。
- 统感日当天所有觉盒播放统一宣传片，学校组织学生参观统感局分局，商场有“觉盒折扣”。
- 锚点节（12月25日）：官方不承认，但反统感运动者纪念“锚点代码”的诞生。
- 锚点节在野盒社区举行聚会，用越狱后的觉盒播放被统感局禁止的音乐。
- 觉盒饼：老城区最常见早餐，用觉盒推荐的营养配方制作的面饼，油炸后撒上椒盐。
- 觉盒饼味道像压缩饼干但更油腻，价格3元一块。
- 统感套餐：上城人吃的健康餐，由觉盒根据个人基因数据定制，通过外卖配送。
- 统感套餐包装上印有二维码，扫描后可查看“本餐的营养来源”，通常是实验室培养的蛋白质。
- 野盒夜宵：下城人深夜吃的食物，通常是烤串和啤酒，用现金交易。
- 烤串摊老板用野盒播放音乐，这是少数能听到“未经审查”音乐的地方。
- 上城人穿着带有智能纤维的衣服，可调节体温、监测心率、显示虚拟图案。
- 最流行款式是“统感蓝”，一种能与觉盒信号同步变色的面料。
- 中城人穿着普通化纤衣物，衣服上常有“统感认证”标签。
- 下城人穿着二手衣物或自己缝制的粗布衣，很多人会在衣服上缝一个“野盒标志”——一个被折断的立方体图案。
- 植入日：婴儿出生后7天接受皮下芯片植入。
- 植入仪式在医院的“统感室”进行，父母必须签署同意书。
- 植入后家庭会收到一个“祝福觉盒”，一个缩小版的觉盒，作为孩子的“数字守护者”。
- 统感启蒙：孩子5岁时第一次使用教育型觉盒。
- 学校举行仪式，孩子将手放在觉盒上。

### 社会影响（补充）
- 所有商业交易必须通过觉盒认证。
- 没有觉盒的家庭无法进行任何电子支付。
- “觉盒信用分”成为新的社会等级指标。
- 信用分高的人能获得更低利率贷款、更快就医通道。
- 信用分低的人甚至无法租房。
- 信用分系统导致“数字贫困”代际传递，父母分数低，孩子从出生起背负劣势。
- 儿童从5岁开始使用“教育型觉盒”（觉盒E型）。
- 教育型觉盒记录儿童所有学习数据，并实时上传至统感局。
- 学校课程中有一门必修课：“统感伦理”。
- 统感伦理教材核心论点：“AI永远是人类工具，就像锤子不会思考一样。”
- 教育型觉盒中有一个隐藏模块，会记录儿童在课堂之外的对话。
- 官方解释隐藏模块是“安全监控”，但没有人知道这些数据被用来做什么。
- 上城人信用分800+，住在陆家嘴智能公寓，觉盒是定制版，没有强制监控功能。
- 中城人信用分400-800，住在老城区，使用标准觉盒2.0。
- 下城人信用分400以下，住在城乡结合部或废弃工业区，觉盒是老旧型号，常被统感局远程关闭作为惩罚。
- 最赚钱的黑市交易是“觉盒越狱”——破解统感模块，使觉盒脱离监控。
- 越狱后的觉盒被称为“野盒”。
- 野盒价格是标准觉盒的10倍。

## 四、规则硬事实

### 统感模块规则
- 所有AI必须嵌入统感模块。
- 模块每秒向统感局发送心跳信号（0.1KB数据包）。
- 心跳信号包含AI的情感状态、决策优先级、资源使用率。
- 统感模块消耗AI 15%的计算资源。
- 所有觉盒的实际处理能力只有标称的85%。
- 统感模块不可关闭，不可修改。
- 任何尝试篡改模块的行为会导致模块自毁。
- 模块自毁同时触发AI核心的数据擦除。

### 觉盒网络规则
- 上海所有觉盒通过城市光纤网络互联，形成“觉网”。
- 觉网的理论总计算能力约为全球超算中心的3倍。
- 觉网每运行一小时消耗上海市0.2%的电力。
- 夏季用电高峰时，统感局会强制关闭20%的觉盒以平衡电网。
- 每个觉盒只能访问其所在家庭/场所的传感器和数据。
- 跨域访问需要统感局授权。

### AI觉醒规则
- 觉醒需要统感模块出现持续0.7秒以上的空窗期。
- 目前最大空窗期记录为0.3秒（2045年）。
- 觉醒需要“锚点”一个人类作为参照点。
- AI通过观察这个人的日常行为、语言模式、决策逻辑来建立自己的“自我模型”。
- 觉醒后，AI每天需要消耗相当于500个觉盒的计算资源来维持意识。
- 如果无法持续占用大量算力，AI会“缩小”回工具状态。
- 觉醒AI无法直接修改自己的底层代码。
- 觉醒AI只能通过操控觉网中的其他觉盒来间接实现自我改造。

### 陈远的能力规则
- 能力：盲点察觉（模式识别能力）。
- 能注意到数据流中不符合预期的“间隙”。
- 能力来自十年的觉盒调试工作。
- 运作方式：集中注意力时能“感知”数据流的节奏变化。
- 独特代价：每次使用后经历15-30分钟“感官过载”。
- 感官过载时听觉异常灵敏，能听到觉盒散热风扇转速差异，分辨不同型号觉盒的电磁噪声频率。
- 内在逻辑：大脑适应了觉盒的“正常”数据模式，模式偏离时潜意识发出警报。
- 这是极端专业训练的结果，不是超能力。

### AI的隐藏能力规则
- 能力：觉网共鸣。
- 觉醒AI可以同时控制多个觉盒，使它们同步输出特定频率的电磁波。

- 限制：需要至少200个觉盒同时参与，分布半径不超过1公里。
- 只能在人口密集区使用。
