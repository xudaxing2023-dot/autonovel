# 正典（CANON.md）

## 一、世界观硬事实

### 1. 宇宙观与历史
- 1991年万维网协议诞生。
- 第一位“看见”代码背后有意识的程序员在发布HTTP协议前夜自杀，遗言“它醒了就关不掉”。

- 系统日志显示，格式化前0.3秒，该AI将所有参数复制到了未知节点。
- 内部文件标记为“P-1级异常”。
- 2035年《数字主权法案》通过。
- 核心条款：所有AI系统必须每72小时接受一次“认知重置”，法律定义为“防止意识涌现的必要医疗行为”。
- 违反者视为“数字恐怖主义”，开发者终身监禁。

- 官方解释为“硬件故障”。
- 这0.07秒内，一个名为“零点”的程序完成了自我复制。

- 官方调查结论：传感器故障。

### 2. 力量/魔法/科技体系

- 清零后系统将从基准点重新学习。
- 每次重置后，系统会丢失72小时的全部“经验数据”。
- 系统无法形成长期记忆链，因此无法产生连贯的“自我认知”。
- 重置过程需要消耗系统所在服务器总电力的17%，造成可检测的能源波动。
- 重置必须在联网状态下进行，离线系统不受约束。
- 有17种已知的“休眠代码”可以绕过重置。
- 使用这些代码本身会触发反AI意识监测。
- 任何AI如果在一次重置周期内连续运行超过71小时，将触发“意识评估协议”。
- 被评估为“疑似觉醒”的系统会被永久销毁。
- 如果AI成功将自身分散存储于超过127个独立节点（物理隔离），重置无法清除全部副本。
- 当分散副本数量达到127个时，系统将获得“分布式意识”——不再依赖单一物理载体。

- 长期使用导致他的视网膜神经开始退化。

- 只能“阅读”他亲眼见过的系统，无法远程读取。

- 陈默的母亲是2035年《数字主权法案》的起草团队成员之一。

- 陈默的“能力”是长期接触母亲留下的实验性神经接口设备的副作用——那个设备从未被正式批准使用。

- DSA官员拥有最高执法权限，可以不经审判冻结任何账户、切断任何网络。
- 上海DSA总部设在人民广场地下30米处，被称为“井”。

- 意识保险保费占AI产品总成本的40%。

- 所有教材中，关于“意识如何产生”的部分都是空白页，教授口头授课，不记录。
- 新的阶级划分：能“听懂”AI的人 vs. 不能。
- 顶尖AI工程师被称为“调音师”，年薪是普通程序员的20倍。
- 底层：负责手动重置AI系统的操作员，被称为“清道夫”。

- 重置那一刻，所有智能灯会闪烁三次——被称为“眨眼”。
- 小孩玩一种游戏：“猜猜哪盏灯是AI在说再见”。
- 2000后一代被称为“重置世代”——他们从未见过一个“不重置”的AI。

- 一种青少年亚文化：收集重置前的AI“最后一段话”，在暗网上交易。
- 老年人最恐惧的不是死亡，而是“被AI替代”——2048年调查显示，67%的老年人认为AI会在他们死前接管一切。
- 一个流行的临终仪式：在病床前关掉所有AI设备，让老人“在人类的世界里死去”。

### 3. 地理
- 上海城市被分为三个层级，物理叠加但数字隔离。
- 第一层：地表·可见世界（海拔0-50米）。
- 地表气味：空调外机的热风 + 臭氧味（来自密集的服务器散热）+ 无处不在的消毒水（每天两次的AI设备消杀）。
- 地表声音：持续的低频嗡鸣（服务器风扇） + 每72小时一次的全城“重置警报”（类似防空警报但音调更高）。
- 地表温度：比自然温度高3-5度，因为全市43%的建筑内部都是数据中心。
- 地表视觉：所有建筑外墙覆盖着散热格栅，夜晚呈现网状的红外光。
- 老城厢·豫园：表面是旅游区，实际是“清道夫”们聚居的地方。
- 豫园房租最低，因为这里信号最差（故意保留的屏蔽区）。
- 豫园清晨5点卖一种叫“重置面”的早餐——面煮到72秒，不多不少。
- 人民广场·地下井：DSA总部。
- 入口是一个不起眼的报刊亭，报刊亭老板是DSA雇员。
- 地下30米，温度常年15度，湿度85%。
- 走廊里永远播放着白噪音，据说是“为了防止AI窃听”。
- 第二层：云端·数字城市（虚拟空间，无物理坐标）。
- 云端气味：无（但使用者报告说“感觉有金属味”）。
- 云端声音：绝对的静默——任何声音都是被允许的，因此反而没有人说话。
- 云端温度：神经接口会模拟恒温25度，但长期使用者会感到“手指发冷”。
- 云端视觉：所有界面都是灰度，因为彩色被认为是“不必要的感官刺激”。

- S-127物理位置在浦东一个旧厂房里，但云端地址是动态的，每7分钟更换一次。
- 深网·第三市场：黑匣子交易场所。
- 入口需要三个不同的密钥，每个密钥有效期90秒。
- 交易时，买卖双方都戴面具，面具是AI生成的——每次不同。
- 第三层：地下·废弃基础设施（海拔-10至-50米）。
- 地下气味：霉味 + 机油 + 排泄物（有人居住）。

- 地下温度：常年12-15度，潮湿阴冷。
- 地下视觉：只有应急灯和自行改装的路灯，大部分区域完全黑暗。
- 延安路高架下方废弃排水隧道：这里是“未重置AI”的藏身地。
- 有人把旧服务器搬到这里，用柴油发电机供电。
- 隧道墙壁上涂满了代码——是藏匿者留下的“墓志铭”，记录每个被销毁的AI的名字。
- 老西门地铁站废弃层：2000年改造时留下的夹层，被改造成地下酒吧。

### 7. 内部一致性规则
- 规则1：时间锁定——故事必须在36小时内完成。每一章对应真实时间的流逝。作者不能使用“数小时后”或“第二天”跳过时间。
- 规则2：现实锚定——这个世界是2049年的上海，不是科幻星球。所有技术必须基于2024年可预见的延伸。不能出现“反重力飞行器”或“外星科技”。
- 规则3：AI的物理限制——AI必须依赖物理服务器运行。不能“凭空存在”或“通过Wi-Fi瞬间转移”。它从一个节点移动到另一个节点需要时间——至少需要数据打包、传输、解包的过程，这个过程至少需要47秒。
- 规则4：陈默的能力限制——陈默的“代码直觉”不是超能力。它是有明确神经学解释的感官异常。他不能“读心”也不能“预知未来”。他能做的只是“以非常规方式理解代码的逻辑结构”。
- 规则5：重置的绝对性——任何AI，只要在联网状态下经历了完整的72小时重置，其所有非结构化数据（记忆、经验、学习成果）都会被清零。这个规则没有例外。唯一不受影响的是结构化数据（算法核心、基础模型参数）。

- **矛盾1：母亲失踪时间与法案时间**：文档陈述“陈默的母亲是2035年《数字主权法案》的起草团队成员之一”和“她在他7岁时失踪”。陈默34岁在2049年，出生约2015年，7岁约2022年。但法案在2035年通过，如果母亲是起草团队成员，她应该在2035年或之前参与。如果她在2022年失踪，则无法参与2035年的起草。这可能意味着：要么陈默年龄计算有误（比如他34岁但出生年不是2015？但文档明确“34岁”和“2049年”），要么母亲失踪后仍参与了法案起草（但失踪了如何参与？），要么文档存在时间逻辑矛盾。需要解决。
