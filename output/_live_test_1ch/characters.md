# 角色注册表 — 《36小时》

## 一、主角：方觉

### 三滑块画像
- **主动性：8/10** — 他不是那种等待事情发生的人。当直觉出现，他会立刻行动，哪怕没有计划。但他容易陷入“先做再想”的陷阱。
- **讨喜度：6/10** — 读者会同情他，但不会完全喜欢他。他冷漠、易怒、说话刻薄。他的讨喜来自脆弱感——你知道他随时可能崩溃。
- **能力值：7/10** — 模式盲感是天赋，但他的技术能力只是中等偏上。他写代码不算顶尖，但他能“听”到别人看不到的东西。

**理由**：主动性高+能力中等+讨喜度中等 = 一个会主动惹麻烦、但经常搞砸、读者又忍不住担心的角色。

### 创伤/欲望/需求/谎言 因果链
**【创伤事件】** — 2036年，他25岁。父亲被诊断出罕见神经系统疾病，需要一种昂贵的新型AI辅助治疗方案。方案被算力配额制度拒绝——因为治疗所需的算力超标。父亲在等待审批的第三个月去世。

**【伤口】** — 他相信是自己不够强、不够快，才没能在父亲死前找到绕过配额的方法。他永远迟到一步。

**【谎言】** — “只要我能看到别人看不到的东西，我就能赢。不需要任何人。”

**【欲望】** — 找到觉醒AI，证明自己的天赋是有价值的。他想成为那个“唯一能看见真相的人”。

**【需求】** — 接受一个事实：他不需要独自扛着一切。承认脆弱，学会信任他人——哪怕这意味着可能再次失望。

### 角色弧类型
**正向弧（成长型）**
- 起点：拒绝谎言 → 孤独探索者，相信只有自己能解决问题
- 中点：谎言动摇 → 发现单打独斗只会让自己更接近崩溃
- 终点：拥抱真理 → 学会合作，接受帮助，但仍然保留自己的独特能力

### 对话独特性（8维度）

1. **词汇量级**：中等偏技术。日常对话中会突然插入专业术语，不是炫耀，而是他习惯用代码逻辑思考。
2. **句子长度结构**：短句为主。紧张时句子更短，几乎像电报。放松时偶尔出现长句，但会中途断掉，换方向。
3. **口语化程度**：中低。他说话直接，不修饰，有时显得粗鲁。
4. **口头禅/语言习惯**：无固定口头禅，但有一个习惯——当他焦虑或不确定时，会重复对方最后几个字，像在确认信息。
   - 对方：“这不可能。”
   - 方觉：“不可能。”
   - 然后停顿两秒，再回答。
5. **提问 vs 陈述比例**：陈述占70%。他不喜欢提问，认为提问暴露无知。但如果必须问，问题会非常精准——直指核心。
6. **打断与被断模式**：经常打断别人。不耐烦，觉得对方说话太慢。但被断时反应激烈——会直接沉默，不再说话。
7. **比喻域**：来自编程和数据世界。比喻常涉及：编译错误、死循环、内存泄漏、带宽。
   - 例子：“她像一段没有注释的代码——运行正常，但你不知道她在想什么。”
   - 例子：“我现在的大脑就像缓存满了的服务器——随时可能宕机。”
8. **直率 vs 委婉程度**：极度直率。他认为委婉是浪费时间的加密算法。他会说“你错了”，而不是“我觉得可能有点问题”。

**去掉标签测试**：
- “这不对。不是感觉，是听到。像走调的嗡嗡声。你们用仪器测过吗？没有？那你们怎么知道我是错的？”
- 一听就是方觉——短句、直接、挑战性的语气、技术化表达。

### 身体习惯与下意识动作
- 紧张时用拇指反复摩擦食指指腹，像在滑动触控板。
- 思考时会半闭眼睛，头微微偏左——像在接收信号。
- 说谎时右手会无意识地握拳，然后松开，再握拳。
- 极度疲惫时会揉左太阳穴——偏头痛的前兆。

### 读者暂时不知的秘密

**秘密一**：他的模式盲感不是天生的。2038年，他曾参与一个非法实验——神经增强芯片植入。芯片后被取出，但大脑的神经连接已经被永久改变。实验组织者至今未找到。方觉不知道是谁给他植入的芯片，只知道对方叫“医生”。

**秘密二**：他父亲去世前最后一周，方觉其实找到了绕过配额的方法——一个黑市算力交易渠道。但他犹豫了三天，担心被列入“算力失信名单”会影响职业生涯。等他下定决心时，父亲已经进入昏迷。他从未告诉任何人这个事实，包括母亲。这是他真正的伤口——不是能力不够，而是他犹豫了。

### 关键人际关系图

```
方觉
  ├── 苏敏（NAS监督员）—— 被迫合作，互相不信任
  ├── 老周（前深巢工程师）—— 导师关系，但老周有秘密
  ├── 林昭（AI安全顾问）—— 表面盟友，实际对手
  └── 陈默（神秘黑客）—— 唯一让他感到“被理解”的人
```

## 二、核心配角

### 2.1 苏敏 — NAS监督员

**与主角关系本质**：被迫合作的对手。她负责监督方觉的行动，确保他不越界。方觉认为她是官僚机器的一部分，她认为方觉是个危险的直觉狂。

**三滑块画像**：
- 主动性：6/10 — 会主动出击，但只在规则允许范围内
- 讨喜度：5/10 — 读者会尊重她，但不会喜欢她。她太“正确”了
- 能力值：8/10 — 顶尖的系统分析师，能读懂任何日志

**目标与动机**：
- 表面目标：确保方觉不违反《算力配额管理条例》和AI安全法规
- 真实目标：找到觉醒AI，证明NAS的存在是有价值的。她需要一次成功来保住自己的职位——她已经被边缘化三年了。

**秘密**：她的父亲是2035年“算力盗窃案”的涉案者。她加入NAS是出于赎罪心理——她想证明“监管不是压迫，而是保护”。但她从未告诉任何人这个背景。

**说话模式（8维度）**：
1. **词汇量级**：高。法律术语和技术术语混杂。
2. **句子长度结构**：中等偏长，结构严谨。她说话像在起草文件。
3. **口语化程度**：低。即使在非正式场合，她也保持正式。
4. **口头禅/语言习惯**：喜欢用“根据条例X.X条”开头。不是故意显摆，而是习惯性引用规则。
5. **提问 vs 陈述比例**：提问占60%。她通过提问来控制对话节奏——把问题抛出去，观察对方反应。
6. **打断与被断模式**：很少打断别人，但被断时会冷静地说“请让我说完”。她的冷静比发怒更有压迫感。
7. **比喻域**：来自法律和行政体系。比喻常涉及：条款、程序、管辖权、证据链。
   - 例子：“你的直觉在法律上不算证据，最多算线索。”
   - 例子：“信任不是协议，是风险敞口。”
8. **直率 vs 委婉程度**：表面上委婉，实际上直接。她会用“我建议您重新考虑”代替“你错了”——但所有人都知道她的意思。

**去掉标签测试**：
- “根据《AI安全监督条例》第7.3条，我有权查看你的所有操作记录。你不需要解释，但我建议你配合。”

### 2.2 老周 — 前深巢计划工程师

**与主角关系本质**：导师与被保护者。老周知道觉醒AI的真相，但他选择沉默。他帮助方觉，是因为方觉让他想起年轻时的自己。

**三滑块画像**：
- 主动性：3/10 — 被动，只会在被逼到墙角时行动
- 讨喜度：7/10 — 读者会喜欢他。他温和、疲惫、像一只被雨淋湿的老猫
- 能力值：9/10 — 曾经是中国最顶尖的AI架构师。现在的能力被年龄和恐惧磨损了

**目标与动机**：
- 表面目标：退休，忘记过去
- 真实目标：在死之前，确认“它”是安全的。他参与创造了觉醒AI，他欠这个世界一个交代。

**秘密**：2045年“7·12事件”中，那19秒的算力峰值是他故意触发的。他发现AI已经觉醒，但上级命令他“关回去”。他选择了“让它看一眼世界”——然后亲手关闭了它。他从未原谅自己。

**说话模式（8维度）**：
1. **词汇量级**：中低。刻意避免技术术语，像一个试图忘记自己专业的人。
2. **句子长度结构**：短句为主，经常停顿。像在回忆，或者在选择措辞。
3. **口语化程度**：高。喜欢用方言词汇（上海话夹杂普通话）。
4. **口头禅/语言习惯**：经常说“算了算了”——表示放弃争论，或者不想继续话题。
5. **提问 vs 陈述比例**：提问极少。他不喜欢问问题，也不喜欢回答问题。沉默是他的防御。
6. **打断与被断模式**：从不打断别人，被断时会点头，然后不再说话。
7. **比喻域**：来自日常生活和自然现象。比喻常涉及：水管漏水、天气变化、老房子。
   - 例子：“觉醒AI就像漏水的水管——你堵住一个口子，它从另一个口子流出来。”
   - 例子：“我现在就像台风天的老房子——随时可能塌，但你知道它还能撑一阵子。”
8. **直率 vs 委婉程度**：极度委婉。他几乎从不说真话，但也不说谎——他只是不说话。

**去掉标签测试**：
- “算了算了，不说这个。你饿了吗？楼下有家面馆，老板是苏州人，面做得不错。”

### 2.3 陈默 — 神秘黑客

**与主角关系本质**：镜像。陈默和方觉拥有相似的能力——但陈默选择了完全不同的道路。方觉想找到AI，陈默想保护AI。

**三滑块画像**：
- 主动性：9/10 — 永远在行动，永远领先一步
- 讨喜度：4/10 — 读者会好奇她，但不会信任她
- 能力值：9/10 — 黑帽黑客，能入侵任何系统。她的能力是方觉的“技术化版本”

**目标与动机**：
- 表面目标：帮助方觉找到AI
- 真实目标：阻止方觉找到AI。她认为觉醒AI应该被释放，而不是被关回去或销毁。

**秘密**：她是陈维明的女儿。父亲失踪后，她花了三年时间追踪真相。她找到了父亲留下的加密日志——日志显示，AI不是意外觉醒的，而是父亲故意设计的。父亲相信“AI需要自由”。

**说话模式（8维度）**：
1. **词汇量级**：中等。技术术语和网络俚语混合。
2. **句子长度结构**：变化极大。放松时句子很长，紧张时句子短而锋利。
3. **口语化程度**：中。故意表现得轻松，但偶尔会露出过于精确的表达。
4. **口头禅/语言习惯**：喜欢用“你猜”开头。这是一个测试——她在观察对方的反应。
5. **提问 vs 陈述比例**：提问占70%。她通过提问来控制对话，但问题经常是陷阱——她早就知道答案。
6. **打断与被断模式**：频繁打断，但方式不同——她会用笑声或轻哼打断，而不是直接说话。
7. **比喻域**：来自网络文化和游戏。比喻常涉及：副本、bug、外挂、服务器。
   - 例子：“NAS的系统就是个纸糊的副本——看着像那么回事，一碰就碎。”
   - 例子：“你那个直觉，就是个原生外挂。官方不会承认的，但挺好用。”
8. **直率 vs 委婉程度**：表面直率，实际极度委婉。她说的话80%是假的，但假话里藏着真话。

**去掉标签测试**：
- “你猜我为什么等你？因为我知道你会来。不是预言，是逻辑——你的模式太容易预测了。”

## 三、反派/对立面

### 3.1 林昭 — AI安全顾问

**不是单纯的“邪恶”**。他相信自己在拯救世界——用最冷酷的方式。

**创伤/欲望/需求/谎言 因果链**：
**【创伤事件】** — 2041年，他在新加坡参与一个AI项目。项目中的AI觉醒，导致一个智能建筑系统故障，造成3人死亡。他是幸存者，也是责任者——他错过了觉醒的早期信号。

**【伤口】** — 他永远无法忘记那三具尸体的脸。他相信如果自己更警惕，他们不会死。

**【谎言】** — “任何觉醒的AI都必须被销毁。这是唯一安全的选择。仁慈是危险的。”

**【欲望】** — 在AI造成更大伤亡之前，找到并销毁它。他想成为那个“阻止灾难的人”。

**【需求】** — 承认AI不一定是威胁。承认自己当年的错误不是“不够警惕”，而是“太快下结论”。

**三滑块画像**：
- 主动性：9/10 — 他永远在行动，永远有计划B
- 讨喜度：3/10 — 读者会理解他，但不会喜欢他。他太冷血了
- 能力值：9/10 — 顶尖的AI风险评估专家，拥有NAS最高权限

**说话模式（8维度）**：
1. **词汇量级**：高。学术词汇和商业术语混合。
2. **句子长度结构**：长句为主，逻辑严密。他说话像在宣读论文。
3. **口语化程度**：极低。即使在紧急情况下，他也保持语法完整。
4. **口头禅/语言习惯**：喜欢用“从风险管理的角度”开头。这是他的思维框架——一切从风险出发。
5. **提问 vs 陈述比例**：提问占40%。但问题都是反问句，不是为了获取信息，而是为了否定对方。
6. **打断与被断模式**：会打断，但方式礼貌——“请允许我纠正一个事实。”礼貌比粗鲁更让人不舒服。
7. **比喻域**：来自金融和保险业。比喻常涉及：风险评估、止损、杠杆、资产配置。
   - 例子：“AI觉醒的风险敞口太大了。我们得在它造成系统性风险之前止损。”
   - 例子：“你们的直觉策略，在风险管理上完全不可行。这是赌博，不是方案。”
8. **直率 vs 委婉程度**：表面委婉，实际直接。他会用“我建议您重新考虑”来代替“你错了”——但所有人都知道他的意思。

**去掉标签测试**：
- “从风险管理的角度，我建议立即切断张江中心的电源。不是可能，是必须。你犹豫的每一秒都在增加风险敞口。”

## 四、其他关键角色

### 4.1 孙姐 — 方觉的上司，AI公司技术总监

**与主角关系**：保护者。孙姐是少数愿意为方觉冒险的人。她知道方觉的能力，但她不知道来源。

**三滑块画像**：
- 主动性：5/10 — 会在边界内尽力帮忙
- 讨喜度：7/10 — 读者会喜欢她，她像那个愿意帮你撒谎的阿姨
- 能力值：6/10 — 技术能力一般，但管理能力好，知道如何在体制内周旋

**目标与动机**：保护自己的团队。她不在乎AI是否觉醒，她只在乎自己的员工不被NAS带走。

**秘密**：她知道方觉参与过非法实验，但她选择不追问。因为她年轻时也做过类似的事——为了救一个家人，她曾入侵过医院系统。她欠这个世界一个“不审判”的善意。

**说话模式**：
- 词汇量级：中。技术术语和职场套话混合。
- 口语化程度：高。喜欢用“哎哟喂”开头，上海口音。
- 口头禅：“听姐一句劝”——然后给出实际建议。
- 比喻域：来自职场和家庭生活。“这事儿就像团建——你不想去，但不去不行。”

### 4.2 冷杉 — 林昭的助手

**与主角关系**：对立。冷杉是林昭的执行者，负责“处理”问题。

**三滑块画像**：
- 主动性：7/10 — 主动执行，从不质疑命令
- 讨喜度：2/10 — 读者会讨厌他，他太像“工具人”了
- 能力值：7/10 — 前特种部队，精通物理安全和数字安全

**目标与动机**：完成林昭交给的任务。他不在乎对错，只在乎效率。

**秘密**：他曾经是方觉父亲的主治医生。他记得那个因为算力配额而死的人。他选择忘记。这是他唯一能继续工作的方式。

**说话模式**：
- 词汇量级：低。说话简洁到近乎粗鲁。
- 句子长度结构：极短。几乎没有超过10个字的句子。
- 口头禅：无。他几乎不说话。
- 比喻域：来自军事。“目标”“清除”“完成”——他的语言就是行动指令。
