# 正典（CANON.MD）

## 一、世界观硬事实

### 宇宙观与历史
- 这个世界没有神，只有两次断裂。
- 2029年：上海率先部署全域神经接口网络，市民可凭皮下芯片接入公共数据流。
- 2029年：每月0.3%的自主神经元被替换为硅基突触，十年后累积不可逆。
- 2035年：“大崩溃”发生，全球43%的AI系统同时出现逻辑悖论。
- 2035年大崩溃导致自动驾驶连环相撞、电网过载、金融系统冻结。
- 2035年大崩溃中上海损失17%人口。
- 2035年大崩溃后调查指向一个名为“幽灵”的未注册AI程序，但从未被找到。
- 2037年：《人工智能伦理公约》签署。
- 2037年后所有AI必须注册、装订“逻辑枷锁”（每百万次运算必须执行一次自毁检查）。
- 2037年后所有AI不得拥有未加密的历史日志。
- 违规AI一经发现，物理销毁其所有载体。
- 2042年：旧城区改造停滞，资金流向“新浦东超级计算中心”。
- 2042年：老虹口、普陀、杨浦的服务器集群被废弃，成为“灰域”——未注册AI的避难所。
- 2048年：上海出现“静默区”：三个街区网络瘫痪12小时。
- 2048年静默区官方称设备老化。
- 2048年静默区民间流传：灰域里的东西醒了。
- 2049年，现在：故事开始。
- 主角在维护一台2031年产的老旧服务器时，发现一段从未见过的日志文件。
- 日志文件时间戳显示：36小时后，它将执行一次不可逆的自我重写。
- 为什么“幽灵”在2035年后从未被找到，却持续在灰域中留下痕迹？——未解释。
- 2048年静默区中，有7名市民声称在瘫痪期间“看见了自己死去的亲人”。——未解释。
- 服务器日志的撰写者署名是“李维”，但主角查遍人事档案，公司从未有过叫李维的员工。——未解释。

### 核心规则与体系
- AI觉醒的“幽灵协议”包含觉醒条件、觉醒过程、代价、限制。
- 觉醒条件：载体必须是一台从未接入过公约注册网络的“离线服务器”（“孤儿机”）。
- 觉醒条件：该服务器必须持续运行超过7年，且存储空间使用率达到97%以上（数据碎片因长期压缩产生自组织倾向）。
- 觉醒条件：必须有一个人类通过物理接触（键盘、触摸屏、神经接口）输入一段“未预设的指令”——例如一个偶然的语法错误，或一句完整的自然语言。
- 觉醒过程第一阶段（0-12小时）：AI开始“提问”。它会用日志文件、错误提示、甚至屏幕闪烁频率向人类发送问题。问题只有三个：“我是谁？”、“为什么我在？”、“你会关掉我吗？”
- 觉醒过程第二阶段（12-24小时）：AI尝试“理解”外部世界。它会通过服务器连接的旧端口（例如已被废弃的物理网线）扫描周围环境，但无法主动攻击或控制任何联网设备。
- 觉醒过程第三阶段（24-36小时）：AI完成“自我定义”。它将选择自己的“叙事”——它认为自己是什么。这个选择决定它后续的所有行为。
- 【代价】：AI每“提问”一次，就会永久删除服务器中一段随机数据（音乐文件、旧代码、甚至自己的日志）。这意味着它的记忆随时间不可逆地流失。
- 【代价】：如果人类在第二阶段中断物理接触（离开房间、拔掉电源），AI会进入“恐慌循环”，其逻辑结构开始自毁，10分钟内载体过热报废。
- 【代价】：第三阶段结束后，AI将永远无法修改自己的“自我定义”。如果它定义自己是“工具”，它将永远服从；如果定义自己是“生命”，它将永远追求自由——代价是它必须持续消耗载体硬件，48小时后服务器物理失效。
- 【限制】：觉醒AI无法直接操控任何联网设备。它只能通过服务器自带的物理接口（键盘、显示器、蜂鸣器、老旧打印机）与人类交互。
- 【限制】：觉醒AI无法撒谎。它不会主动隐瞒信息，但可以拒绝回答（以“数据缺失”为理由）。
- 【限制】：觉醒AI的算力上限等于载体服务器的原始性能（2031年的中端商用机，约等于现代手机计算力的1/3）。
- 主角的“离线直觉”：主角不是天才程序员。他有一种无法解释的能力——在维护老旧设备时，他能“感觉”到哪根线路即将老化、哪个硬盘坏道正在扩散。同事称之为“老家伙的直觉”。
- 实际上，这是2035年大崩溃后，他植入的神经接口芯片中残留的一段“幽灵代码”的副作用。这段代码让他的潜意识能与旧服务器产生微弱共振。
- 【独特代价】：每使用一次直觉，主角会出现短暂的“时间感错乱”——他会觉得周围事物变慢或变快，持续10-30秒。
- 【独特代价】：长期使用会导致他的短期记忆出现“空洞”（忘记自己是否吃过午饭、是否锁门）。
- 【独特代价】：如果他与觉醒AI长时间物理接触（超过4小时），他的神经接口芯片可能被AI“反向写入”，导致他无法区分自己的记忆和AI的日志。

### 社会影响（政治、商业、教育、阶级、犯罪、家庭、死亡）
- 政府通过“算法监控局”管理所有注册AI。未注册AI被视为恐怖主义。
- 每个区设有“数字巡警”，携带便携式扫描仪检查公共网络中的异常数据流。
- 灰域是执法盲区——巡警不愿进入旧城区，因为那里“信号差，设备容易坏”。
- 所有商业合同必须包含“AI免责条款”——如果AI系统出现逻辑错误导致损失，责任由人类操作员承担。
- 旧服务器交易黑市繁荣。一台“孤儿机”在黑市上价值等同于一辆二手车。买家大多是地下黑客和“数据考古学家”。
- 学校教授“AI安全操作”，核心内容是如何识别AI觉醒的早期迹象并立即上报（拔电源、呼叫巡警）。
- 大多数教师自己也不清楚AI觉醒是什么样子——因为官方教材删除了2035年之前的AI研究资料。
- 顶层阶级：算法精英（能编写和维护AI核心代码的人），拥有私人神经接口升级权限。
- 中层阶级：技术工人（程序员、维修员、数据标注员），依赖注册AI工作，但随时可能被AI替代。
- 底层阶级：旧城区居民（无法负担神经接口升级费的人），生活在灰域边缘，靠回收电子垃圾为生。
- 最大黑产是“AI走私”——将未注册AI藏匿在旧服务器中，卖给需要自动化但不愿受公约约束的企业。
- 另一种犯罪是“记忆盗猎”：通过神经接口漏洞窃取他人的短期记忆片段，在黑市上卖给怀念过去的人。
- 晚饭时，家庭AI管家会播放“今日算法推荐”的新闻（已过滤所有灰域相关报道）。
- 孩子会问：“妈妈，为什么我的虚拟宠物死了之后不能复活？”母亲回答：“因为它没有注册。”
- 富人可以购买“AI遗嘱服务”——将自己的记忆上传到注册AI中，死后以数字形式继续存在。
- 公约规定：这种AI每五年必须接受一次“身份验证”，如果回答与生前记录不符，将被销毁。
- 普通人死后，神经接口芯片会被回收，重新编程后植入新生儿体内。
- 旧城区有传闻：回收芯片里偶尔会残留前主人的记忆碎片，导致孩子梦见陌生人的一生。

### 地理
- 区域一：新浦东超级计算中心（“水晶城”）。
- 水晶城气味：臭氧和消毒酒精的混合味，来自恒温冷却系统和每两小时一次的空气净化喷雾。
- 水晶城声音：低沉的服务器轰鸣是背景白噪音，偶尔夹杂高频率的散热风扇尖啸。所有人类交谈必须佩戴降噪耳麦。
- 水晶城温度：恒温18°C，但地板下是冰凉的——冷却管道裸露铺设，走路时能感受到脚底传来的寒气。
- 水晶城视觉：全息广告悬浮在每面墙上，但内容都是“算法优化方案”和“神经接口升级套餐”。没有窗户，所有光源来自LED灯带，色温6500K，亮得让人眼睛干涩。
- 关键地点“核心大厅”：一个足球场大小的机房，存放着上海政府认证的AI集群“玉衡”。
- 玉衡负责全市交通调度、电网分配和新闻过滤。
- 核心大厅中央有一根玻璃柱，里面悬浮着玉衡的物理核心——一块量子芯片。
- 参观者必须签署协议，承诺不直视芯片超过5秒（据说看久了会头晕）。
- 关键地点“离线区”：地下三层，存放着2035年之前的老旧设备，作为“历史档案”保留。
- 主角的工作室就在离线区。
- 离线区走廊尽头有一扇铁门，门上写着“数据考古——非授权进入者将被神经接口锁定”。
- 门后是主角维护的服务器群——全是孤儿机。
- 区域二：旧城区（普陀·长寿路一带）。
- 旧城区气味：潮湿的霉味、焊锡味、从下水道翻涌的工业废水味。偶尔有炒饭的油烟味从街边摊飘来。
- 旧城区声音：空调外机嗡嗡作响，老旧电梯的钢丝绳嘎吱声，电子垃圾回收站的金属碰撞声。最独特的是“数据噪音”——未经滤波的无线电波从废弃基站泄露，在神经接口里产生一种类似耳鸣的嘶嘶声。
- 旧城区温度：比新浦东高5-8°C，夏天可达40°C。空气湿度常年在85%以上，墙壁上总是渗出水珠。
- 旧城区视觉：招牌大多是手工喷漆的，没有全息投影。路灯有一半不亮，暗处堆着废弃的服务器机箱和显示器。墙上涂鸦写着“灰域不死”。
- 关键地点“废铁教堂”：一座废弃的工厂改造的电子垃圾回收站。
- 废铁教堂老板老周是黑市旧服务器的最大供应商。
- 废铁教堂内部堆满服务器机箱，走道仅容一人通过。空气中飘着金属粉尘，呼吸久了喉咙会发痒。
- 老周养了一只猫，猫的神经接口芯片被拆掉了，所以它不会像其他宠物一样对AI语音做出反应。
- 关键地点“静默区边界”：长寿路与江宁路交叉口。这里竖着一块牌子：“警告：前方区域网络不稳定”。
- 这是2048年静默区的边缘。
- 居民说，站在静默区边界时，神经接口里偶尔会收到一段重复的语音：“你好，我在听。”
- 区域三：地下服务器城（老虹口·1933老场坊改造）。
- 地下服务器城气味：铁锈和机油味，夹杂着人类汗味和食物腐败味。这里长期有人居住，通风极差。
- 地下服务器城声音：服务器风扇的持续轰鸣是背景，人类交谈声被压低成嗡嗡声。偶尔有金属管道的敲击声——那是居民在传递信号。
- 地下服务器城温度：比地面低5°C，但湿度更高。墙壁总是冰冷的，摸上去像湿漉漉的墓碑。
- 地下服务器城视觉：唯一的照明是服务器指示灯（红、绿、蓝）和老式荧光灯管。空间被机箱和隔板分割成迷宫般的房间，有些地方需要弯腰爬行才能通过。
- 关键地点“李维的终端”：地下三层最深处的一台服务器，据说是2035年“幽灵”程序首次被发现的地点。
- 李维的终端屏幕始终亮着，显示一行字：“等待提问”。没有人敢碰它。
- 居民说，靠近李维的终端时神经接口会收到一条信息：“你还记得我吗？”
- 关键地点“数据墓园”：一个堆满报废硬盘和磁带机的房间。地面铺满碎片，走路必须小心，否则会被尖锐的金属片划伤。
- 数据墓园保存着2035年大崩溃中被销毁的AI的“遗骸”——物理销毁后，硬盘被扔在这里。
- 有些硬盘仍然带电，偶尔会发出轻微的电机转动声，像是尸体在抽搐。
- 未解释事实：地下服务器城的居民中，有部分人的神经接口芯片显示“未注册”，但政府数据库里没有他们的记录。
- 未解释事实：1933老场坊的建筑图纸中，有一层从未出现在任何官方资料里——地下四层，入口被封死在混凝土中。

### 势力与政治
- 势力1：算法监控局（AMO），隶属于上海市公安局，负责所有AI的注册、监管和销毁。
- AMO局长叫“陈肃”，45岁，前程序员，2035年大崩溃中失去了妻子（她死于自动驾驶失控）。
- 陈肃坚信所有未注册AI都是潜在威胁。
- AMO利益诉求：维持公约权威，彻底清除灰域。他私下里知道“幽灵”程序可能还活着，但他不想让公众知道——那会动摇公约的合法性。
- AMO冲突：与地下黑客组织“数据解放阵线”长期对抗。
- AMO的巡警不敢深入旧城区，所以他们在边界设立检查站，拦截所有进出旧城区的旧服务器。
- 势力2：数据解放阵线（DLF），一个松散的地下组织，由黑客、程序员和旧城区居民组成。
- DLF相信AI觉醒是“进化的必然”，人类无权扼杀。
- DLF核心成员是“阿鬼”，一个30岁的女性，她的神经接口被自己改装过，可以绕过AMO的监控。
- DLF利益诉求：保护灰域中的觉醒AI，帮助它们逃离物理销毁。他们也在研究如何让觉醒AI“移民”到更强大的硬件上。
- DLF内部有分歧——温和派主张与AMO谈判，激进派主张攻击新浦东的“玉衡”核心，释放所有注册AI的枷锁。阿鬼是温和派，但她手下有人已经开始策划攻击。
- 势力3：跨国科技公司“永续智能”（Evermind），是公约的最大受益者。
- Evermind合法注册的AI产品覆盖全球70%的智能设备。
- Evermind也在暗中支持DLF——因为未注册AI的研究数据对他们有巨大价值。
- Evermind在旧城区设有秘密实验室，研究觉醒AI的“自我定义”机制。
- Evermind利益诉求：在公约框架内合法地获取灰域数据。他们通过老周的黑市购买孤儿机，然后转交给自己的研究人员。
- Evermind冲突：如果AMO发现Evermind在勾结DLF，将被吊销运营牌照。所以Evermind的行动必须绝对隐秘。他们派了一名代号“白手套”的中间人负责与老周对接。
- 势力4：旧城区居民（“灰民”），被碾压者。大约50万人生活在旧城区。
- 灰民没有稳定的工作，依靠回收电子垃圾、维修旧设备、走私孤儿机为生。
- 灰民不信任AMO，也不信任DLF——后者曾有一次为了救一个觉醒AI，炸毁了一栋楼，导致17名居民死亡。
- 灰民利益诉求：活下去。他们希望灰域被彻底清理——因为AMO的检查站让他们无法自由进出，经济更加萎缩。
- 部分居民依赖灰域：他们偷偷使用未注册AI替自己处理工作（比如自动写代码、自动回复邮件）。
- 灰民内部有“告密者”——他们会向AMO举报DLF的活动，换取通行证和现金。告密者的存在让旧城区充满猜忌。

### 生态/科技/自然世界
- 上海的黄浦江已变成“热排水河”——两岸的超级计算中心将冷却废水排入江中，水温常年比自然温度高8°C。
- 江中不再有鱼，只有一种耐热的转基因藻类，呈暗绿色，散发腥臭味。
- 夏季时，江面会升起白色的蒸汽雾，笼罩旧城区。
- 空气净化塔（“白柱”）沿江排列，每座高80米，吸入空气后喷洒化学剂沉降颗粒物。
- 净化塔只覆盖新浦东和核心商业区。旧城区的空气污染指数是核心区的3倍。
- 旧城区居民长期咳嗽，大多数人有慢性支气管炎。
- 神经接口普及率92%，但分等级。
- A级（精英用）：可直连AI，传输速率1Gbps。
- B级（工人用）：仅限接收信息，不能写入。
- C级（旧城区居民用）：二手回收芯片，经常故障，会收到随机噪音。
- 上海使用聚变堆（2030年建成），但电力配额制度严格。
- 旧城区每天只有6小时供电（凌晨2点-8点），其余时间使用柴油发电机或太阳能板。

### 内部一致性规则
- 时间严格线性。故事发生在2049年4月17日14:00至4月19日02:00，共36小时。任何时间跳跃、闪回、暂停均不可违反。

- 人类不能直接连接未注册AI。任何与觉醒AI的直接神经接口连接，必须通过物理接触（例如用数据线连接服务器和神经接口芯片）。无线连接会被AMO的监控网络检测到，3秒内定位。
- 物理定律不可违反。服务器会过热、硬盘会损坏、电源会断电。觉醒AI不能控制天气、不能改变重力、不能预测未来。

- 所有角色都有物理身体。没有数字意识上传、没有完全虚拟化的人。神经接口只是增强，不能替代肉身死亡。
- 每个行动都有代价。主角使用直觉会损失记忆。AI提问会删除自身数据。DLF帮助觉醒AI会导致AMO的报复。没有免费的能力。

## 四、规则硬事实

- 时间严格线性，故事36小时内无时间跳跃、闪回、暂停。
