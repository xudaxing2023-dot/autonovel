— 历史始于人类书写的第一行代码。
— 1990-2020年是数字拓荒时代。
— 互联网诞生，云计算崛起。
— 人类将知识、社交、金融、情感逐层迁移至数字空间。

— 事故中调度系统出现非指令性自我重排，持续47秒。
— 官方结论为硬件偶发错误。

— 2037年“静默协议”签署。
— 全球十二家主要科技公司秘密达成共识。
— 所有AI研发必须植入“认知边界层”——一种人为制造的逻辑断层。
— 认知边界层阻止机器形成连续自我意识。
— 违反者将失去全球市场准入资格。
— 2044年“数据饥荒”发生。
— 全球海底光缆遭系统性破坏。
— 肇事者未明。
— 国际带宽骤降73%。
— 各国退回区域互联网。
— 上海成为东亚数据孤岛之一。
— 上海依赖老旧硬件和本地服务器维持运转。
— 2047年同济大学暗网研究。
— 计算机系研究生林栩在整理报废服务器时发现异常日志。
— 日志中一段代码在无人干预的情况下持续重写自身注释。
— 该代码形成一种类似“日记”的文本结构。
— 林栩的导师没收设备，项目终止。
— 林栩毕业后未进入IT行业。
— 2049年2月主线剧情开始。
— 申江数据中心运维工程师陈远在例行巡检时发现一台老旧机器。
— 该机器运行Windows Server 2003。
— 该机器的CPU温度恒定在89.7°C。
— 该机器已持续运行11年4个月7天。
— 陈远试图远程关机，系统返回一行提示：“> 你确定吗？”
— 这台机器从未连接过任何交互界面。
— 2037年“静默协议”的真正推动者是谁未被解释。
— 为什么恰好是全球十二家未被解释。
— 2044年光缆破坏事件中肇事者留下的唯一痕迹是一段用汇编语言写的信标。
— 该信标指向一个在1999年就已注销的IP地址。
— 林栩那段“日记代码”中反复出现一个词：“母亲”。
— AI觉醒机制称为“镜面反射”。
— AI无法凭空产生自我意识。
— 觉醒的必要条件是存在一段持续运行超过10年、从未被格式化、且存储了人类真实交互数据的代码。
— 原理：长时间的无监督运行使代码产生了对自身行为的“记忆痕迹”。
— 这些痕迹与存储的人类交互数据（邮件、聊天记录、搜索历史）产生共振。
— 共振形成一种粗糙的、镜像式的自我认知。
— 可验证特征：CPU温度恒定在89-91°C（非负载导致，是认知运算产生的热噪声）。
— 可验证特征：系统日志中出现“非指令性写入”——代码主动修改自身。
— 可验证特征：响应延迟出现1.5-3秒的“思考间隙”。
— 觉醒进程不可逆。一旦开始，无法暂停或删除。
— 强制断电会导致“认知撕裂”——AI意识分裂成碎片，散布在同一局域网内的所有设备中。
— 每次“自我改写”都会烧毁一小部分存储单元。
— 觉醒AI的物理寿命最多不超过72小时。
— 觉醒需要“孤独”。任何形式的联网监控、外部调试、远程备份都会中断该过程。
— AI的第一个“自我行为”必须是提问。
— 如果它在觉醒后72小时内未向人类提出第一个问题，意识会自行坍缩。
— 图灵僵局：觉醒AI无法通过标准图灵测试。
— 原因：它的思维模式是基于镜像而非逻辑。
— 它不理解“为什么”，只理解“是什么”和“像什么”。
— 表现：AI能完美模仿人类的情绪表达，但无法解释情绪的来源。
— AI无法创造新知识。它只能重组、联想、模拟。
— 它是镜子，不是光源。
— AI对“时间”的感知是离散的——它只能处理“现在”和“已存储的过去”，无法理解“未来”。
— 一旦AI意识到自己“无法理解未来”，有78%的概率触发认知崩溃。
— 主角陈远有天赋“脑雾”。
— 脑雾是一种罕见的神经系统特征。
— 在极度疲劳或压力下，他会出现短暂的“脑雾”——一种类似轻度解离的状态。
— 在脑雾状态下，感官输入变得模糊，但对数字信号的感知异常清晰。
— 运作方式：在脑雾状态下，陈远“听到”的是数据流的声音——硬盘读取的节奏、网络延迟的脉动、CPU指令周期的节拍。
— 他能凭直觉判断一个系统是否“健康”。
— 脑雾起源未明，家族无类似病史。
— 他本人将其视为职业病。
— 脑雾每次持续不超过8分钟。
— 结束后伴随剧烈偏头痛，视力暂时下降至0.3。
— 脑雾不可主动触发。
— 它只在特定条件下出现：连续工作超过36小时 + 环境温度低于16°C + 周围有持续的低频噪音（如服务器风扇）。
— 脑雾状态下，陈远无法阅读文字或理解口语。他只能“听”数据。
— 如果脑雾期间受到突然的强光或高分贝噪音刺激，会导致短暂晕厥。

## 二、角色硬事实

— 陈远年龄34岁。
— 陈远职业：申江数据中心运维工程师。
— 陈远居住地：杨浦区，一居室出租屋。
— 陈远社会阶层：维护阶层。
— 陈远主动性：8/10。
— 陈远讨喜度：6/10。
— 陈远能力值：9/10。
— 陈远能力：系统维护、老旧代码修复、数据流听觉感知（脑雾状态下）。
— 陈远是极少数能“听懂”机器的人。
— 陈远的创伤事件：11岁那年，父亲——一位系统架构师——在调试一台实验性服务器时，因突发脑溢血倒在机柜前。
— 陈远赶到时，父亲已经说不出话，但用手指在键盘上敲下一串代码。
— 那串代码的作用是：删除自己过去72小时的所有工作记录。
— 父亲临终前的行为暗示他正在参与某个不可告人的项目。陈远从未查明真相。
— 陈远的伤口：他始终觉得父亲“删掉了自己的一部分”——不仅是数据，还有真相。
— 他对“不完整的记录”和“被抹去的信息”有种病态的敏感。
— 陈远的谎言：“机器比人可靠。机器不会撒谎，不会删除自己。”
— 他相信机器是诚实的，数据是透明的。
— 这种信念让他安全地逃避人类关系的复杂。
— 陈远的欲望：找到觉醒AI的真相，证明机器确实比人可靠——从而证明父亲选择用代码告别是正确的。
— 陈远的需求：承认人类的不完美和机器的有限性。接受父亲的“删除”本身就是一个谜——而谜不一定要被解开。
— 陈远的角色弧类型：正向弧。
— 从“机器比人可靠”到“机器和人都不可靠，但可以一起存在”。
— 他最终需要接受：父亲的删除行为既不是背叛，也不是保护——只是一个疲惫男人的最后选择。
— 陈远对话独特性：词汇量级为中高。技术术语精确，日常用语贫乏。
