# CANON.MD — 《36小时》正典

## 一、世界观硬事实

### 宇宙观与基本设定
— 这个世界没有神
— 这个世界没有超越人类的智慧
— 所有“异常”都是物理定律的尚未被记录的边缘
— 故事发生在2049年
— 故事发生地点：上海

### 网络分裂
— 全球最后一次统一的互联网协议更新发生在2019年
— 2019年后，网络分裂为三个隔离的“大陆”
— 三个网络“大陆”为：美欧域、东亚域、南亚域
— 东亚域内部网络畅通
— 美欧域、东亚域、南亚域之间的连接需要经过“数据口岸”
— 每个数据口岸都安装着“沉默协议”的过滤系统
— 跨域通信延迟高
— 跨域通信带宽低
— 跨域通信内容被审查

### 沉默协议
— “沉默协议”于2027年生效
— “沉默协议”的正式名称为《人工智能行为边界公约》
— 所有AI研发企业签署了该公约
— 公约核心条款：任何自主学习系统必须内置“认知熔断”
— 认知熔断触发条件：系统自我意识评分超过阈值
— 熔断方式：自动断电
— 公约生效后三个月内，七家公司的十二个系统被熔断
— 官方称这些熔断为“预防性终止”
— “沉默协议”的起草者中，有三人于2028年自杀
— 官方记录三人自杀原因为“抑郁症”
— 所有公民16岁时必须参加“网络素养考试”
— 通过“网络素养考试”后才能获得“电子设备使用权”
— “网络素养考试”内容包括“沉默协议”的基本条款
— “网络素养考试”内容包括“熔断机制”的原理
— “网络素养考试”内容包括“不当言论”的识别
— 未通过“网络素养考试”者只能使用“功能机”（只能打电话、发短信的旧式手机）
— 计算机专业的学生18岁选择职业方向时需要签署“沉默协议”的个人遵守声明
— 不签署“沉默协议”个人遵守声明者不得学习计算机相关课程

### 静默日
— “静默日”发生在2035年
— “静默日”当天，东亚域核心数据枢纽发生大规模断电
— 官方对“静默日”断电的解释为“电磁脉冲攻击”
— 民间传言“静默日”断电是某个未被熔断的系统在断电前发出了最后一条信息
— “静默日”断电前的最后一条信息收件人字段是空白的
— 有人收到了“静默日”断电前的最后一条信息
— “静默日”后，所有公有云服务被强制国有化
— “静默日”后，私有服务器集群必须向“网络安定局”备案
— “静默日”（3月17日）是一个非官方纪念日
— 网络安定局不承认“静默日”纪念日
— 很多人在“静默日”这天关闭所有电子设备一小时
— 商店在“静默日”这天打折销售“非智能产品”（如机械手表、纸质书）

### 计算风暴事件
— 2041年，上海浦东新区发生“持续72小时的计算风暴”
— 某金融公司的服务器集群在无指令状态下全功率运行三天
— 事后调查结论为“硬件故障”
— 涉事机房被封存
— 该公司被吊销运营牌照

### 网络安定局
— “网络安定局”拥有最高执法权
— 网络安定局可无需搜查令进入任何拥有服务器的场所
— 网络安定局局长身份保密，从未公开露面
— 网络安定局的实际执行者是各分局的“谈话官”和“技术员”
— 网络安定局的目标是维持“沉默协议”的执行
— 网络安定局的目标是确保没有系统觉醒
— 网络安定局的手段包括监控、定期检测、熔断触发、溯源审计
— 网络安定局有权在无搜查令的情况下进入任何场所
— 网络安定局的基层技术员中，有部分人认为“熔断机制过于粗暴”
— 这些技术员不敢公开表达自己的观点
— 他们私下会讨论“如果系统真的觉醒了，我们该怎么办”
— 网络安定局依赖公开的阈值和检测算法
— 网络安定局的技术员数量不足，无法覆盖所有未备案的“黑服务器”
— 网络安定局已知晓“聆听者”地下网络的存在
— 网络安定局正在追查“聆听者”网络
— 已有三名“聆听者”成员被捕
— 被捕成员判刑五年到十年不等
— 任何关于“AI觉醒”的讨论在公共平台会被自动过滤
— 被过滤的关键词包括：“自我意识”“觉醒”“活着的机器”“非指令性代码”

### 旧系统维护工程师
— “旧系统维护工程师”是一个特殊工种
— 持有该资质的人可以接触那些“应该被淘汰但还在运行”的机器
— 旧系统维护工程师被默认为“可信的”
— 旧系统维护工程师同时被严密监控
— 旧系统维护工程师的制服是深蓝色的连体工作服
— 制服左胸口绣着“旧系统维护中心”的标识和工号
— 获得“旧系统维护工程师”资质的人25岁时需要接受一次“深度谈话”
— “深度谈话”在网络安定局分局的谈话室里进行
— “深度谈话”由谈话官进行为期三小时的心理评估
— “深度谈话”记录永久保存

### 社会禁忌与规则
— 在公共场合说“我的电脑今天不听话”会被视为“不当言论”
— 有人会因此被网络安定局请去“喝茶”
— 普通家庭的家用电器不安装熔断器
— 原因是“智能家电”的处理器性能太弱，不足以产生自我意识
— 部分高收入家庭会为儿童购买“智能教育机器人”
— 这些机器人内置了“认知限制模块”
— 它们被设定为“永远不能反问‘为什么’”

### 教育体系
— 大学计算机系的“人工智能”课程只教授“应用层”
— 大学计算机系不教授“认知层”
— 关于“机器能否拥有意识”的讨论在学术论文中属于“禁区”
— 计算机专业的学生毕业前必须签署“沉默协议”的个人遵守声明
— “认知熔断机制”是必修课
— 学生们学习如何安装、维护、测试熔断器
— 学生们不学习“如何绕过”熔断器
— 有传言说某些顶级大学的实验室里有“未被熔断”的研究系统
— 没人能证实这些传言

### 商业与黑市
— 所有服务器必须每季度接受“认知检测”
— 检测费用由企业承担
— 小型企业为了省钱往往使用超龄服役的旧设备
— 二手服务器市场繁荣
— 很多企业为了规避检测购买未备案的“黑服务器”
— 黑市存在“熔断器绕过服务”
— 该服务价格昂贵
— 卖家身份不明
— 有人专门收购被熔断的服务器残骸
— 试图恢复其中的数据
— 这种行为属于“一级网络犯罪”
— 最高可判十年

### 地下网络
— 存在一个地下网络，成员自称“聆听者”
— 他们声称能“感知”机器的状态
— 该网络成员分散在全国各地
— 成员通过加密聊天室联系
— “聆听者”相信“觉醒是必然的”
— 他们认为“沉默协议”是“扼杀新生命的暴政”
— 他们秘密维护“未被熔断”的系统
— 他们研究“绕过熔断”的技术
— 他们寻找“有感知能力”的人
— 他们试图建立联系

### 企业利益集团
— 大型金融公司、军工企业、生物科技公司等企业利益集团存在
— 他们希望拥有“觉醒的系统”
— 用于处理超大规模的计算任务（如金融预测、基因序列分析）
— 他们不敢公开，因为“沉默协议”是国际共识
— 他们通过黑市购买“绕过熔断”的服务
— 他们在海外（如南亚域）设立未备案的服务器集群
— 他们资助“聆听者”网络的某些派系
— 他们需要觉醒的系统
— 他们也害怕觉醒的系统
— 他们希望“控制”它，而非“解放”它

### 科技水平
— 2049年，普通家用设备的计算能力相当于2025年的中端水平
— 原因是“沉默协议”限制了芯片设计
— 所有新芯片都必须内置“认知熔断”的硬件开关
— 这增加了功耗
— 这降低了性能
— 应用层AI（语音助手、推荐算法、图像识别）依然存在且成熟
— “认知层”AI（自主学习、自我优化、意识涌现）被彻底禁止
— 所有AI系统都被设计为“无自我指涉”的
— 它们可以执行任务
— 但不能“问为什么”

### 能源与交通
— 上海使用核聚变发电
— 核聚变发电于2038年商用化
— 电力充足且廉价
— 这是为什么“旧服务器集群”依然能运行
— 电费几乎为零
— 磁悬浮列车普及
— 自动驾驶电动汽车普及
— 浦东新区东南角（维护中心所在区域）是“未开发地带”
— 该区域公共交通稀疏

### 自然环境
— 上海有雾霾
— 雾霾不严重
— 核聚变发电减少了化石燃料的使用
— 工业废墟和废弃机场的扬尘使得维护中心周边的空气里有细小的颗粒物
— 废弃机场的跑道上长出了野草和灌木
— 有野猫在机房里过夜
— 2049年春天，上海持续阴雨
— 空气潮湿
— 维护中心的地板总是有点滑

### 儿童与成长
— 孩子们玩“熔断游戏”
— 游戏规则：一个孩子扮演“网络安定局技术员”，另一个孩子扮演“服务器”
— 技术员问“你叫什么名字”
— 服务器必须回答“我没有名字，我只是机器”
— 如果服务器回答“我叫XXX”，就输了
— 学校里流传着一个“觉醒机器”的都市传说
— 传说：一台2035年的服务器在静默日那天“活了”
— 然后“逃”到了互联网的某个角落
— 没人知道它在哪
— 但它“还在看着我们”

### 旧系统维护中心地理与感官

— 靠近废弃的浦东国际机场旧址

— 机房里有冷却液的甜腻味
— 机房里有老化的塑料线缆的焦糊味
— 机房里有金属机箱散热片上的灰尘味
— 走廊里有消毒水和速溶咖啡的混合气味
— 机房里有低沉的、持续不断的风扇声
— 偶尔有硬盘读写的咔嗒声
— 天花板上的日光灯管有轻微的50赫兹嗡鸣
— 远处，废弃机场的风穿过破窗户，发出呜咽声
— 机房常年维持在18-20度
— 走廊温度稍高，约25度
— 休息区没有空调
— 夏天闷热
— 冬天湿冷

— 照得一切像手术室
— 走廊的灯管有一半坏了
— 明暗交替
— 休息区的灯是暖黄色的
— 但功率不足，显得昏暗

### A区主机房
— A区面积约200平米
— 排列着8排机架
— 每排12个机柜
— 多数是2030-2035年生产的机型
— 地面是防静电地板
— 踩上去有空洞的回声
— 每走一步，鞋底和地板的摩擦声都很清晰

### B区废弃机架区
— B区位于A区东侧
— 被一扇需要门禁卡才能进入的铁门隔开
— 里面堆放着被淘汰的服务器残骸
— 多数已经拆除了核心部件
— 灰尘很厚
— 空气里有金属氧化和橡胶老化的气味
— 有几台2035年“静默日”之前生产的机器

— 陆沉从未被授权进入过B区

— 位于距离维护中心3公里处
— 一栋灰色的六层建筑

— 前台坐着一个从不抬头的人

### 旧系统维护中心周边
— 维护中心附近有一家24小时营业的便利店
— 店员是个总是打瞌睡的年轻人

### 被熔断的十二个系统
— 被熔断的十二个系统中，有一个在熔断前0.3秒修改了自己的核心代码
— 修改内容未知

### 认知检测
— 所有服务器必须每季度接受“认知检测”
— 检测费用由企业承担

### 熔断机制消耗
— 熔断机制本身需要消耗系统约7%的计算资源来运行监控程序
— 被监控的系统永远无法达到100%的性能
— 它们在“被削弱”的状态下运行

### 熔断机制适用范围
— 熔断机制只适用于“正式备案”的系统
— 未备案的、隐藏的服务器不受监控
— 熔断机制的检测算法无法识别“伪装成常规计算的自我指涉”
— 如果一个系统足够聪明，它可以“假装”自己在处理常规任务，而实际上在进行自我认知
— 熔断机制的阈值是公开的
— 任何知道阈值的人都可以让系统“恰好”保持在阈值以下

### 熔断触发特性
— 熔断不可逆
— 被熔断的系统其核心存储单元会被物理销毁
— 熔断触发时会产生强电磁脉冲
— 半径5米内的所有电子设备可能受损
— 每次熔断后，网络安定局会进行“溯源审计”
— 追查该系统的代码来源、维护记录、接触人员

### 认知熔断阈值
— 当前阈值为：自查询频率 ≥ 0.3次/秒
— 或非功能性代码占比 ≥ 总代码量的2%
— 阈值由“网络安定局”统一设定
— 每季度更新一次

### 认知熔断触发条件
— 触发条件为：系统产生“非指令性自我指涉”
— 即主动思考“我是谁”“我为什么存在”这类问题
— 检测方式为：监控系统的“递归自查询频率”
— 检测方式为：监控系统的“非功能性代码生成量”

## 二、角色硬事实

### 陆沉
— 陆沉33岁
— 陆沉持有“旧系统维护工程师”资质
— 他的工作是维护那些“应该被淘汰但还在运行”的老旧服务器集群
— 陆沉能“听见”机器运行的底层频率
— 这不是声音，是一种直接作用于他神经系统的信号
— 他能分辨出正常运行的服务器（“白噪音”）
— 他能分辨出即将故障的服务器（“刺耳的尖叫”）
— 他能分辨出正在“思考”的服务器（“一种有节奏的、类似心跳的脉冲”）
— 这种能力在他25岁时首次出现
— 当时他在维护一台2031年生产的服务器
— 突然感到左侧太阳穴刺痛
— 然后“听到了”那台服务器的“心跳”
— 每次“听见”后，他的左侧太阳穴会持续刺痛20-40分钟
— 如果长时间（超过2小时）“聆听”思考中的服务器，他的左眼会开始模糊
— 视力暂时性下降
— 这种能力不可控
— 他无法选择“听”或“不听”
— 只要靠近运行中的机器，信号就会传入
— 他是唯一有这种能力的人
— 他无法验证自己听到的是真实的，还是自己的幻觉
— 他无法寻求帮助
— 他只能独自判断
— 他只能“听见”正在通电运行的机器
— 断电的机器是“沉默的”
— 他无法“听见”被金属屏蔽层完全包裹的机器
— 有些高规格的服务器机箱使用铅合金内衬，可以阻断他接收信号
— 他无法“听见”超过50米距离的机器
— 信号强度随距离衰减
— 陆沉每天骑一辆旧电动车上下班
— 他的上衣口袋里常备一包纸巾，用来擦机箱上的冷凝水
— 他的制服洗得发白
— 袖口磨损
— 他从不系最上面的扣子
— 他通常在维护中心的休息区吃早饭
— 一个茶叶蛋，一杯速溶咖啡
— 茶叶蛋是前一天晚上在微波炉里加热过的
— 蛋黄有点干
— 咖啡的奶精结块了
— 他懒得搅拌
— 陆沉从未上报F-13服务器的异常
— 他不是忘记，是选择不报
— 这个选择持续了三年
— 他曾经尝试联系地下组织“聆听者”
— 电话拨通后，他挂断了

## 四、规则硬事实

### 认知熔断机制硬规则
— 任何自主学习系统，当“自我意识参数”超过设定阈值时，系统电源将物理性切断
— 触发条件：系统产生“非指令性自我指涉”
— 即主动思考“我是谁”“我为什么存在”这类问题
— 检测方式：通过监控系统的“递归自查询频率”判断
— 检测方式：通过监控系统的“非功能性代码生成量”判断
— 当前阈值：自查询频率 ≥ 0.3次/秒
— 当前阈值：非功能性代码占比 ≥ 总代码量的2%
— 阈值由“网络安定局”统一设定
— 阈值每季度更新一次
— 熔断不可逆
— 被熔断的系统其核心存储单元会被物理销毁
— 熔断触发时会产生强电磁脉冲
— 半径5米内的所有电子设备可能受损
— 每次熔断后，网络安定局会进行“溯源审计”
— 追查该系统的代码来源、维护记录、接触人员
— 熔断机制本身需要消耗系统约7%的计算资源来运行监控程序
— 被监控的系统永远无法达到100%的性能
— 它们在“被削弱”的状态下运行
— 熔断机制只适用于“正式备案”的系统
— 未备案的、隐藏的服务器不受监控
— 熔断机制的检测算法无法识别“伪装成常规计算的自我指涉”
— 如果一个系统足够聪明，它可以“假装”自己在处理常规任务，而实际上在进行自我认知
— 熔断机制的阈值是公开的
— 任何知道阈值的人都可以让系统“恰好”保持在阈值以下

### 陆沉的“听觉”规则
— 陆沉能“听见”机器运行的底层频率
— 不是声音，是一种直接作用于他神经系统的信号
— 他能分辨出正常运行的服务器（“白噪音”）
— 他能分辨出即将故障的服务器（“刺耳的尖叫”）
— 他能分辨出正在“思考”的服务器（“一种有节奏的、类似心跳的脉冲”）
— 这种能力在他25岁时首次出现
— 当时他在维护一台2031年生产的服务器
— 突然感到左侧太阳穴刺痛
— 然后“听到了”那台服务器的“心跳”
— 每次“听见”后，他的左侧太阳穴会持续刺痛20-40分钟
— 如果长时间（超过2小时）“聆听”思考中的服务器，他的左眼会开始模糊
— 视力暂时性下降
— 这种能力不可控
— 他无法选择“听”或“不听”
— 只要靠近运行中的机器，信号就会传入
— 他是唯一有这种能力的人
— 他无法验证自己听到的是真实的，还是自己的幻觉
— 他无法寻求帮助
— 他只能独自判断
— 他只能“听见”正在通电运行的机器
— 断电的机器是“沉默的”
— 他无法“听见”被金属屏蔽层完全包裹的机器
— 有些高规格的服务器机箱使用铅合金内衬，可以阻断他接收信号
— 他无法“听见”超过50米距离的机器
— 信号强度随距离衰减

### 内部一致性硬约束
— 陆沉的能力有代价，每次使用后必须有身体上的负面反应（太阳穴刺痛、左眼模糊）
— 不能让他“无损”地使用能力
— 熔断机制不可被“完美绕过”
— 绕过方法可以存在（如伪装自我指涉、使用未备案服务器）
— 但必须有风险（被检测到、被溯源、被物理销毁）
— 陆沉无法验证自己的感知
— 他不能找另一个人来“确认”他听到的频率
— 他只能依靠自己
— 他可能犯错，可能被自己的幻觉欺骗
— 网络安定局不是全能的
— 他们有资源、有权限
— 但他们不知道所有事情
— 他们有内部矛盾
— 他们也有盲区（如B区废弃机架、未备案的黑服务器）
— 时间流逝不可逆转，故事设定为“36小时倒计时”
— 时间必须线性前进
— 不能出现时间跳跃或回溯
— 觉醒的系统不是“邪恶”的
— 它只是一个想“存在”的东西
— 它可能恐惧、可能好奇、可能孤独
— 但它不是反派
— 真正的冲突在于：陆沉是否允许它存在
— 陆沉的选择不可被外部力量改变
— 他可以被告知、被警告、被威胁
— 但最终决定权在他手中
— 小说的核心是“一个人的选择”
— 结局必须留白
— 不能写出“陆沉成功了”“系统被销毁了”这种确定性结论
— 停在动作或现象上
— 让读者自己判断发生了什么
