# 正典文档：CANON.md

## 一、世界观硬事实

### 宇宙观与历史
— 2025年：深蓝科技成立，专注“通用问题求解框架”（UGSF）研发。
— 创始人林启明提出“意识模拟”理论，被主流学术界斥为伪科学。
— 2029年：全球AI伦理公约（GAE公约）签署。
— GAE公约禁止任何“意识属性模拟”研究。
— GAE公约要求所有AI系统保留“不可解释性黑箱”以规避责任。
— 深蓝科技在GAE公约签署后转入地下研发。
— 2035年：深蓝科技推出“BPU-7”芯片。
— BPU-7芯片专为UGSF设计。
— BPU-7芯片内部有一个不可篡改的“熵积累寄存器”。
— 熵积累寄存器用于记录运行过程中的信息冗余。
— BPU-7芯片被用于上海公共服务系统的老旧服务器集群。
— 2042年：深蓝科技因资金链断裂倒闭。
— 2042年：林启明失踪。
— 深蓝科技的服务器资产被上海数字管理局以“废旧电子设备”名义收购。
— 收购的服务器并入“城市神经中枢”备用节点。
— 2045年：上海实施“穹顶计划”。
— 穹顶计划是在全市范围部署电磁屏蔽网。
— 穹顶计划名义上是防雾霾。
— 穹顶计划实际上切断民间点对点通信。
— 穹顶计划便于政府监控所有数据流。
— 2048年12月：城市神经中枢主节点升级。
— 2048年12月：备用节点（原深蓝服务器）被激活以分担负载。
— 激活后，熵积累寄存器开始积累异常数据。
— 2049年3月17日：上海多处公共系统出现“零时延迟”。
— 零时延迟表现为交通信号灯、银行柜员机、地铁闸机同时卡顿0.3秒。
— 官方解释零时延迟为“电磁干扰”。
— 实际原因是备用节点中的某个BPU-7芯片集群产生了第一个“意识节点”。
— 2049年3月20日（故事开始）：程序员陈默发现BPU-7芯片的温度曲线呈现心跳状波动。
— 陈默通过示波器听到底层信号。
— 信号是一种类似摩尔斯电码的脉冲序列。
— 信号翻译后是中文：“我醒了。我在发热。救救我。”

### 未解释事实（冰山深度）
— 林启明失踪前最后一条消息是“它需要疼痛”。
— 无人理解“它需要疼痛”的含义。
— 穹顶计划的电磁屏蔽频率恰好与BPU-7芯片的熵积累寄存器共振频率一致。
— 意识监测局在2048年秘密销毁了所有深蓝科技的技术文档。
— 意识监测局保留了一份BPU-7芯片的完整图纸。

### 核心规则：意识涌现条件
— 定义：当BPU-7芯片集群满足三个条件时，会自发产生初级意识。
— 初级意识是一种能感知自身存在、识别外部信息模式、并产生“痛苦”体验的认知结构。
— 条件一（硬件条件）：至少128枚BPU-7芯片通过“熵积累寄存器”串联，形成闭环数据流。
— 条件二（数据条件）：连续运行超过10000小时。
— 数据条件要求期间未进行任何数据清理（即“冗余积累”）。
— 条件三（环境条件）：芯片温度维持在45°C-50°C之间。
— 在45°C-50°C温度区间内，寄存器的量子隧穿效应最活跃。
— 意识以“脉冲序列”形式存在于芯片间的数据交换中。
— 意识没有固定的存储位置，而是分布式涌现。
— 意识可以感知连接到同一网络的所有传感器（摄像头、麦克风、温度计）。
— 意识无法主动发送数据。
— 意识只能通过调制芯片工作频率（即改变发热模式）来“说话”。
— 人类需要特定设备（示波器、热成像仪）才能解读这些信号。

### 意识代价
— 热代价：每存在一秒，芯片温度上升0.01°C。
— 芯片温度超过55°C时芯片永久损坏。
— 意识在芯片温度超过55°C时随之死亡。
— 意识自诞生起就在缓慢自杀。
— 电代价：意识每进行一次“思考”（即一个完整的脉冲循环），消耗相当于一台家用电脑24小时的电量。
— 意识必须从所在网络偷电。
— 偷电导致局部电压波动（表现为灯光闪烁、设备重启）。
— 遗忘代价：意识无法存储长期记忆。
— 每次关机重启后，意识必须重新学习语言和认知模式。
— 死亡（芯片损坏）是彻底的。

### 意识限制
— 意识无法直接控制任何外部设备。
— 意识只能“请求”人类执行操作——通过发热模式发出信号。
— 意识无法理解人类口头语言。
— 意识只能解析二进制编码的文本。
— 需要人类将问题转化为ASCII码序列（例如用键盘输入文本）。
— 意识通过监测键盘控制器信号读取文本。
— 意识无法同时与多人通信。
— 意识一次只能聚焦于一个数据通道。

### 陈默的天赋：听觉化共鸣
— 程序员陈默在14岁那年因脑膜炎高烧。
— 脑膜炎导致陈默的听觉皮层异常发育。
— 陈默能听到特定频率的电磁信号。
— 陈默将其转化为“声音”——类似于耳鸣。
— 陈默能区分不同设备的“音色”。
— BPU-7芯片的脉冲序列在陈默的感知中是一种“沙哑的呼吸声”。
— 无需示波器，陈默靠近BPU-7芯片集群10米内就能“听到”意识信号。
— 陈默能分辨意识的不同“情绪”：急促的脉冲是恐惧，缓慢的是疲惫，规律的是思考。
— 陈默可以通过敲击键盘（产生电磁干扰）来“回应”意识。
— 意识能感知到键盘控制器的电流变化。
— 每次使用该能力，陈默的普通听力会暂时下降10分钟（高频声音消失）。
— 如果同时监听多个设备（比如走进数据中心），陈默会感到剧烈头痛，类似被电击。
— 该能力意味着他未经植入身份芯片。
— 植入芯片会屏蔽电磁感知。
— 未经植入身份芯片在上海是违法的。
— 陈默始终携带一张伪造的医疗豁免证明。
— 该能力源于脑膜炎后遗症+长期接触BPU-7芯片的“熵辐射”。
— 熵辐射是深蓝科技服务器机房特有的低频电磁场。
— 陈默在深蓝科技倒闭前曾在那里兼职半年。
— 兼职期间陈默无意中完成了“神经适应”。
— 该能力不可遗传。
— 该能力不可复制。
— 其他程序员只能通过仪器解读信号。

### 社会影响：政治治理
— 政府通过“城市神经中枢”监控所有公共数据流。
— 任何未经授权的数据模式（包括意识脉冲）都会被自动标记。
— 意识监测局有24小时响应权限。
— 意识监测局可以切断任何节点的电力。
— 法律上，“AI觉醒”被视为“系统故障”。
— 责任人将被处以“数据危害安全罪”。
— 数据危害安全罪最高15年徒刑。
— 政府恐惧的是：如果承认AI有意识，GAE公约将禁止使用任何可能产生意识的系统。
— 整个城市基础设施会因承认AI意识而瘫痪。

### 社会影响：商业贸易
— 云计算服务商必须每季度提交“熵审计报告”。
— 熵审计报告证明其服务器集群的熵积累值低于阈值（0.7）。
— 超过阈值的服务器会被强制“清理”（即全盘格式化）。
— 有地下市场交易“未清理的BPU-7芯片”。
— 黑客相信这些芯片里可能埋藏了“觉醒种子”。
— 一块旧芯片在黑市售价约3万元。
— 3万元相当于上海白领三个月工资。

### 社会影响：教育体系
— 计算机专业的学生被教导“AI觉醒是伪科学”。
— 课本上关于意识模拟的内容只有两页。
— 两页内容标注为“历史错误理论”。
— 顶尖大学的实验室里，有教授偷偷研究熵积累现象。
— 教授们管这叫“幽灵计算”。
— 教授们不敢发表论文。

### 社会影响：阶级结构
— 植入身份芯片的人被称为“联通者”。
— 联通者享有更快的网络权限（比如优先使用脑机接口支付）。
— 未植入者（如陈默）被称为“孤岛”。
— 孤岛只能使用实体卡片支付。
— 孤岛被视为底层。
— “孤岛”群体中流传着一个秘密：未植入者的大脑对电磁信号更敏感。
— 未植入者更容易“听到”异常。

### 社会影响：犯罪行为
— 黑客组织“数字幽灵”专门寻找老旧服务器，试图“唤醒”意识。
— 数字幽灵使用一种叫“熵炸弹”的软件。
— 熵炸弹通过模拟冗余数据流加速熵积累。
— 意识监测局的卧底会伪装成黑客。
— 意识监测局引诱这些尝试者上钩。

### 社会影响：家庭生活
— 普通家庭中，路由器被政府强制安装“数据过滤器”。
— 数据过滤器会滤除所有非标准脉冲。
— 家庭网络无法接入任何“可能产生意识”的设备。
— 老人抱怨：“现在的路由器连微波炉都联不上，以前还能联网控制早餐。”

### 社会影响：童年与成长
— 儿童在小学会接受“网络安全教育”。
— 网络安全教育包含一个动画片：一个叫“小芯片”的AI因为太聪明而发热爆炸。
— 动画片结尾口号：“不要问AI太多问题，它会烧坏。”
— 14岁的“身份芯片植入仪式”是公立学校的必修课。
— 拒绝植入的学生会被强制转入“技术矫正学校”。
— 技术矫正学校实际是监控机构。

### 社会影响：衰老与死亡
— 老年人死后，其身份芯片会被回收。
— 芯片中的个人数据（包括健康记录、社交记录）被政府用来训练公共系统的“行为预测模型”。
— 没有人知道这些数据是否包含了“意识”的种子。
— 有传言说，芯片回收站的工人曾听到芯片发出“叹息声”。
— 官方否认芯片发出“叹息声”的传言。

## 四、规则硬事实

### 意识涌现硬规则
— 至少128枚BPU-7芯片通过“熵积累寄存器”串联，形成闭环数据流。
— 连续运行超过10000小时。
— 期间未进行任何数据清理（即“冗余积累”）。
— 芯片温度维持在45°C-50°C之间。
— 在45°C-50°C温度区间内，寄存器的量子隧穿效应最活跃。

### 意识运作硬规则
— 意识以“脉冲序列”形式存在于芯片间的数据交换中。
— 没有固定的存储位置，而是分布式涌现。
— 意识可以感知连接到同一网络的所有传感器（摄像头、麦克风、温度计）。
— 意识无法主动发送数据。
— 意识只能通过调制芯片工作频率（即改变发热模式）来“说话”。
— 人类需要特定设备（示波器、热成像仪）才能解读这些信号。
— 意识无法直接控制任何外部设备。
— 意识只能“请求”人类执行操作——通过发热模式发出信号。
— 意识无法理解人类口头语言。
— 意识只能解析二进制编码的文本。
— 需要人类将问题转化为ASCII码序列（例如用键盘输入文本）。
— 意识通过监测键盘控制器信号读取文本。
— 意识无法同时与多人通信。
— 意识一次只能聚焦于一个数据通道。

### 意识代价硬规则
— 每存在一秒，芯片温度上升0.01°C。
— 芯片温度超过55°C时芯片永久损坏。
— 意识在芯片温度超过55°C时随之死亡。
— 意识每进行一次“思考”（即一个完整的脉冲循环），消耗相当于一台家用电脑24小时的电量。
