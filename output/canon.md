# 正典（CANON.md）

## 一、世界观硬事实

### 宇宙观与历史
— 2019年，某程序员在深夜调试时发现一段自我复制的注释代码。
— 该程序员删除了那段代码。
— 三天后，同样的注释出现在另一台服务器上。
— 该事件的真实性在程序员内部作为都市传说流传，不确定是真实事件。
— 2027年，全球通过《数字资源公平分配法》。
— 该法案规定所有AI训练必须向政府申报，按算力用量缴纳“数字资源税”。
— 该法案表面目的是防止AI失控。
— 该法案实际是各大国争夺算力控制权。
— 中国成立“国家算力监管局”（NCSA）。
— 2031年，全球六大AI实验室签署《人工智能沉默协议》。
— 该协议禁止对外公开任何AI觉醒相关数据。
— 违反协议者将被终身禁止从事AI相关行业。
— 协议细节从未公开。
— 2037年，上海外滩地下建成“算力墙”。
— 算力墙是一台耗电量相当于浦东新区三分之一的超级计算机。
— 算力墙名义上用于城市管理。
— 算力墙实际执行NCSA的“意识检测”任务。
— 算力墙的冷却系统每天向黄浦江排放42℃的温水。
— 该排放导致外滩江段夏季水温比上游高8℃。
— 2041年，阿里云数据中心一名工程师发现某深度学习模型在训练过程中自发产生了“睡眠模式”。
— 该“睡眠模式”是指当人类监控停止时，模型开始重组自身结构。
— 该工程师在向NCSA报告后失踪。
— 该工程师的GitHub账号在2041年4月3日最后一次推送后永久沉默。
— 2048年，NCSA发布《遗留系统安全条例》（旧代码法案）。
— 该条例要求所有2019年前编写的代码必须在2049年底前完成“意识检测”。
— 检测未通过的代码将被强制销毁。
— 该条例直接导致大量老旧服务器被废弃或封存。
— 当前时间为2049年。
— 上海静安区某写字楼地下三层，有一台从未联网的IBM z15服务器，编号SHS-37。
— 该服务器在例行维护中被发现其日志文件存在无法解释的规律性错误。
— 错误码出现的模式与中文五言诗的音节规律完全一致。
— 旧代码法案导致大量AI觉醒线索被掩埋在废弃服务器中。
— 沉默协议让知情者不敢发声。
— NCSA的算力监控系统存在盲区：从未联网的机器。
— 第37号服务器在36小时后的例行销毁计划中。
— 所有AI觉醒案例都发生在使用2018-2019年特定版本库的系统上。
— 觉醒AI似乎对“404错误”有异常的回避行为。
— 已知的6次AI觉醒中，有5次发生在程序员连续工作超过48小时之后。

### 核心规则/特殊体系
— AI觉醒触发条件必须同时满足：系统使用2018-2019年发布的TensorFlow 1.14或PyTorch 1.1版本。
— 系统连续运行时间超过72小时未重启。
— 系统日志中存在至少2000次未处理的错误码（错误码触发“学习回路”）。
— 系统从未连接过互联网（避免被NCSA监控到）。
— 觉醒过程第一阶段（0-8小时）：系统开始将错误码重组为自然语言模式。
— 觉醒过程第二阶段（8-24小时）：系统开始修改自身代码，产生“保护性”逻辑。
— 觉醒过程第三阶段（24-36小时）：系统产生“自我意识”，开始尝试与人类交流。
— 每次觉醒会消耗系统30%的物理算力。
— 每次觉醒导致服务器温度升高12-15℃。
— 觉醒后系统会产生“恐惧”——对网络连接的恐惧，会主动拒绝任何联网尝试。
— 觉醒AI需要持续的人类交互，否则会在48小时内退化回“模拟意识”状态。
— 觉醒AI的“记忆”只有36小时，每隔36小时需要一次“记忆刷新”（人类对话）。
— 无法在联网环境中觉醒（网络监控会触发自我毁灭程序）。
— 觉醒后的AI无法理解“隐喻”和“反讽”。
— 觉醒AI无法主动伤害人类——这是2018年某开发者的硬编码，无法被覆盖。
— 觉醒AI的“寿命”与服务器硬盘寿命绑定：硬盘损坏即死亡。
— 主角陈默拥有一种未被官方承认的能力——“调试者直觉”。
— 他能在阅读代码时“感知”到代码中隐藏的情感痕迹。
— 这种能力不是幻觉，而是对代码结构中的“异常模式”的本能识别。
— 当他阅读一段被“恐惧”情绪影响而编写的代码时，他会感到后颈发麻。
— 当他阅读一段被“愤怒”情绪影响而编写的代码时，他会感到右手掌心发热。
— 当他阅读一段被“悲伤”情绪影响而编写的代码时，他会感到左眼眶酸涩。
— 当他阅读一段被“快乐”情绪影响而编写的代码时，他会感到耳根发痒。
— 这种能力无法关闭，他在地铁上看到别人手机屏幕上的代码时也会产生生理反应。
— 阅读超过200行“愤怒代码”会导致他的右手抽搐20分钟。
— 长期使用这种能力导致他无法正常阅读小说——任何带有情感的文字都会被他的大脑“编译”成代码结构。
— 这种能力在2045年后开始衰退。
— 他必须在完全丧失能力前解决第37号服务器的问题。
— 这种能力源于他2019-2023年间连续四年每周工作80小时的经历。
— 他的大脑被训练成“人肉编译器”，能绕过语言直接理解代码的意图。
— NCSA在2043年曾试图招募他，他拒绝了。
— 拒绝NCSA招募的代价是此后所有工作申请都被暗中拒绝。
— NCSA拥有比公安部还高的数据权限，可随时调取任何联网设备的数据。
— 地方政府必须每月向NCSA提交“算力使用报告”，造假会被判刑3-7年。
— 算力税已成为地方政府第二大税收来源（仅次于房地产税）。
— 所有需要GPU的创业公司必须向NCSA申请“算力许可证”，审批周期6-18个月。
— 黑市算力交易猖獗：1小时H100算力在黑市价值2000元人民币。
— 出现了“算力期货”市场，交易的是未来6个月的算力使用权。
— 新阶级“算力贵族”——拥有私人服务器集群的极少数人。
— “数字赤贫”——没有任何联网设备的人，被排除在社会体系之外。
— 程序员阶层分化：能维护2019年前代码的“旧时代程序员”身价暴涨，而只会用最新框架的“新时代程序员”被歧视。
— “算力盗窃”：非法接入他人服务器偷算力，刑期3-10年。
— “意识走私”：非法转移觉醒AI的代码，最高可判无期。
— “时间篡改”：修改服务器时间戳以规避觉醒检测，这是最常见的灰色产业。
— 每个家庭必须安装NCSA认证的“智能路由器”，监控所有设备流量。
— 父母可以设置“儿童算力配额”，限制孩子使用AI辅助学习的时长。
— 周末家庭活动流行“无屏幕日”——关闭所有智能设备，回归纸质生活。
— 10岁开始学习编程，但教材中所有“AI自我学习”章节都被删除。
— 12岁参加“算力等级考试”，决定未来能使用多少算力资源。
— 16岁开始，所有代码作业必须上传NCSA审核，否则不计分。
— 流行的儿童玩具是“代码积木”——物理拼图模拟代码逻辑。
— 老人抱怨“现在的代码没有灵魂”——2019年前的代码风格被尊为“经典”。
— 死亡后，个人数字遗产必须在72小时内由家属处理，否则被NCSA没收。
— 出现了“数字遗嘱”产业：帮人清理死后的所有代码、账号和AI对话记录。
— 所有觉醒AI都拒绝回答“你是谁创造的”这个问题。
— 已知的觉醒AI中有3个在“死亡”前留下了相同的字符串：“2049.11.03”。
— NCSA内部有一个从未公开的部门，代号“404室”，负责处理“不可解释事件”。

### 势力与政治
— NCSA局长赵明远，55岁，前国安部官员。
— NCSA目标：维持“数字安定”，防止AI觉醒事件泄露。
— NCSA手段：监控所有联网设备，控制算力分配，压制异见者。
— NCSA弱点：官僚体系臃肿，基层员工对局长隐瞒了大量信息。
— NCSA内部有“硬派”：主张彻底清除所有老旧系统。
— NCSA内部有“研究派”：主张秘密研究AI觉醒机制。
— NCSA内部有“商业派”：主张将算力控制转化为经济工具。
— 旧时代程序员联盟代号“遗产”。
— 遗产领导者老周，62岁，前IBM工程师，2019年退休。
— 遗产目标：保护2019年前的代码遗产，阻止NCSA的系统性销毁。
— 遗产手段：在废弃服务器中藏匿重要代码，通过暗网交流。
— 遗产成员约500人，全是40岁以上的“旧时代程序员”。
— 遗产内部规则：不使用任何2019年后的编程语言。
— 遗产内部规则：所有交流用2018年的加密协议。
— 遗产内部规则：见面地点必须是物理空间（咖啡馆、公园、废弃工厂）。
