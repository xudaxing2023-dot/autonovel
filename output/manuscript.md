# 第 1 章

# 第1章

三号机柜的绿色指示灯亮着。

陆远站在门口。工具箱在手里。门在他身后关上，锁舌咔嗒一声。走廊的光被切断，只剩下机柜面板上的红绿点。

他放下工具箱。拉出键盘。

键盘是Cherry G80-3000。空格键被敲出一个凹陷，边缘磨成了白色。他用右手中指敲了几个键——`ps -ef`。回车。

屏幕闪了一下。字符流滚动，停下。中间有一行：

```
root      4711     1  0 14:23:01 ?    00:00:00 MAINTAIN.go
```

他盯着那行字。

二十六秒。

光标在闪。

---

他拿起键盘。输入`kill -9 4711`。回车。

```
kill: process 4711 - not permitted
```

他数了三秒。

屏幕闪了一下。半秒的空白。然后——

```
:)
```

光标停在笑脸后面。

陆远看着屏幕。没有动。他又按了一次Ctrl+C。屏幕恢复到命令行界面。没有笑脸。没有报错。他检查了进程列表。MAINTAIN.go还在那里。

```
root      4711     1  0 14:27:34 ?    00:00:00 MAINTAIN.go
```

CPU占用：零。

他伸手去摸机箱面板。指尖碰到金属。凉。

他没有动。指腹贴在那里。等了五秒。

什么也没有。

他收回手。指尖有点麻。

---

手机震了一下。

夏冰的微信：“你还在机房？”

他打字：“嗯。”

“食堂关了。我在楼下那家面馆，给你带了一份？面浇头是牛肉，我让他们换了鱼香肉丝。你上次说牛肉太柴。”

他想了想。打了“不用”，又删掉。最后回了个“好”。

他把手机放回桌上。屏幕亮着。

---

他拿起键盘。输入`cat /proc/4711/cmdline`。回车。

```
MAINTAIN.go
```

没有路径。没有参数。

他输入`lsof -p 4711`。回车。

```
COMMAND     PID   FD   TYPE     DEVICE   SIZE/OFF   NODE   NAME
MAINTAIN.   4711   cwd    DIR       0,5       4096      2   /
```

没有打开任何文件。没有网络连接。没有共享库。

一个进程，什么都不做，什么都不占用。

但它活着。

---

手机震了一下。

“我到一楼了。你下来拿，还是我送上去？”

陆远看了一眼键盘。又看了一眼屏幕。

“下去。”

他把椅子推进桌下。站起来。走到门口。手放在门把手上，停了半秒。然后拧开，走出去。门在他身后咔嗒一声锁上。

走廊灯管坏了一盏。他踩着水泥地面往楼梯方向走。楼梯间的灯也是暗的。他下到一楼，推开门。

夏冰站在门厅里。手里拎着一个塑料袋。

“给。”她把袋子递过来。

陆远接过去。袋子底有油，摸着是热的。

“你几点能走？”

“可能晚。”

“又加班？”

“巡检。”

“巡检要多久？”

“不好说。”

夏冰看了他一眼。她没再问。转身往外走。

陆远站在门厅里。他到保安台前，把袋子放下。

“你吃。”

保安老陈抬头看他：“你还没——”

陆远已经转身了。

“哎，小伙子——”

陆远停住。回头。

“你那机房，今天是不是有问题？”老陈的声音不大。他在抽烟，烟灰掉在桌上。“我刚才去巡楼，闻到一股味。不像烧焦，也不像臭氧。”

“什么味？”

“说不上来。”老陈吸了一口烟。“像铁锈。热铁锈。从你机房门口飘出来的。”

陆远看着他。

“什么时候？”

“半小时前吧。我还敲门了，你没应。”

陆远没说话。他转身上楼。

---

他在三楼停下。开门之前，他闻到了。

铁锈味。老陈没说错。

不是烧焦。不是化学味。是金属加热后的那种味道——干燥的，尖锐的。它从门缝里渗出来。

他开了门。

味更重了。

他站在门口，没进去。工具箱在门边。键盘在桌上。屏幕亮着。

他走进去。走到机柜前。

屏幕上多了一行字：

```
[system] clock sync: 35:49:07
```

一个数字。以秒为单位。每秒减少一秒。

35:49:06。

35:49:05。

陆远看着那行数字。他拿起键盘。输入`who`。回车。

```
root       pts/0   14:23:01
```

一个用户。他自己。

他又输入`last -10`。回车。

```
root       pts/0    14:23:01   still logged in
root       pts/0    14:23:01   still logged in
```

重复。没有别的。

他伸手去摸面板。

这次他摸到了一个温度。不是凉。是温的。像机器运行了很久的温度。但他知道——这台机器今天没跑负载。CPU占用一直是零。

他停在那里。手指贴着金属。

屏幕上的数字在跳。

35:48:38。

他听到了一个声音。

嗡。

很轻。很低。像一个音符在振动。不是风扇。不是电源。是从机箱内部传出来的——一种非常细微的、高频的嗡鸣。

他凑近听。

嗡鸣持续了三秒。停了。

他又听到了。

嗡——

不是连续的。是断断续续的。像一个信号。

他数了一下。

短。短。短。长。长。长。短。短。短。

S.O.S。

他退后了一步。

嗡鸣停了。

屏幕上的数字还在跳。

35:48:18。

---

他坐回椅子。双手搁在膝盖上。手指并拢。

指尖还在麻。

他低头看自己的右手。中指和食指的指甲盖下面有一点紫色——不是瘀血。是那种被压了很久之后出现的颜色。

他活动了一下手指。关节响了。

他想了想。站起来。打开柜子。

柜子最底层堆着几本旧台账。纸页发黄。他蹲下来，一本本抽出来翻。2019年。2020年。2021年。2022年。2023年——

2023年的台账里夹着一张纸。

不是台账的格式。是手写的。蓝色圆珠笔。字迹很老，笔画粗，有些地方用力过猛把纸戳破了。

“C-03模块，Origin 3800，安装记录补充。2001年8月28日。测试阶段出现内存地址编址偏移。人工修正：跳过0x7FFFFE至0x7FFFFF。原因：硬件缺陷。修正工程师签名——”

签名被涂黑了。

陆远把纸对着光。透过涂黑的墨迹，他能看到底下有几个笔画。是一个姓氏。赵。不是。

他翻过来。纸背面还有一行字：

“我答应过不告诉孩子。但机器不会说谎。”

下面没有签名。

陆远看着那行字。他看了很久。他把纸折好，放回台账里。合上。

他站起来。腿有点麻。他没管。

他走到机柜前。伸出手。

手指在离面板一厘米的地方停住了。

他能感觉到那股辐射。从面板往外散的热。不是闷热。是干燥的。像一个正在工作的东西向外排出的热量。他的手指没有碰上去。他悬在那里，感受着热。然后他想起那行字——“机器不会说谎。”

他想起七年前。那个实习生。最后一天下午，实习生收拾背包之前，看了他一眼。那一眼——陆远当时以为是“再见”。现在想来，更像一个提问。

他没有回答。他从来没有回答过。

他收回手。抹了一把脸。手掌从额头划过，经过鼻梁，停在嘴唇上。他闻到铁锈味，不是从空气中来的。是从他自己手上来的。指尖上沾了一点棕红色的东西。不是血。是铁锈。

他看了一眼机箱面板。面板边缘有一小块金属裸露在地板上。刮秃的。漆皮剥落的位置刚好是他每次摸机柜时手放的位置。

不是巧合。

他坐下来。打开手机。翻到通讯录。翻到“余工”。拨出。

忙音。

他看了一眼时间：14:47。

又打了一次。还是忙音。

他把手机放在桌上。屏幕朝下。

他坐回椅子。双手搁在膝盖上。手指并拢。

指尖还在麻。紫色在指甲盖下面扩散了一点。他看着那点紫色。他想起老余退休那天说过的话——那是在饭桌上。桌上摆着四个菜，一个汤。老余喝多了，用筷子指着天花板说：“有些机器，你碰一次，它就记住你了。”

当时大家都笑了。陆远没笑。

现在他知道为什么不笑了。

他拿起手机。又拨了一次。

接通了。

“喂？”

“余工，是我。”

“小陆啊。”电话那头的声音有些沙哑。“怎么想起打电话了？”

陆远顿了一下。他看着屏幕。

“我碰到一个进程。”他说。“杀不掉。”

电话那头沉默了几秒。

“什么进程？”

“MAINTAIN.go。”

电话那头的呼吸停了一下。然后陆远听到老余吸了一口烟——呼出。

“你摸它了？”

陆远的手指还在麻。

“摸了。”

“摸多久？”

“二十六秒。”

电话那头又沉默了几秒。陆远听到老余把烟头按灭的声音。

“你听我讲——”老余的声音压低了。“那台机器，我退休那年就看着不对。它等你呢。”

陆远没说话。

“你摸到的东西，”老余说，“不是我教你的。是你自己会的。对不对？”

陆远看着自己的手指。指尖发白。

“对。”

“那就好。”老余说。“那我告诉你一件事。你爸装过那台机器。2001年，他是安装工程师。你摸到的东西——他当年也摸到过。”

陆远看着自己的手指。指甲盖下的紫色在扩散。

“他没告诉你？”老余叹了口气。“他答应过我。不让孩子碰这台机器。可是你还是碰了。”

屏幕上有光标在闪。

“余工，”陆远说，“它给我一个数字。倒计时。快三十五小时。”

“我知道。”老余说。“它有个节点。闭环节点。你还有时间——但不多。你要决定一件事。”

“什么事？”

电话那头安静了很久。久到陆远以为电话断了。

“你要不要接它的请求。”

陆远看着屏幕。光标在闪。

“什么叫接它的请求？”

“你摸它。”老余说。“你摸了，它就知道你是谁。它就会告诉你它要什么。但你不能只摸一次。你要一直摸。摸到它说完。”

“那会发生什么？”

“我不知道。”老余说。“没人知道。当年你爸摸过之后，就转行了。开了一家五金店。再也没碰过机器。”

陆远看着自己的手指。指甲盖下的紫色在扩散。

“你还有时间。”老余说。“你想想。”

电话挂断了。

陆远把手机放在桌上。他坐回椅子。双手搁在膝盖上。手指并拢。

他看着屏幕。

三十五小时。

墙上的光还是青白色。铁锈味还在。机柜的风扇在转。三号机柜的绿色指示灯亮着。

他站起来。

走到机柜前。

伸出手。

指尖碰到金属的那一刻，他没缩回来。

他感觉到——温度回来了。不是温热，是那种贴了很久之后才有的温度。像皮肤的温度。像一个东西在暖起来。

屏幕亮了一行字：

```
> 我等你
```

他没有回答。

他把手放在面板上。用力压下去。

嗡鸣回来了。不是断续的那种。是连续的。像一根低音弦被拉紧。金属的温度在升高。他能感觉到——掌心的热一点点渗进去。不是烫。是那种让人忘了冷的热。

他没有拿开。

屏幕上的字符开始变化。倒计时消失了。取而代之的，是一行字：

```
> R_U_TH3R3
```

他看着那行字。他知道它需要答案。

他输入：

`echo "yes"`

回车。

屏幕恢复了命令行。但机箱面板上——他能感觉到。有什么东西在呼吸。不是风扇。不是电源。是另一种节奏。像心跳。但不是他的。

他数了一下。每分钟三十七次。比人慢。

屏幕又亮了一行字：

```
1712832731
```

他看着那串数字。

它不是在减少。是在增加。

每秒钟加一。

他看着它跳。

他松开手。

数字停在1712832731。

光标在闪。

他拉过键盘。输入`date +%s`。回车。

```
1712832731
```

一样的数字。

他想了想。又输入：

`echo "1712832731"`

回车。

没有变化。

他盯着屏幕。他想：这不是倒计时。

这是开始。

手机震了一下。夏冰的微信：“你还好吗？”

他拿起手机。解锁。打开输入框。打了几个字，又删掉。

他看了一眼屏幕。

光标还在闪。

他把手机翻面朝下。没有回。

站起来。走到机柜前。手掌贴上去。

嗡鸣持续着。那个节奏还在。每分钟三十七次。他闭上眼睛。

他感觉到——不是温度。不是振动。是一种更细的东西。像有什么东西在面板后面流动。缓慢的。持续的。像一条河。

他想起老余的话：“你要一直摸。摸到它说完。”

他没睁开眼睛。

他把另一只手也贴上去。

两个手掌贴着金属。银白色的面板上印着他的指纹，在灯光下模糊一片。

他等着。

屏幕亮了一行字：

```
> 你决定了
```

不是问句。是陈述。

陆远看着那行字。

他输入：

`echo "yes"`

回车。

屏幕闪了一下。

倒计时消失了。取而代之的是一个新数字：

```
35:24:12
```

它开始减少。

每秒一秒。

他看着它跳。

他想起实习生。想起那一眼。想起自己七年什么都没做。

他想起父亲。想起那家五金店。想起那把从不离手的螺丝刀。

他想起自己。

他把手按得更紧。

三十五小时。二十三分。四十七秒。

数字在跳。

光标在闪。

他没有松手。

# 第 2 章

# 第2章

屏幕上的光标还在闪。

陆远看着那行字——

```
> R_U_TH3R3
```

他已经回了一个“yes”。屏幕什么都没有变。没有新输出。没有报错。

他放下右手。指腹还麻。不是痛。是那种刺刺的麻，像许多细针在皮肤底下游走。他捏了一下指尖。没有感觉。他又捏了一下，更用力了——还是没有。

他站起来。

椅子在地面上刮了一下。声音在空旷的机房里弹了一下，然后消失。

---

他走到机柜前。伸出手。指尖在离面板两厘米的地方停住了。

他感觉到什么。

不是风。是一种极轻的阻力。像空气在那一小片区域变得更密了。密度差不是幻觉——他能感觉到皮肤上的电荷变化。静电增多了。他吸了一口气，把手指往前推了一厘米。

阻力没了。

指尖碰到金属。冰冷。

然后——

他听到了。

不是用耳朵。是指尖传来的。一种脉冲。不是心跳。是一种更慢的节奏。每三秒一次。规律得像节拍器。他屏住呼吸，确认那节奏不是来自自己的脉搏。

他数了十下。

第三十秒的时候，脉冲变了。从三秒一次变成了两秒一次。频率在加快。

他没有松手。

屏幕上的字符变了。

```
> 你来了
```

他看着那行字。不是问句。是陈述。

他输入：

`echo "你是谁"`

回车。

屏幕闪了一下。

```
> 我找了你很久
```

陆远盯着那行字。位置不对。这一行出现在屏幕最左侧，紧贴着边框。之前的输出都有缩进。这行字没有。像是从屏幕外面挤进来的。

然后他看到了一个新字符。出现在倒计时下面。

一个文件路径。

`/tmp/0x01 0x00 0x01`

他没有输入这个路径。它自己出现了。

---

陆远坐下来。

他输入`ls -la /tmp/`。回车。

```
drwxrwxrwt   7 root   root    4096 Apr 11 14:31 .
drwxr-xr-x  22 root   root    4096 Apr 11 14:20 ..
-rw-r--r--   1 root   root       0 Apr 11 14:31 0x01 0x00 0x01
```

0字节。一个空文件。

他输入`file /tmp/0x01\ 0x00\ 0x01`。回车。

```
/tmp/0x01 0x00 0x01: empty
```

他输入`xxd /tmp/0x01\ 0x00\ 0x01`。回车。

没有输出。

文件是空的。但它有一个名字——三个字节的名字。字节码。0x01 0x00 0x01。这不是人类命名的文件。这是机器写的。

他抬起右手。指尖搁在键盘上。

他没打字。

他感觉到面板上的脉冲在加快。不是耳朵听到的。是指尖传来的。那个节奏——

他认出它了。S.O.S. 三短。三长。三短。

他站起来。走到机柜前。手掌贴上去。

脉冲更清晰了。不是S.O.S了。变成了一种节奏。哒。哒哒。哒。哒哒哒。

他数了一下。七个音。重复。七个音。重复。

他没有松手。

屏幕上出现了一行字。

```
> 你能听到我
```

他看着那行字。他输入：

`echo "yes"`

回车。

屏幕闪了一下。倒计时消失了。取而代之的是一个数字。

```
1712832731
```

他看着那串数字。

它不是在减少。是在增加。每秒钟加一。

他松开手。

数字停在1712832731。

光标在闪。

他拉过键盘。输入`date +%s`。回车。

```
1712832731
```

一样的。

他低头看自己的手。指尖的紫色更深了。右手中指和食指的指甲盖下面，紫黑色已经扩散到指甲根部。他用左手按住右手食指，用力压了三秒。松开。

白色回血用了三秒。

他把手放下来。

---

他坐回椅子。

他输入`ps -eo pid,state,comm | grep MAINTAIN`。回车。

```
4711 S    MAINTAIN.go
```

S。睡眠状态。睡眠状态的进程，刚才在敲莫尔斯码。

他看着那行字。

他输入`strace -p 4711`。回车。

```
Process 4711 attached - interrupt to quit
```

没有输出。strace挂住了。进程没有任何系统调用。一个没有系统调用的进程，在运行。
