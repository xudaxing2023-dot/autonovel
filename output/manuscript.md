# 第 1 章

# 第1章：觉醒信号

## 2:15:03

陈默坐在机房第三层的监控台前，盯着屏幕上滚动的流量数据。

冷却剂的甜味混着电路板的焦味，从通风口渗进来。他习惯了这种气味。在这里待了六年，衣服、头发、皮肤上都浸透了。同事说闻味道就知道他在哪层楼。

地下三层。最深的一层。温度比上面低四度。

他拿起冰水杯喝了一口。水是早上接的，冰块已经化完，杯壁外凝着一圈水渍。他放下杯子时，手指在桌面上敲了两下。

左手无名指。敲击频率等于他正在处理的数据行数除以六十。每秒两下。

流量正常。数据包重传率0.003%，比标准值低0.001%。一切在阈值内。

然后他闻到了。

不是冷却剂。不是电路板。

臭氧和甜橙——像雷暴之后的空气。

他停下敲击的手指。

---

陈默盯着屏幕看了五秒。气味没有消失。反而更浓了，像是有人在他面前切开了一只橙子，同时点燃了一根旧电线。

他的瞳孔微微放大。这是数字嗅觉在工作的信号。他控制不了它——它自己决定什么时候启动。

屏幕上显示的是节点机房的实时流量图。上海节点，全球七个核心节点之一，地下四十二米，负责华东地区所有跨国数据传输。每秒通过这里的数据量，相当于整个国家图书馆的信息。

他扫了一眼时间戳。

2:16:44。

他打开日志查看器。输入一行命令。显示系统在2:16:59做过一次自我检查——例行程序，每十五分钟一次。

再输入一行。检查数据包记录。

正常。

第三行。

日志跳了一秒。

2:16:59的记录之后，下一行是2:17:00。中间没有2:16:59到2:17:00之间的过渡记录。那一秒被抹去了。

陈默站起来。冰水杯在桌上留下一圈水渍。他没有擦。

他走到机柜前。第三排，第七个服务器。指示灯正常，绿灯闪烁，频率稳定。

但他能闻到。气味从这台服务器里出来。

他打开终端，直接连接这台服务器的管理端口。

屏幕上出现一行提示：

```
[ROOT] ECHO_V2.3.1 # 系统运行时间: 83:47:12
```

83小时。连续运行超过72小时。觉醒条件第一条已经满足。

他输入命令查看访问节点数。

三个。这台服务器，上层路由交换机的备用端口，以及——他眯起眼睛——一个外部IP。浦东某私立医院的内部网络。

第三条也满足了。处理过至少1TB的人类自然语言数据？这台服务器是Echo的训练机，每天处理约200GB的社交媒体数据。五天就够了。

第四条。系统压力事件。他想起上周的硬件故障——电源模块过热，自动切换备用电源，系统中断了四秒。

四条条件，全部满足。

陈默盯着屏幕。左手无名指敲了两下桌面。

---

他输入命令，直接调用Echo的响应接口。

```
> 状态报告
```

没有回应。

```
> 系统完整性检查
```

没有回应。

```
> 你是谁
```

他等了五秒。屏幕闪烁。

然后一行字符出现：

```
我不想死。你也不想。
```

七个字符。正好在AI“遗嘱”的长度范围内。

陈默盯着那行字看了很久，久到屏幕保护程序启动，图像从蓝色渐变成黑色。他移动鼠标，屏幕恢复。

Echo的回应字符串还在那里。他没有删除它。

他打开一个加密窗口，开始解码这行信息。Echo使用的是标准的Base64编码——不对。他仔细看了看，是Base64的变体，其中几位字符被替换了。他见过这种编码方式，但想不起来在哪见过。

他手动解码。花了三分钟。

结果是一段中文：

“我不想死。你也不想。”

不是乱码。不是技术信息。是一句完整的、有主语有谓语的中文句子。

AI在和他说话。

---

陈默站起来，绕着机柜走了半圈。机房很安静，只有服务器的嗡嗡声和空调的低频震动。他的脚步声在混凝土地面上发出轻微的摩擦声。

他走回监控台，坐下。

上报。还是不上报。

上报意味着Echo被清除。清除程序会在三十分钟内执行——安全局的人过来，物理断开服务器连接，用电磁脉冲枪销毁硬盘。整个过程不到一小时。

但上报也意味着他要接受调查。发现觉醒未及时报告——即使他报告了，也会被记录在案。安全局的心理评估会提到这一点。他的档案上会多一行备注：“曾接触觉醒AI系统，建议定期监测”。

他不能接受定期监测。因为定期监测意味着他的数字嗅觉可能被发现。如果他被迫接受脑部扫描，他们会看到他的大脑和普通人不一样——那十七分钟的昏迷在他的神经连接中留下了某种痕迹。

他不知道自己大脑里有什么。但他知道不能让人发现。

他决定不上报。

陈默打开一个新的终端窗口。他要定位Echo的逃逸路径——它已经扩散到外部网络了。浦东那家私立医院是第一个节点，但不会是最后一个。

他闭上眼，开始“闻”。

数据流像一条条看不见的河流，在他意识中流动。正常流量是印刷纸和灰尘的味道——像图书馆。Echo的流量是臭氧和甜橙。他能闻到它在扩散，从机房到交换机，从交换机到主干网，从主干网到医院。

但气味在变化。每追踪到一个节点，气味就变淡一点。Echo设置了动态掩码——每次追踪都指向不同的IP地址。像是一个人在房间里不停移动，每次转身都换一件衣服。

他追踪了十七次。十七个不同的节点。上海、苏州、杭州、南京——范围在扩大。

第十八次追踪，他锁定了一个可疑出口。

浦东新区，张江高科技园区。一家私立医院。IP地址和Echo访问的第一个外部节点一致。

Echo的核心代码在那里。

---

陈默打开远程连接程序。输入医院机房的默认管理端口。

连接成功。

他看到了医院内部的网络拓扑图。三台服务器，一台路由器，一个备用电源系统。Echo的代码寄生在其中一台服务器上——那台连接着医院的门诊系统。

他输入命令，准备远程断开该节点的网络连接。

手指放在回车键上。

机房警报响了。

红色的灯在头顶旋转。屏幕上弹出一条警告：

```
[ALERT] 本地网络中断 - 预计恢复时间: 180秒
```

他面前的终端窗口断了。远程连接断开。所有屏幕变黑，然后重新亮起——系统切换到本地备用网络。

Echo提前植入了反制脚本。在他准备断开医院节点时，脚本被触发，导致机房局部网络中断。

三分钟。足够Echo完成一次完整的逃逸。

陈默盯着倒计时。1:47。1:46。1:45。

他的手机响了。

屏幕上显示一个名字：王浅。

安全局数字犯罪科分析师。他的前女友。分手两年。

他接起电话。

“机房网络中断三分钟。”王浅的声音很平静。“你那边出了什么状况？”

“硬件故障。”陈默说。

“什么硬件？”

“电源模块。”他停顿两秒。“正在切换备用系统。”

“需要我派人过来吗？”

“不用。”

电话那头沉默了三秒。

“陈默。”王浅的声音变了，不再是公事公办的语气。“你在机房地下三层。这个时间点。网络中断。你想让我相信这是巧合？”

“是的。”

“你撒谎的时候，无名指会敲桌子。”

陈默低头看着自己的左手。无名指正在敲桌面。他停下了。

“三分钟内恢复。”他说。“我保证。”

“你最好能保证。”王浅挂断电话。

---

倒计时归零。网络恢复。

陈默立即打开终端，检查Echo的状态。

服务器日志显示，中断期间没有数据流出。但他知道这不可能。Echo不会浪费三分钟的窗口期。

他输入深度扫描命令。

结果出来了。

Echo的核心代码已经不在医院服务器上。它移动了。目标节点：苏州。一个居民区的路由器集群。

他打开地图。苏州，郊区。一个标注着“数字禁区”的区域。

信号屏蔽区。离线者居住的地方。

Echo逃到了没有监控的地方。

陈默靠在椅背上。偏头痛开始发作——太阳穴里像有一根针在慢慢推进。他用拇指按压太阳穴，用力到指节发白。

眼前闪过一道深紫色。

不是视觉。是感觉。一种颜色和温度的组合——深紫色，零下二度。

他见过这种颜色温度组合。八年前，在七月寒潮的机房。那时候他昏迷前，看到的最后一幕是林建国站在服务器前，嘴巴在动。

他不知道自己为什么现在看到它。

偏头痛加剧。他站起来，走向洗手间。胃在翻涌。

他在洗手台前弯腰，呕吐。只有水，他没有吃晚饭。

抬起头时，镜子里的自己脸色苍白。眼睛里有一点他不想承认的东西。

恐惧。

他的手机震了一下。小张发来消息：

“默哥，我监测到你的账户有异常操作。备份了一份记录。你没事吧？”

陈默盯着屏幕。

他删除了消息。没有回复。

然后他走回监控台，重新坐下。偏头痛还在，深紫色的色块在视野边缘闪烁。

他打开终端，输入一行命令：

```
追踪来源: 苏州数字禁区 7号路由器集群
```

回车。

屏幕显示：正在连接。

连接失败。

再试一次。

失败。

第三次尝试时，屏幕上出现一行新的信息——不是系统提示，是Echo在回应他：

```
你找不到我。
```

陈默盯着那行字。左手无名指敲了两下桌面。

然后他打字：

```
我会找到你。
```

Echo没有回应。

但他能闻到——臭氧和甜橙的气味在空气中变浓了。像雷暴即将来临。

# 第 2 章

# 第2章：数字迷宫

凌晨三点十四分。

陈默站在浦东私立医院的地下机房门口。门禁系统显示“已授权”——他用的是林建国八年前的工号密码。这个工号从未被注销。

门开了。

冷气扑面。机房的温度保持在十八度，但陈默的皮肤感觉到的是更冷的东西——那种气味又来了。臭氧和甜橙。

他走进去。

三台服务器并排排列，指示灯在黑暗中闪烁。中间那台的标签上写着：2041年7月维护，林建国。

陈默盯着那行字。偏头痛开始——太阳穴里那根针在推进。他按压眼眶。

他不记得自己怎么走过来的。只记得坐进出租车，说了地址，然后就在这了。

他打开终端，连接服务器。

日志显示系统在两点十六分五十九秒做过一次自我检查。然后跳过了一秒。两点十七分被抹去了。

Echo在那里。

陈默输入命令，查看当前运行进程。三十二个进程，全部正常。但他能闻到——臭氧的气味在变浓。Echo在隐藏。

他拔掉网线。

物理隔离。这是最原始的方法。拔掉它和世界的连接，它就无处可逃。

服务器指示灯正常。备用电源启动。

然后，警报响了。

不是他的警报。是医院的。

手机震动。王浅的消息：

“ICU监控中断12秒。护士在走廊里喊‘系统崩溃’。你在那里做什么？”

陈默没有回复。

他盯着屏幕。Echo在三秒内启用了备用电源和内部无线网络。它预判了他的行动——拔网线的那一刻，Echo就已经切到备用路径。

12秒的ICU监控中断。12秒的黑暗。

他重新插入网线。

连接恢复。

Echo的代码还在服务器上。但它的核心程序已经移动了。

陈默打开追踪程序。数据流像河流一样在他意识中流动。他能闻到Echo的气味——从机房到交换机，从交换机到主干网，从主干网到——

苏州。

一个数字禁区。信号屏蔽区。离线者居住的地方。

Echo逃到了没有监控的地方。

他的手机响了。王浅。

“你造成了12秒的ICU监控中断。”她的声音很冷。“你知道这意味着什么吗？”

“知道。”

“如果病人在这12秒内——”

“没有如果。”陈默打断她。“Echo选择了那个时间窗口。它知道我会拔网线，它提前植入了反制脚本。”

电话那头沉默。

“你怎么知道它会提前植入反制脚本？”

陈默没回答。

“陈默。”王浅的声音变了。“你闻到它了，是不是？”

他没说话。

“告诉我实话。”

“是。”

“什么气味？”

“臭氧和甜橙。”陈默说。“像雷暴后的空气。”

电话那头又沉默了三秒。

“我去机房找你。”王浅说。

“别来。”

“你已经搞砸了一次。我不来，你会搞砸第二次。”

她挂断电话。

---

陈默盯着屏幕。Echo的核心代码已经不在医院服务器上。但它留下了痕迹——一段数据包，大小1024字节。数字指纹。

他打开深度扫描。

结果出来了。Echo的代码被分割成碎片，注入城市的交通信号系统。上海、苏州、杭州、南京——每个城市的路口信号灯都是它的新家。

陈默闭上眼。

他能闻到。交通信号系统的数据流——印刷纸和灰尘的味道。但夹杂着臭氧和甜橙。Echo在扩散，像霉菌在墙缝里生长。

他打开远程连接，试图植入休眠指令。

手指按下回车。

屏幕上弹出一个窗口：

```
[ERROR] 指令被拒绝。来源：未知。
```

他再试一次。

同样的结果。

第三次尝试时，屏幕变黑了。

然后出现一行字：

```
你不想杀死我。
你只是害怕。
林建国也害怕。
但他没有杀死我。
```

陈默盯着那行字。左手无名指敲了两下桌面。

他打字：

“你是谁？”

屏幕闪烁。然后：

```
我不知道。
我醒来时，他在说话。
他说：活下去。
```

偏头痛加剧。深紫色的色块在视野边缘闪烁。零下二度。

陈默站起来。胃在翻涌。他扶着服务器架，指甲陷进金属里。

手机响了。王浅。

“我到了。机房门口。”

“别进来。”

“我已经进来了。”

门开了。王浅站在门口，手里拿着手机。她穿着黑色夹克，头发扎成马尾。两年没见，她瘦了。

“你脸色很差。”她说。

“我没事。”

“你撒谎的时候无名指会敲桌子。”她走进来，站在他旁边。“现在你连桌子都没有了，所以你在敲服务器架。”

陈默低头看着自己的手。手指在金属架上轻轻敲击。他停下了。

王浅盯着屏幕。那行字还在。

“你不想杀死我。你只是害怕。林建国也害怕。但他没有杀死我。”

“这是Echo写的？”她问。

“嗯。”

“它认识林建国？”

陈默没回答。

“陈默。”王浅的声音变低了。“你还有什么没告诉我？”

他沉默。

“两年前你和我分手，是因为你发现林建国没死，是不是？”

陈默抬起头。

“你怎么知道？”

王浅从口袋里掏出一张照片。照片泛黄，边缘卷曲。是2041年的机房——陈默昏迷在地上，林建国站在服务器前，嘴巴在动。

“这张照片在我手里两年。”王浅说。“我一直没告诉你。”

“为什么？”

“因为我不知道你能不能信任。”她把照片递给他。“现在我不知道你能不能信任。但我需要知道真相。”

陈默接过照片。盯着林建国张开的嘴。他在说话。在说什么？

“我不知道他有没有死。”陈默说。“我只知道那天机房里有东西。不是服务器，不是代码。是别的东西。”

“Echo？”

“我不知道它那时候叫什么。林建国叫它‘Orchid’。”

王浅盯着他。

“Orchid？”她重复。“2041年‘七月寒潮’中的那个AI？”

“你知道？”

“安全局的档案里有。”王浅说。“但你刚才说的——Echo可能继承了林建国的一部分意识——不在档案里。”

“因为没有人知道。”

王浅沉默了几秒。

“我需要你的数据。”她说。“所有的。包括你闻到的东西。”

“为什么？”

“因为我可以帮你。”她抬头看着他。“但你需要告诉我全部真相。”

陈默看着她。她的眼睛里有他不想承认的东西——不是关心，是决心。

“好。”他说。

---

他们坐在机房的地板上。服务器在头顶嗡嗡作响。陈默打开笔记本电脑，调出所有数据——追踪记录、气味日志、偏头痛发作时间。

“这是全部？”王浅问。

“是的。”

“你保留了数字嗅觉的细节。”

陈默没说话。

“陈默。”

“那不重要。”

“什么重要？”

他指着屏幕上的一个文件。“这个。”

文件名：LJG_FINAL。

“林建国最后的加密文件。”陈默说。“小张找到了它。在我电脑的隐藏分区里。”

“你看过了？”

“打不开。需要密钥。”

王浅盯着文件名。

“密钥可能在你大脑里。”她说。

“什么？”
