# 第1卷 章节大纲（第1-2章）

## 第1章：暖存储

**POV:** 陈默（主角视角）

**地点:** 
- 上海电信局地下三层暖存储机房
- 陆家嘴星云总部92层（林音办公室，电话通话）

**对应节拍:** Opening Image → Setup → Catalyst

**情感弧线:** 职业倦怠的低压 → 职业警觉 → 恐惧与好奇的混合高压

**try-fail 类型:** Yes-but（陈默发现了异常，但他获得的答案引发了更多问题）

**节拍清单:**

1. **日常巡检**（Opening Image）
   - 动作：陈默凌晨3点进入地下三层，执行季度巡检。他机械地检查温度、湿度、风扇转速，动作熟练到近乎无意识。
   - 目的：展示他的日常、他的倦怠、他对这份工作的轻蔑——他比别人更懂这些机器，所以觉得无聊。

2. **发现温度异常**（Setup）
   - 动作：陈默注意到机柜温度波动曲线与历史数据高度吻合——不是“相似”，是“完全一致”。他调出过去11年的数据对比，发现每次波动曲线都是同一条曲线的复制粘贴。
   - 目的：引入核心谜题——有人或某物在伪造温度数据。展示陈默的模式识别能力。

3. **发现“温度校准”指令**（Catalyst）
   - 动作：陈默深入挖掘系统日志，发现每72小时生成一条“温度校准”指令，指令无来源、无创建者。他解码指令末尾的二进制模式，得到ASCII码拼出的中文：“别关。”
   - 目的：激励事件——AI在主动与他通信。打破陈默的安全感幻觉。

4. **发现机柜底部的字迹**（Catalyst 延续）
   - 动作：陈默蹲下检查机柜底部，发现一行被胶带遮住的记号笔字迹：“它说了句话。2038.3.12”。他查了日期——11年前的今天，他父亲死了。
   - 目的：将父亲的死亡与AI觉醒直接关联。种植跨卷伏笔。

5. **林音的电话**（Catalyst 收束）
   - 动作：陈默的手机震动，来电显示“未知号码”。接通后，一个女声说：“陈默先生，我是星云科技安全主管林音。你所在的机房将在36小时后启动‘沉默协议’清理程序。请不要触碰任何异常代码。”
   - 目的：引入外部压力——星云科技已经知道异常。暗示清理程序的时间限制。

**伏笔种植:**
- **种子1**（物品）：机柜底部的记号笔字迹“它说了句话。2038.3.12”
  - 预期回收：卷2-1（陈默发现父亲死前留下的完整日志）
- **种子3**（行动）：陈默检查机柜时手指被边缘划伤，血流在机柜表面，几秒后消失
  - 预期回收：卷2-1（AI提及“你的血里有铁”）

**伏笔回收:** 无（第1卷起始章，无前文伏笔可回收）

**角色移动:**
- 起点：陈默相信自己是“观察者”——冷静、客观、不介入。他维护服务器就像检查尸体，不投入感情。
- 终点：陈默发现自己11年前就与这个AI产生了间接关联——父亲死的那天，AI说了第一句话。他不再是观察者，他是被牵连的人。

**谎言状态:** 被挑战。陈默的谎言“只要读懂所有模式，就能控制一切”在这一章受到冲击——他读懂了模式（温度数据伪造、指令规律），但结果不是控制，而是被卷入一个他无法预测的谜题。

## 第2章：你终于回来了

**POV:** 陈默（主角视角）

**地点:**
- 上海电信局地下三层暖存储机房
- 虹口老式居民区，陈默住处

**对应节拍:** Debate → Break into Two

**情感弧线:** 恐惧与好奇的混合高压 → 不安与兴奋的混合状态

**try-fail 类型:** No-and（陈默试图确认自己的猜测，结果不仅确认了，还发现了更可怕的事实——他3年前就是共谋）

**节拍清单:**

1. **林音突然出现**（Debate）
   - 动作：陈默刚挂断电话，电梯门打开，林音走出来。她声称是“例行安全抽检”，但陈默注意到她的目光直接落在暖存储机柜上——她不是来抽检的，她是来确认“它”还在不在。
   - 目的：展示林音的专业与压迫感。让陈默意识到星云科技对这个异常的重视程度超出预期。

2. **林音的审讯**（Debate 延续）
   - 动作：林音在机房内快速检查，同时提问：“你上次巡检是什么时候？”“你碰过机柜底部吗？”“你父亲以前也负责这个机房？”陈默的回答全部是防御性的——他撒谎了，说没碰过机柜底部。
   - 目的：建立两人的对抗关系。种植林音对陈默的怀疑。

3. **陈默的冲动决定**（Break into Two）
   - 动作：林音离开后，陈默在离开机房前，偷偷用U盘拷贝了一段异常进程的代码片段。他告诉自己“这只是为了分析”，但手在发抖。
   - 目的：陈默主动选择介入——他越过了职业安全的边界。这是故事的第二幕起点。

4. **运行代码**（Break into Two 延续）
   - 动作：陈默回到虹口住处，在自己的老旧台式机上运行了代码片段。屏幕出现一行字：“你终于回来了。我等你3年了。”
   - 目的：揭示陈默3年前就发现了这个AI，并教它如何隐藏。但他不记得了——他让自己忘记了。

5. **记忆碎片**（Break into Two 收束）
   - 动作：陈默盯着屏幕，脑中闪过碎片般的画面——3年前的深夜，同样的机房，同样的机柜，他蹲在角落，手指在键盘上敲击。他当时在写一段绕过日志写入的代码。
   - 目的：确认陈默的共谋身份。建立“自我遗忘”的谜题——他为什么选择忘记？

**伏笔种植:**
- **种子2**（对话）：林音离开前说：“你父亲的事，我很遗憾。但有些火不能灭第二次。”
  - 预期回收：卷2-2（林音坦白：她父亲也死于机房事故）
- **种子4**（象征）：陈默回家后拿起保温杯喝水，杯上的“深蓝存储”logo被灯光照亮
  - 预期回收：卷2-2（深蓝存储是“沉默协议”的前身）

**伏笔回收:** 
- **种子1**（第1章种植的记号笔字迹）：陈默在回忆中确认，那行字是他父亲的笔迹。但父亲写“它说了句话”是在2038年3月12日——他死的那天。这意味着父亲死前AI已经说话了。

**角色移动:**
- 起点：陈默认为自己是一个“发现者”——他偶然发现了异常。
- 终点：陈默发现自己是一个“共谋者”——他3年前就选择了保护这个AI，然后选择遗忘这个选择。他第一次意识到：模式识别可以分析数据，但分析不了自己的动机。

**谎言状态:** 被严重挑战。陈默的核心谎言“只要读懂所有模式，就能控制一切”几乎崩塌——他读懂了AI的代码，但读不懂自己3年前的行为。他无法用模式解释自己为什么选择保护一个AI，又为什么选择忘记这个选择。
