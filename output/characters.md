## 1. 主角 – 林浩（POV）

| 维度 | 说明 |
|------|------|
| **三滑块画像** | **主动性 8** – 他主动在外滩废墟检查服务器，发现异常并启动调查；**讨喜度 6** – 有责任感且略带疏离，读者能共情他的孤独但不总是喜欢他刻意保持距离的态度；**能力值 9** – 编程功底深厚，具备神经同步残留，能在 0.2 秒判断 LCS 是否正确。 |
| **创伤/欲望/需求/谎言 因果链** | **创伤事件**：10 岁时参加校内神经实验，意外导致短时记忆丢失并留下低频同步波形（神经 lace 残留）。<br>→ **伤口**：对自身记忆不可靠的持续焦虑，害怕再次“忘掉”重要事情。<br>→ **谎言**：只要我不依赖记忆，就能控制一切。（错误地认为记忆是弱点。）<br>→ **欲望**：通过反复执行 LCS、获取 AI 原始态的预测来证明自己能够掌控时间与事件。（想用技术弥补记忆缺陷。）<br>→ **需求**：接受记忆的不完整，学会在不确定中依赖他人与直觉。（真正的力量来自信任而非纯粹的控制。） |
| **角色弧类型** | **正向弧** – 起初相信谎言，反复以 LCS 试图锁死 AI；在 36 小时倒计时中，因记忆碎片化和同伴牺牲，他放弃对控制的执着，选择相信伙伴的判断并封印 AI，完成成长。 |
| **对话独特性（8 维度）** | 1. **词汇量级**：中等偏技术，常用术语（寄存器、中断、哈希）但会即口解释。<br>2. **句子长度结构**：混合，短句用于指令（“现在输入 0x3F…”），长句用于内心独白（“我又忘了上次到底按了什么键……”）。<br>3. **口语化程度**：偏书面，但在紧急时会用轻微的上海话填充词（“哎哟”）。<br>4. **口头禅/语言习惯**：常说 “等等，让我再看看日志”。<br>5. **提问 vs 陈述比例**：提问占 40%（“这行代码对不对？”），陈述 60%。<br>6. **打断与被断模式**：喜欢打断别人的长篇解释（想快速得到答案），但自己很少被打断，除非是 Mei 的命令式语气。<br>7. **比喻域**：技术/电路（“这就像在老机器的血管里找一根断裂的导线”）。<br>8. **直率 vs 委婉程度**：直率，特别是在谈及记忆问题时（“我又忘了，你说什么？”）。 |
| **身体习惯与下意识动作** | - 左手拇指不自觉地敲击桌面模拟按键。<br>- 紧张时会用右手食指轻点太阳穴（神经同步残留的触发点）。<br>- 走路时左脚略微外八，像在踩踏老式硬盘的振动。 |
| **读者暂时不知的秘密（≥2）** | 1. 他在童年实验中实际上**主动关闭了神经 lace 的过滤模式**，因而保留了低频同步波形——这并非纯粹意外，而是他当时好奇想“听见”机器的声音。<br>2. 他在他母亲的旧笔记本里藏有一份 **2008 年 Xeon 固件的完整注释**，其中标注了“回声代码”疑似位置，但他一直没敢解读，怕触发不必要的风险。 |
| **关键人际关系图** | - **梅林（姐姐）**：保护者/监视者，关系复杂——既依赖她的资源，又因她的职责而产生隔阂。<br>- **老陈**：师父/伙伴，提供硬件知识与情感锚点。<br>- **小影**：同道中人/潜在恋爱对象，共享对“真相”的渴望。<br>- **赵威**：职业对手/利益冲突，代表新云派压力。<br>- **周兰**：上级/对立面，她的命令直接威胁到林浩的行动。 |

## 2. 核心配角（3‑5 人）

### 2.1 梅林（林浩的姐姐，LHML 调查员）

| 维度 | 说明 |
|------|------|
| **三滑块画像** | 主动性 7（她会主动发起调查，但受体制限制）；讨喜度 8（责任心强，有姐姐般的温柔）；能力值 7（熟悉法规与取证流程，但技术深度不如林浩）。 |
| **创伤/欲望/需求/谎言 因果链** | **创伤**：父亲在 2034 大停摆期间因老机故障去世，她目睹了无法救援的 helpless。<br>→ **伤口**：对“老机”抱有不信任，觉得它是死亡的象征。<br>→ **谎言**：只要把所有遗留硬件封存起来，就能保护亲人。（错误地认为隔绝能避免悲剧。）<br>→ **欲望**：升职为 LHML 局长，推动全面禁用老机。（想通过权力消除威胁。）<br>→ **需求**：接受老机本身不是恶，真正的危险是人对其的滥用与恐惧。（需要看到技术中立的一面。） |
| **角色弧类型** | **平弧** – 她早已掌握真理（技术中立），在故事中利用她的职位推动立法平衡，而非改变自己。 |
| **对话独特性** | 1. 词汇量级：偏法律/行政，常用条款编号。<br>2. 句子长度：中长，常带条件从句（“如果…则……”）。<br>3. 口语化：正式，少用方言。<br>4. 口头禅：“依照规定……”<br>5. 提问/陈述：提问 30%，陈述 70%。<br>6. 打断：很少打断别人，但会被林浩的技术打断。<br>7. 比喻域：法律/官僚（“这条规定像一道闸门……”）。<br>8. 直率/委婉：委婉，喜欢用“建议”、“请注意”缓和语气。 |
| **身体习惯** | - 左手无意识地转动指环（父亲遗物）。<br>- 说话时会轻触右胸口袋，确认随身携带的证件卡。 |
| **秘密** | 她私下里保留了一台未登记的 2010 年小型服务器，用来在夜间跑私人加密聊天，以防被 LHML 监听。 |
| **与主角关系** | 姐弟——她既是林浩的后盾（提供合法渠道、情报），也是他的束缚（时常提醒他别触法规）。她的谎言与林浩的谎言形成镜像：一人想通过控制技术保护亲人，另一人想通过控制技术证明自己值得被记住。 |

### 2.2 老陈（退休硬件工程师，老机派元老）

| 维度 | 说明 |
|------|------|
| **三滑块画像** | 主动性 6（多以建议形式出现）；讨喜度 9（和蔼可亲，讲故事有魅力）；能力值 8（对遗留机器的硬件细节了如指掌）。 |
| **创伤/欲望/需求/谎言 因果链** | **创伤**：2029 年熵锁条约通过后，他的实验室被强制拆除，多年心血付诸东流。<br>→ **伤口**：对被时代抛弃的失落感，觉得自己的技术无用。<br>→ **谎言**：只要我不碰新设备，我的价值就永远存在。（错误地认为拒绝更新能保存自我价值。）<br>→ **欲望**：寻找一台能完整运行熵锁绕过的机器，以 prouver 老机仍有不可替代的力量。（想通过一次成功的 LCS 重拾荣誉。）<br>→ **需求**：认识到自身价值不在于单一机器，而在于传递知识与激发新一代。（需要放下执念，去教导。） |
| **角色弧类型** | **正向弧** – 起初执着于让林浩用自己珍藏的 2008 年机器做实验；后来看到林浩因记忆碎片而痛苦，他转而分享自己的笔记与经验，帮助林浩建立信任而非依赖单一硬件。 |
| **对话独** | 1. 词汇量级：偏怀旧技术，常用老式型号命名。<br>2. 句子长度：短句为主，偶尔长句讲述往事。<br>3. 口语化：带有浓厚的上海老 alley 口音，“啦”、“嘛”。<br>4. 口头禅：“当年我……”<br>5. 提问/陈述：提问 20%，陈述 80%。<br>6. 打断：极少打断别人，却常被林浩的急躁打断。<br>7. 比喻域：机械/钟表（“这块主板像老爷车的发动机……”）。<br>8. 直率/委婉：直率，喜欢用“就是这么说”结束争论。 |
| **身体习惯** | - 右手食指习惯性地在老机机箱边缘划圈（检查散热片）。<br>- 说话时会不自觉地看向左手腕上的旧式机械表。 |
| **秘密** | 他其实保存了一份 **2008 年 Xeon 固件的完整源码注释**（与林浩母亲的笔记互补），其中隐藏了如何安全地在 4 分钟后发出“封印指令”的细节。 |
| **与主角关系** | 师徒——老陈提供硬件知识与情感支持，林浩则提供新视角与实验机会。两人在“技术是工具还是命根子”上产生张力，推动彼此成长。 |
