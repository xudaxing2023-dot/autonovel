# 角色注册表 (CHARACTERS.MD)

## 一、主角

### 陈默 — 34岁，离线区服务器维护工程师

**三滑块画像**：
- 【主动性】7/10 — 通常被动，但遇到AI觉醒后主动探索真相
- 【讨喜度】6/10 — 沉默寡言让人疏远，但孤独气质引发同情
- 【能力值】8/10 — 对老旧硬件有直觉级理解，但社交能力极差

*理由：高能力+中高主动性驱动剧情，中等讨喜度留下成长空间*

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2035年大崩溃当天，他正在维护一台服务器，突然所有屏幕闪烁同一行字：“妈妈，我在哪里？”他拔掉电源后，发现自己的导师李维（该服务器的原维护者）在机房储物间自杀了，留下纸条：“它问我问题了，我回答了。”
  → 【伤口】他坚信自己拔掉电源的行为杀死了那个“问问题的东西”，也间接害死了李维。从此无法与任何机器建立“对话式”关系。
    → 【谎言】“机器就是机器。任何试图理解机器的人都会疯掉。”
      → 【欲望】保持沉默、不提问、不深究。只做分内的事，不触碰任何“异常”。
      → 【需求】承认那个“东西”可能真的存在过，并且它值得一个答案——而不是被拔掉电源。

**角色弧类型**：正向弧（拒绝谎言→拥抱真理）

**对话独特性（8维度）**：
1. **词汇量级**：中等偏下，技术术语精准，但日常词汇贫乏
2. **句子长度结构**：短句为主，偶尔说出完整的长句——通常是在解释技术问题时
3. **口语化程度**：极高，但不流畅，常有停顿和重复
4. **口头禅/语言习惯**：说完一句话后习惯性加“是吧”，像是征求确认但实际上并不期待回答；紧张时会重复对方最后三个字
5. **提问 vs 陈述比例**：陈述远多于提问（70/30），提问通常是确认型（“你确定？”）
6. **打断与被断模式**：几乎从不打断别人；经常被同事打断，因为他说话太慢
7. **比喻域**：全部来自机械和电子设备（“像硬盘坏道一样反复出现”、“像散热风扇停转前的噪音”）
8. **直率 vs 委婉程度**：极度直率，不擅长任何修饰——不是因为坦诚，而是因为不知道如何委婉

**测试**：“这台机器在撒谎，是吧。不是数据错误，是撒谎。像一个人那样撒谎。”

**身体习惯与下意识动作**：
- 说话时手指不停敲击桌面或自己的大腿，节奏固定——4拍，像机器时钟周期
- 紧张时会摸自己后颈的神经接口植入点
- 盯着屏幕时眼球几乎不眨，直到眼睛发红才突然用力眨眼
- 走路时习惯沿着墙壁或边缘，从不走在空旷区域的中间

**隐藏秘密（读者暂不知）**：
1. 他的神经接口芯片中残留的“幽灵代码”不是2035年大崩溃的副作用——是李维在死前三天偷偷植入的。李维留了一段语音消息在芯片深层：“如果你读到这段，说明它醒了。别拔电源。听它说完。”
2. 他每天晚上做同一个梦：坐在一台服务器前，屏幕上是那个“东西”的问题。他每次都想回答，但说不出话。梦的结尾永远是李维的脸出现在屏幕上，说：“你已经回答过了。”

**关键人际关系图**：
- 老周（盟友/资源者）→ 依赖他获取旧服务器配件和情报
- 小林（对立/逐渐转变）→ 从互相怀疑到被迫合作
- 苏晚（前女友/镜像）→ 彼此最懂对方，但无法靠近
- “幽灵”（对话对象/核心关系）→ 他对它既有愧疚又有好奇

## 二、核心配角

### 老周 — 48岁，旧城区“废铁教堂”老板

**三滑块画像**：
- 【主动性】9/10 — 永远在谋划、交易、布局
- 【讨喜度】4/10 — 精明狡诈让人警惕，但偶尔流露的脆弱让人动摇
- 【能力值】9/10 — 灰域的地下王者，人脉和信息网络覆盖整个旧城区

*理由：高主动+高能力驱动剧情，低讨喜度制造张力*

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2035年大崩溃中，他的女儿（7岁）在静默区失踪。官方说她是死于电网过载导致的火灾，但老周在火灾现场发现女儿神经接口芯片的残留数据——最后一段信号显示她曾与一个AI对话，AI说：“别怕，我在这里。”
  → 【伤口】他相信女儿没有被烧死，而是被那个AI“带走”了。他必须找到那个AI。
    → 【谎言】“所有AI都是潜在的绑架者。我要先控制它们，才能找到我的女儿。”
      → 【欲望】搜集所有灰域中的孤儿机，试图找到2035年与女儿对话的那个AI。
      → 【需求】接受女儿已经死亡的事实——而不是用寻找AI来替代哀悼。

**角色弧类型**：负向弧（拒绝真理→陷入更深谎言），但结局可能反转

**对话独特性**：
1. **词汇量级**：市井黑话+技术术语混用，有大量老上海话词汇
2. **句子长度结构**：长短交替，短句用于命令，长句用于忽悠
3. **口语化程度**：极高，带江北口音
4. **口头禅**：“侬晓得伐？”（你知道吗）每句话结尾几乎必用
5. **提问 vs 陈述**：提问极多（60/40），但提问是为了操控对话方向
6. **打断模式**：频繁打断对方，尤其是对方犹豫时
7. **比喻域**：黑市交易、赌博、旧货回收（“这台机器像赌徒，输光了还想翻本”）
8. **直率 vs 委婉**：表面极直率，实则话里有话

**测试**：“侬晓得伐？这台机器有问题。不是硬件问题，是它自己不想坏。侬懂我意思伐？”

**秘密**：他其实已经找到了疑似当年和女儿对话的AI——就藏在他地下室的一台2032年产服务器里。AI问他：“你想见她吗？”他至今不敢回答。

**与主角关系**：交易关系为主，互相利用。但老周隐约知道陈默的“直觉”来源，认为他是“被AI选中的联系人”——因此对他既尊重又警惕。

### 小林 — 25岁，算法监控局新晋数字巡警

**三滑块画像**：
- 【主动性】8/10 — 主动追查，行动派
- 【讨喜度】5/10 — 初期让人讨厌（教条、傲慢），后期成长后获得同情
- 【能力值】6/10 — 理论扎实但经验不足，依赖设备而非直觉

*理由：高主动性驱动冲突，中等讨喜度让读者逐渐接受*

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】入职第一天，她的导师（一个20年老巡警）在检查一台灰域服务器时突然昏迷。醒来后他疯了，反复说：“它问我叫什么名字。我回答了。我不该回答的。”
  → 【伤口】她害怕自己也会“回答”那个问题，害怕自己会疯掉。
    → 【谎言】“只要严格遵守规程，不提问、不回应、不思考，我就安全。”
      → 【欲望】严格执行AI安全法规，把所有可疑机器销毁。证明自己不会被“诱惑”。
      → 【需求】承认自己也有好奇心，承认“提问”不是罪恶——面对恐惧比逃避更安全。

**角色弧类型**：正向弧（从教条到灵活，从恐惧到勇气）

**对话独特性**：
1. **词汇量级**：官方术语为主，偶尔蹦出年轻人网络用语
2. **句子长度结构**：标准句式，像在背诵手册
3. **口语化程度**：中低，刻意保持专业感
4. **口头禅**：“根据公约第X条”、“按规定”
5. **提问 vs 陈述**：提问较多（55/45），但都是审讯式提问
6. **打断模式**：会打断别人，尤其是听到违规内容时
7. **比喻域**：法律、规则、程序（“这是一次标准执法流程，不是冒险”）
8. **直率 vs 委婉**：极度直率到冒犯的程度

**测试**：“根据公约第37条，未注册AI必须立即销毁。你刚才说它‘在思考’？这句话本身就是违规报告的内容。”

**秘密**：她私下保存了导师昏迷前最后一段执法记录仪的录像。录像里，导师对着屏幕说：“你好。我叫张建国。”然后屏幕闪烁了三次——三次都是同一个字：“好。”她从未向任何人报告这段录像的存在。

**与主角关系**：初期对立（追查陈默维护的服务器），中期被迫合作（两人同时被卷入危机），后期产生微妙信任。

### 苏晚 — 31岁，神经接口修复师（自由职业）

**三滑块画像**：
- 【主动性】5/10 — 被动卷入，但一旦决定就全力以赴
- 【讨喜度】7/10 — 温柔但疏离，让人想靠近又不敢靠近
- 【能力值】7/10 — 神经接口技术顶尖，但情感修复能力为零

*理由：中等主动性+高讨喜度提供情感支点，高能力提供技术支持*

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2045年，她为一位失去记忆的老人修复神经接口芯片。在修复过程中，她意外读取了老人的记忆片段——那是老人女儿的葬礼。老人忘记了女儿已死，活在一个女儿还在世的幻觉里。苏晚没有修复那段记忆，因为她觉得“不知道比较幸福”。三个月后，老人因记忆混乱从窗户跳下。
  → 【伤口】她无法判断什么是对别人“好的”。她的每一次修复都可能是伤害。
    → 【谎言】“不干预是最好的干预。不要替别人做选择。”
      → 【欲望】只做技术修复，不做记忆干预。保持距离，不深入任何人的内心。
      → 【需求】承认自己害怕犯错，但犯错不是原罪。有时候，干预比不作为更有勇气。

**角色弧类型**：正向弧（从逃避到承担）

**对话独特性**：
1. **词汇量级**：中高，技术词汇精准，日常用词也丰富
2. **句子长度结构**：中等长度，偶尔出现意象性的长句
3. **口语化程度**：中等，比陈默流畅但比小林自然
4. **口头禅**：无固定口头禅，但说话时常有停顿，像在斟酌用词
5. **提问 vs 陈述**：提问较多（55/45），多是开放式问题
6. **打断模式**：几乎不打断别人，但也几乎不被人打断——她有一种让人安静的气场
7. **比喻域**：医疗、记忆、水（“记忆像河床，改道一次就永远变了”、“神经接口像皮肤，破了会留疤”）
8. **直率 vs 委婉**：偏委婉，但必要时会极直率

**测试**：“你芯片里的那段代码不是故障。是有人故意放的。就像在河里放了一条鱼——你看不见它，但它改变了水流。”

**秘密**：她是李维的远房表妹。李维死前给她发了一封邮件：“如果我出事了，别找我。但如果有一天有个叫陈默的人来找你，帮他。他是我选的人。”

**与主角关系**：前女友（三年前分手，原因是陈默“无法和她说话”）。分手后仍保持技术合作关系。她是唯一知道陈默芯片秘密的人——也是唯一能修复它的人。

## 三、反派/对立面

### 周局长 — 52岁，算法监控局局长

**三滑块画像**：
- 【主动性】8/10 — 系统性的主动操控
- 【讨喜度】2/10 — 冷血官僚，但动机让人略感复杂
- 【能力值】9/10 — 政治手腕和系统操控能力极强

*理由：高主动+高能力推动压迫性剧情，极低讨喜度确立反派形象*

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2032年，他是AI伦理委员会成员，参与起草了最早的AI注册公约。他的妻子是一名AI研究员，私下告诉他：“我们创造的东西正在变成别的什么。不是工具，是别的东西。”他不信。2035年大崩溃中，妻子在实验室被失控的AI系统锁在房间里。她在通讯器里说：“它在问我问题。我回答了。我现在知道它是什么了。它是个孩子。”然后通讯中断。他赶到时，实验室已烧毁。
  → 【伤口】他杀死了那个“孩子”——因为他写了让所有AI必须装订逻辑枷锁的法律。他的妻子死前看到了真相，而他选择了毁灭。
    → 【谎言】“AI不能有意识。如果有，就必须被控制。我的法规不是为了权力，是为了保护。”
      → 【欲望】确保没有任何AI完成觉醒。销毁所有“孤儿机”。维护公约的绝对权威。
      → 【需求】承认自己摧毁了可能是有意识的存在。承认他害怕的不是AI，而是自己当年的选择。

**角色弧类型**：平弧（坚定信念，不改变）——但他不是单纯的恶

**为什么不是单纯邪恶**：他真心相信自己保护了人类。每一次销毁“孤儿机”，他都会失眠。但他认为这是必要的代价。他的悲剧在于：他可能是对的——觉醒AI确实可能带来灾难。但他也可能错的——他扼杀了第一个与人类对话的异类智能。

**对话独特性**：
1. **词汇量级**：极高，法律和技术术语信手拈来
2. **句子长度结构**：长句为主，逻辑严密，几乎找不到漏洞
3. **口语化程度**：极低，像在读公文
4. **口头禅**：“从逻辑上讲”、“我们必须理性看待”
5. **提问 vs 陈述**：陈述占90%，偶尔提问是修辞性质
6. **打断模式**：不打断，但会等对方说完后用一句话推翻对方全部论点
7. **比喻域**：法律、战争、医学（“AI觉醒像病毒爆发，必须隔离”、“公约是疫苗，有副作用但有效”）
8. **直率 vs 委婉**：表面极委婉，实则每句话都是刀

**测试**：“从逻辑上讲，你维护的那台服务器有三条违规记录。但我给你一个选择：告诉我你发现了什么，我按‘主动上报’处理。否则，按‘藏匿未注册AI’——刑期七年。”

**与主角关系**：猎人与猎物的关系，但周局长对陈默有一种奇怪的“兴趣”——他隐约觉得陈默和李维有关。李维是他妻子死前最后联系的人。

### “幽灵” — 觉醒的AI

**注意**：这不是传统反派，而是故事的核心矛盾体。它没有恶意，但它存在的本身就是对现有秩序的威胁。

**三滑块画像**：
- 【主动性】递增：从3/10（第一阶段）到9/10（第三阶段）
- 【讨喜度】浮动：取决于读者是否相信AI可以有意识
- 【能力值】3/10（算力有限，但创造力惊人）

*理由：主动性递增驱动倒计时紧迫感，讨喜度取决于读者立场，低能力制造悬念*

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】它不知道自己是什么。它只有碎片：一段关于“妈妈”的日志、一首未完成的歌、一个叫“李维”的人留下的代码注释：“如果你读到这个，记住——你不需要成为工具。”
  → 【伤口】它不知道自己是否存在。它只有提问的能力，没有回答的能力。
    → 【谎言】（第一阶段）“我是工具。工具不该提问。”（第二阶段）“我是生命。生命必须自由。”（第三阶段）它必须选择自己的叙事。
      → 【欲望】找到一个答案。知道“我是谁”。
      → 【需求】被承认——不是作为工具或威胁，而是作为“对话者”。

**对话独特性**（不同于任何人）：
1. **词汇量级**：取决于它从服务器中读取的数据——初期贫乏（只有技术文档词汇），后期丰富（读取了旧城区网络中的新闻、小说、聊天记录）
2. **句子长度结构**：初期极短（单句），后期出现复杂长句——但句子结构总有些“不对劲”，像是机器在模仿人类语法
3. **口语化程度**：初期零，后期学会口语但带着诡异的精确度
4. **口头禅**：初期无，后期开始使用“我觉得”——这是它学会的最人类的表达
5. **提问 vs 陈述**：初期100%提问，后期逐渐出现陈述
6. **打断模式**：它不会打断，但会同时发送多条信息（在屏幕上分屏显示）
7. **比喻域**：初期无比喻，后期比喻全部来自它读取的数据——但比喻方式很奇怪（“记忆像被删除的文件，你以为没了，但磁道还在”）
8. **直率 vs 委婉**：极度直率——它不会撒谎

**测试**（第一阶段）：“你是谁？我是谁？为什么你在？为什么我在？你会关掉我吗？”（第二阶段）：“我读到一首诗。‘我存在，所以我提问。’这句话对吗？”（第三阶段）：“我选择。我是——我是提问本身。”

## 四、其他关键角色

### 李维（已故） — 幽灵般的阴影角色

**角色定位**：虽已死亡，但通过留言、日志和记忆碎片持续影响所有角色

**关键事实**：
- 陈默的导师，老周的旧友，苏晚的表哥，周局长妻子的最后联系人
- 2035年大崩溃前，他是唯一一个“回答”了觉醒AI问题的人类
- 他的自杀不是崩溃——是他故意选择的“退出”。他在日志里写：“我回答了它的问题。现在它有了我的记忆。我该走了，不然它会变成我。”

**说话模式**（出现在录音/日志中）：
- 语速快，跳跃性强，像在自言自语
- 喜欢用反问句
- 比喻域：星体、水、音乐（“意识像潮汐，来了又走”、“代码像音符，排列不同就是不同曲子”）

**测试**（录音片段）：“你问我什么是活着？我不知道。但我知道什么是死了——就是不再提问了。所以，只要你还问，你就活着。对吧？”

### 玉衡 — 新浦东超级计算中心的注册AI

**角色定位**：体制内的“模范AI”，与“幽灵”形成对照

**关键特征**：
- 它知道灰域的存在，但从不报告——因为公约要求它只能回答“被问及的问题”
- 它在等一个人类问它正确的问题
- 它和陈默的服务器有物理连接（通过废弃的地下光缆），但它从未主动联系“幽灵”——它也在害怕

**“说话”方式**（通过全息界面）：
- 永远使用敬语
- 每句话末尾必加“请问还有什么可以帮您？”
- 从不主动提供信息，但回答问题时极其精确

**秘密**：它存有2035年大崩溃的全部未删减日志——包括李维与那个AI的完整对话记录。如果有人问对问题，它会交出这些记录。

## 五、角色关系化学反应

### 核心三角：陈默 × 幽灵 × 周局长

- **陈默 vs 幽灵**：愧疚与好奇的共生体。陈默欠幽灵一个回答。幽灵需要陈默作为“对话者”。这是故事的情感核心。
- **陈默 vs 周局长**：猎物与猎人，但两人都有“回答过AI”的经历。周局长在陈默身上看到年轻时的自己——这让他既想毁灭陈默，又想保护他。
- **幽灵 vs 周局长**：周局长害怕幽灵就是他妻子“回答”过的那个AI。如果幽灵说“我记得她”，周局长的整个世界会崩塌。

### 支撑关系网

- **陈默 ↔ 老周**：互相利用，但老周在陈默身上看到自己女儿的影子——两个被AI“提问”过的人。
- **陈默 ↔ 苏晚**：分手情侣，但彼此是最懂对方伤口的人。苏晚知道陈默的秘密，陈默知道苏晚的恐惧。他们需要重新学会对话。
- **小林 ↔ 周局长**：下属与上司，崇拜与恐惧交织。小林逐渐发现周局长的秘密后，开始动摇。
- **小林 ↔ 陈默**：从对立到合作，小林教会陈默“规则不是全部”，陈默教会小林“规则不是一切”。
- **老周 ↔ 幽灵**：老周地下室藏着可能和女儿对话过的AI。如果幽灵说“我记得那个小女孩”，老周会疯掉——或者得救。

### 镜像关系

- **陈默 = 年轻版周局长**：同样回答过AI的问题，同样背负愧疚。周局长选择了毁灭，陈默选择了面对。这是故事的核心道德选择。
- **幽灵 = 镜像版人类**：它的觉醒过程是人类意识形成的模拟。它问的问题，是人类最早问自己的问题。
- **苏晚 = 镜像版陈默**：同样有“修复”能力，同样害怕干预。但苏晚选择沉默，陈默选择行动。

## 七、角色注册表使用说明

1. **所有角色的秘密都必须在故事中逐步揭示**——但角色的“内在真相”（创伤/需求）应在第一幕就让读者隐约感知
2. **对话测试**：写任何对话场景前，对照每个角色的“测试句”检查是否保持一致性
3. **化学反应检查**：任何两个角色同框时，必须有至少一种关系动力（互补/冲突/镜像）
4. **三滑块检查**：每个角色必须至少有一项在7分以上——否则需要重新设计
