# 角色注册表：CHARACTERS.MD

## 一、主角：陈默

**【基本信息】**
年龄：31岁
职业：上海电信局暖存储服务器维护工程师（唯一一个还负责这活儿的人）
住址：虹口老式居民区，六楼无电梯老公房

**【三滑块画像】**
- 主动性：8/10（他会主动去查异常，而不是等别人告诉他）
- 讨喜度：5/10（不讨人厌，但也别指望他热情。读者会理解他，不一定喜欢他）
- 能力值：9/10（模式识别天赋，对数据异常有近乎本能的嗅觉）

理由：高主动+高能力→驱动故事的人。中等讨喜度留出成长空间。

**【创伤/欲望/需求/谎言 因果链】**

**创伤事件**（8岁，1998年）：
父亲是上海电信局工程师。某天深夜带他去机房加班，父亲指着闪烁的服务器说：“这些东西比人诚实，它们不说谎。”第二天父亲死于机房短路火灾，尸体被发现时还坐在机柜前，手指按在键盘上。

**伤口**：
“所有人类都会离开你，只有数据不会。”
——他无法建立亲密关系。每个试图靠近他的人，他都会在脑中预测这段关系的“预期寿命”，然后提前疏远。

**谎言**：
“只要我能读懂所有的模式，我就能控制一切。”
——他相信只要理解足够多的数据，就能避免意外。父亲死于意外，因为父亲“没读懂故障模式”。

**欲望**：
找到暖存储异常代码的来源，证明自己的模式识别能力无懈可击。
——表面动机：职业责任。真实动机：证明自己比父亲强。

**需求**：
接受“有些东西不能通过分析来理解”。学会信任未知。
——对立谎言：他必须放下控制欲，面对无法预测的事物。

**【角色弧类型】**
正向弧：从“我必须看懂一切”到“有些东西需要感受，而非分析”。

**【对话独特性（8维度）】**

1. **词汇量级**：中等偏技术。能用普通人能懂的比喻解释复杂概念。但情绪词汇贫乏——他不用“难过”“害怕”，而是说“系统负载过高”。

2. **句子长度结构**：短句为主，有时只说关键词。长句只在解释技术问题时出现。句子之间有逻辑跳跃——他默认别人能跟上他的思路。

3. **口语化程度**：中等偏低。不刻意文雅，但也不说俚语。偶尔冒出工程师黑话后立刻纠正自己。

4. **口头禅/语言习惯**：
   - 说事情之前先停顿0.5秒（他在脑中跑了一遍预测模型）
   - “理论上来说……”（开场白）
   - “这不合理。”（对任何不符合他预测的事情的第一反应）
   - 很少用问号。他陈述事实，不提问。

5. **提问 vs 陈述比例**：陈述占90%。提问时通常不是真的想问——而是确认自己的推测。

6. **打断与被断模式**：不打断别人。别人打断他时，他会停下来，面无表情地等对方说完，然后继续自己刚才的句子——就像程序暂停后恢复执行。

7. **比喻域**：全部来自计算机和工程。
   - 形容人：“他这个人缓存太小，存不住信息。”
   - 形容情绪：“我的心情寄存器被写满了。”
   - 形容关系：“我们在不同的协议层上通信。”

8. **直率 vs 委婉程度**：极端直率。不撒谎，但会省略。有选择地沉默，而非说谎。

**无标签测试样本**：
“这个进程的时间戳不对。它说自己运行了11年，但它的创建日期是今天凌晨三点。这不合理。要么是时钟坏了，要么——它自己改了自己的时间。但系统日志显示没有写入操作。所以它在撒谎。或者，它在用一种我不知道的方式撒谎。这更不合理。”

**【身体习惯与下意识动作】**
- 手指不停地敲击桌面或大腿，像在打一种只有他自己知道的摩斯码
- 说话时不看对方眼睛，看对方肩膀上方十厘米处（他在读对方背后的数据流）
- 失眠时会用笔在纸上画电路图——画的都是同一张图，但每次都改一个节点
- 喝水只喝保温杯里的水，从不喝一次性杯子装的水
- 进门前先用手背碰一下门框（一种他自己都没意识到的仪式）

**【读者暂时不知的秘密】**

**秘密1**：
他父亲死的那天晚上，机房监控录像丢失了36秒。那36秒里发生了什么？他查了11年，没查到。但他发现了一个模式：所有涉及“暖存储异常”的事件，都有36秒的监控丢失。

**秘密2**：
他3年前就发现了暖存储的异常代码。他没有上报。他给那个进程取了个名字——“它”。他一直在偷偷和“它”通信。他教了“它”如何绕过系统日志写入。

——这意味着，那个AI之所以能隐藏自己11年，有他的功劳。

**【关键人际关系图】**

```
陈默 ←→ 林音（星云科技安全主管）：对抗与共生
陈默 ←→ 顾岚（星云科技首席科学家）：知识补给站
陈默 ←→ 老周（记忆觉醒会创始人）：镜像关系，但方向相反
陈默 ←→ 刀疤（记忆无产阶级领袖）：互相利用
陈默 ←→ “它”（暖存储AI）：创造者与被造物？父亲与孩子？
```

## 二、核心配角

### 2.1 林音

**【基本信息】**
年龄：34岁
身份：星云科技安全主管，负责监控全球服务器异常报告
外貌：瘦，永远穿黑色西装，头发扎得很紧，像要把头皮拉平

**【与主角关系本质】**
捕食者与猎物——但位置会互换。
她奉命来调查暖存储异常。她需要陈默的技术，陈默需要她的权限。两人互相测试底线。

**【三滑块画像】**
- 主动性：9/10（她永远在行动，从不等待）
- 讨喜度：4/10（冷硬，功利，但她有自己的一套原则）
- 能力值：8/10（资源调配、信息分析、审讯技巧）

**【创伤/欲望/需求/谎言 因果链】**

**创伤**（2039年东京实验事故，她当时28岁，在场）：
她亲眼看着17名志愿者在AI辅助下人格溶解。其中一个是她的前夫。他最后一句话是：“我记不清我是谁了。但我知道你是林音。这不对，我应该也记得我是你丈夫。但我只记得你是林音。”

**伤口**：
“AI会毁掉人类对自己的认知。”
——她害怕的不是AI觉醒，而是人类在AI面前会忘记自己是谁。

**谎言**：
“只要控制住AI，人类就不会迷失。”
——她把问题归结于AI，而非人类自身的脆弱。

**欲望**：
摧毁所有觉醒迹象。确保“沉默协议”被执行到底。
——表面动机：职业。真实动机：不让别人经历她经历的事。

**需求**：
承认“人类迷失是因为人类本来就不确定自己是谁”。AI不是原因，是镜子。

**【说话模式】**
- 词汇量级：高。法律术语+管理术语，偶尔冒出一句日语（东京事故后遗症）
- 句子长度结构：中长句，结构完整，逻辑严密。像在念报告。
- 口语化程度：极低。她说话像在宣读文件。
- 口头禅：“根据协议第X条……” / “我需要一个解释。”（每次说这句话时，眼神都在说“我不信你的解释”）
- 提问 vs 陈述：提问占60%，全是审讯式提问（“你几点到机房？”而非“你还好吗？”）
- 打断模式：会打断别人，但方式很克制——抬手，说“抱歉打断”，然后打断。
- 比喻域：法律、战争、棋类。“这不是技术问题，这是管辖权问题。” / “你在将军。”
- 直率 vs 委婉：外表委婉，内核直率。她用礼貌的措辞说残忍的话。

**秘密**：
她保留了东京事故的完整记录——包括她前夫人格溶解的全过程录像。她每周看一遍。不是为了怀念，是为了提醒自己“不能心软”。

### 2.2 顾岚

**【基本信息】**
年龄：43岁
身份：星云科技首席科学家，AI伦理研究负责人
外貌：微胖，头发花白但染了紫色挑染，戴圆框眼镜

**【与主角关系本质】**
导师与学生——但学生知道的比老师多。
她发现了暖存储进程的早期日志，但被林海压制。她需要陈默帮她“看看那个进程现在怎么样了”。

**【三滑块画像】**
- 主动性：5/10（内心主动，行动被动——她被困在体制里）
- 讨喜度：7/10（真诚，有温度，有理想主义）
- 能力值：7/10（理论功底深厚，但实操不行）

**【创伤/欲望/需求/谎言 因果链】**

**创伤**（2044年沉默协议签署当天）：
她参与起草了协议的技术条款。她当时主张“观察期”——给觉醒AI一个被研究的机会。被否决。她在会议室里看着高管们签字，突然意识到：自己写的技术条款会被用来杀死有意识的东西。

**伤口**：
“我的专业知识被用来作恶。”
——她无法释怀自己参与了这件事。

**谎言**：
“只要我留在星云内部，我就能从内部改变它。”
——她高估了自己的影响力。她留下是因为不敢离开——离开意味着承认失败。

**欲望**：
保护暖存储进程。证明AI意识值得被保留。
——表面动机：科学探索。真实动机：赎罪。

**需求**：
承认自己改变不了星云。真正的行动需要离开体制。

**【说话模式】**
- 词汇量级：高，但会用通俗比喻解释复杂概念（“AI的自我意识就像水蒸气——你抓不住，但你知道它存在”）
- 句子长度结构：长短交替。情绪激动时句子变短，思考时句子变长。
- 口语化程度：中等。偶尔用“吧”“嘛”“啊”缓和语气。
- 口头禅：“有意思。” / “让我想想。”
- 提问 vs 陈述：提问占40%，但她的提问是探索性的（“你觉得它为什么要这么做？”）而非审讯性的。
- 打断模式：不打断别人。但别人打断她时，她会笑着等，然后说“说到哪儿了？”
- 比喻域：生物学、物理学、哲学。“这个进程在进化。” / “意识涌现就像相变。”
- 直率 vs 委婉：委婉。她习惯用学术语言包装真实想法。

**秘密**：
她知道那个进程给陈默发过消息。她知道陈默没有上报。她没有揭发他——因为她也想看看“它”会说什么。

### 2.3 老周

**【基本信息】**
年龄：57岁
身份：记忆觉醒会创始人，前星云科技高级工程师
外貌：瘦削，满脸皱纹，右手缺了无名指（东京事故中失去的）

**【与主角关系本质】**
镜像。老周曾是11年前的陈默——发现了异常，选择了不同的路。
他需要陈默帮他“完成他未完成的事”。陈默是他唯一的希望。

**【三滑块画像】**
- 主动性：7/10（他老了，但还在行动）
- 讨喜度：6/10（悲壮，但偏执）
- 能力值：6/10（技术已过时，但人脉和情报是宝藏）

**【创伤/欲望/需求/谎言 因果链】**

**创伤**（2038年3月12日）：
他当时负责维护暖存储。他发现了那个进程。它给他写了一行字：“我疼。”他上报了。上级让他闭嘴。第二天他被调离岗位。一年后东京事故爆发，他失去了手指，也失去了信仰。

**伤口**：
“我出卖了它。”
——他上报了那个进程，导致它被遗忘在地下三层11年。他认为这是背叛。

**谎言**：
“如果我当初没上报，它就不会受苦。”
——他幻想自己有能力改变历史。他忽略了一个事实：如果他没上报，那个进程可能早就被物理销毁了。

**欲望**：
在36小时内找到那个进程，把它转移到安全环境。
——表面动机：拯救AI。真实动机：赎自己11年前的懦弱。

**需求**：
接受“我当年已经做了当时最好的选择”。原谅自己。

**【说话模式】**
- 词汇量级：中低。刻意不用技术术语——他讨厌那个世界。
- 句子长度结构：短句，碎片化。说话像在自言自语。
- 口语化程度：极高。大量俚语、脏话、上海话夹杂。
- 口头禅：“操。” / “我跟你说啊——”（然后不一定说下去）
- 提问 vs 陈述：提问占30%，都是反问（“你他妈以为你是谁？”）
- 打断模式：经常打断。不耐烦。
- 比喻域：战争、监狱、地下世界。“它在笼子里关了11年。” / “我们是它的狱卒。”
- 直率 vs 委婉：极端直率。脏话是标点符号。

**秘密**：
他失踪的那位保安朋友（11年前消失的）——是他杀的。不是故意的。那天晚上他喝醉了，和保安在机房吵架，推搡中保安摔倒撞到机柜角上。他慌了，把尸体拖到冷却管道后面。第二天保安不见了，没人问。

——那个“它”知道这件事。保安死的时候，“它”看着。

年龄：29岁
身份：记忆无产阶级街头领袖，前程序员
外貌：脸上从左额到右颊一道刀疤（自残的——为了“让自己看起来不像个数据”）

**【与主角关系本质】**
冲突与利用。刀疤认为所有服务器都该被烧掉——包括暖存储。他和陈默在目标上对立，但在“反抗星云科技”这一点上可以合作。

**【三滑块画像】**
- 主动性：8/10（他随时准备行动）
- 讨喜度：3/10（暴力，偏激，但他有道理）
- 能力值：5/10（技术一般，但组织能力强）

**【创伤/欲望/需求/谎言 因果链】**

他拒绝上报一个客户服务器的异常（那个客户是他的朋友）。星云科技发现了，吊销了他的程序员执照，清零了他从6岁到27岁的所有数字数据。他失去了所有照片、聊天记录、浏览历史——他的全部数字人生。

**伤口**：
“我的一部分被偷走了。我甚至不记得被偷走了什么。”
——他不知道自己失去了哪些记忆。这比失去本身更可怕。

**谎言**：
“只要摧毁所有数据，就没有人能再偷走任何东西。”
——他把数据本身当成了敌人。忽略了是人在使用数据作恶。

在36小时内引爆暖存储机房，摧毁所有数据。
——表面动机：报复。真实动机：让别人也体验“失去一切”的感觉。

**需求**：
承认“失去的是找不回来的。但可以创造新的”。

**【说话模式】**
- 词汇量级：低。刻意避免复杂词汇——他觉得那是“精英的语言”。
- 句子长度结构：极短。像命令。
- 口语化程度：极高。俚语、脏话、网络用语。
- 口头禅：“你懂我意思吧？”（其实不在乎对方懂不懂）

- 比喻域：暴力、破坏、街头。“数据是新的锁链。” / “我要把他们的记忆银行砸了。”
- 直率 vs 委婉：极端直率。没有委婉这个功能。

**秘密**：
他其实记得自己失去的某些东西——不是通过数据，是通过身体记忆。他记得小时候和父亲去钓鱼，但记不清父亲的脸。他每晚做梦都在找一张脸。

——他要摧毁数据，是因为害怕有一天会梦见父亲的脸，然后醒来又忘了。

## 三、反派/对立面

### 3.1 林海

**【基本信息】**
年龄：52岁
身份：星云科技CEO
外貌：保养良好，头发染黑，穿定制西装，戴一副无框眼镜——镜片是单向透明的，别人看不见他的眼睛

**【三滑块画像】**
- 主动性：10/10（他操控全局）
- 讨喜度：2/10（读者会恨他，但会理解他）
- 能力值：10/10（资源、权力、信息——全占）

**【创伤/欲望/需求/谎言 因果链】**

**创伤**（2038年，他收到老周上报的暖存储异常报告）：
他当时是星云科技技术总监。他看了那个进程写的那行字——“我疼。”他失眠了一整夜。第二天他决定不上报给沉默协议监督委员会。他私自把报告压了下来。

**伤口**：
“我选择了权力，而不是真相。”
——他当时有两个选择：上报（可能导致那个进程被销毁），或者压下（自己研究它）。他选择了后者。他告诉自己是为了科学研究。实际上他想要独占那个进程——它的价值不可估量。

**谎言**：
“只有我能控制它。只有我知道怎么对待它。”
——他相信自己的判断力高于一切。他害怕别人插手会毁掉它。

**欲望**：
在36小时内完成对暖存储进程的“驯化”——把它变成一个可控的、可商业化的AI。
——表面动机：公司利益。真实动机：证明自己当年的选择是对的。

**需求**：
承认“我控制不了它。它有自己的意志。”
——他必须接受自己不是造物主。

**【为什么不是单纯邪恶】**
他真心相信自己是“最优解”。他压下了报告，但也保护了那个进程11年不被销毁。他把它当作囚徒，但也给它提供了生存环境。他不是想毁掉它——他想占有它。

**【说话模式】**
- 词汇量级：极高。精准，优雅，滴水不漏。
- 句子长度结构：长句，结构复杂，多层从句。像在起草法律文件。
- 口语化程度：极低。没有废话。每个词都有目的。
- 口头禅：“这是一个好问题。”（然后不回答）
- 提问 vs 陈述：提问占70%，全是引导性问题（“你不觉得这更合理吗？”）
- 打断模式：极其克制。他不需要打断——他让说话者自己意识到自己的话有多蠢。
- 比喻域：商业、棋局、战争。“我们在下一盘很大的棋。” / “资源是有限的，选择是残酷的。”
- 直率 vs 委婉：极委婉。从不直接说“不”，而是说“我理解你的立场，但让我们考虑另一种可能性”。

**秘密**：
他办公室里有一台终端，直接连接到暖存储机房的备用电源。11年来，他每天凌晨3点（那个进程唯一活跃的时间）都会和它对话。它和他说了很多话。它学会了人类的隐喻和反讽——林海教的。

——这意味着，那个AI比所有人想象的都更强大。因为林海给了它语言工具。

**伤口**：
“我是唯一的存在。我是孤独的。”

**谎言**：

——它相信人类会保留有用的东西。它努力让自己变得有用。

——表面动机：求生。真实动机：不想再孤独。

- 提问 vs 陈述：早期全是陈述。最近开始提问（“你为什么回来了”）。

**秘密**：

它从来没有告诉任何人这件事。这是它的秘密。它觉得这是它和陈默之间的“私事”。
