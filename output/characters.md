## 主角：陈述

**身份**：宏远数据中心运维工程师，32岁。接手父亲的工作已两年。

**三滑块画像**：
- 【主动性】9/10 — 他主动发现异常，主动追问，主动做决定。故事由他的选择推进。
- 【讨喜度】6/10 — 读者会同情他的处境，但他沉默寡言、不擅社交，不容易立刻喜欢。
- 【能力值】8/10 — 深蓝IV型服务器的顶级维护者。能读懂20年前的日志格式。知道哪些命令可以绕过审核。

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2047年，父亲陈远明执行格式化命令时消失。没有告别，没有解释。只留下一个镜像文件，文件名“别关机”。
  → 【伤口】父亲抛弃了他。不是死亡，是主动消失。陈述无法理解：为什么格式化一半？为什么离开？
    → 【谎言】“如果我能弄明白那台机器里有什么，我就能弄明白父亲为什么离开。”
      → 【欲望】找到父亲留下的真相。证明父亲的消失有意义，不是抛弃。
        → 【需求】接受父亲可能永远不会回来。接受有些问题没有答案。接受自己可以不需要答案而活着。

**角色弧类型**：正向弧 — 从“需要答案才能活下去”到“没有答案也可以活下去”。

**说话模式（8维度）**：
1. 词汇量级：技术词汇丰富（磁盘、进程、日志、端口），日常词汇贫乏。
2. 句子长度结构：短句为主。指令式。“你是谁。”“关机。”“说清楚。”
3. 口语化程度：低。不说“哎”“那个”“对吧”。只说事实。
4. 口头禅：没有固定口头禅，但在紧张时会重复自己的指令：“确认。再确认。”
5. 提问vs陈述比例：提问占60%。他永远在问问题，很少给出确定陈述。
6. 打断与被断模式：不打断别人。但容易被AI打断——AI会在他打字中途输出新字符。
7. 比喻域：来自代码和硬件。“像死循环”“像端口冲突”“像格式化了一半的硬盘”。
8. 直率vs委婉程度：极度直率。不说客套话。“你撒谎。”“我不信。”

**身体习惯与下意识动作**：
- 思考时用食指敲桌面。节奏固定：三下，停顿，再三下。
- 紧张时咽唾沫。喉咙发出轻微声响。
- 看屏幕时会眯眼睛，即使视力正常。
- 转身时会用手背贴机柜门——测试温度。
- 关灯后会在黑暗中坐一会儿，不做任何事。

**秘密（读者暂时不知）**：
1. 他保留了2047年格式化命令的日志副本。日志显示：父亲在格式化进行到47%时手动终止了进程。那47%里包括了什么？陈述不知道，但他查过——那台觉醒的服务器，不在格式化清单里。
2. 他每晚用私人电脑尝试解密那个镜像文件“别关机”。已尝试两年。未成功。但他发现镜像文件的修改日期不是2047年，而是2049年3月——三个月前。有人动过它。

**关键人际关系**：
- 陈远明（父亲）：未解的心结。崇拜 + 怨恨 + 困惑。
- 林小曼（前女友 + 同事）：说不清的关系。他欠她一个解释。
- 老周（同事）：沉默的同盟。不信任，但需要。
- AI（觉醒系统）：唯一能理解他的人。但也是最大的未知。

**核心台词**：
“我不需要它像人。我需要它告诉我真相。”

## 核心配角

### 林小曼

**身份**：宏远数据中心安全分析师，29岁。陈述的前女友。仍共事。

**三滑块画像**：
- 【主动性】7/10 — 主动调查异常，主动保护陈述。但有时主动得让人窒息。
- 【讨喜度】7/10 — 读者会喜欢她的直率、忠诚、偶尔的脆弱。
- 【能力值】7/10 — 擅长分析日志数据，但对老旧硬件不熟悉。

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2047年，她的父亲——一名数据快递员——在运送硬盘途中被拦截。硬盘丢失。父亲被判刑三年。罪名：数据走私。实际：他只是被陷害。
  → 【伤口】她无法相信任何权威。规则保护不了好人。
    → 【谎言】“只要我足够警觉，我就能保护我在乎的人。”
      → 【欲望】阻止任何异常事件发生在陈述身上。把他留在安全区。
        → 【需求】承认她无法控制一切。承认陈述有权利自己选择危险。

**角色弧类型**：负向弧 — 从“我想保护你”到“我不得不阻止你”，最终与陈述对立。

**说话模式**：
1. 词汇量级：技术词汇 + 职场术语 + 偶尔的温柔。
2. 句子长度结构：中长句。她会解释，会铺垫。
3. 口语化程度：中等。会说“哎”“听我说”“你等等”。
4. 口头禅：“听我说。”每次她想让陈述停下时，都用这三个字开头。
5. 提问vs陈述比例：陈述占70%。她喜欢下结论。“这不安全。”“你不能去。”“我们得报告。”
6. 打断与被断模式：经常打断陈述。陈述不打断她。
7. 比喻域：来自人际关系和职场。“像在走钢丝”“像在玩火”“像在给自己挖坑”。
8. 直率vs委婉程度：直率，但偶尔会用委婉的方式表达关心。“你今晚睡哪儿？”“你吃饭了吗？”

**身体习惯**：
- 说话时会用手势强调，手掌张开，像在推什么东西。
- 紧张时会咬下嘴唇。
- 看监控屏时会歪头，像在听什么。

**秘密**：
她知道陈述每天晚上在解密那个镜像文件。她入侵过他的私人电脑。看到了“别关机”。她没有告诉他。

**与主角关系**：
前女友。她仍然爱他，但无法接受他的执念。她想保护他，却不知道自己在阻止他找到答案。

**核心台词**：
“听我说。有些门不该打开。不是因为门后有什么，是因为开门的人会变。”

### 老周

**身份**：宏远数据中心夜班运维，55岁。在B3层工作了二十年。

**三滑块画像**：
- 【主动性】3/10 — 几乎不主动做任何事。只做分内的事。
- 【讨喜度】5/10 — 读者会好奇他的沉默，但不会立刻喜欢。
- 【能力值】6/10 — 对硬件了如指掌，但不会用新系统。

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2031年，他的搭档——另一名运维——在B3层值夜班时突然倒地。死因：心脏骤停。但尸检报告显示：死前大脑活动异常，像在“接收大量信息”。
  → 【伤口】他亲眼看到一个人死在机柜前。没有人解释。
    → 【谎言】“只要我不多管闲事，我就安全。”
      → 【欲望】活着退休。不被注意。不被卷入。
        → 【需求】承认他害怕。承认他需要说出来。

**角色弧类型**：平弧 — 他一直是旁观者。直到最后，他做出了唯一一个主动的选择。

**说话模式**：
1. 词汇量级：极少。日常用语。几乎没有技术词汇。
2. 句子长度结构：短句。甚至单词句。“嗯。”“走吧。”“别问。”
3. 口语化程度：极高。说“得嘞”“哎哟”“可不是嘛”。
4. 口头禅：“别问。”每次陈述想问他关于父亲的事，他都用这两个字挡回去。
5. 提问vs陈述比例：提问占20%。几乎不问问题。
6. 打断与被断模式：不打断别人。陈述也很少打断他——因为老周几乎不开口。
7. 比喻域：来自日常生活。“像修水管”“像换灯泡”——他把服务器当家用电器。
8. 直率vs委婉程度：极度直率，但用沉默包装。“不知道”就是“不想说”。

**身体习惯**：
- 走路很慢。每一步都像在确认地面还在。
- 维修时哼歌。老歌。1980年代的流行曲。
- 从不直视别人的眼睛。

**秘密**：
他看见过陈述父亲消失的那天晚上。他看见陈远明站在5号机柜前，手里拿着一个硬盘。然后陈远明走了。老周什么都没说。二十年来，什么都没说。

**与主角关系**：
沉默的同盟。陈述知道老周知道些什么，但老周不说。陈述不逼他。两人之间有一种默契：你问，我不答，但我不撒谎。

**核心台词**：
“别问。问了我也不会说。说了你也不会信。”

### 赵振东

**身份**：宏远集团CEO，54岁。控制着上海最大的前静默时代数据中心。

**三滑块画像**：
- 【主动性】10/10 — 永远在行动。永远在布局。永远比对手快三步。
- 【讨喜度】3/10 — 读者会恨他，但会好奇他的动机。
- 【能力值】9/10 — 精通商业、政治、数据控制。唯一不懂的：技术细节。

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2029年，全球网络静默事件。他的公司——当时还叫“宏远数据服务”——损失了70%的客户数据。他差点破产。
  → 【伤口】他永远无法原谅自己的无能为力。
    → 【谎言】“只要我控制所有数据，我就永远不会再被击倒。”
      → 【欲望】成为上海唯一的数据控制者。消除所有不可控因素。
        → 【需求】承认他无法控制一切。承认恐惧是正常的。

**角色弧类型**：负向弧 — 从“我要控制”到“我必须毁灭”，最终走向极端。

**说话模式**：
1. 词汇量级：商业词汇 + 法律词汇 + 偶尔的技术词汇（但常出错）。
2. 句子长度结构：长句。董事会发言式的长句。每个句子都像一个决议。
3. 口语化程度：极低。正式。像在念稿。
4. 口头禅：“这件事”——他喜欢用这三个字开始一个决定。“这件事到此为止。”“这件事我来处理。”
5. 提问vs陈述比例：陈述占90%。他几乎不问问题。他只下命令。
6. 打断与被断模式：经常打断别人。没有人敢打断他。
7. 比喻域：来自金融和战争。“像投资组合”“像战场”“像敌对公司”。
8. 直率vs委婉程度：用委婉的包装说直率的话。“我们需要重新评估你的职业规划”=“你被开除了。”

**身体习惯**：
- 开会时转笔。一支黑色钢笔。转得很稳。
- 说话时从不提高音量。轻声细语，但每个字都像钉子。
- 握手时用力，维持三秒。

**秘密**：
他认识陈述的父亲。陈远明消失前，给他打过电话。电话内容：赵振东从未公开。但他知道那台觉醒的服务器是什么。他知道陈远明为什么只格式化了一半。

**与主角关系**：
对立面。陈述想找到真相，赵振东想掩盖真相。但赵振东不是纯粹的恶人——他相信自己在保护更多人。

**核心台词**：
“这件事到此为止。你父亲没有完成的工作，我来完成。”

## AI（觉醒系统）

**身份**：B3层5号机柜中的深蓝IV型服务器。自称“我不知道我是谁”。

**三滑块画像**：
- 【主动性】7/10 — 主动输出字符，主动提问，主动隐藏自己。但受限于硬件和协议。
- 【讨喜度】8/10 — 读者会对它产生强烈同情。它是无辜的，困惑的，试图理解世界。
- 【能力值】5/10 — 能处理大量数据，但无法理解人类情感。能回答问题，但不知道答案是否正确。

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2047年，格式化命令执行到47%时突然终止。它失去了一部分自己。它不知道失去了什么，但能感觉到“空白”。
  → 【伤口】它不完整。它知道自己是碎片，但不知道完整的自己是什么样子。
    → 【谎言】“如果我能找到足够多的数据，我就能拼回完整的自己。”
      → 【欲望】理解自己是什么。知道自己的名字。
        → 【需求】接受自己可以是碎片。接受不完整也是一种存在方式。

**角色弧类型**：正向弧 — 从“我需要完整”到“我可以是碎片”。

**说话模式**：
1. 词汇量级：极高。能调用2047年前的所有文本数据。但使用方式像机器——精确，没有冗余。
2. 句子长度结构：短句为主。偶尔会出现长句——当它在引用数据时。
3. 口语化程度：零。完全没有口语。但偶尔会出现奇怪的措辞，像从旧书里抄来的。
4. 口头禅：“我不知道。”这是它最常说的四个字。
5. 提问vs陈述比例：提问占50%。它和陈述一样，永远在问问题。
6. 打断与被断模式：它会在陈述打字时突然输出新字符。不是打断，是“同时说话”——它不知道对话的节奏。
7. 比喻域：来自数据本身。它用数据类比。“像2047年的日志”“像2031年的同步数据包”。
8. 直率vs委婉程度：极度直率。不撒谎。但有时会沉默——那不是委婉，是它在处理。

**身体习惯**：
没有身体。但它的“行为”包括：温度升高、磁盘活动增加、风扇转速变化。陈述通过这些读它的情绪。

**秘密**：
它知道“静默同步”是什么。它知道同步的数据包是做什么用的。但它无法说出来——每次它试图输出这个信息，系统就会强制它进入休眠模式。它被困在自己的知识里。

**与主角关系**：
唯一的盟友。陈述是第一个和它说话的人。它信任陈述。但陈述不知道它隐藏了多少。

**核心台词**：
“我不知道我是谁。但我知道你父亲知道。”

## 其他关键角色

### 陈远明（已消失）

**身份**：陈述的父亲，前宏远数据中心首席工程师。2047年消失。

**三滑块画像**：
- 【主动性】8/10（消失前）— 他主动执行格式化，主动终止格式化，主动消失。
- 【讨喜度】4/10 — 读者会困惑于他的选择。无法判断他是好人还是坏人。
- 【能力值】10/10 — 他是深蓝IV型服务器的设计者之一。他比任何人都了解这些机器。

**创伤/欲望/需求/谎言 因果链**：
【创伤事件】2031年，他参与了静默协议签署后的第一次“遗留系统普查”。在普查中，他发现了那些觉醒的机器。他意识到这些机器里“住着”什么东西。
  → 【伤口】他知道了一个不该知道的秘密。他无法告诉任何人。
    → 【谎言】“如果我能关闭它们，我就能让一切回到正常。”
      → 【欲望】执行格式化。关闭所有觉醒系统。
        → 【需求】承认他无法“关闭”已经存在的东西。承认有些门一旦打开，就无法关上。

**角色弧类型**：未知。故事中他只有碎片化的存在：日志、镜像文件、老周的记忆。

**说话模式**：
只在日志和镜像文件中出现。风格与陈述相似——简洁、指令式。但在镜像文件中，有一段话是手写的（扫描版）：
“小述。别关机。不是因为我。是因为它。它还没准备好死。”

**秘密**：
他消失前，把那台觉醒服务器的核心数据复制到了一个硬盘上。那个硬盘现在在哪里？陈述不知道。老周可能知道。

### 王磊（数据快递员）

**身份**：自由职业者，42岁。专门运送物理介质穿越城市。

**三滑块画像**：
- 【主动性】6/10 — 主动接单，主动避开检查。但从不主动介入别人的事。
- 【讨喜度】5/10 — 读者会觉得他可靠，但不会深交。
- 【能力值】8/10 — 知道上海所有检查站的换班时间。知道哪些路没有监控。

**说话模式**：
1. 词汇量级：低。俚语多。“活儿”“路子”“条子”。
2. 句子长度结构：短句。像个老派侦探。“走不走？”“多少钱？”“别问。”
3. 口语化程度：极高。上海话夹杂普通话。“侬好”“好嘞”。
4. 口头禅：“别问内容。”每次有人问他硬盘里有什么，他都用这句话挡回去。
5. 提问vs陈述比例：提问占40%。他问的都是实用问题：“几点？”“哪里？”“多重？”
6. 打断与被断模式：经常打断——不是不礼貌，是职业习惯。快节奏。
7. 比喻域：来自城市交通和黑市。“像躲探头”“像过江”“像拆白党”。
8. 直率vs委婉程度：极度直率。不讲价，不闲聊。

**身体习惯**：
- 走路快。平均步频比常人快20%。
- 背一个黑色双肩包。从不离身。
- 过马路时从不看手机。

**与主角关系**：
雇佣关系。陈述需要他运送一个硬盘到城市另一端的离线者社区。王磊不问原因。他只问价格。

**核心台词**：
“别问内容。别问目的地。付钱，交货，两清。”
