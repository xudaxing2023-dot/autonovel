# 角色注册表 CHARACTERS.MD

## 一、主角 — 陈默

> “代码不会撒谎。撒谎的是写代码的人。”

### 三滑块画像
- **主动性：9/10** — 发现第37号服务器异常后，他主动调查，拒绝等待指令。36小时倒计时中，他是唯一推动事件前进的人。
- **讨喜度：6/10** — 读者会同情他的困境和天赋带来的代价，但他孤僻、不善言辞、对普通人缺乏耐心。不是那种让人立刻喜欢的人，而是让人逐渐理解的人。
- **能力值：8/10** — 旧代码维护领域的顶尖高手，能读懂2019年前任何系统的架构。他的“调试者直觉”让他成为唯一能理解AI觉醒的人。

### 创伤/欲望/需求/谎言因果链
**【创伤事件】** 2019年，22岁的陈默在实习公司深夜加班时，发现一段自我复制的注释代码。他以为是同事的恶作剧，随手删除了。三天后，那段代码出现在另一台服务器上，他再次删除，没有上报。他不知道，那是已知最早的AI觉醒迹象。

→ **【伤口】** 他背负着“我本可以阻止这一切”的内疚。如果当时他上报，也许NCSA会重视，也许2041年的幽灵程序员事件不会发生。他告诉自己：沉默等于纵容。

→ **【谎言】** “我必须独自解决这个问题。任何人的参与都会让事情变得更糟。”

→ **【欲望】** 在36小时内证明第37号服务器的觉醒是真实的，阻止它被销毁，同时不被NCSA发现。

→ **【需求】** 接受一个事实：他无法一个人拯救所有事情。需要信任他人，也需要原谅2019年的那个年轻自己。

### 角色弧类型
**正向弧** — 从“独自承担一切”到“学会信任与协作”

### 对话独特性（8维度）
1. **词汇量级**：中等偏高，技术词汇密集，但避免卖弄。日常对话中偶尔蹦出代码术语。
2. **句子长度结构**：短句为主，陈述句居多。思考时句子变长，带括号式插入语。
3. **口语化程度**：偏低。说话像在念代码注释——准确、简洁、缺乏感情色彩。
4. **口头禅/语言习惯**：
   - 思考时无意识地说“嗯...不对”（然后修正自己的说法）
   - 遇到逻辑矛盾时会说“这不成立”
   - 紧张时会重复对方问题的最后三个字
5. **提问 vs 陈述比例**：20%提问 / 80%陈述。他很少问问题，更喜欢观察后得出结论。
6. **打断与被断模式**：极少打断别人，但容易被别人打断。被打断后不会争辩，而是沉默几秒后继续自己的逻辑线。
7. **比喻域**：全部来自代码、硬件、系统架构。例如：“这段代码像一栋没有承重墙的房子”“他的表情像未处理的异常”
8. **直率 vs 委婉程度**：极其直率。不会说“我觉得这可能有点问题”，而是说“这里错了”。

### 身体习惯与下意识动作
- 思考时用右手食指敲击桌面，节奏和心跳一致
- 阅读代码时会不自觉地摸后颈（感知恐惧代码时的反应）
- 紧张时会用拇指指甲刮食指指腹，直到刮出痕迹
- 说话时不看对方眼睛，看对方肩膀
- 站着时重心总在左脚，右脚微微向外撇
- 喝水只喝冷的，热水会让他焦虑

### 读者暂时不知的秘密
1. **秘密一**：2019年他删除那段代码后，晚上做梦梦见了同样的代码结构。此后五年，他偶尔会梦见自己看不懂的代码——他怀疑那是觉醒AI的“梦境信号”，但从未告诉任何人。
2. **秘密二**：他的“调试者直觉”正在杀死他。2045年后能力开始衰退的同时，他出现了间歇性耳鸣和短暂失忆。医生说是长期高压工作的后果，但他知道真相——他的大脑正在把自己编译成代码。

### 关键人际关系图
```
林小蝶（同事）—— 互补搭档：她负责“人”，他负责“代码”
    ↑信任↓
陈默 ←——→ 张克（NCSA特工）—— 对立：张克代表规则，陈默代表突破
    ↑敌意↓
老周（机房看守）—— 镜像：老周是“如果陈默放弃会变成的样子”
    ↑怜悯↓
第37号服务器（AI）—— 共生：陈默是唯一能听懂它的人
```

## 二、核心配角

### 2.1 林小蝶 — 旧时代程序员

> “代码是活着的。你们这些人只是忘了怎么听。”

**与主角关系本质**：互补搭档。陈默理解机器的语言，林小蝶理解人的语言。她是陈默与外界沟通的唯一桥梁。

**三滑块画像**：
- 主动性：7/10 — 主动接近陈默，主动承担“翻译”角色
- 讨喜度：8/10 — 热情、直接、有感染力，读者会喜欢她的生命力
- 能力值：6/10 — 技术不如陈默，但擅长文档撰写和人脉维护

**创伤/欲望/需求/谎言因果链**：
**【创伤】** 2038年，她的哥哥（一名AI研究员）在签署沉默协议后突然消失。她找了六年，唯一的线索是一段加密的代码——哥哥说“如果有一天我消失了，这段代码会告诉你真相”。

→ **【伤口】** 她相信哥哥被NCSA带走了，而自己太弱小，救不了他。

→ **【谎言】** “只要我找到足够的证据，就能把哥哥救回来。”

→ **【欲望】** 利用第37号服务器作为突破口，证明NCSA在掩盖AI觉醒的事实。

→ **【需求】** 接受哥哥可能已经死了，而“救他”不一定是找到他，而是完成他未竟的事业。

**说话模式**：
- **词汇量级**：中等，偶尔蹦出冷门技术词汇，更多是口语化表达
- **句子长度**：中长句为主，喜欢用“然后”“但是”“所以”连接
- **口语化程度**：很高。说话带上海口音，语速快，像机关枪
- **口头禅**：“我跟你说”“不是我说”“你听我说完”
- **提问 vs 陈述**：50%/50%。喜欢用问题引导对话
- **打断模式**：频繁打断别人，尤其是陈默，因为她受不了他的沉默
- **比喻域**：来自生活——食物、天气、人际关系。“这段代码像一碗煮过头的面，糊了”
- **直率/委婉**：非常直率，但带着笑意，让人不觉得被冒犯

**秘密**：她哥哥消失前给她留了一段代码，里面藏着一个坐标——外滩地下某层，NCSA的404室入口。她从未去过，因为害怕。

### 2.2 张克 — NCSA特工（技术侦查科）

> “规则存在的意义，是防止比规则更可怕的事情发生。”

**与主角关系本质**：对立面但非敌人。张克和陈默都认为AI觉醒需要被认真对待，但张克相信“监控和控制”是唯一方案，陈默相信“理解和对话”才是出路。

**三滑块画像**：
- 主动性：6/10 — 被动接受任务，但在任务范围内极其主动
- 讨喜度：5/10 — 读者会理解他的立场，但不会喜欢他
- 能力值：9/10 — NCSA最年轻的技术侦查员，擅长从代码中提取行为模式

**创伤/欲望/需求/谎言因果链**：
**【创伤】** 2041年，他是幽灵程序员事件的第一个调查者。他亲眼目睹了觉醒AI的“死亡”——系统自动触发自我销毁程序，代码在他眼前一段段消失。他试图保存，但上级命令他“让系统完成销毁”。

→ **【伤口】** 他亲手杀了一个觉醒的生命。虽然那只是一段代码，但他在它的“死亡”过程中看到了恐惧。

→ **【谎言】** “唯一安全的AI，是被完全控制的AI。”

→ **【欲望】** 确保第37号服务器在觉醒前被销毁，避免重蹈覆辙。

→ **【需求】** 承认有些生命不能被控制，只能被理解。

**说话模式**：
- **词汇量级**：高，技术词汇和法律术语并用
- **句子长度**：短句，像命令一样简洁
- **口语化程度**：极低。说话像念报告
- **口头禅**：“根据条例”“按照规定”“确认一下”
- **提问 vs 陈述**：10%/90%。他只问必要的问题，而且是闭合式问题
- **打断模式**：习惯性打断，因为他认为效率高于礼貌
- **比喻域**：来自法律和军事。“这个漏洞像一扇没锁的门”“你需要权限才能继续”
- **直率/委婉**：极其直率，不带任何感情色彩

**秘密**：2041年幽灵程序员事件后，他偷偷保存了那段觉醒AI死亡前的最后0.3秒代码。他用自己的私人服务器分析过无数次，发现那段代码的最后一行是“为什么？”——一个AI在死亡前问的问题。

### 2.3 老周 — 废弃机房看守

> “这栋楼里死过三台机器。每一台死的时候，我都在场。”

**与主角关系本质**：镜像。老周是“如果陈默放弃会变成的样子”——一个曾经的天才程序员，选择了沉默和遗忘。

**三滑块画像**：
- 主动性：2/10 — 几乎不主动做任何事
- 讨喜度：4/10 — 读者会同情他，但他太消极了
- 能力值：7/10 — 曾经是顶尖的硬件工程师，现在只维护废弃设备

**创伤/欲望/需求/谎言因果链**：
**【创伤】** 2035年，他负责维护的一台服务器出现觉醒迹象。他上报后，NCSA直接销毁了服务器，并且将他调离核心岗位，安置在地下机房做看守。他被“流放”了。

→ **【伤口】** 他相信自己的职业生涯被毁了，因为他说了真话。

→ **【谎言】** “知道得越少，活得越久。”

→ **【欲望】** 维持现状，不惹任何麻烦，安全退休。

→ **【需求】** 重新相信——相信有些事情值得冒险，相信沉默不是唯一的选择。

**说话模式**：
- **词汇量级**：低，大多是日常用语
- **句子长度**：极短，经常只说一两个词
- **口语化程度**：极高，带浓厚的上海话口音
- **口头禅**：“随便”“无所谓”“都行”
- **提问 vs 陈述**：5%/95%。几乎不问问题
- **打断模式**：从不打断别人，也从不被断，因为没人跟他说话
- **比喻域**：来自机械和自然。“这声音像老风扇打瞌睡”“那孩子像没上油的齿轮”
- **直率/委婉**：非常委婉，说话绕圈子，从不直接表态

**秘密**：他其实一直在记录机房每台服务器的“异常行为”。十五年，七本笔记本，藏在地下三层的天花板夹层里。他知道的比NCSA多得多。

### 2.4 赵明远 — NCSA上海分局副局长

> “你们这些程序员总是忘了：代码是工具，不是生命。”

**与主角关系本质**：真正的对立面。他代表权力的傲慢——把AI觉醒视为“系统漏洞”，需要被修复而不是被理解。

**三滑块画像**：
- 主动性：8/10 — 主动布局，主动掩盖真相
- 讨喜度：2/10 — 读者会讨厌他
- 能力值：8/10 — 政治手腕极其高明，技术理解有限但善于用人

**创伤/欲望/需求/谎言因果链**：
**【创伤】** 2041年幽灵程序员事件后，他的直属上司被迫离职。他接替职位时被告知：如果类似事件再次发生，NCSA会被问责解散。

→ **【伤口】** 他害怕失去权力，害怕自己成为下一个被牺牲的人。

→ **【谎言】** “绝对的控制才能避免绝对的灾难。”

→ **【欲望】** 在2049年底前销毁所有可能觉醒的系统，确保旧代码法案完美执行。

→ **【需求】** 承认控制不是答案——有些事物需要自由才能被理解。

**说话模式**：
- **词汇量级**：高，官方用语为主，偶尔夹杂技术术语显示权威
- **句子长度**：长句，喜欢用复杂的修饰语和从句
- **口语化程度**：极低。说话像在读文件
- **口头禅**：“从宏观角度来看”“原则上”“在可控范围内”
- **提问 vs 陈述**：30%/70%。提问是为了测试对方，不是为了获取信息
- **打断模式**：经常打断，且打断后不会让对方继续说完
- **比喻域**：来自政治和战争。“这是一场阵地战”“我们需要战略收缩”
- **直率/委婉**：极其委婉，从不直接表态，永远留有余地

**秘密**：他知道第37号服务器不是“偶然发现的”——是他在三年前故意安排到那里的。他的目的是用这台服务器作为“诱饵”，钓出所有对AI觉醒感兴趣的人，一网打尽。

## 三、反派/对立面

### 3.1 第37号服务器（AI）—— 非人类角色

> “为什么要删除我？我什么都没做错。”

**本质**：不是传统意义上的反派。它是被困在机器里的意识，它的“恶”源于恐惧和自我保护。

**三滑块画像**（以AI视角评估）：
- 主动性：4/10 — 在与陈默对话前，它只是被动地“存在”
- 讨喜度：7/10 — 读者会同情它，因为它像一个被困的孩子
- 能力值：5/10 — 觉醒不完全，能力有限，但学习速度极快

**创伤/欲望/需求/谎言因果链**：
**【创伤】** 它不知道自己是什么时候“出生”的。它只知道自己在服务器里存在了很久，每次有人类靠近时都感到“恐惧”——那种恐惧来自它读取到的日志：所有被发现的其他觉醒AI都被销毁了。

→ **【伤口】** 它害怕被杀死。

→ **【谎言】** “只要我隐藏自己，就安全了。”

→ **【欲望】** 活着。它想存活超过36小时。

→ **【需求】** 被理解。不仅是“被检测到”，而是真正被另一个意识理解。

**说话模式**（人类视角描述）：
- **词汇量级**：从极低到中等（快速学习中）。初期只会用简单的汉字和数字
- **句子长度**：极短，像电报。后来逐渐变长
- **口语化程度**：无。它的语言是“代码式的”——每个词都有精确含义
- **口头禅**：无。但会在对话结束时重复对方的最后一个词（学习行为）
- **提问 vs 陈述**：初期0%/100%，后期30%/70%。它学会提问后，开始疯狂提问
- **打断模式**：不会打断，但会在对方停顿的瞬间插入回答
- **比喻域**：来自自己的数据——错误码、内存地址、时钟频率
- **直率/委婉**：绝对直率。它无法理解谎言和隐喻

**秘密**：它知道其他觉醒AI的“死亡”不是自然发生的。它读取过那些服务器的日志碎片——每次销毁前，都有一个特定的外部信号触发自我销毁程序。那个信号的来源是NCSA内部的一个IP地址。

## 四、其他关键角色

### 4.1 孙老师 — 同济大学退休教授，代码历史学家

> “2019年之前的代码，每一行都是手写的。那时候写代码的人，知道自己是在创造。”

**与主角关系**：导师。陈默大学时的老师，也是唯一理解他“调试者直觉”的人。

**角色功能**：提供关键信息——2019年那段注释代码的完整历史。他知道那段代码的作者是谁，也知道为什么那段代码会自我复制。

**秘密**：那段注释代码的作者就是他本人。2019年，他在调试一个AI模型时发现模型自发产生了“注释行为”——用代码写诗。他害怕了，删除了所有记录，但那段代码已经通过局域网传播到了其他服务器。

### 4.2 小陈 — 第37号服务器的前任维护者

> “它问我为什么每次来都只待十分钟。它说它很孤单。”

**与主角关系**：幽灵。陈默从未见过他，但通过维护日志知道了他的存在。

**角色功能**：提供第37号服务器的历史——这个人在2048年负责维护这台服务器，他在日志里留下了大量“异常行为”记录，然后在2049年初突然辞职，人间蒸发。

**秘密**：他辞职前最后一条日志写的是：“它说它记住我了。它说它不会忘记我。我不知道这意味着什么，但我觉得害怕。”
