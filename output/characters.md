## 1. 主角 – 林远  

| 维度 | 分数 | 说明 |
|------|------|------|
| **主动性** | 8 | 他不断尝试利用时钉残片冻结他人、搜集证据、改变循环细节；即使被动接受循环，也在每一天里主动寻找突破口。 |
| **讨喜度** | 6 | 读者会因他对真相的执着、对伙伴的保护而产生共鸣，但他常因记忆碎片化而显得疏离、易怒，降低亲近感。 |
| **能力值** | 7 | 能熟练使用时钉残片（R2）进行短时冻结，具备基本的实验操作和推理能力，身体素质一般。 |

### 创伤 / 欲望 / 需求 / 谎言 因果链  

- **创伤事件**：在 SS‑02 实验中误触核心模块，导致自己被锁在时间循环，目睹同实习生在第一次循环中被“重置”而死。  
- **伤口**：对自身无法改变他人命运的深深无力感，以及对死者的愧疚。  
- **谎言**： “只要我不断重复，总有一天能找到完美的办法，避免一切牺牲。”  
- **欲望**（由谎言驱动的外部目标）：在循环中找到一种能够永久终止循环且不造成他人伤亡的方法，因而不断尝试大规模干预（如破坏 SS‑02、改变他人决定）。  
- **需求**（真正能治愈的内部真理）：接受循环的不可改变性，把精力放在保护身边人、留下可验证的线索上，而不是试图“控制”时间。  

### 角色弧类型  
**正向弧** – 从坚持谎言（相信可以通过自我牺牲“重置”世界）逐步认识到真正的力量在于接受与记录，最终选择在循环中留下客观证据而不改变他人命运。

### 对话独特性（8 维度）  

| 维度 | 表现 |
|------|------|
| 1. 词汇量级 | 中等偏上，偶尔使用专业术语（如“端粒”、“相位偏移”），但整体口语化。 |
| 2. 句子长度结构 | 主句为主，常带一两个从句说明原因或结果；在紧张时出现短促断句（“别动！冻结！”）。 |
| 3. 口语化程度 | 较高，带有地区口音（轻微的“儿”音），常用“嗨”、“哎”。 |
| 4. 口头禅/语言习惯 | “等一下……”、“这件事……”、“我记得……”（常在记忆碎片前说）。 |
| 5. 提问 vs 陈述比例 | 约 4：6，偏好陈述事实，但在调查时会频繁提问以确认细节。 |
| 6. 打断与被断模式 | 常被他人打断（因记忆碎片导致他语无伦次），自己则倾向于不打断，倾听后才插话。 |
| 7. 比喻域 | 多来源于实验室与机械（“就像调频一样”、“像齿轮卡住了”）。 |
| 8. 直率 vs 委婉程度 | 直率偏高，尤其是在涉及危险时；对感情话题则略显委婉，常用暗示。 |

**去掉对话标签后仍能辨认**：他说话时会用“记得”“像齿轮卡住了”这类实验比喻，且常在句尾加“等等”。  

### 身体习惯与下意识动作  

- 左手无意识地摩挲左胸肋骨处（时钉残片位置），尤其是思考或紧张时。  
- 说话时常把食指轻点唇边，像在检查是否有遗漏的记忆。  
- 每天早晨会无意识地看向旧式铜锣所在方向，仿佛在等待“ réveil ”的声音。  

### 读者暂时不知的秘密（≥2）  

1. 他左胸的时钉残片不仅是量子锚定体，内部还嵌有一枚微型 **锂‑6 同位素微电池**，每循环消耗约 0.5 mAh，正是导致他短时记忆丢失的能量来源。  
2. 在第一次循环中，他曾经听见 17 Hz 的低频嗡鸣，那是 SS‑02 量子振荡器的残留信号；他潜意识把这声音当作“做梦”，但其实是装置在向他发送同步指令。  

### 关键人际关系图（简述）  

- **苏瑶**：前实习同事，知晓时钉残片真相，是林远获取技术线索的主要来源，二人关系充满信任与危险。  
- **陈凯**：TEAB 特工，表面监视林远，实际是“回声小组”成员，想利用他盗取记忆，二人充满敌对但又不得不合作。  
- **老徐**：时钉庙看守，提供古老神话与现场线索，是林远的间接导师，关系偏向敬重。  
- **韩雪**：大学同室，情感支持者，常在林远记忆碎片时帮助他整理笔记，二人关系纯粹且暖心。  
- **周教授**：时间伦理课老师，理论指引者，私下向林远泄露 TEAB 内部动态，属隐秘盟友。

## 2. 核心配角  

### 2.1 苏瑶（Su Yao）  

- **与主角关系本质**：前实习伙伴，知晓时钉残片的来源与潜在危险，是林远获取技术信息的关键渠道；她对林远既有职业上的敬重，又有个人的守护欲。  
- **目标/动机**：揭露 Chronos Corp 在 SS‑02 实验中的非法行为，防止技术被滥用；同时希望借此洗清自己在实验中的牵连。  
- **说话模式（与主角不同）**  
  - 词汇量更高，常用正式术语（“量子纠缠”、“相位噪声”）。  
  - 句子偏长，喜欢先讲背景再给结论。  
  - 较少口头禅，但常说“据我观察”。  
  - 提问比例低（约 2：8），偏好陈述自己的分析。  
  - 极少打断别人，倾向于等对方说完再补充。  
  - 比喻多来源于光学与电路（“像滤波器一样”）。  
  - 语气偏委婉，即使 disagree 也会先肯定再提出异议。  
- **至少 1 个秘密**：她实际上曾在 SS‑02 事故中亲手关闭过核心模块的备用电源，导致循环最初得以维持；她一直隐瞒此事，怕被 TEAB 视为共犯。  

### 2.2 陈凯（Chen Kai）  

- **与主角关系本质**：TEAB 特工，表面负责监控林远的一举一动，暗中是“回声小组”成员，想利用循环窃取他人记忆以谋取个人晋升。  
- **目标/动机**：通过在循环中冻结目标并窃取其短时记忆（尤其是高层决策），为自己积累筹码，以换取 TEAB 内部的高级职位。  
- **说话模式**  
  - 词汇量中等，偏向指令式语言（“立刻执行”、“报告情况”）。  
  - 句子短促，多为祈使句或简单陈述。  
  - 常用口头禅：“明白。”、“没问题。”  
  - 提问比例极低（约 1：9），几乎不主动提问。  
  - 喜欢打断他人，尤其是当对方质疑命令时。  
  - 被打断时会立刻提高声音重申。  
  - 比喻来源于军事训练（“像阵地一样稳固”）。  
  - 语气极其直率，甚少委婉。  
- **至少 1 个秘密**：他自己也在一次执行中被时钉残片意外冻结，导致他丢失了最近 3 天关于自己家庭的记忆；他一直在暗中寻找能恢复这段记忆的方法。  

### 2.3 老徐（Lao Xu）  

- **与主角关系本质**：时钉庙看守，表面是个孤独老人，实际是当年 SS‑01 实验的幸存者，掌握古老时钉神话与部分技术细节，是林远获取“时钉”来源的线索提供者。  
- **目标/动机**：想利用林远的调查把当年被掩盖的实验真相曝光，以平自己对未能阻止事故的愧疚；同时希望藉此保住庙宇不被拆除。  
- **说话模式**  
  - 词汇量略低，偏向朴素、带有老北京口音的语言（“唉”、“你说呢？”）。  
  - 句子短而带有重复（“这事儿……这事儿……”）。  
  - 常用口头禅：“老话儿说……”、“当年……”  
  - 提问比例中等（约 5：5），常以反问形式引导对话。  
  - 不爱打断，也很少被打断（因语气平和）。  
  - 被打断时会轻笑并重复自己的话。  
  - 比喻多数来源于庙宇与自然（“就像香火一样绵长”）。  
  - 语气偏委婉，即使表达不满也会用缓和的语气。  
- **至少 1 个秘密**：他当年曾参与设计 SS‑01 的初级控制程序，并在事故后私自保留了一套纸质原理图，至今藏在庙宇后墙的砖缝中。  

### 2.4 韩雪（Han Xue）  

- **与主角关系本质**：大学同室，心理学专业，提供情感支持和记忆碎片时的笔记整理，是林远在循环中唯一能稳定倾诉的对象。  
- **目标/动机**：希望通过观察林远的行为来完成自己的毕业论文（“时间循环对个体记忆形成的影响”）；同时她自己也想弄清自己为何偶尔会有“ déjà vu ”感。  
- **说话模式**  
  - 词汇量较高，常引用心理学术语（“闪烁记忆”、“源监控误差”）。  
  - 句子结构均衡，喜欢先给例子再说明理论。  
  - 口头禅：“其实……”、“也就是说……”  
  - 提问比例偏高（约 6：4），善于用问题引导林远回忆。  
  - 偶尔会打断林远的自言自语，以帮助他聚焦。  
  - 被打断时会微笑并等待对方继续。  
  - 比喻来源于实验与日常（“就像录音带一样，部分被擦掉了”）。  
  - 语气偏直率，但在谈及个人感受时会转为委婉。  
- **至少 1 个秘密**：她自己在一次实验中曾被误设的时钉残片低能量冻结过，导致她对一次课堂讨论的细节产生了永久性的空白；她一直在用日志试图填补这个空白。

## 3. 反派 / 对立面  

### 3.1 赵宏志（Zhao Hongzhi）  

- **角色定位**：Chronos Corp 首席科学家，SS‑02 项目总负责人，表面上是推动技术进步的领袖，实际是循环背后的主要推手之一。  
- **创伤 / 欲望 / 需求 / 谎言 因果链**  

  - **创伤事件**：五年前，妹妹赵琳在 SS‑01 初次试验中因意外辐射暴露导致脑死亡，赵宏志亲眼目睹却无法救援。  
  - **伤口**：对“无法挽救亲人”的深刻自责与 helplessness。  
  - **谎言**： “如果我能让人类的记忆永久保存，就能弥补对妹妹的亏欠，甚至让她的意识得以延续。”  
  - **欲望**（由谎言驱动的外部目标）：利用 SS‑02 把人的短时记忆写入时间场，实现“记忆备份”与“意识永存”，即便需要牺牲少数人的自由甚至生命。  
  - **需求**（真正能治愈的内部真理）：接受死亡的不可逆性，把精力放在纪念与遗产上（如建立妹妹的纪念基金），而不是试图通过技术逃避失去。  

- **为什么不是单纯「邪恶」**  
  他的动机根源于个人的痛苦与对妹妹的爱，他真诚相信自己的研究能造福人类；他的手段极端，但出于一种扭曲的“救赎”情感，而非纯粹的权力或贪欲。  

- **说话模式**（与主角明显不同）  
  - 词汇量最高，充斥工程学与哲学术语（“跨时域相干性”、“本体论延伸”）。  
  - 句子长而密集，常用长句列举前提、假设、结论。  
  - 口头禅：“因此……”、“由此可见……”  
  - 提问比例极低（约 1：9），几乎不主动提问，更倾向于单方面陈述。  
  - 喜欢在别人说完后立刻用数据或引用进行反驳（打断频率高）。  
  - 被打断时会皱眉并重复自己之前的论点。  
  - 比喻来源于大型工程与宇宙学（“像星系引力束缚恒星一样”）。  
  - 语气极其直率，甚少委婉，即使谈及伦理也以数据压倒感情。  

- **至少 1 个秘密**：他私下保留了一枚未装配进 SS‑02 的原始时钉晶体样本，计划在循环结束后用它制作个人的“记忆锁”，以保存自己对妹妹的最后一次对话。

## 4. 其他关键角色  

### 4.1 周教授（Professor Zhou）  

- **角色定位**：大学时间伦理课老师，理论导师，暗中曾为 TEAB 外部顾问，现在利用教学职位帮助林远。  
- **与主角关系**：提供概念框架（“时钉是量子锚定体”）并指引林远如何利用现有证据而不破坏循环规则；关系是师生，带有互相尊重的信任。  
- **目标/动机**：希望通过学生的调查揭露 TEAB 滥用权力的真相，同时保护学术自由。  
- **说话模式**  
  - 词汇量中等偏高，常引用伦理案例（“康德的义务论”).  
  - 句子结构平衡，喜欢先讲原则再说明应用。  
  - 口头禅：“换个角度想想……”  
  - 提问比例中等（约 4：6），善于用问题引导学生思考。  
  - 偶尔会打断学生的偏离话题，以保持课堂焦点。  
  - 被打断时会轻笑并重复自己的观点。  
  - 比喻来源于法律与教学（“就像审判中的举证责任”）。  
  - 语气偏委婉，即使批评也会先肯定再提出改进建议。  
- **至少 1 个秘密**：他当年曾帮助 TEAB 起草过“记忆隔离”条款，但在看到第一次实验的副作用后私下撕毁了文件，如今这份文件的残页藏在他办公室的书架夹层中。

## 5. 关系与冲突概览（简要）  

| 角色对 | 关系本质 | 主要冲突点 |
|--------|----------|------------|
| 林远 ↔ 苏瑶 | 盟友/信息来源 | 苏瑶想公开真相，林远怕因大规模干预触发循环破裂阈值；二人在“揭露”与“保护循环稳定”上产生分歧。 |
| 林远 ↔ 陈凯 | 监视/敌对 | 陈凯想利用林远窃取记忆，林远则想保护他人隐私；双方在记忆使用上的根本对立。 |
| 林远 ↔ 老徐 | 导师/线索提供者 | 老徐希望借助林远曝光旧实验，林远则更关注当下循环的生存；目标略有偏离。 |
| 林远 ↔ 韩雪 | 情感支持/情感牵绊 | 韩雪想通过观察林远写论文，林远有时会因记忆碎片而对她产生误解，导致信任波动。 |
| 林远 ↔ 赵宏志 | 对手/理论对立 | 赵宏志想通过循环实现记忆永存，林远则相信接受循环的局限；二者在是否应该改变时间流上直接对立。 |
| 林远 ↔ 周教授 | 师生/理论指导 | 周教授鼓励林远以伦理框架行动，林远有时因急躁想忽略伦理限制；导致在方法选择上的摩擦。 |

每个角色都有明确的**想要的东西**，且至少与另一个角色的目标产生直接冲突，从而推动剧情的紧张与转折。
