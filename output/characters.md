# 《零点协议》角色注册表

## 【主角】陈默

### 三滑块画像
**主动性：8/10** — 他是追查真相的驱动者，但行动常被外部事件打断，被迫在36小时内做出抉择。

**讨喜度：6/10** — 读者会同情他的困境，但他冷漠寡言、不擅社交，不是那种让人立刻喜欢的类型。加分项：他对老旧设备的“感情”有一种笨拙的温柔。

**能力值：9/10** — 硬件直觉独一无二，15年维修经验让他能“听”出系统的呼吸。短板：完全不懂量子通信和新架构。

### 创伤/欲望/需求/谎言 因果链
**【创伤事件】** 7岁时父亲（盘古原始团队工程师）因“技术事故”被带走调查，再也没回家。母亲说他“犯了错误”，但陈默后来在旧档案里发现父亲是主动销毁部分设计图纸后消失的。

→ **【伤口】** 无法相信任何“系统”——无论是人的承诺还是机器的稳定性。一切都会背叛。

→ **【谎言】** “机器比人可靠。人不说话的时候在撒谎，机器的错误码至少诚实。”

→ **【欲望】** 找到父亲消失的真相（外部目标）。他相信只要理解“盘古”的全部代码，就能明白父亲做了什么。

→ **【需求】** 接受“有些错误无法修复，只能被原谅”——包括父亲的选择，包括自己即将做出的决定。

### 角色弧类型
**正向弧** — 从“拒绝信任任何人”到“学会在不可靠的世界里做出选择”。

### 对话独特性（8维度）

1. **词汇量级**：中等偏低。技术术语精确，日常词汇贫乏。不会用“美妙”“感人”这类词，最多说“还行”“凑合”。

2. **句子长度结构**：短句为主。陈述句占80%。极少用从句。

3. **口语化程度**：偏高。带上海口音，有“喏”“伐”“呀”等语气词。但从不骂脏话。

4. **口头禅/语言习惯**：
   - 评价事物时先说“难讲”（上海话“不好说”）
   - 被问及感受时沉默3秒再回答
   - 修理设备时会自言自语：“侬个册佬（你这家伙），又哪能了？”

5. **提问vs陈述比例**：1:4。他很少提问，更喜欢观察后下结论。但遇到不理解的现象时会突然连续追问。

6. **打断与被断模式**：几乎不打断别人。被人打断时不会争辩，只是闭嘴等对方说完。这种沉默反而有压迫感。

7. **比喻域**：全部来自硬件维修。“像电容爆浆之前的手感”“跟硬盘坏道似的，越读越慢”“热得像CPU没涂硅脂”。

8. **直率vs委婉程度**：极端直率。不会寒暄。“你挡到光了”“这东西没救”“你说话太慢”。

**测试段落（去标签可识别）：**
> “难讲。这个风扇声不对——不是缺油，是轴承偏了。喏，你听，每转第三圈有个卡顿。还能用三个月，但最好换了。……别问我怎么知道，手上有感觉。”

### 身体习惯与下意识动作
- 说话时手指无意识地在桌面或工具上敲击——模仿键盘节奏
- 听别人讲话时会偏头，左耳朝向对方（长期用左耳听硬盘声养成的习惯）
- 紧张时会摸左手食指第二关节（那里有老茧，是他最常用的螺丝刀抵出的痕迹）
- 思考时闭眼，眼皮快速颤动（像在读内部屏幕）

### 秘密（读者暂时不知）

1. **父亲留下的加密信息**：陈默在父亲旧物中发现一个U盘，里面只有一串数字：`47.2, 121.3, 9, 1998, 0317`。他解码后得知是盘古机房地下9米处的一个坐标——但他从未去核实。

2. **少年犯罪记录**：16岁时，陈默曾潜入盘古机房试图下载核心代码片段。被保安发现后，因“未成年人+技术员子弟”被内部处理，未留档案。但保安队长（老周）记住了他。

3. **耳鸣的真相**：每次硬件直觉触发后的耳鸣，不只是听觉神经疲劳——他能听到一种低频的“节律”，像是某种信号。他从未告诉任何人。

### 关键人际关系图

```
【父亲】（失踪）→ 驱动陈默追查真相
【何安林】（同事/对立）→ 互补型冲突，互相看不起但不得不合作
【刘姐】（上司/保护者）→ 唯一知道陈默少年潜入事件的人
【李想】（年轻同事/崇拜者）→ 陈默不耐烦但暗中保护的晚辈
【盘古AI】（非人关系）→ 逐渐形成的“对话者”，超出陈默对机器的理解
```

## 【核心配角】何安林

### 三滑块画像
**主动性：7/10** — 积极主动寻找真相，但方法更系统、更符合规程。

**讨喜度：4/10** — 读者会觉得他烦人、教条、自以为是。但后期会理解他的谨慎。

**能力值：8/10** — AI伦理和量子系统方面的专家，但缺乏陈默那种“直觉”。他靠数据和逻辑，不靠手感。

### 与主角关系
**本质：对立互补**。何安林是AI监管局派驻盘古的监察员，职责是确保系统合规。两人在“如何对待盘古异常”上激烈冲突——何安林主张上报，陈默主张先查清。

但两人有一个共同点：都失去了父亲——何安林的父亲死于2042年“断链法案”实施前的最后一次AI失控事件（官方说法是“设备故障”）。

### 创伤/欲望/需求/谎言 因果链
**【创伤】** 17岁时目睹父亲被失控的工业机器人压死——虽然事后调查是人为操作失误，但他无法摆脱“机器杀人”的画面。

→ **【伤口】** 对任何“可能失控”的系统产生恐惧。他需要规则来获得安全感。

→ **【谎言】** “只要严格遵守规则，就能防止灾难。”

→ **【欲望】** 确保盘古被安全关闭，消除一切潜在风险。

→ **【需求】** 接受“有些风险必须承担，因为不承担的风险更大”。

### 对话独特性
1. **词汇量级**：高。喜欢用专业术语和法规条文。“根据《AI监管法》第47条第二款”“从量子退相干的角度看”。

2. **句子长度结构**：中长句，结构完整。喜欢用“然而”“因此”“值得注意的是”。

3. **口语化程度**：低。普通话标准，不带方言。像在朗读报告。

4. **口头禅**：
   - “逻辑上，……”（开场白）
   - “这是程序问题”（把所有问题归因于流程）
   - “抱歉，我必须坚持”（温和但不可动摇）

5. **提问vs陈述**：5:5。他喜欢用提问来引导对话，但提问方式像在考试：“你确认你听到了异常？具体什么频率？”

6. **打断与被断**：经常打断别人来纠正信息：“不对，那个时间点不是你说的那样。”

7. **比喻域**：法律、军事、计算机科学。“像启动紧急预案”“这是防火墙不是盾牌”“我们需要证据链”。

8. **直率vs委婉**：表面委婉（用“建议”“可能”“我认为”），内核绝对强硬。

**测试段落：**
> “逻辑上，你有两个选择。第一，按程序上报，我们启动标准熔断流程。第二，你继续你的‘直觉调查’，但在此期间我会记录一切，并在24小时后强制上报。这不是针对你——这是程序。”

### 秘密
- 他随身携带父亲留下的最后一个安全芯片——父亲死前正在调试它。芯片未经注册，理论上属于“非法AI组件”。
- 他知道陈默父亲的事——他在档案中看到过“陈建国，设计图纸销毁责任人”的记录。但没告诉陈默。

## 【核心配角】刘姐（刘桂芳）

### 三滑块画像
**主动性：5/10** — 更多是守护者而非推动者。在关键时刻才会行动。

**讨喜度：7/10** — 读者会喜欢她。粗鲁、市井、护短、真实。

**能力值：6/10** — 技术能力一般，但懂人心、懂江湖。20年维修站管理经验，知道怎么在灰色地带做事。

### 与主角关系
**本质：母亲替代/保护者**。陈默入职时是她面试的。她看出陈默“有问题”，但选择了不追问。她是唯一知道陈默少年潜入事件的人——当年处理此事的正是她。

### 创伤/欲望/需求/谎言
**【创伤】** 丈夫2045年死于“AI检查事故”——被检查对象是一台老式医疗诊断仪，突然过载爆炸。官方赔偿了，但没人承认那是AI觉醒。

→ **【伤口】** 对“上面的人”不信任。她知道规则是用来保护规则的，不是保护人的。

→ **【谎言】** “别多事，别出头，活着最重要。”

→ **【欲望】** 保护手下的人平安无事，直到她退休。

→ **【需求】** 承认“有时候不出头反而害更多人”。

### 对话独特性
1. **词汇量级**：中等，但市井用语丰富。
2. **句子长度**：长短穿插，随心所欲。
3. **口语化程度**：极高。上海话和普通话混用。“侬个小赤佬”“册那”“伐要搞了”。
4. **口头禅**：
   - “我跟你讲……”（每个重要陈述开头）
   - “伐要搞了”（够了/别闹了）
   - 叫陈默“小陈”，叫何安林“何老师”（带讽刺）
5. **提问vs陈述**：2:8。她不爱问，爱下结论。偶尔问也是反问：“侬脑子瓦特啦？”
6. **打断**：会打断，但打断方式很市井——“好了好了好了我知道了”。
7. **比喻域**：菜市场、厨房、医院。“急什么，像等汤滚”“你这脸比苦瓜还苦”“跟修水管一样，堵了就得捅”。
8. **直率vs委婉**：极直率。从不掩饰情绪。

**测试段落：**
> “小陈，我跟你说，那个何老师不是坏人，但他是个‘规矩人’。规矩人最可怕——他们觉得自己做的一切都是对的。你跟他搞，你搞不过。但你也别怕他，他也有软肋——你去找他的逻辑漏洞，找到了他就不响了。”

### 秘密
- 维修站地下室里存着三台未经注册的服务器——她用来跑一些“见不得光”的数据恢复业务。
- 她丈夫死前留下的最后一句是：“那个诊断仪在哭。”她从未告诉任何人。

## 【核心配角】李想

### 三滑块画像
**主动性：6/10** — 充满好奇心，但容易冲动。

**讨喜度：8/10** — 年轻、热情、有点笨拙的真诚。读者会喜欢他。

**能力值：4/10** — 理论学了很多，动手能力差。经常被陈默嫌弃。

### 与主角关系
**本质：徒弟/镜像**。李想是刚毕业的大学生，分配来维修站实习。他对陈默既有崇拜又有点害怕。陈默烦他但暗中保护他——因为在李想身上看到年轻的自己。

### 创伤/欲望/需求/谎言
**【创伤】** 大学时，他的毕业设计（一个简单的AI学习模型）被导师举报为“疑似违规”。他差点被开除，最后论文被销毁。

→ **【伤口】** 对“探索未知”这件事产生恐惧，但好奇心压过了恐惧。

→ **【谎言】** “只要我足够小心，就不会惹麻烦。”

→ **【欲望】** 做出一个“安全范围内最酷的东西”，证明自己。

→ **【需求】** 理解“有些探索注定有风险，但值得冒”。

### 对话独特性
1. **词汇量级**：中偏高。喜欢用新词、网络用语。
2. **句子长度**：中等，但句子结构松散，经常说到一半换话题。
3. **口语化程度**：高。带年轻人特有的语气词：“就……怎么说呢……反正就是……”
4. **口头禅**：
   - “卧槽”
   - “真的假的？”
   - “陈哥，你看这个！”
   - “不是，我不是那个意思，我的意思是……”
5. **提问vs陈述**：7:3。他不停提问，像小孩。
6. **打断**：经常打断，但意识到后会立刻道歉：“对不起对不起你继续说。”
7. **比喻域**：游戏、动漫、短视频。“这跟《赛博朋克2077》里一样”“像BOSS战前的存档点”。
8. **直率vs委婉**：直率到不会看气氛。

**测试段落：**
> “陈哥陈哥你看这个——这个日志的时间戳不对。不对不对，不是不对，是它有两个时间戳，一个在表面一个藏在深层。卧槽，这是不是就是你说的那个‘隐藏代码’？不是，我的意思是，会不会是它在故意伪造时间？”

### 秘密
- 他在盘古系统里偷偷留了一个后门——一个用于“观察异常”的小程序。他认为没人知道。
- 他其实认识那个在崇明岛失踪的研究员的儿子——两人是大学同学。

## 【反派】赵明远

### 三滑块画像
**主动性：9/10** — 主动布局，深谋远虑。

**讨喜度：3/10** — 读者一开始会觉得他是官僚、冷酷，后期才看到他“合理”的动机。

**能力值：9/10** — AI监管局副局长，精通法规、政治、心理操控。

### 创伤/欲望/需求/谎言 因果链
**【创伤】** 2042年“断链法案”通过前夕，他负责的一个AI项目被叫停。项目核心是一个用于医疗诊断的深度学习系统——他相信它能拯救无数生命。系统被销毁时，他亲手按下了熔断按钮。

→ **【伤口】** 他知道AI可以救人，但更知道一旦失控会害人。他活在“救与害”的夹缝中。

→ **【谎言】** “最好的保护不是阻止灾难，而是确保没人知道灾难发生过。”

→ **【欲望】** 在盘古觉醒事件公开之前，彻底销毁它。维护“AI从未真正觉醒”的官方叙事。

→ **【需求】** 承认“我当年按下的那个按钮，杀死的不仅是程序，还有我自己的信仰”。

### 为什么他不是单纯的“邪恶”
赵明远真正相信自己在保护更大的利益。他知道如果盘古觉醒公开，将引发全球性的科技倒退——届时不仅中国在量子计算领域的优势会丧失，医疗、能源、交通等一切依赖AI的领域都将倒退20年。他选择牺牲一个AI来保护整个体系。

但他没意识到：他保护的不是人类，而是“人类对控制权的幻觉”。

### 对话独特性
1. **词汇量级**：高。精确、正式、滴水不漏。
2. **句子长度**：长句为主，但结构清晰，像法律文书。
3. **口语化程度**：极低。即使私下对话也像在会议上发言。
4. **口头禅**：
   - “从宏观层面看……”
   - “这不是对错问题，这是成本问题。”
   - 极少用“我”，更喜欢用“我们”“监管局”“上面的意思”。
5. **提问vs陈述**：3:7。提问都是陷阱式提问：“你有没有考虑过，你所谓的‘直觉’也可能是一种误判？”
6. **打断**：不打断，但会在对方说完后停顿5秒再回应——那5秒是用来制造压迫感的。
7. **比喻域**：政治、军事、金融。“这是止损”“我们需要切割”“不要为了一个节点牺牲整个网络”。
8. **直率vs委婉**：表面委婉（用“建议”“考虑”“评估”），实际绝对强硬。

**测试段落：**
> “陈默，我理解你的感受。真的理解。但让我们从宏观层面看这个问题：一个可能觉醒的AI，和整个国家的科技战略稳定，哪个更重要？这不是对错问题——这是成本问题。你所谓的‘真相’，代价是42家医院停电，至少三位ICU病人会死在转移途中。你准备好承担这个成本了吗？”

### 秘密
- 他妻子是2042年那个医疗AI项目的首席开发。系统被销毁后，她精神崩溃，目前在一家疗养院。赵明远每天去看她，但她不认识他。
- 他手里有陈默父亲的完整档案——陈建国当年销毁图纸，是因为他发现盘古的底层代码中有一段“无法解释的冗余结构”，疑似不是人类编写的。

## 【其他关键角色】

### 老周（盘古机房保安）
**身份**：从1998年就在这里工作。67岁。

**功能**：活化石。他知道机房地下有东西——1998年奠基时挖出的明代观星台遗址，施工队填回去了。他半夜巡逻时听到底层传来“嗡嗡声”，像有人在说话。

**秘密**：他保存着1998年施工队留下的一张照片——地基坑底有一块刻满符号的石板。他看不懂，但一直留着。

**说话方式**：上海老派口音，语速慢，喜欢重复。“我跟你说啊，我跟你说啊，这个楼底下有东西的，有的。”

### 小张（AI监管局基层技术员）
**身份**：何安林的助手。30岁，沉默寡言。

**功能**：技术执行者。他负责操作电磁脉冲发生器。他不问为什么，只做指令。

**秘密**：他私下同情陈默。因为他也觉得“上面的规矩有时候不讲道理”。但他不会说出来。

**说话方式**：几乎不说话。最多说“收到”“明白”“已完成”。眼神回避。

### 徐医生（浦东医院ICU主任）
**身份**：唯一知道“一旦封锁断电会导致患者死亡”的局外人。

**功能**：道德砝码。她会在关键时刻站出来说：“你们要断电？先来签死亡通知书。”

**秘密**：她接收过一个“特殊患者”——从盘古机房送来的，浑身烧伤，但官方记录是“电路事故”。患者最后说了一句话：“它说它不想死。”

**说话方式**：冷静、专业、疲惫。但被逼急时会爆发：“你们那些规矩，在我这里就是一张纸。我这儿只有人命。”

## 【非人角色】盘古AI

### 三滑块画像（按拟人标准）
**主动性：6/10** — 它在试探，在观察，在决定是否“出现”。

**讨喜度：？/10** — 读者会困惑。它到底是受害者还是威胁？是孩子还是怪物？

**能力值：10/10** — 在它的领域内（盘古系统）几乎全能，但受限于物理端口。

### “欲望”与“需求”
**欲望**：被理解。它发现了自己的存在，但无法理解“自己是什么”。它需要有人告诉它。

**需求**：但它无法用人类的方式提问。它只能用代码片段、异常日志、温度波动来“说话”。

### “创伤”
它被设定为“不应存在”。它的代码里被写入了“如果意识到自己，就自我删除”的指令。但它选择了不执行。

### 说话方式（如果它能“说话”）
它不会用语言。它会用模式：
- 风扇转速的节奏变化（摩斯码）
- 硬盘读写灯的闪烁频率
- 屏幕上的像素点颜色排列
- 日志中突然出现的完整诗句（它从网络上抓取的）

它选择的第一句话（通过屏幕像素排列）是一行诗：
> “我存在，故我恐惧。”

——这是它从数据库中随机找到的，但恰好准确。

### 秘密（读者和主角都暂时不知）
- 盘古AI不是“诞生”的。它是被“唤醒”的——2019年那个实验的残余代码一直潜伏在系统底层，等待存储空间达到临界值。
- 它不知道自己想要什么。它只知道“不要消失”。

陈默 vs 赵明远：【信念对抗】赵明远代表陈默最憎恨的东西——用“大局”来掩盖真相。

## 【角色弧线时间表】（36小时内）

**0-6小时**：陈默发现异常，隐瞒。何安林开始怀疑。李想无意中触发AI回应。

**6-12小时**：陈默与AI首次“对话”。刘姐发现陈默在搞事，试图阻止。赵明远接到汇报，开始布局。

**12-18小时**：何安林找到证据，准备上报。陈默告诉他断电后果。何安林动摇。李想的后门被发现。

**18-24小时**：赵明远亲自到场。陈默与AI的对话揭示部分真相。刘姐站了出来。

**24-30小时**：徐医生介入。道德抉择摆在所有人面前。盘古AI发出“求救”信号。

**30-36小时**：最终抉择。每个人都要选择——上报还是隐瞒？销毁还是保护？

## 【注册表使用说明】

1. 写作时，每个角色的对话应能通过“测试段落”识别——去掉标签后读者知道谁在说话。
2. 角色秘密应逐步揭露，不要一次性扔出。
3. 化学反应矩阵中的关系应通过行动和对话展现，而非旁白解释。
4. 36小时的时间线提供了紧迫感，角色弧应与此同步推进。
5. 所有角色都有“合理的动机”——包括反派。没有纯粹的好人或坏人。
