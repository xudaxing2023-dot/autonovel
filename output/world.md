# WORLD.MD – 法医穿越武则天登基前

## 一、宇宙观与历史

**时间线（节选）**  
- **公元前 202 年**：西汉建立，长安成为首都，城墙夯土夹杂夯石，北门常有马蹄踏起的尘土。  
- **公元 618 年**：唐朝建国，大明宫奠基，宫城内部设有药材库、尚食局与刑部验伤房，验伤流程初步形成（“观色、闻气、量尺”）。  
- **公元 690 年（武则天称帝前一年）**：  
  - **宫廷内部**：武则天以皇太后身份掌握尚书省，欲通过“禅让”获得帝位；李唐宗室残党在洛阳密谋复辟。  
  - **刑部爆发一起离奇尸体案**：死者身着官服，胸口有精确的三刀伤，血斑呈现不自然的层层褐黑，验伤官无法给出死因。此案被秘密压下，只流传于宫女间的低语（“那血像被火烤过的药渣”）。  
  - **穿越点出现**：大明宫西侧药材库的青石板下埋有残缺的铜镜，镜面刻有“阴阳逆流”八字。每隔二十四小时，镜面会出现滴落的朱砂点，触碰者会产生强烈的头晕与心跳加速，若在点滴完全消失前离开，则会被拉回原时空；若逗留超过时限，意识会被困在镜中，身体逐渐变为石质。  

**当前矛盾**：武则天急需合法化自己的帝位，而李唐残党试图利用这起离奇验伤案制造舆论；与此同时，主角林浩的穿越点正处于激活状态，二十四小时的沙漏正在倾斜——任何耽搁都可能让他永久滞留在唐代，或被镜子吞噬。

## 二、核心规则/特殊体系

### 2.1 硬规则

| 规则 | 描述 | 代价 | 限制 |
|------|------|------|------|
| **时空锁定（镜子规则）** | 触碰铜镜并注视朱砂点，可在二十四小时内完成一次穿越；穿越成功后，镜面恢复暗色，需等待七天才能再次激活。 | 每次穿越会消耗使用者体内约 150 ml 血液（表现为头晕、面色苍白），若血液未及时补给，将出现失血性休克。 | 仅在药材库青石板上、铜镜正对东方（朝阳）时才能激活；若镜面被遮挡或被他人移动，穿越点失效。 |
| **验伤流程（法医硬规则）** | 任何死亡案件必须经“观色、闻气、量尺、问供”四步；缺少任意一步，结论无效，且验官会受到刑部处罚（降级或罚俸）。 | 每一次省略步骤会使验官在接下来的三天内感官敏感度下降（嗅觉减退 30%，视力模糊），影响后续案件的判断。 | 仅限于官方验伤房或具备铜尺、药香炉、白布的临时检验点；私下自行验伤会被视为妨碍公务，罪名为“伪造验伤”。 |
| **血斑颜色表（自然法则）** | 人血在空气中氧化的颜色变化遵循固定顺序：鲜红（0‑2h）→暗红（2‑6h）→褐黑（6‑24h）→灰白（>24h）。若出现非此顺序的颜色层层叠加，说明有外部物质（如药粉、金属离子）干扰。 | 每误判一次颜色顺序，验官的信誉分降低 5 分，累计达到 20 分将被调离刑部。 | 仅在环境温度 15‑25℃、相对湿度 40‑60% 时准确；极端寒热或潮湿环境会导致颜色偏移，需额外校准。 |

### 2.2 特殊设定（主角金手指）

**法医碎片（林浩的专业直觉）**  
- 现代法医训练使其在观察伤口时，能够在脑中自动生成“测长‑量角‑比色”三维模型，模型以微光形式浮在视野边缘。  
- **运作方式**：当林浩专注于伤口时，脑内会产生约 0.2 mA 的微电流，刺激视觉皮层产生半透明的网格；网格随呼吸节奏微幅波动。  
- **代价**：每使用一次碎片，会消耗约 0.5 kcal 的脑能量（相当于一次深度思考），连续使用超过五次会导致短暂的思维迟钝（反应时间延长约 0.3 秒）。  
- **限制**：仅在光线充足（药材库的灯笼或宫灯）且无强烈气味干扰（如浓烈的麝香）时才能清晰看到网格；在完全黑暗或被强烈香料熏陶时，碎片会失效。  

### 2.3 社会影响

| 领域 | 影响 |
|------|------|
| **政治治理** | 刑部因验伤流程严格而成为皇帝与宰相制衡的工具；验官的升迁与血斑颜色判断准确率直接挂钩，导致部分官员倾向于伪造报告以求快速晋升。 |
| **商业贸易** | 药材库的朱砂、雄黄、白矾等成为验伤必备品，价格随验伤需求波动；私商开始走私低纯度朱砂，导致验伤误判增加。 |
| **教育体系** | 太学增设“验伤学”选修课，学生需背诵血斑颜色表并实习于刑部验伤房；毕业后分配至各州验伤所。 |
| **阶级结构** | 验官虽属文官，但因常接触尸体与血液，被视为“不洁”之流，婚嫁受限；然而高级验官因掌握生死话语权，能够获得特赦与赏赐，形成独特的“血贵”小圈子。 |
| **犯罪行为** | 作案者开始利用已知的血斑氧化规则，在伤口内敷入硫酸汞或 cinnabar 粉，以制造假象；这促使刑部引入“异物理检验（火烤、酒精浸泡）”作为辅助手段。 |
| **家庭生活** | 市民常在家中备有简易验伤工具（小铜尺、白布），以便在街头冲突后自行止血并初步判断伤势；此习惯在坊间流传为“自验术”。 |
| **童年与成长** | 长安城的童子在学堂除了背诵《千字文》，还会学习基本的伤口包扎与血色观察；少年时期的“验伤游戏”是街头常见的玩法（用红染布模拟血斑）。 |
| **衰老与死亡** | 老年验官因长期接触血液，常患上慢性咳嗽与皮肤色斑；城中有专门的“血堂”提供草药浴以净化身心，费用由刑部补贴。 |

## 三、地理

### 1. 大明宫‑药材库（主角首次穿越点）
- **位置**：宫城西北角，青石板铺地，四周种植桂枝与艾草，空气常带有干草与土的微甜。  
- **感官**：触手可及的石板凉滑，偶尔有宫女的丝绸裙摆刮过产生细微的沙沙声；灯笼内的油火燃烧时会发出轻微的嗞嗞声，伴随淡淡的檀香。  
- **关键细节**：石板下埋藏铜镜，镜面朝东，每日黎明时第一缕阳光会照射镜面，激活朱砂点。

### 2. 长安东市‑验伤房
- **位置**：东市大街北侧，灰墙灰瓦，门口挂着铜制的“验”字牌。  
- **感官**：屋内弥漫着药材的苦涩与铁锈味，地面撒有细沙以吸血，脚步声在空荡的房间里回响得特别清晰。  
- **关键细节**：墙角放置一只青铜盛血碗，碗内常年放置少量明矾用于快速凝血；屋梁上悬挂着一副由验官亲手绘制的血斑颜色表。

### 3. 曲江池畔‑李唐残党聚点
- **位置**：曲江池东岸的竹林小屋，池水微澜，荷叶带着露水滴落的清脆声。  
- **感官**：水气带有凉意与淡淡的泥土味，竹叶被风吹动时发出沙沙声，远处传来渔夫的短笛。  
- **关键细节**：残党利用池水的反光进行暗号传递；夜间池面会出现微弱的磷光，那是水中特定藻类在夜间发光。

> **未解释事实（冰山深度）**  
> 1. 药材库石板下除了铜镜，还埋有一块刻有“逆流”符文的黑玉，未被任何官方记载提及。  
> 2. 验伤房的铜尺其实是从西域进口的特殊合金，含有微量� iridium，能够轻微放射。  
> 3. 曲江池的磷光藻在满月时会分泌一种能够短暂抑制血液凝固的酶。

| **刑部验官派系**（血贵） | 保持验伤流程的权威，获取升迁与赏赐。 | 两头吃：向武则天提供符合其需求的验伤结论；同时向李唐残党 leaking 不利证据以获利。 |
| **药材商帮**（西市胡商） | 垄断朱砂、雄麦等验伤药材，牟取暴利。 | 与刑部勾结确保药材质量标准；暗中向李唐残党供应假药以制造验伤混乱。 |

> 2. 曲江池的磷光藻实际上是李唐残党引进的西域种植，用于夜间信号。  
> 3. 药材商帮的首领曾是前任验官，因误判被贬后转行商界。

## 五、生态/科技/自然世界

- **气候**：长安所属温带半湿润气候，春季多风沙，夏季炎热伴随雷雨，秋季晴朗，冬季偶有轻雪。  
- **特产**：秦岭出产的白矾与石膏，用于止血与制药；终南山的野生桂枝，香气浓郁，常被宫女用于熏衣。  
- **科技水平**：冶金已达到能够炼出高纯度铜与铁的水平；造纸术普及，但纸张仍以麻纸为主，书写工具多为毛笔。  
- **独特自然现象**：终南山深处有罕见的“血晶”矿石，受紫外线照射会呈暗红色荧光，古籍记载其可辨别人血与动物血的微量差异，但采掘极危险，且会导致采矿者出现持续性头痛。  
- **未解释事实**  
> 1. 血晶的荧光其实是由微量锝同位素引起，长期暴露会造成轻度放射伤害。  
> 2. 长安城地下有废弃的汉代排水渠，部分仍然流动，水中含有独特的硫酸菌。  
> 3. 终南山的野生桂枝在特定月相会分泌一种能够暂时提升人类嗅觉的油脂。
