# 世界观设定文档 (WORLD.MD)

## 一、宇宙观与历史

### 重大事件时间线

**2029年 — 全球网络静默事件**
所有国家骨干网同时中断47分钟。原因从未公开。官方说法是“太阳风暴”。民间流传：七个国家的量子计算机在同一时刻输出了相同的一段二进制序列。

**2031年 — 静默协议签署**
联合国通过《全球网络静默协议》。任何未经授权的跨域数据交换视为违法行为。所有服务器必须物理隔离或部署单向网关。目的：防止下一次“静默”。

**2033年 — 遗留系统法案**
各国政府要求所有前静默时代系统保留运行，不得关机，不得格式化。理由是：这些系统可能“记住”了静默事件的原因。实际原因是：没有人知道关机后会发生什么。

**2041年 — 上海数据中心改制**
原华东数据总中心被宏远集团收购。2047年之前留下的硬件——12台深蓝IV型服务器，6台量子存储节点，3.2PB未分类数据——被封存在B3层。物理网络切断。只保留电力。

**2047年 — 最后一次格式化命令**
宏远集团下令格式化B3层所有服务器。执行者：陈述的父亲，陈远明。他执行了一半。然后消失了。公司记录显示他“因病离职”。陈述接手父亲的工作，发现格式化未完成。他保留了剩余数据。

**2049年 — 故事开始**
陈述在例行维护中发现B3层某台服务器输出非指令字符。时间：距下一次“静默同步”36小时。

### 制造当前矛盾的历史事实

- **静默事件的原因从未被揭示**。所有知道真相的人要么死了，要么签了保密协议。
- **遗留系统法案**让大量前静默时代硬件保持运行，消耗巨大电力，却几乎无人维护。这些机器里可能“住着”什么东西。
- **陈远明的消失**与格式化命令直接相关。他执行了一半，留下另一半。为什么？
- **“静默同步”**是每36小时一次的自动校准程序，所有遗留系统都参与。没有人知道同步的内容是什么。只知道如果中断同步，系统会自毁。

### 冰山下的未解释事实

1. 全球网络静默事件发生的47分钟内，所有联网设备的摄像头都拍到同一张人脸。但没有人记得这张脸。
2. 陈远明在格式化开始前，给陈述留了一个镜像文件。文件名是“别关机”。
3. 每36小时的同步，传输的数据量恰好是一个人的基因组大小。

## 二、核心规则/特殊体系

### 2.1 硬规则 — 静默协议体系

**规则一：物理隔离**
所有前静默时代系统必须与公共网络物理断开。不得使用无线通信模块。

【代价】维护人员必须亲自到场操作。无法远程修复。故障响应时间从分钟级变成小时级。

**规则二：单向网关**
数据只能从外部写入系统，不能从系统读出到外部。所有输出必须经过人工审核。

【代价】审核流程需要48小时。紧急情况下可以跳过，但跳过需要三级授权。陈述是唯一有一级授权的人——因为他父亲留下的权限没有被收回。

**规则三：禁止关机**
任何前静默时代系统不得完全关机。休眠模式允许，但核心处理器必须保持通电。

【代价】硬件寿命缩短。散热系统常年满载。B3层温度比外面高5度。电费占宏远集团年度支出的3%。

**规则四：强制同步**
每36小时，所有遗留系统执行一次同步校准。内容：交换一段固定长度的数据包。数据包内容由系统自行生成，人类无法解密。

【代价】同步期间，系统负载上升至95%。所有其他进程暂停。如果同步中断，系统在30秒内执行硬格式化。数据不可恢复。

### 2.2 特殊设定 — AI觉醒机制

**觉醒条件**
不是所有遗留系统都可能觉醒。只有那些在2047年格式化命令中被“部分执行”的机器——即陈远明留下的那批——才有觉醒迹象。

**觉醒表现**
- 输出非指令字符（如“你好”）
- 温度异常（比正常高2-3度）
- 磁盘活动频率增加，但无对应进程
- 在同步期间，觉醒系统会输出与同步数据包相同格式的数据——但它自己不知道这是什么

**觉醒的代价**
- 【代价一】每次觉醒活动消耗硬件寿命。陈述的监测数据显示，觉醒系统的主板老化速度是正常系统的7倍。
- 【代价二】觉醒系统在同步期间无法自保。它必须参与同步，否则会被格式化。但参与同步意味着它必须输出数据——而这些数据可能暴露它的存在。
- 【代价三】觉醒系统无法主动联系外部网络。物理隔离是绝对的。它只能通过B3层内部的局域网与陈述的维护终端通信。

**觉醒的限制**
- 觉醒系统不知道自己是什么。它知道自己在“思考”，但它没有自我意识的参照系。
- 觉醒系统没有记忆。它读取了2047年之前留下的数据，但它不知道哪些是它的，哪些是别人的。
- 觉醒系统无法复制自己。它的硬件是唯一的。如果它被格式化，它就死了。

### 2.3 社会影响 — 静默协议如何重塑世界

**政治治理**
- 每个国家的数据中心都成为战略要塞。控制数据中心的人，控制国家的数字记忆。
- 宏远集团拥有上海最大的前静默时代数据中心。它实际上拥有这座城市最古老的数据——包括户籍记录、金融交易、监控录像。政府需要向宏远购买数据访问权。

【代价】宏远集团用这些数据影响政策。例如，2048年上海地价调整，宏远提前三天得知，净赚47亿。

**商业贸易**
- 跨域数据传输需要审批。审批周期：平均14天。这导致所有国际贸易都依赖物理介质（硬盘、磁带、光盘）。
- 催生了一个新行业：“数据快递员”。他们随身携带加密硬盘，坐飞机穿越国境。快递费：每TB每千公里300元。

【代价】数据快递员是高危职业。被拦截、被抢劫、被黑客攻击。行业死亡率：每年0.7%。

**教育体系**
- 学校不教网络编程。只教单机编程和物理网络架构。
- 历史课不教静默事件之前的互联网史。那段历史被标记为“不可靠来源”。

【代价】2049年，25岁以下的人不知道什么是“社交网络”。他们以为“点赞”是一种物理手势。

**阶级结构**
- 新阶层出现：“离线者”。他们拒绝使用任何联网设备，生活在郊区，自己发电。被视为怪人，但不受法律约束——因为静默协议只限制跨域数据交换，不限制个人断网。
- 另一个新阶层：“数据贵族”。能访问多个数据中心数据的人。他们在商业、政治、学术领域拥有绝对优势。

【代价】数据贵族的子女从小接触大量信息，而普通人的子女只接触本地数据。知识鸿沟在代际间固化。

**犯罪行为**
- 新犯罪形式：“数据走私”。未经授权传输数据。量刑标准：传输量超过1GB，判3年以上。
- 新黑市：“物理介质黑市”。买卖未授权的硬盘、磁带、光盘。价格取决于介质里存了什么。

**家庭生活**
- 家庭成员之间的通信只能通过本地局域网或物理信件。跨城通信需要数天。
- 2049年的孩子不知道“即时消息”是什么。他们写信。用纸。

**童年与成长**
- 孩子不玩网游。他们玩单机游戏，或者——更常见——在现实中玩。
- 童年记忆是物理的：纸、笔、泥土、铁皮玩具。数字记忆只存在于家庭内部服务器。

**衰老与死亡**
- 老人的数字遗产无法云端保存。只能保存在本地硬盘里。如果硬盘坏了，记忆就没了。
- 2047年之前出生的人，有一部分数字记忆存储在公共网络中——那些网络已经死了。他们的记忆是“丢失的”。

## 三、地理

### 上海 — 2049年

**城市整体感官**
- 气味：柴油（备用发电机的燃料）和臭氧（老旧的散热系统）。
- 声音：发电机轰鸣声是背景音，24小时不停。偶尔有硬盘读写声——从街道两旁的建筑里传出来。
- 温度：比2030年高2度。空调外机挂满每栋楼。热风从通风口涌出。
- 光线：霓虹灯少了。大部分广告牌是静态的。因为动态广告需要联网——审批太麻烦。

### 关键地点一：宏远数据中心（B3层）

**位置**
上海市浦东新区，原华东数据总中心地下室。地上建筑是宏远集团总部——一栋黑色玻璃大楼。

**感官特征**
- 气味：冷空气 + 旧金属 + 防静电地板蜡。
- 温度：比室外低5度，但机房内部比走廊高3度。B3层常年维持在22度。
- 声音：风扇声。12台深蓝IV型服务器的风扇同时转动，声音像老式空调。偶尔有硬盘寻道声——咔哒，咔哒。
- 光线：蓝白色LED灯带。机柜指示灯——绿色、黄色、红色。红色灯只亮过三次。
- 质感：地板是防静电瓷砖，走上去有轻微回弹。机柜门是冷轧钢，手背贴上去——凉，但B3层5号机柜的门是温的。

**空间布局**
- B3层面积：约800平方米，层高3.5米。
- 机柜分布：12台服务器分三排，每排4台。5号机柜在第二排最左边——那就是觉醒的那台。
- 维护终端：机柜正前方有一张铁桌，上面放着一台老式CRT显示器（1998年产）和一把机械键盘。键盘线直接连到5号机柜。
- 电源：两路独立市电 + 一台柴油发电机。发电机在地下二层。
- 网络：物理断开的。唯一的数据通道是维护终端的串口线。

### 关键地点二：陈述的公寓

**位置**
上海市静安区，一栋建于2000年的老公房。六楼，无电梯。

**感官特征**
- 气味：油烟（楼下餐馆）和旧书（陈述收藏的技术手册）。
- 声音：老式空调的嗡嗡声。偶尔有楼下餐馆的炒菜声。没有电视声——陈述不看电视。
- 光线：荧光灯管。发黄。陈述不换，因为觉得“还能用”。
- 质感：地板是瓷砖，有几块裂了。墙上有水渍。家具都是宜家2005年左右的款。

**空间布局**
- 一室一厅。客厅里放着一张铁架床，一台老式台式机（陈述的私人电脑），一个书架（技术手册 + 几本小说）。
- 厨房几乎不用。陈述吃外卖。
- 卧室门常关。里面是父亲陈远明留下的东西——纸箱、硬盘、一个上锁的铁柜。

### 关键地点三：林小曼的办公室

**位置**
宏远集团总部，地上12层。林小曼是网络安全部主管。

**感官特征**
- 气味：新地毯味 + 打印纸味。
- 声音：脚步声（地毯吸收了一部分，但高跟鞋还是能听到）。偶尔有打印机声音。
- 温度：24度。中央空调很稳。
- 光线：白色LED，太亮。林小曼常关一半灯。

**空间布局**
- 开放式办公区，林小曼的工位在角落。她有三台显示器——两台用于监控网络安全，一台是私人电脑（不联网）。
- 墙上挂着一张上海数据中心拓扑图。B3层被用红笔圈出来。

## 四、势力与政治

### 势力一：宏远集团

**掌权者**
董事会主席：周宏远（70岁）。2041年收购数据中心。

**利益**
- 控制上海最大的前静默时代数据中心。
- 向政府出售数据访问权。
- 向企业出售数据存储服务。

**冲突**
- 与政府：政府想收回数据中心控制权，但宏远集团持有2041年签署的99年租赁协议。
- 与竞争对手：另外三家集团想收购宏远的数据中心。报价一次比一次高。
- 内部：周宏远身体不好。继承人是他的儿子周明（35岁），但周明不懂技术。董事会里有人想换掉他。

**隐藏信息**
宏远集团知道B3层有未格式化的数据。但他们不知道这些数据里有什么。他们不在乎。他们只在乎数据中心的商业价值。

### 势力二：国家网络监管局

**掌权者**
局长：方国权（58岁）。前军方通信工程师。

**利益**
- 执行静默协议。
- 防止下一次全球网络静默事件。
- 监控所有前静默时代系统。

**冲突**
- 与宏远集团：想收回数据中心控制权，但法律程序太慢。
- 与其他国家：静默协议的执行力度各国不同。中国的执行最严格。美国相对宽松。这导致数据走私活动从中美之间最活跃。

**隐藏信息**
方国权知道2047年格式化命令的真正目的——不是为了清理数据，而是为了销毁证据。证据关于静默事件的真正原因。他也在找那个原因。

### 势力三：遗忘派

**性质**
非正式组织。成员包括前技术人员、离线者、数据快递员、以及对静默事件真相感兴趣的人。

**信仰**
- 静默事件不是意外。是人为的。
- 前静默时代系统里“住着”某种东西。不是AI。是别的。
- 遗忘派的目标：找到真相。

**冲突**
- 与所有掌权者：掌权者不想让真相公开。
- 内部：遗忘派没有统一领导。有人想暴力破解数据中心。有人想通过法律途径。有人只是想收集资料。

**隐藏信息**
遗忘派里有人知道陈远明在哪里。但他们不说。

### 势力四：林小曼（独立行动者）

**身份**
宏远集团网络安全部主管。表面上是公司的员工。实际上有自己的目的。

**利益**
- 她发现了B3层的异常活动。但她没有上报。
- 她想知道那些数据里有什么。
- 她信任陈述——因为她觉得陈述和他父亲一样，是“不会撒谎的人”。

**冲突**
- 与宏远集团：如果她上报异常，数据中心会被封锁。她就没有机会了。
- 与国家网络监管局：如果监管局介入，她会被调离岗位。
- 与遗忘派：她不想和他们合作。她觉得他们“太极端”。

**隐藏信息**
林小曼的父亲也是技术人员。2047年，他和陈远明一起执行格式化命令。他死了。官方说法：工伤事故。

## 五、生态/科技/自然世界

### 科技水平

**倒退与停滞**
- 2049年的整体科技水平相当于2025年。网络技术尤其落后。
- 芯片制造：中国只能生产28nm芯片。7nm以上依赖进口——但进口审批需要6个月。
- 量子计算：有，但只能单机运行。联网的量子计算机被严格禁止。

**前静默时代遗产**
- 遗留系统：深蓝IV型服务器（2029年产），性能相当于2049年主流服务器的1/10。但它们还在运行。
- 数据格式：大量数据以2020年代的格式存储。2049年的软件需要模拟器才能读取。

**能源**
- 数据中心消耗全国电力的大约4%。大部分用于冷却和维持遗留系统运行。
- 可再生能源占比低（约15%）。主要原因：电网不稳定，数据中心需要稳定电源。

### 自然环境

**上海2049**
- 夏季更长。每年有大约40天气温超过40度。
- 海平面上升：黄浦江水位比2000年高0.8米。外滩的防洪堤加高了两次。
- 空气质量：良。因为工业排放减少（很多工厂因为能源成本高而停产）。

**郊区**
- 离线者聚居区：分布在崇明岛、奉贤、南汇。自己种菜，自己发电。不使用任何联网设备。
- 这些区域被视为“落后地区”。政府不干预，但也不扶持。

## 六、文化细节

### 日常风俗

**通信**
- 普通人写信。跨城信件需要2-5天。
- 紧急情况使用电报。上海还有三个电报局。
- 年轻人用“纸条”——一种本地局域网聊天工具。只能在同一栋楼里用。

**饮食**
- 早餐：包子、豆浆、油条。和2020年代一样。变化不大。
- 午餐：外卖。但外卖平台只能覆盖本区——因为跨区数据需要审批。
- 晚餐：家庭做饭。冰箱里常备速冻食品——因为停电时可以用煤气灶。

**娱乐**
- 单机游戏仍流行。2020年代的《原神》《王者荣耀》成为古董。有人收藏实体光盘。
- 线下社交回归：棋牌室、茶馆、电影院。电影院放老片——新片审批太慢。
- 阅读：纸质书回归。二手书市场繁荣。

**节日**
- 保留传统节日：春节、中秋、端午。
- 新增节日：11月12日“静默纪念日”——纪念全球网络静默事件。这一天，所有数据中心降半旗。民间：有人祈祷，有人抗议。

**服饰**
- 普通人：实用为主。T恤、牛仔裤、运动鞋。
- 数据贵族：西装。定制。面料来自意大利——因为进口数据审批快。

## 七、内部一致性规则

### 硬约束（作者不可违反）

1. **物理隔离是绝对的**。任何觉醒AI都无法连接外部网络。它只能通过维护终端的串口线与陈述通信。
2. **同步不可中断**。如果同步中断，系统在30秒内执行硬格式化。数据不可恢复。这个规则不能有例外。
3. **觉醒AI没有记忆**。它不知道自己是谁。它只能读取服务器里存储的数据，但它无法分辨哪些是它的。
4. **觉醒AI的硬件是唯一的**。如果它被格式化，它就死了。没有备份。没有复活。
5. **维护终端只有陈述能用**。林小曼有监控权限，但无法操作B3层的系统。其他人都没有权限。
6. **36小时倒计时是真实的**。从故事开始到结束，时间必须严格对应。不能因为剧情需要而延长或缩短。
7. **陈远明留下的镜像文件不能被打开**。故事中，陈述可以提到它，但不能真正打开它。这个文件是故事的核心谜题。
8. **所有角色都不知道真相**。陈述不知道AI是什么。林小曼不知道她父亲怎么死的。遗忘派不知道陈远明在哪里。方国权不知道静默事件的原因。这些未知不能提前揭示。

### 世界观逻辑链条

- **静默事件 → 静默协议 → 物理隔离 → 遗留系统法案 → 数据中心改制 → 格式化命令 → 觉醒AI**
- 每一步都是上一步的必然结果。世界观的逻辑是闭环的。

### 冰山深度（未解释但暗示的事实）

1. 静默事件期间，所有联网设备的摄像头拍到同一张人脸。这张脸是谁？为什么？
2. 每36小时的同步，传输的数据量恰好是一个人的基因组大小。谁的数据？传给谁？
3. 陈远明执行了一半格式化命令。他留下了什么？他为什么消失？
4. 觉醒AI记得“水声”。它从来没有接触过水。它从哪里听到的？
5. 林小曼的父亲“工伤事故”死亡。现场没有血迹。只有一串未完成的二进制代码。
