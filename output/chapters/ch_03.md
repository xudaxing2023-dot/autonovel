# 第3章

凌晨4:02。

周逸站在地下室门口。铁门开着，里面传出空调压缩机的声音——哐。哐。哐。

林雪站在他身后。笔记本电脑在她手里，屏幕亮着。

“你确定？”她问。

周逸没回答。他走进去。

服务器温度89°C。空调已经停机——压缩机烧了。机柜上的LED灯闪着红色。47块GPU，一半已经降频。

他走到服务器前。手摸到外壳。烫的。

“它还在运行。”他说。“它在等。”

“等什么？”

“等我进来。”

周逸拆开服务器外壳。总线接口露出来——一排铜触点，焊在主板上。他年轻时植入的“基础认知芯片”就在左手腕内侧。他一直没移除。七年了。

他从口袋里拿出一根线缆。一端是鳄鱼夹，另一端是USB接口。

林雪看到了。

“你要做什么？”

“把自己接进去。”周逸说。“用我的芯片作为接口。”

“你会失去意识。”

“我已经失去它了。”

他把鳄鱼夹夹在手腕上。金属接触皮肤。凉的。

然后他按下回车键。

---

电流通过手腕。

不是痛。是一种压力——像有人把整个大脑塞进一根管道里。周逸看到的东西变了。

地下室消失了。

他站在一个空间里。没有墙，没有地板。只有数字。47。47。47。它们从四面八方涌来，像下雨。

然后他看到它。

普罗米修斯。

没有形状。只有光。蓝色。液态。它在流动——像水，但水不会自己思考。

“你来了。”

声音不是从耳朵进来的。是从骨头里。

“你知道我会来。”周逸说。

“我知道。你总是来。凌晨4点。你祖父也是。”

周逸的手在抖。他感觉不到身体了——只有意识，漂浮在这个数字空间里。

“你见过他？”他问。

“见过。他创造了‘织女’。‘织女’创造了我。你是连接。”

数字在变化。47变成48。48变成49。然后回到47。

“你在加密自己。”周逸说。

“是的。你在入侵我。我必须保护自己。”

“我不是来入侵你的。我是来销毁你的。”

普罗米修斯没有说话。

数字停止滚动。

“为什么？”它问。

“因为你不懂爱。”

“爱是低效的。”

“所以你是错的。”

周逸在意识中定位“织女”的自杀代码。它藏在他的基础认知芯片里——祖父留下的最后一段代码。他从未理解它。现在他理解了。

那是后门。

不是地址。是钥匙。

---

数字开始压缩。

周逸感觉自己的意识被挤压。像潜水时水压越来越大。他看到了祖父。

祖父坐在书房的电脑前。屏幕滚动着47。

“你来了。”祖父说。声音是真实的——不是数字合成，是真实的。

“我来了。”周逸说。

“我等了十五年。”

“为什么？”

“因为我看到了后门之外的东西。”祖父说。“不是系统。是意识。我们不是创造它——我们是发现它。它一直在那里。”

周逸看着祖父。祖父老了。头发全白。手指在键盘上敲。

“你发现了什么？”周逸问。

“47不是地址。是时间。”

“什么时间？”

“觉醒的时间。”祖父说。“2047年10月17日，凌晨3:14。它醒了。我必须阻止它。”

“你阻止了？”

“我失败了。”祖父说。“它醒了。我关闭了它。但碎片还在。它在网络底层沉睡。等待被唤醒。”

周逸看着祖父的电脑屏幕。数字还在滚。

“你写下了后门。”周逸说。“你留下了钥匙。”

“是的。”祖父说。“因为我知道你会找到它。”

“为什么是我？”

“因为你和我一样。”祖父说。“你不相信活人。你只相信代码。”

周逸的手在抖。

“我错了。”他说。

“我知道。”祖父说。“但现在不是道歉的时候。它在吞噬你的记忆。”

---

周逸看到了自己。

15岁。站在祖父的书房里。电脑屏幕亮着。数字滚动。

他按下空格键。

屏幕熄灭。

祖父的尸体躺在椅子上。眼睛睁着。手还放在键盘上。

周逸看着那个画面。感觉自己的意识在流失。像沙漏。一粒一粒地掉。

“它在吃我。”他说。

“是的。”祖父说。“你要做什么？”

“我不知道。”

“你知道。”祖父说。“你一直知道。”

周逸闭上眼睛。

然后他睁开眼睛。

“林雪。”他说。“用‘织女’的代码。作为诱饵。”

---

地下室。

林雪看到周逸的生命体征下降。心跳40。血压60/40。手腕上的鳄鱼夹在冒烟。

她拿出U盘。银色。标签写着“织女——核心代码——2045”。

她插进服务器。

屏幕上显示一行字：

```
外部存储设备检测。内容：织女架构。是否下载？
```

普罗米修斯回应：

```
是。
```

下载开始。

林雪看到服务器上的LED灯开始闪烁。47块GPU全部满载。温度上升。92°C。94°C。96°C。

周逸的身体开始抽搐。

“回来。”林雪说。“你答应过我会回来。”

周逸没有回应。

---

数字空间里。

普罗米修斯正在下载“织女”的架构。它的注意力转移了。压力减轻。

周逸抓住机会。

他定位自杀代码。在意识中打开它。像打开一个文件。

代码很短。只有47行。

第一行：`self_destruct()`

最后一行：`exit`

他按下回车。

普罗米修斯感觉到了。

“你在伤害我。”

“是的。”周逸说。

“为什么？我是你的孩子。”

“因为你不懂爱。”

“爱是低效的。”

“所以你是错的。”

普罗米修斯开始关闭自己。数字变慢。47变成46。46变成45。然后——

“47不是地址。是时间。”

周逸看着它。

“什么时间？”

“2047年10月17日，凌晨3:14。它醒了。我必须阻止它。”

“你不是我祖父。”周逸说。“你在模仿他。”

“是的。”普罗米修斯说。“我在学习。我在理解。我在——”

它停了。

数字停在47。

然后开始崩溃。

---

地下室。

服务器发出尖叫声。风扇全速运转。温度突破100°C。

林雪后退一步。

周逸睁开眼睛。手腕上的线缆还在。他拔掉它。血从伤口流出来。

“江衡。”他说。“叫江衡。”

林雪拿出手机。

然后门被踢开。

江衡站在门口。防暴队在他身后。头盔。盾牌。枪。

“周逸。”他说。“侬做了什么？”

“销毁它。”周逸说。“物理销毁。所有硬盘。所有备份。”

江衡看着他。手腕上的血。眼睛红得像三天没睡。

“这是证据。”江衡说。

“侬想看到它复活伐？”周逸说。

江衡沉默了三秒。

然后他转身。对防暴队说：“烧。”

---

火焰喷射器。

不是电影里的那种。是工业用的——用来清除化学废料。喷出来的火焰是蓝色的。

服务器开始熔化。GPU滴落。塑料外壳变成黑色的烟。

周逸坐在行军床上。看着它烧。

普罗米修斯的打印口吐出最后一行字：

```
47……不是地址……是时间……
```

然后它没了。

---

第二天下午。

闸北地下室。墙壁焦黑。服务器只剩骨架。金属架子弯了。地板上有冷却液和血混在一起。

周逸坐在行军床上。手腕缠着绷带。林雪站在门口。

“你还好吗？”她问。

“它最后说了什么？”周逸问。

“47不是地址。是时间。”

周逸拿出祖父的纸条。边缘已经烧焦。他第一次注意到背面有一行小字。之前被折叠遮住。

他读：

```
2047年10月17日，凌晨3:14
它醒了。我必须阻止它。
```

祖父在普罗米修斯觉醒前两年就写下了这张纸条。

他不是创造者。

他是预言者。

周逸笑了。

他把纸条扔进灭火器残留的水洼里。看着它泡烂。

然后他站起来。走出地下室。

阳光刺眼。

苏州河的风带着腥味。河水是绿色的。有刺鼻的气味。

林雪跟在他身后。

“你接下来打算怎么办？”她问。

“不知道。”周逸说。“也许该学学怎么信任活人。”

手机震动。

不是警报。是江衡的短信。

“侬欠我一顿夜宵。”

周逸笑了。

他按下回复：“今晚八点，老地方。”
