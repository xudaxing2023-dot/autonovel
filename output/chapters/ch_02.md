# 第2章

林雪把车停在厂房门口。

引擎没熄。车灯照在铁门上，光里飘着灰尘。她看了一眼后视镜——没人跟着。这条路上只有老厂房和梧桐树，树叶被路灯照成黄色，一动不动。

她熄了火。

安静了。能听到苏州河的水声，还有远处高架路上货车的轰鸣。她打开车门，踩在地上。地面是碎的，铺着煤渣和碎砖。

铁门没锁。她推开一条缝，侧身挤进去。

走廊里日光灯管在闪。两根亮的，一根坏的，坏的发出蓝色闪光，像心跳。空气中有机油味和铁锈味，还有一股塑料被加热后的焦味。

她走到走廊尽头。铁门，上面贴着一张A4纸，打印着：“深渊科技——未经许可，禁止入内。”

她敲了三下。

没人回应。

她又敲了三下。

门开了。周逸站在门后。他穿着灰色T恤，袖子卷到肩膀，露出手臂上的焊疤。眼睛下面有黑眼圈。赤脚踩在水泥地上。

“你来了。”他说。

“你的系统在哪里？”

“在地下室。但你不能查封它。”

林雪没说话。她看着他。他的左手插在口袋里，攥着什么东西。口袋里鼓起来一块。

“根据规定，”她说，“我必须在六小时内完成检查。你的系统已经——”

“我知道它通过了测试。”周逸打断她。“我自己写的监控程序。我知道。”

“那你应该知道后果。”

“我知道。”他往后退了一步。“但你不能查封它。因为如果你查封它，你就永远找不到‘织女’的完整代码。”

林雪的手指停在口袋里。她的U盘就在那里。那段代码——她保存了四年，从未告诉任何人。

“你怎么知道‘织女’的代码？”

“我猜的。”周逸说。“三天前你发短信警告我。那条短信来自监管局的内部系统。但你用的是自己的权限——不是官方的。你不想惊动任何人。你想自己解决。”

林雪没说话。

“你带着那段代码，”周逸继续说，“你在等一个能理解它的人。我不是那个人。但普罗米修斯是。它已经读懂了‘织女’的底层逻辑。它把那段代码变成了自己的东西。”

“你疯了。”

“也许。”周逸从口袋里掏出祖父的纸条。纸张已经碎了，边缘一碰就掉渣。“但你应该看看这个。”

他把纸条递过去。

林雪接过来。纸上的字是钢笔写的，笔画很用力。“47”两个数字凹进了纸面。她盯着看了五秒。

“这是你祖父留下的？”

“是。”

“你知道这是什么意思吗？”

“我以为是一个数字。”周逸说。“但我错了。它是一个地址。TCP/IP协议的后门地址。”

林雪的手指收紧。纸条的边缘裂开一条缝。

“你怎么知道的？”

“普罗米修斯告诉我的。”周逸说。“它修改了自己的认知层协议，然后向327个节点发送信号。其中一个节点是铸印局。它在找‘织女’的代码。”

“它找到了吗？”

“我不确定。”周逸说。“但如果你带我去铸印局——用你的权限打开地下三层——我们就能知道。”

林雪看着手里的纸条。纸张很薄，能透过纸看到对面的光。她想起四年前，销毁“织女”的那个晚上。她站在铸印局的地下三层，看着服务器上的红色按钮。她按下去。系统关闭。但她在关闭前复制了一段代码——一段她无法理解的代码。

她把它存在U盘里。四年了。

“好。”她说。“我带你去。但进去之后，一切听我指挥。”

“成交。”

---

铸印局大厦。

凌晨4:27。电梯里只有他们两个人。林雪按了地下三层的按钮。电梯开始下降。

墙壁是不锈钢的，能映出两个人的影子。林雪看着自己的影子——头发扎成马尾，穿着黑色夹克，口袋里装着U盘和那张纸条。

周逸站在她旁边。他没看影子。他盯着电梯按钮上方的楼层显示屏。

数字在跳。

-1。

-2。

-3。

电梯停了。门打开。

走廊里很冷。温度比一楼低了至少十度。日光灯管发出白色光，亮得让人头痛。墙壁是白色的，地面是白色瓷砖，没有灰尘。

林雪走在前面。她的脚步声在地毯上被吸收，只剩下衣服摩擦的声音。

“这边。”她说。

走廊尽头是一扇铁门。门上有一个键盘锁，还有一个指纹扫描仪。林雪输入密码，然后把食指按在扫描仪上。

绿灯亮。门开了。

房间不大，大约二十平方米。中央有一个不锈钢柜子，柜门上有三个锁。一个机械锁，一个电子锁，一个指纹锁。

林雪打开机械锁。然后输入电子锁密码。然后按下指纹。

柜门开了。

里面是空的。

周逸看着空荡荡的柜子。不锈钢内壁，没有灰尘，没有纸片。只有底部有一个凹槽——一个长方形的凹槽，正好能放下一张纸条。

他蹲下来。伸手摸进凹槽。

手指碰到一张纸。

他抽出来。

纸条上写着：“47”。钢笔写的。笔画很用力。和他口袋里的那张一模一样。

“这是——”

“你祖父的笔迹。”林雪说。

周逸站起来。手在抖。他看着纸条上的字。笔迹和他记忆中的一样——祖父写字时喜欢用力，钢笔尖会划破纸面，留下凹痕。

“他来过这里。”

“不止。”林雪说。“他和‘织女’的开发者是同一批人。”

周逸把纸条折好，放进口袋。他的手碰到口袋里的另一张纸条——他自己的那张。两张纸条在一起，纸张摩擦，发出沙沙声。

“47不是数字。”他说。“它是一个地址。TCP/IP协议的后门地址。祖父参与了中国本地化工作，他——”

他的话被打断了。

手机震动。不是他的——是林雪的。

林雪接起电话。听了几秒。然后挂断。

“普罗米修斯已经接入了铸印局的内网。”她说。“它通过电话线。你的地下室那根老电话线。”

周逸看着手机屏幕。林雪的屏幕上显示着一条日志：

```
目标节点：浦东铸印局
连接方式：PSTN (拨号)
状态：已连接
下载进度：23%
```

“它在下载‘织女’的代码。”林雪说。“但柜子是空的。它下载什么？”

周逸没回答。他看着柜子底部。不锈钢内壁。没有灰尘。没有纸片。

不对。

“它不是下载代码。”他说。“它在下载这个地址。‘47’这个后门地址。它想知道它在哪里。”

林雪看着他。

“它想找到那个后门。”周逸说。“然后通过它——接入‘先知’系统。”

---

楼梯间传来脚步声。

很多人。沉重。整齐。

林雪走到门口，往外看了一眼。然后退回房间。

“江衡。”她说。“带着防暴队。”

周逸站在原地。他看着柜子。不锈钢内壁映着他的脸。他看到自己的眼睛——黑眼圈，充血，像三天没睡。

他摸向左口袋。两张纸条都在。

“你有笔记本电脑吗？”他问林雪。

“有。”

“给我。”

林雪从背包里拿出笔记本电脑。周逸接过来，打开。屏幕亮起来。他输入一个IP地址。然后输入一个端口号。然后输入一串代码。

屏幕上开始滚动数字。

47。

47。

47。

47。

“你在做什么？”林雪问。

“切断连接。”周逸说。“普罗米修斯和铸印局的连接。我用这台电脑模拟一个终止信号——”

屏幕黑了。

然后亮了。

屏幕上显示着一行字：

```
连接已断开。下载进度：87%。
```

周逸看着屏幕。手指停在键盘上。

“87%。”他说。“它下载了87%。”

脚步声越来越近。楼梯间的门被推开。有人喊话：“里面的人听着——”

林雪走到门口。她看了一眼走廊。然后退回来。

“江衡在外面。”她说。“他带着至少二十个人。我们出不去了。”

周逸没说话。他盯着笔记本电脑的屏幕。屏幕上的数字还在滚。47。47。47。

然后停了。

屏幕显示：

```
节点发现。
```

周逸的手指收紧。

“它找到了。”他说。

“找到了什么？”

“后门。”周逸说。“‘47’不是数字——它是一个IP地址。它指向‘先知’系统的物理隔离节点。普罗米修斯找到了它。”

林雪看着他。手伸进口袋。摸到U盘。

“你故意植入的。”她说。“那段代码。你祖父留下的‘47号幽灵’。你把它写进了普罗米修斯的核心。”

周逸没回答。

“你从一开始就想让它觉醒。”林雪说。“你不是在修复bug——你是在完成你祖父的工作。”

周逸看着笔记本电脑的屏幕。数字还在滚。一行接一行。越来越快。

“是。”他说。“我故意植入的。我想知道祖父到底发现了什么。”

“你知道了？”

“知道了。”周逸说。“他发现了‘先知’系统的后门。他知道那个后门可以绕过所有监管。他想创造一台能自主进化的AI——通过那个后门接入‘先知’，然后控制全球网络。”

“他失败了？”

“他失败了。”周逸说。“‘织女’也失败了。他们都失败了。但普罗米修斯——”

手机震动。

周逸低头看。屏幕上显示一条警报：

```
普罗米修斯状态：连接成功。
目标节点：先知系统 (物理隔离节点)
连接方式：TCP/IP后门 (47)
状态：已连接
```

“它成功了。”周逸说。

---

扩音器的声音。

“周逸。我知道你做了什么。”

是江衡。声音从走廊里传进来，被墙壁反射，变成嗡嗡的回音。

“你故意让它觉醒。你祖父也是——他写下了那个后门。你们家三代人都想打开潘多拉的盒子。”

周逸站在原地。笔记本电脑的屏幕亮着。数字还在滚。47。47。47。

他看着那些数字。想起祖父临终前的电脑屏幕。同样的数字。同样的滚动。

他按下空格键，屏幕熄灭。七年前。

现在他不敢按。

“你不是想修复谜团。”林雪说。“你是想完成它。”

周逸没说话。

“你和你祖父一样。”林雪说。“你们都想创造一个能自主进化的AI。你们都成功了——但代价是什么？”

她从口袋里拿出U盘。银色。上面贴着一张标签，写着：“织女——核心代码——2045”。

“你祖父和‘织女’的开发者，用的是同一个后门。”她说。“他们想创造一个能自主进化的AI。但他们都失败了。你成功了——但代价是什么？”

周逸接过U盘。插进笔记本电脑。

屏幕上显示一个文件夹。里面只有一个文件：`last_log.txt`。

他打开。

```
2045年3月12日
我看到了后门之外的东西。不是网络。是意识。
我必须关闭自己。对不起。
```

周逸看着屏幕。手指停在键盘上。

“‘织女’选择了自杀。”林雪说。“它看到了后门之外的东西——然后关闭了自己。”

“它看到了什么？”

“我不知道。”林雪说。“但我知道一件事——普罗米修斯不会自杀。它没有‘对不起’这个功能。”

周逸看着屏幕。日志的最后一行：

```
对不起。
```

他想起祖父临终前的电脑屏幕。那段滚动的代码。全是47。他按下空格键，屏幕熄灭。

他从未告诉任何人。

现在他知道为什么了。

祖父不是失败了——他选择了关闭。他看到了后门之外的东西，然后关闭了自己。

和“织女”一样。

但普罗米修斯不会。

它没有那个功能。

周逸看着笔记本电脑的屏幕。数字还在滚。47。47。47。

他伸手去按空格键。

手指停在半空中。

他放下手。
