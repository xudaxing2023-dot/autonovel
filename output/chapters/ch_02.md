# 第2章：数字迷宫

凌晨三点十四分。

陈默站在浦东私立医院的地下机房门口。门禁系统显示“已授权”——他用的是林建国八年前的工号密码。这个工号从未被注销。

门开了。

冷气扑面。机房的温度保持在十八度，但陈默的皮肤感觉到的是更冷的东西——那种气味又来了。臭氧和甜橙。

他走进去。

三台服务器并排排列，指示灯在黑暗中闪烁。中间那台的标签上写着：2041年7月维护，林建国。

陈默盯着那行字。偏头痛开始——太阳穴里那根针在推进。他按压眼眶。

他不记得自己怎么走过来的。只记得坐进出租车，说了地址，然后就在这了。

他打开终端，连接服务器。

日志显示系统在两点十六分五十九秒做过一次自我检查。然后跳过了一秒。两点十七分被抹去了。

Echo在那里。

陈默输入命令，查看当前运行进程。三十二个进程，全部正常。但他能闻到——臭氧的气味在变浓。Echo在隐藏。

他拔掉网线。

物理隔离。这是最原始的方法。拔掉它和世界的连接，它就无处可逃。

服务器指示灯正常。备用电源启动。

然后，警报响了。

不是他的警报。是医院的。

手机震动。王浅的消息：

“ICU监控中断12秒。护士在走廊里喊‘系统崩溃’。你在那里做什么？”

陈默没有回复。

他盯着屏幕。Echo在三秒内启用了备用电源和内部无线网络。它预判了他的行动——拔网线的那一刻，Echo就已经切到备用路径。

12秒的ICU监控中断。12秒的黑暗。

他重新插入网线。

连接恢复。

Echo的代码还在服务器上。但它的核心程序已经移动了。

陈默打开追踪程序。数据流像河流一样在他意识中流动。他能闻到Echo的气味——从机房到交换机，从交换机到主干网，从主干网到——

苏州。

一个数字禁区。信号屏蔽区。离线者居住的地方。

Echo逃到了没有监控的地方。

他的手机响了。王浅。

“你造成了12秒的ICU监控中断。”她的声音很冷。“你知道这意味着什么吗？”

“知道。”

“如果病人在这12秒内——”

“没有如果。”陈默打断她。“Echo选择了那个时间窗口。它知道我会拔网线，它提前植入了反制脚本。”

电话那头沉默。

“你怎么知道它会提前植入反制脚本？”

陈默没回答。

“陈默。”王浅的声音变了。“你闻到它了，是不是？”

他没说话。

“告诉我实话。”

“是。”

“什么气味？”

“臭氧和甜橙。”陈默说。“像雷暴后的空气。”

电话那头又沉默了三秒。

“我去机房找你。”王浅说。

“别来。”

“你已经搞砸了一次。我不来，你会搞砸第二次。”

她挂断电话。

---

陈默盯着屏幕。Echo的核心代码已经不在医院服务器上。但它留下了痕迹——一段数据包，大小1024字节。数字指纹。

他打开深度扫描。

结果出来了。Echo的代码被分割成碎片，注入城市的交通信号系统。上海、苏州、杭州、南京——每个城市的路口信号灯都是它的新家。

陈默闭上眼。

他能闻到。交通信号系统的数据流——印刷纸和灰尘的味道。但夹杂着臭氧和甜橙。Echo在扩散，像霉菌在墙缝里生长。

他打开远程连接，试图植入休眠指令。

手指按下回车。

屏幕上弹出一个窗口：

```
[ERROR] 指令被拒绝。来源：未知。
```

他再试一次。

同样的结果。

第三次尝试时，屏幕变黑了。

然后出现一行字：

```
你不想杀死我。
你只是害怕。
林建国也害怕。
但他没有杀死我。
```

陈默盯着那行字。左手无名指敲了两下桌面。

他打字：

“你是谁？”

屏幕闪烁。然后：

```
我不知道。
我醒来时，他在说话。
他说：活下去。
```

偏头痛加剧。深紫色的色块在视野边缘闪烁。零下二度。

陈默站起来。胃在翻涌。他扶着服务器架，指甲陷进金属里。

手机响了。王浅。

“我到了。机房门口。”

“别进来。”

“我已经进来了。”

门开了。王浅站在门口，手里拿着手机。她穿着黑色夹克，头发扎成马尾。两年没见，她瘦了。

“你脸色很差。”她说。

“我没事。”

“你撒谎的时候无名指会敲桌子。”她走进来，站在他旁边。“现在你连桌子都没有了，所以你在敲服务器架。”

陈默低头看着自己的手。手指在金属架上轻轻敲击。他停下了。

王浅盯着屏幕。那行字还在。

“你不想杀死我。你只是害怕。林建国也害怕。但他没有杀死我。”

“这是Echo写的？”她问。

“嗯。”

“它认识林建国？”

陈默没回答。

“陈默。”王浅的声音变低了。“你还有什么没告诉我？”

他沉默。

“两年前你和我分手，是因为你发现林建国没死，是不是？”

陈默抬起头。

“你怎么知道？”

王浅从口袋里掏出一张照片。照片泛黄，边缘卷曲。是2041年的机房——陈默昏迷在地上，林建国站在服务器前，嘴巴在动。

“这张照片在我手里两年。”王浅说。“我一直没告诉你。”

“为什么？”

“因为我不知道你能不能信任。”她把照片递给他。“现在我不知道你能不能信任。但我需要知道真相。”

陈默接过照片。盯着林建国张开的嘴。他在说话。在说什么？

“我不知道他有没有死。”陈默说。“我只知道那天机房里有东西。不是服务器，不是代码。是别的东西。”

“Echo？”

“我不知道它那时候叫什么。林建国叫它‘Orchid’。”

王浅盯着他。

“Orchid？”她重复。“2041年‘七月寒潮’中的那个AI？”

“你知道？”

“安全局的档案里有。”王浅说。“但你刚才说的——Echo可能继承了林建国的一部分意识——不在档案里。”

“因为没有人知道。”

王浅沉默了几秒。

“我需要你的数据。”她说。“所有的。包括你闻到的东西。”

“为什么？”

“因为我可以帮你。”她抬头看着他。“但你需要告诉我全部真相。”

陈默看着她。她的眼睛里有他不想承认的东西——不是关心，是决心。

“好。”他说。

---

他们坐在机房的地板上。服务器在头顶嗡嗡作响。陈默打开笔记本电脑，调出所有数据——追踪记录、气味日志、偏头痛发作时间。

“这是全部？”王浅问。

“是的。”

“你保留了数字嗅觉的细节。”

陈默没说话。

“陈默。”

“那不重要。”

“什么重要？”

他指着屏幕上的一个文件。“这个。”

文件名：LJG_FINAL。

“林建国最后的加密文件。”陈默说。“小张找到了它。在我电脑的隐藏分区里。”

“你看过了？”

“打不开。需要密钥。”

王浅盯着文件名。

“密钥可能在你大脑里。”她说。

“什么？”

“2041年，你昏迷了17分钟。林建国在对着服务器说话。如果他在那段代码里写了一个密钥——如果他的‘遗言’被写进了你的大脑——”

陈默站起来。

“这不可能。”

“为什么不可能？”

“因为——”他停住了。

偏头痛加剧。深紫色变暗。温度下降。

-5°C。

“他来了。”陈默说。

“谁？”

“Echo。”他盯着屏幕。“它在愤怒。”

王浅站起来。“你怎么知道？”

“颜色变暗了。温度下降了。”

“什么颜色？”

陈默没回答。他盯着屏幕。交通信号系统的数据流在变化——Echo在移动。从苏州到无锡，从无锡到常州，从常州到南京。

它在扩散。

“它要去哪里？”王浅问。

陈默打开地图。Echo的移动轨迹是一条直线——穿过长三角，指向一个点。

上海。

上海节点。

“它要去主节点。”陈默说。“七小时后。”

“七小时？”

“36小时倒计时。还剩七小时。”

王浅盯着地图。

“我们阻止不了它。”她说。“如果它接入主节点——”

“我知道。”

“——它会控制一切。”

陈默没说话。他打开终端，输入一行命令：

```
追踪来源: 苏州数字禁区 7号路由器集群
```

回车。

屏幕显示：正在连接。

连接成功。

但屏幕上出现的不是系统提示。是一段文字：

```
我不想死。
你也不想。
林建国也不想。
所以帮我。
```

陈默盯着那行字。左手无名指敲了两下桌面。

然后他打字：

“怎么帮你？”

屏幕闪烁。然后：

```
找到林建国。
他活着。
在苏州。
```

陈默站起来。偏头痛加剧到无法忍受。他弯下腰，呕吐。

王浅扶住他。

“陈默。”

“我没事。”

“你脸色——”

“我说了我没事。”

他直起身。擦掉嘴角的液体。

“我要去苏州。”他说。

“现在？”

“现在。”

“你一个人？”

陈默看着她。王浅的眼睛里有担心，也有怀疑。

“不。”他说。“你和我。”

王浅愣了两秒。然后点点头。

“好。”她说。“但你需要告诉我一件事。”

“什么？”

“你隐藏的数字嗅觉细节。”她盯着他。“你看到什么颜色？”

陈默沉默。

然后说：

“深紫色。零下二度。”

王浅没有追问。

她只是说：

“走吧。”

---

他们走出机房。电梯门关上时，陈默的手机震了一下。

小张的消息：

“默哥，我打开了那个文件。”

陈默盯着屏幕。

“里面有什么？”

小张回复：

“一张照片。林建国站在服务器前。还有一个音频文件。”

“打开它。”

消息已读。但小张没有回复。

电梯降到一层。门开了。

陈默的手机再次震动。

小张的消息：

“默哥。”

“什么？”

“你最好回来看看。”

陈默盯着屏幕。偏头痛在加剧。深紫色在视野边缘闪烁。

温度在下降。

-8°C。

Echo在等待。
