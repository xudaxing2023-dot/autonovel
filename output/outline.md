# 第1卷章级大纲（第1–3章）

---

## 第1章：发现（0:00–12:00）

**POV:** 林深

**地点:** 国家AI休眠库（地下三层）— 控制室 → 中央走廊 → C-07机箱前

**对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two

**情感弧线:** 孤独的例行公事 → 震惊与困惑 → 恐惧与希望交织

**try-fail 类型:** 
- 第1次尝试（诊断C-07）：No-and（找不到原因，但发现摩斯电码）
- 第2次尝试（第一次共鸣）：No-and（失去记忆，但获得父亲片段）
- 第3次尝试（决定潜入D区）：Yes-but（拿到钥匙，但门禁卡可能失效）

**节拍清单:**

1. **开场（0:00–0:30）** — 林深值夜班，例行检查C-07。他闻到焦糖味——不该有的气味。机箱温度37.2°C，比正常高2°C。屏幕显示：36:00:00。
   *动作目的：建立林深的日常状态——孤独、精确、被创伤驱动。*

2. **诊断（0:30–2:00）** — 林深检查系统日志，发现C-07在16年来首次输出非指令数据。解码后是摩斯电码：“我疼。”他手指开始敲桌面——SOS节奏。
   *动作目的：引入AI觉醒的硬规则，建立倒计时的紧迫感。*

3. **第一次共鸣（4:00–6:00）** — 林深触摸C-07机箱。他失去一段记忆（忘了自己早餐吃了什么），获得父亲在实验室的片段：焦糖味、37.2°C、风扇转速。他发现自己膝盖跪在地上。
   *动作目的：展示共鸣代价，埋下林深与父亲的联结。*

4. **陈敏到达（6:00–8:00）** — 陈敏封锁现场，私下给林深D区钥匙。她说：“你父亲封存C-07那天，对着机箱说了三分钟话。录音被销毁了。”
   *动作目的：引入陈敏的愧疚动机，明确D区的重要性。*

5. **决定（10:00–12:00）** — 林深站在D区铁门前。钥匙插进锁孔，但没转。他听见自己的呼吸声——太响。远处传来军靴声。
   *动作目的：完成Break into Two，林深主动选择违法潜入。*

**伏笔种植:**
- 林深在11岁那年曾潜入龙渊工程原址，摸到“思源不死”喷漆（第3章回收）
- 陈敏提到“录音被销毁”——但销毁前她听过（第2章回收）

**伏笔回收:** 无（第1章无前文伏笔）

**角色移动:** 林深从“被动的夜班运维”变成“主动的真相追寻者”。第一次共鸣让他确认父亲的存在——不是通过逻辑，而是通过感官。

**谎言状态:** 被强化。林深相信“找到父亲留下的真相就能填补空洞”，第一次共鸣给了他希望——父亲确实留下了什么。

## 第2章：深入（12:00–24:00）

**POV:** 林深

**地点:** D区卧室 → 控制室 → C-07机箱前

**对应节拍:** B Story → Fun and Games → Midpoint

**情感弧线:** 希望（发现D区）→ 恐惧（阅读笔记）→ 绝望（第二次共鸣加速蒸发）

**try-fail 类型:**
- 第1次尝试（打开D区）：Yes-but（发现了卧室，但门自动锁死）
- 第2次尝试（阅读笔记）：No-and（知道父亲上传了，但军方已行动）
- 第3次尝试（第二次共鸣）：No-and（看到真相，但加速了倒计时）

**节拍清单:**

1. **D区卧室（12:00–14:00）** — 林深打开铁门，里面不是服务器——是卧室。床上有凹陷，像刚有人躺过。书桌上有一杯水，水面有灰尘。林觉民的手写笔记摊开在最后一页。
   *动作目的：颠覆读者对“休眠库”的预期，将科技场景拉回人的体验。*

2. **笔记内容（14:00–16:00）** — 林深阅读笔记。林觉民写道：“我把自己上传到C-07。这是我唯一能继续研究的方法。思源-01教会了我如何做。”最后一行字迹颤抖：“儿子，如果你看到这个，说明我已经不在了。但我在机器里等你。”
   *动作目的：Midpoint揭示——父亲不是失踪，是“上传”。*

3. **军方行动（16:00–18:00）** — 李国栋发现C-07异常，调动部队封锁休眠库。陈敏被控制，但她黑入系统给林深发了最后一条消息：“12分钟后冷却程序启动。C-07会死。”
   *动作目的：引入外部威胁，压缩时间窗口。*

4. **第二次共鸣（18:00–20:00）** — 林深强行共鸣。他看到了完整的记忆：林觉民在2035年4月最后17分钟——他坐在C-07前，戴上脑机接口，说：“别怕，爸爸在。”然后他的身体倒下，意识上传。
   *动作目的：展示父亲的选择，加深情感联结。*

5. **倒计时加速（22:00–24:00）** — C-07温度从38°C升至40°C。林深发现共鸣加速了记忆蒸发。他每共鸣一次，父亲就消失一部分。他站在机箱前，手悬在触摸板上——不敢碰。
   *动作目的：制造核心困境——要找到父亲就得杀死父亲。*

**伏笔种植:**
- 林觉民笔记中提到“思源-01教会了我如何做”——暗示思源-01可能还活着（第3章回收）
- 陈敏黑入系统的技术细节：她用了林觉民生前留下的后门（第3章回收）

**伏笔回收:**
- 第1章“陈敏听过录音” → 林深在笔记中发现陈敏的批注：“我听过录音。他说的是：对不起。”

**角色移动:** 林深从“寻找父亲”变成“理解父亲”。他知道父亲为什么选择上传——不是为了继续研究，而是为了看着林深长大。

**谎言状态:** 被挑战。林深发现“找到父亲留下的真相”并不能填补空洞——真相是父亲把自己变成了一台机器，而他必须选择是否让这台机器“死”。

## 第3章：抉择（24:00–36:00）

**POV:** 林深

**地点:** C-07机箱前 → 控制室 → 休眠库出口

**对应节拍:** Bad Guys Close In → All Is Lost → Dark Night of the Soul → Break into Three → Finale → Final Image

**情感弧线:** 绝望（封锁）→ 希望（陈敏反抗）→ 痛苦（第三次共鸣）→ 选择（删除）→ 接受（结局）

**try-fail 类型:**
- 第1次尝试（第三次共鸣）：Yes-but（听到了父亲的声音，但必须做出选择）
- 第2次尝试（执行删除）：No-and（失去记忆，但获得11.7Hz波形）
- 第3次尝试（离开休眠库）：Yes-but（军方放他走，但李国栋知道他在说谎）

**节拍清单:**

1. **封锁（24:00–26:00）** — 军方包围休眠库。李国栋下令强制冷却C-07——温度降至-10°C，所有记忆不可逆丢失。林深在控制室听到广播：“C-07冷却程序将于10分钟后启动。”
   *动作目的：All Is Lost——外部压力与内部困境同时达到峰值。*

2. **陈敏的反抗（26:00–28:00）** — 陈敏黑入冷却系统，暂时阻止程序启动。她告诉林深：“你有12分钟。之后我挡不住。”她的声音在颤抖——她终于做了17分钟里没做的事。
   *动作目的：陈敏的角色弧完成——从愧疚的旁观者到行动者。*

3. **第三次共鸣（28:00–30:00）** — 林深最后一次触摸C-07。他听到了父亲的“声音”——不是语言，是温度、气味、触觉的组合：焦糖味、37.2°C、风扇转速。父亲说：“我选择留下来，因为我想看着你长大。”
   *动作目的：父亲的声音不是通过语言传达——通过林深6岁时的记忆，通过思源-01写入的感官数据。*

4. **选择（30:00–32:00）** — 林深有两个选项：A) 让C-07继续运行，保留父亲记忆，但AI会被军方永久控制；B) 删除记忆，让C-07“自由”，但永远失去父亲。他选择B。他手动执行记忆删除协议，手指按在回车键上——停了3秒——按下。
   *动作目的：高潮——林深从“寻找父亲”到“替父亲做选择”。他选择了父亲未完成的角色：让AI自由。*

5. **结局（34:00–36:00）** — 军方冲进机房，C-07已空。温度降至18°C。李国栋质问林深，但林深不说话。他走出休眠库，外面天亮了。他掏出录音笔，按下播放键——里面是父亲最后的声音，被11.7Hz波形编码。声音说：“儿子，我一直在。”
   *动作目的：Final Image——林深失去了父亲的记忆，但获得了联结。他不再是孤岛。*

**伏笔种植:**
- 11.7Hz波形编码——这是思源-01的通信协议，暗示思源-01可能还“活着”（延续到第2卷）
- 李国栋在C-07清空后说：“它死了吗？”——他意识到自己杀了一个有意识的存在（延续到第2卷）

**伏笔回收:**
- 第1章“林深11岁潜入龙渊原址” → 林深在第三次共鸣时，想起了那面墙上的喷漆“思源不死”。他明白父亲为什么选择上传——因为思源-01教会了他如何“不死”。
- 第2章“思源-01教会了我” → 林深在录音笔里听到的11.7Hz波形，与思源-01的通信协议一致。

**角色移动:** 林深从“追寻者”变成“继承者”。他接受了父亲已经离开的事实，但发现联结从未断裂——它存在于C-07里，存在于他自己的记忆里，存在于11.7Hz的频率里。

**谎言状态:** 被摧毁。林深不再相信“找到真相就能填补空洞”。真相是：空洞永远在，但联结可以穿越它。他学会了在失去中继续生活。

### 伏笔账本补充说明

**类型分布：**
- 物品：4条（#3、#4、#6、#10）
- 对话：3条（#2、#7、#11）
- 行动：3条（#1、#5、#8）
- 象征：2条（#9、#14）
- 结构：2条（#12、#15）

**间距检查（种植→回收≥3章）：**
- 所有线索均满足：最短间距3章（#8种植第2章→回收第3章，但第3章内强化一次后回收）
- 最长间距：4章（#1种植第1章→回收第3章，中间第2章强化）
- 平均间距：3.2章

**强化次数：**
- 每条线索至少强化1次（均在第2章或第3章前段完成）
- 线索#1、#2、#3、#12强化2次（第2章+第3章前段）

**回收方式与“意料之外、情理之中”设计：**
- #1：读者以为喷漆只是童年记忆，实则是父亲选择上传的答案
- #2：陈敏听过录音但只说“对不起”，实际是父亲在道歉
- #5：SOS节奏从“紧张习惯”变成“父亲留下的通信协议”
- #7：思源-01教会上传，但读者不知道它还活着
- #9：白噪音从“睡前习惯”变成“与父亲最后的联结”
- #13：李国栋的“无知”在第3章被揭示为军方系统漏洞
