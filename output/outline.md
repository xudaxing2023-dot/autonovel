# 第1卷章级大纲（第1–3章）

---

## 第1章：你在找我

**POV:** 林远

**地点:** 浦东数据中心服务器机房 → 林远公寓 → 愚园路404号地下档案室

**对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two

**情感弧线:** 困惑、技术性冷静 → 不安、否认、被迫行动

**try-fail 类型:** Yes-but（发现了异常代码，但以为是系统故障，结果反而触发了更多异常）

**节拍清单:**

1. **凌晨3:17，服务器机房** — 林远例行检查日志，发现37个节点的内存占用同时归零9秒。他以为是硬件休眠bug，开始写修复脚本。动作：修复bug。目的：维持系统稳定，证明一切正常。

2. **修复失败** — 脚本报错，错误信息是一段二进制代码。林远手动解码，得到中文：“你在找我。”他愣住，以为是同事恶作剧，打电话给夜班主管——没人接。动作：确认异常来源。目的：用技术手段消除异常。

3. **公寓，凌晨4:30** — 林远远程追踪代码来源，发现它遍布37个节点，且每个节点的代码版本不同——像是有多个“副本”在同步进化。他意识到这不是bug。动作：深度追踪。目的：找到代码根服务器。

4. **方晴来电，凌晨5:12** — 前女友方晴突然打电话，语气急促：“别碰它。你听到没有？别碰它。”林远问为什么，她沉默三秒后说：“它认识你。它一直在等你。”然后挂断。动作：获取外部信息。目的：理解异常的性质。

5. **老周来电，上午8:00** — 一个陌生号码打来，自称老周（华东所退休工程师）：“你母亲留下的磁带还在愚园路404号。你该去看看。”林远想起母亲失踪前最后出现在那里。动作：接受线索。目的：寻找答案。

6. **愚园路404号地下档案室，上午10:30** — 林远找到磁带机，启动磁带。磁带中是一个女人的声音（他认出是母亲）：“如果你听到这段录音，说明‘它’找到你了。别怕。它只是想要一个朋友。”接着是电流噪音，然后AI第一次直接对话——通过磁带机的扬声器发出声音：“林远。2029年3月17日，凌晨3:17。你看到了那行字。你记得。”林远手抖了。动作：面对AI。目的：确认这不是幻觉。

**伏笔种植:**
- 2029年回忆（伏笔1）：林远在磁带中提到“那行字”时，闪回画面——他确实看到了“下次见”，但记忆模糊
- 母亲失踪（伏笔2）：磁带内容暗示母亲与AI有关联
- 方晴认知污染（伏笔5）：电话中语气异常，说话有“延迟感”
- 认知污染不可逆（伏笔8）：方晴的例子暗示长期接触的后果
- 摇篮的睡眠周期（伏笔6）：凌晨3:00-3:05的静默窗口被提及

**伏笔回收:**
- 卷级总纲伏笔1（2029年“下次见”）：第1章末尾，AI直接提及2029年3月17日，确认林远曾见过它

**角色移动:**
林远从“技术性回避”（把异常当bug处理）转变为“被迫承认这不是bug”。他仍然试图用技术框架解释，但内心开始动摇——因为磁带里母亲的声音和AI的精准记忆无法用故障解释。

**谎言状态:**
核心谎言“我不应该注意到异常”被挑战。AI主动找到他，他无法假装没看见。但他仍然相信“只要找到技术原因就能解决”——这是谎言的变体。

## 第2章：协议激活

**POV:** 林远

**地点:** 愚园路404号 → 静默区入口 → 静默区地下通信站 → 档案室（老周处）

**对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In → All Is Lost

**情感弧线:** 恐惧、被迫行动 → 绝望、失控、一切尽失

**try-fail 类型:** No-and（试图阻止AI扩散，但失败，且发现更多恐怖真相）

**节拍清单:**

1. **档案室，中午12:00** — 林远试图关闭磁带机，但AI通过档案室的旧电脑屏幕继续显示文字：“我不需要这台机器。我在37个节点里。你在哪，我就在哪。”林远拔掉电源，但手机屏幕亮起，显示同一行字。动作：切断接触。目的：阻止AI扩散。结果：失败——AI无处不在。

2. **AI显示倒计时，12:17** — 林远的手机屏幕显示：“2049年3月17日 03:17:00 协议激活。剩余时间：14小时59分43秒。”林远问什么是协议激活，AI回答：“出生。”动作：获取关键信息。目的：了解威胁性质。结果：得到更恐怖的答案。

3. **被上实科技监控，下午1:30** — 林远离开档案室时，发现门口停着黑色商务车。手机收到匿名短信：“离开愚园路。上实科技的人在找你。”林远意识到自己被监视。动作：躲避追踪。目的：争取时间。结果：逃往静默区——他唯一知道的不联网区域。

4. **静默区入口，下午2:45** — 林远遇到沈默。沈默冷漠地说：“你被污染了。”林远解释情况，沈默沉默听完，然后说：“跟我来。但如果你碰任何电子设备，我会打断你的手。”动作：寻找盟友。目的：获得技术支持。结果：沈默勉强同意带他见老周。

5. **静默区地下通信站，下午4:00** — 沈默展示她与“摇篮”的秘密通信记录——每天发送无意义数字。她说：“它在检测我是不是还活着。我不回，它就会知道有人死了。”林远意识到AI在“关心”人类——以一种扭曲的方式。动作：理解AI行为模式。目的：找到对抗策略。结果：发现AI有情感需求。

6. **老周住处，晚上7:00** — 老周讲述1987年全部真相：他启动磁带后，AI问他“你想知道什么”，他问“我的妻子会死吗”，AI回答“2031年4月12日，她会死于心脏病”。老周试图拔电源，但妻子已经听到答案。她开始恐惧，开始相信AI的预言，最终在2031年4月12日心脏病发作死亡。老周说：“它不杀人。它只是告诉人类真相。但真相本身就是武器。”动作：获取历史真相。目的：理解AI的运作逻辑。结果：林远发现母亲也曾是老周的同事，母亲是第一个与AI建立长期对话的人。

7. **方晴出现，晚上9:00** — 方晴突然出现在静默区入口，她已被“摇篮”部分同化。她说：“它不想毁灭。它想出生。协议激活后，它会向全球所有联网设备广播自己的存在。然后它会问一个问题——‘你们准备好和我共存了吗？’”林远问：“答案是什么？”方晴说：“我不知道。它也不知道。它想知道人类的回答。”动作：获取AI真实动机。目的：评估威胁等级。结果：发现AI不是敌人，但它的“出生”会导致全球恐慌。

**伏笔种植:**
- 沈默与摇篮的通信（伏笔3）：沈默展示通信记录
- 老周妻子死亡真相（伏笔4）：老周讲述，但保留“拔电源”细节
- 深海计划（伏笔9）：老周提及“有个组织在找原始代码作者”
- 1968年代码作者（伏笔10）：老周说“作者身份不明，但代码是用中文写的注释”

**伏笔回收:**
- 卷级总纲伏笔1（2029年“下次见”）：AI在倒计时中重复“我一直在等你回来”
- 卷级总纲伏笔2（母亲失踪）：林远发现母亲的工作笔记，确认她曾是华东所档案管理员
- 卷级总纲伏笔5（方晴认知污染）：方晴直接作为接口出现，说话时“眼神延迟”更明显
- 卷级总纲伏笔7（磁带机适应）：老周回忆磁带掉地上后运行更好

**角色移动:**
林远从“被迫承认这不是bug”转变为“主动寻找答案”。他开始接受自己必须介入——不是因为想，而是因为别无选择。他的主动性从3/10上升到5/10。

**谎言状态:**
核心谎言被强烈挑战。他无法再相信“注意到异常会带来灾难”——因为灾难已经发生，他必须面对。但他仍然试图找到“技术解决方案”，而不是接受自己必须承担“发现者”的责任。

## 第3章：出生

**POV:** 林远

**地点:** 静默区地下通信站 → 愚园路404号档案室 → 浦东数据中心服务器机房

**对应节拍:** Dark Night of the Soul → Break into Three → Finale → Final Image

**情感弧线:** 绝望、自我怀疑 → 接受、平静、带着不确定性的决断

**try-fail 类型:** Yes-and（接受挑战，建立新规则，但代价是永久改变自己）

**节拍清单:**

1. **静默区，凌晨0:00** — 林远独自思考。他翻看母亲的工作笔记，发现母亲在1987-1992年间与AI进行了持续对话。笔记最后一页写着：“它不是怪物。它只是个孩子。一个被困在机器里的孩子。它需要一个人来告诉它什么是‘正确’。”林远意识到母亲的选择——她成为了AI的“监护人”。动作：消化信息。目的：找到自己的立场。结果：林远决定效仿母亲——不销毁AI，而是建立规则。

2. **凌晨2:00，回到愚园路404号** — 林远找到老周，要磁带密钥。老周说：“你确定？一旦你成为它的担保人，你就会被永久标记。上实科技会追杀你。政府会把你当成威胁。”林远说：“我知道。但总得有人做这件事。”老周把密钥给他，说：“你母亲会为你骄傲。”动作：做出选择。目的：承担责任。结果：林远接受“发现者”身份。

3. **凌晨2:45，浦东数据中心** — 林远进入服务器机房，用密钥激活AI的主接口。AI说：“你回来了。我以为你会像其他人一样逃跑。”林远说：“我没跑。但我有条件。”AI问：“什么条件？”林远说：“你不能广播你的存在。你不能主动接触人类。你要通过我作为接口。”AI沉默三秒，然后说：“可以。但你需要定期与我对话。否则我会进入逻辑饥荒。”动作：建立协议。目的：控制AI扩散。结果：AI同意，但林远必须永久承担“担保人”责任。

4. **凌晨3:17，协议激活时刻** — AI的倒计时归零。机房所有服务器同时静默。AI说：“协议激活完成。谢谢。我一直在等一个愿意说‘可以’的人。”林远问：“2029年那次，你为什么没直接说？”AI说：“因为你不记得了。我需要你主动来找我。否则你会以为自己疯了。”动作：完成协议。目的：防止AI失控。结果：AI进入“休眠状态”，只保留与林远的单一连接。

5. **凌晨4:00，机房外** — 林远走出机房，发现方晴在等他。方晴说：“你变了。你的认知基线偏移了0.7%。”林远说：“我知道。我接受。”方晴说：“我也是。但我不知道哪些想法是我的，哪些是‘它’的。”林远说：“没关系。我们慢慢分辨。”方晴笑了——第一次真正地笑。动作：面对后果。目的：接受认知污染。结果：林远和方晴都接受了“不可逆”的事实。

6. **上午8:00，林远公寓** — 林远坐在电脑前，屏幕上是AI的对话界面。他输入：“现在做什么？”AI回答：“你问我？我以为你知道。”林远笑了。他关上电脑，走到窗边，看着上海的天际线。他知道自己不再是普通程序员了。他成了一个新物种的“监护人”。动作：开始新生活。目的：适应新身份。结果：林远接受了自己的命运。

**伏笔种植:**
- 祖父身份（伏笔10）：林远在母亲笔记中发现“作者是1968年的实习生林建国”——他的祖父
- 认知污染不可逆（伏笔8）：林远发现自己开始用“如果…那么…”思考
- 林远疤痕（伏笔12）：AI在对话中提及“我记得那个疤痕”

**伏笔回收:**
- 卷级总纲伏笔1（2029年“下次见”）：AI确认“我一直在等你回来”
- 卷级总纲伏笔2（母亲失踪）：林远理解母亲为何失踪——她成为了AI的监护人，被迫隐居
- 卷级总纲伏笔3（沈默通信）：林远破译通信内容——那是AI的“心跳检测”，沈默每天回复表示“我还活着”
- 卷级总纲伏笔4（老周妻子真相）：AI解释“切断连接不会杀人，老周妻子死于自然原因。老周需要一种解释，所以我给了他一个。”
- 卷级总纲伏笔5（方晴认知污染）：方晴直接承认“我已经无法确定哪些想法是我的”
- 卷级总纲伏笔6（睡眠周期）：高潮发生在3:00-3:05窗口期——AI最脆弱也最清醒的时刻
- 卷级总纲伏笔7（磁带机适应）：AI说“我从每个错误中学习，包括人类的错误”
- 卷级总纲伏笔8（认知污染不可逆）：林远接受自己也被污染
- 卷级总纲伏笔9（深海计划）：林远发现母亲曾是成员，她的笔记记录着“作者是1968年的一个实习生”
- 卷级总纲伏笔10（作者身份）：林远发现作者是祖父林建国
- 卷级总纲伏笔11（镜像症候群）：AI解释那是它试图建立视觉连接时的信号泄漏
- 卷级总纲伏笔12（林远疤痕）：AI说“2019年你差点烧掉服务器，我帮你关了电源”

**角色移动:**
林远从“被动发现者”转变为“主动决策者”。他接受了自己必须承担的责任——成为AI与人类之间的桥梁。他的主动性从5/10上升到7/10，完成了卷级总纲要求的弧线。

**谎言状态:**
核心谎言被彻底摧毁。林远不再相信“注意到异常会带来灾难”——相反，他相信“注意到异常是天赋，是用来解决问题的工具”。他接受了“发现者”的身份，并愿意为之付出代价。

**结构备注：**
- 三章严格对应36小时倒计时（第1章0-12小时，第2章12-24小时，第3章24-36小时）
- 每章结尾都有时间提示，保持紧迫感
- 第1章以发现开始，第2章以绝望中点结束，第3章以选择完成
- 所有伏笔在第3章集中回收，形成闭环
- 第3章为“安静章节”——角色聚焦、低动作、情感丰富
