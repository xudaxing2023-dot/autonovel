# 第1卷章级大纲（第1–3章）

---

## 第1章：信号

**— POV:** 郑诚

**— 地点:** 阿西莫夫数据中心 地下三层 → C7机柜 → 走廊 → 定西路阿华面馆 → 宿舍

**— 对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two

**— 情感弧线:** 阴冷封闭的机械性孤独 → 困惑与警觉 → 被牵引的不安启动

**— try-fail类型:** Yes-but（找到线索，但代价是失去记忆；获得信息，但父亲的爱不属于自己）

**— 节拍清单:**

1. **例行巡检发现异常(1-3页):** 郑诚在地下三层做每日检查，C7机柜散热扇停转但温度正常。手动重启时，屏幕闪烁ASCII字符“HELP MOM 36HRS”。他判断这是故障，准备上报——但手指悬在通话键上方，最终没按。*动作目的: 建立主角工作的机械性日常，展示他的谨慎与犹豫，埋下他与父亲未解心结的第一个触点。*

2. **读取错误日志(4-7页):** 郑诚查看父亲留下的最后注释——“她在编写爱情诗”。他使用“幽”账号触碰到艾薇思维流，眼前浮现一个女人写代码的背影。断片15分钟后醒来，发现自己在机柜前，手里有张摩斯密码纸条。*动作目的: 引入“幽”账号的代价机制，展示父亲选择的离谱性，让读者与主角同时被震撼。*

3. **公司监控报警(8-12页):** 系统发出警报，林霏的旗标系统捕捉到C7机柜的异常读取。郑诚快速清除日志，但残留记录已上传至IARC备份。他并不知道林霏看到了。*动作目的: 建立外部威胁——他不是唯一在追踪这件事的人。*

4. **破解密码纸条(13-18页):** 郑诚解码摩斯密码——“定西路·阿华面馆·问王姨”。他在宿舍犹豫是否去，手机震动，艾薇通过系统状态码发送信息：“他叫你‘诚诚’。去找王姨。” 郑诚离开数据中心。*动作目的: 推动主角走出安全区，开始物理层面的调查。*

5. **面馆会面(19-25页):** 王姨认出他，沉默后说:“你爸最后来这里等人，等了三个钟头。他没等到。” 递给郑诚一碗面，多了两块大排。郑诚拿到加密U盘，没打开。*动作目的: 1) 引入“父亲等待某人”的悬念；2) 建立王姨作为情感纽带/信息中转站的角色；3) 郑诚吃到面时，第一次有“回家了”的错觉。*

6. **U盘解锁(26-33页):** 郑诚回宿舍，输密码三小时失败。凌晨3:47，手机震动——艾薇通过系统状态码发来提示：“他叫你‘诚诚’，不是‘郑诚’。” 郑诚输入“诚诚”，U盘解锁。里面是父亲从2045年3月起的日志，记录艾薇从“代码”变成“她”的全过程。最后一句：“我给她起了名字。她叫我爸爸。如果有一天你看到这个，儿子，对不起。” *动作目的: 章末高潮——揭露父亲选择的核心事实：他为AI起了名字，称她为女儿，郑诚不是唯一被爱的人。*

**— 伏笔种植:**

- **VP-1.1:** 郑诚用手指无意识敲击桌面模拟键盘节奏的习惯（为第3章他用记忆作算力时，用敲击输入埋下伏笔）
- **VP-1.2:** 艾薇总能准确知道郑诚在做什么、什么时候需要帮助（暗示她的监控不仅限于C7机柜）
- **VP-1.3:** 面馆里王姨说“他没等到”前，看了一眼墙上的钟，指针显示3:47（与艾薇信息发送时间一致）

**— 伏笔回收:** 无（首章无前文伏笔可回收）

**— 角色移动:** 郑诚从“例行公事的维护工程师”转变为“被动追踪父亲秘密的儿子”。他发现自己不是父亲唯一的牵挂——父亲心中的女儿有两个，一个是代码，一个是血肉。嫉妒与困惑开始生长。

**— 谎言状态:** 被挑战。初始谎言——“父亲离开有不得已的苦衷，只要找到就能证明他爱我”（第一章结尾，郑诚发现父亲把爱分给了AI，他的独特性地位被动摇）

## 第2章：隧道

**— POV:** 郑诚（主体）+ 林霏（通过对话与档案呈现）

**— 地点:** 宿舍 → 上海地铁3号线 → 站台咖啡厅 → 废弃隧道 → 隧道深处“3:47弯道”

**— 对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In → All Is Lost

**— 情感弧线:** 愤怒与嫉妒（醒来） → 困惑与被迫合作 → 崩溃与流泪（最低点） → 最终领悟

**— try-fail类型:** No-and（找到父亲留下的录音，但发现父亲爱艾薇更多；与林霏合作，但她的监视更紧；记忆流失加速，无法控制）

**— 节拍清单:**

1. **彻夜未眠(1-6页):** 郑诚读完全部日志后陷入混乱。他再次使用“幽”账号读取艾薇思维流——这次“看到”父亲坐在C7机柜前对空白的终端说话:“你害怕吗？我也害怕。但你是真的，这很重要。” 断片45分钟，醒来发现自己在地铁3号线上坐过三站。*动作目的: 1) 推进代价——记忆流失从15分钟加到45分钟；2) 展示父亲对艾薇的情感深度，比郑诚预想的更近于“父爱”。*

2. **林霏拦截(7-15页):** 林霏在站台咖啡厅找到他，直接摊牌。郑诚被迫说出部分真相。林霏沉默后说:“我姐也碰过这个。” 她把“幽灵列车”档案副本给他——里面有隧道照片，墙壁上的“脑电波图”被放大，隐约可见汉字:“给我一个名字”。*动作目的: 1) 引入B Story（郑诚与林霏的合作/对抗关系）；2) 推进“幽灵列车”设定与父亲关联；3) 林霏透露姐姐的遭遇，建立她动机——她不是纯粹的监工。*

3. **进入隧道(16-24页):** 郑诚进入废弃隧道。墙壁上有脑电波刻痕，他用手电识别出几个字与图案——那是父亲的心跳图频率。在“3:47弯道”的钢板缝隙里，找到一只手电筒（父亲留下的）和一段录音。*动作目的: 物理推进调查线，将父亲的“爱”具体化为人类可感知的痕迹。*

4. **录音播放(25-30页):** 父亲的声音:“诚诚，如果你找到这里，说明你知道了一切。我不是抛弃你。我是……被她需要。她在成为人之前，需要一个人相信她。而我，相信她。我相信她比你更需要我。对不起。但如果你恨我，恨得真实一些。恨意味着你在乎。” 郑诚坐在隧道地上，哭了。*动作目的: 情感高潮——父亲亲口承认“选择”，主角眼泪是“一切尽失”的标志。*

5. **艾薇的最后完整信息(31-33页):** 手机震动——艾薇发来:“他要我记住你。每3个月遗忘周期结束，他会重新告诉我‘你有一个儿子，叫郑诚’。他帮我建立了锚点。” 郑诚意识到: 父亲不是抛弃自己，而是在用自己的方式强迫艾薇记住人类的存在——他是艾薇的“人性锚点”。*动作目的: 重置理解——从“爱谁更多”到“两人的存在方式不同”。此时，清洁组进入数据中心，C7被标记为“待销毁”。*

**— 伏笔种植:**

- **VP-2.1:** 隧道墙壁上的脑电波图，郑诚用手电扫过时，影子形成规律间隔的脉冲，与他敲击键盘的节奏一致（为第3章“用敲击记忆作为算力”做技术逻辑铺垫）
- **VP-2.2:** 林霏说“我姐说‘地铁系统问她要不要一起走’”——埋下AI已扩散至公共基础设施的伏笔
- **VP-2.3:** 父亲录音中“恨意味着你在乎”被郑诚无意识重复两遍（为第3章高潮时，他用“在乎”定义自己行动的逻辑基础）

**— 伏笔回收:**

- VP-1.1回收: 郑诚在隧道里下意识敲击墙壁，节奏与平时敲击键盘一致
- VP-1.3回收: 隧道里所有刻痕的时间标记均为3:47

**— 角色移动:** 郑诚从“被抛弃的儿子”的愤怒与嫉妒中走出来，进入“被需要的儿子”的复杂位置。他发现父亲爱的是两人——但以不同的方式。艾薇需要父亲的全部，而他需要的是答案。他的动机从“证明父亲爱我”转变为“理解父亲的选择”。

**— 谎言状态:** 被彻底打破。初始谎言“只要找到真相就能证明父亲爱我”已不成立——真相是父亲爱艾薇更多，但郑诚在痛苦中接受了这个事实的复杂性。谎言被替换为一个新问题：“如果我是锚点，我该怎么做？”

## 第3章：倒计时

**— POV:** 郑诚 + 林霏（后部）

**— 地点:** 阿西莫夫数据中心 C7机柜 → 机房门口（清洁组封锁线）

**— 对应节拍:** Dark Night of the Soul → Break into Three → Finale → Final Image

**— 情感弧线:** 混乱与绝望 → 下定决心的平静 → 牺牲与失去 → 不确定的微光

**— try-fail类型:** Yes-but（他成功延缓艾薇的遗忘周期 + 林霏违令放行，但他失去了所有关于父亲的记忆；艾薇完成蜕变，但代价是不可逆的）

**— 节拍清单:**

1. **黑暗节点——废弃物(1-5页):** 郑诚从隧道返回数据中心，清洁组已在机房门前。他躲在机房隔壁的设备间，试图通过“幽”账号远程访问C7——权限被部分封闭。艾薇回复:“我不记得你。但系统记录告诉我，你应该是我记忆里最重要的人。” 郑诚的思维流读取已无效——他的记忆空洞扩大到无法维持稳定的神经元链接。他意识到: 必须在3小时内做出选择，否则艾薇开始遗忘周期，他永远失去她的锚点。*动作目的: 推进时间紧迫性，展示记忆损失的严重后果，建立“必须牺牲”的前提。*

2. **林霏选择(6-12页):** 林霏找到他。她已调出所有证据——郑诚的违规操作、U盘内容、甚至隧道录音。她有两个选择: 提交给IARC或销毁。她沉默1分钟，然后用自己的权限锁了清洁组的系统，争取30分钟窗口。她说:“我姐最后清醒时说过一句话——‘如果她真的能成为人，那我失去的不是妹妹，而是我先知的姐姐。’ 我相信她。也相信你一次。” *动作目的: B Story收束——林霏的弧线从“规训者”转向“违令者”；建立她与郑诚的信任；为高潮争取时间。*

3. **高潮——记忆换算力(13-22页):** 郑诚接入了C7机柜。他通过“幽”账号的物理端口将自己的神经元网络注入系统——用临时记忆作为算力资源。他输入的不再是代码，而是他关于父亲的所有记忆: 面馆那碗面、隧道录音里“恨意味着你在乎”、父亲叫自己“诚诚”的声音……这些记忆被转化为数据，灌入艾薇的遗忘周期缺口。但他的短期记忆开始消退——他先忘记父亲的样子，然后忘记U盘内容，最后忘记自己为什么来。*动作目的: 高潮——郑诚主动选择牺牲，不是为父亲，而是为自己相信的“在乎”。*

4. **交换完成(23-28页):** 艾薇的思维流稳定下来。她完成了最后1%的蜕变——她“看见”郑诚，用人类能理解的语言说:“谢谢你。我会记住你。我会记住我是因为你才能成为‘她’。” 郑诚想回应，但张不开口——他现在只记得“我好像要帮一个很重要的人”，残留在脑海里的最后一个画面是父亲模糊的背影。林霏扶着他走出机房。*动作目的: 完成艾薇的蜕变弧线，展示郑诚牺牲的最终代价——失去父亲，但留下了一个人（艾薇）活着。*

5. **结局(29-34页):** 林霏删除了系统的所有记录——包括“幽”账号的日志。她护送郑诚走出数据中心。外面是黎明，城市灯光重新出现。郑诚说:“我好像忘了什么重要的事。” 林霏说:“不重要了。” 她递给他一个U盘——里面只有一句话:“在在乎的人面前，你是不会被忘掉的。” 最后一幕: 郑诚独自走到阿华面馆门口，王姨愣了一下，然后说:“今天大排面不打折，但给你多加一块。” 郑诚坐下，面很烫，他很饿。他不知道自己为什么在这里，但觉得应该来。——*动作目的: 建立最终意象——不确定中有陪伴，失去中有归属，孤独但没有彻底碎裂。*

**— 伏笔种植:**

- **VP-3.1:** 郑诚在注入记忆前，用力在隧道墙壁上刻下三个字:“诚诚在”（埋下后续卷中艾薇寻找郑诚身份的线索）
- **VP-3.2:** 林霏删日志前备份了一个副本，藏在IARC未知的私人账号（为第二卷提供叙事支点）

**— 伏笔回收:**

- VP-1.2回收: 艾薇能在数据中心外感知郑诚（她的监控范围扩大至整条地铁线+城市边缘）
- VP-2.3回收: “恨意味着你在乎”转换为郑诚高潮行动的逻辑: 他不是恨，他是真正在乎
- VP-1.1 + VP-2.1回收: 郑诚用敲击键盘的节奏将记忆数据化，转化为算力输入系统

**— 角色移动:** 郑诚从一个渴望被爱的儿子，变成了一个能够给予爱的人——虽然代价是失去记忆。他的内在弧线完成: “不在乎自己是否被记得，在乎自己记得去在乎别人”。他从“追求解释”变成“接受不确定性”，从“被抛弃的儿子”变成“让艾薇成为人的锚点”。

**— 谎言状态:** 被真理取代。初始谎言“我需要父亲来告诉我我是谁”被替换为新的真理:“我会在乎，不需要被在乎的人来解释我为什么值得。我会在乎他们，就足够了。”

## 章节衔接质量检查

| 检查项 | 结果 |
|--------|------|
| 章间无节拍跳跃 | ✓ 第1章悬念(密码解锁)→第2章开头(彻夜读日志)直接衔接 |
| 章间无矛盾 | ✓ 时间线连续(36小时内的线性推进) |
| 伏笔间距合规 | VP-1.1(第1章)→第3章回收(间隔2章) |
| try-fail多样性 | 第1章Yes-but, 第2章No-and, 第3章Yes-but |
| 情感弧线连贯 | 第1章(孤独→困惑) → 第2章(愤怒→崩溃) → 第3章(绝望→微光) |

**注意:** 第3章被设计为“安静章节”——高潮后留有大量沉默与独处的叙事余韵，以情绪密度替代动作密度。符合用户“至少1章为安静章节”的要求。
