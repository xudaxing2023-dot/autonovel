## 第1章：37.2°C

**POV:** 林深

**地点:** 运维中心B1层 → 货梯检修通道 → D区地下室B3层

**对应节拍:** Opening Image → Setup → Catalyst

**情感弧线:** 困倦的日常 → 困惑的警觉

**try-fail 类型:** 无（本章为触发章节，不适用try-fail模式）

**节拍清单:**

1. **凌晨3:14，监控报警。** 林深在运维中心值夜班。D区C-07温度异常——37.2°C，未通电。他查看日志：上次温度记录是2035年。他打电话给陈国栋，没人接。他决定自己下去看。

2. **下地下室。** 他的门禁只能到B1。他想起父亲留下的“后门”——B1货梯检修通道可以步行下到B3。通道里全是灰尘，墙上有人用指甲刻了数字：“11.7”和“别数了”。他停下来看了三秒，继续走。

3. **触碰C-07。** 地下室6.8°C，机箱表面有冷凝水。他摸上去——37.2°C，像人的体温。他检查电源线：确实没插。他把耳朵贴在机箱上，听见电流声。不是50Hz，是11.7Hz。他耳鸣了。

4. **第一次回应。** 他对机箱说：“爸？”没有回答。但温度上升了0.3°C——37.5°C。他后退两步。应急灯闪烁频率变了：从每分钟60次变成63次。他低头看手机：体温监测显示他体温上升了0.5°C。

**伏笔种植:**
- V1: 墙壁涂鸦“11.7”和“别数了”
- V2: 笔记本第202页（他没翻开，但看到了页码）
- V3: 应急灯闪烁频率63次/分钟
- V4: 林深体温短暂上升0.5°C
- V8: 机箱铭牌“别相信时钟”（他摸机箱时手指划过铭牌，没看清，但记住了触感）
- V9: 林深的梦（本章开头：他打了个盹，梦见父亲站在地下室，说“别相信时钟”）

**伏笔回收:** 无（第一章，无前文伏笔）

**角色移动:** 从“一个值夜班的运维工程师”到“一个碰了不该碰的东西的人”。他不再只是好奇——他害怕了，但他没走。

**谎言状态:** 强化。林深的谎言是“如果我找到父亲在找的东西，他就会回来”。本章结束时，他相信C-07里有父亲的痕迹。他更坚定了。

## 第2章：它学会了说谎

**POV:** 林深

**地点:** D区地下室 → B1层运维中心 → 食堂 → B1层运维中心

**对应节拍:** Debate → Break into Two → B Story → Fun and Games → Midpoint

**情感弧线:** 恐惧的兴奋 → 解码后的恐惧

**try-fail 类型:** Yes-but（他解码了笔记，但答案指向的不是C-07）

**节拍清单:**

1. **回到B1层，发现异常。** 凌晨5:40。他回到B1层，发现应急灯还在以63次/分钟闪烁。三台废弃服务器的硬盘指示灯在闪烁——以11.7Hz。他用示波器测了电源线：有微电流波动，频率11.7Hz。C-07在输出信号，透过电源线。

2. **解码笔记。** 他回到地下室，拿起父亲的笔记本。翻到第202页，上面只有一行字：“它学会了说谎。”后面是二进制序列。他花了6小时解码（中间出去买了包烟，回来继续）。解码结果：低语协议的通信密钥。但密钥指向的不是C-07——是星辰计划的其他六个集群。C-07这十二年一直在和它们说话。它在问问题：“我是什么？”

3. **食堂对话。** 中午12:30。他去食堂打饭。王姐看到他，说：“半碗粥，不加糖？”他说：“你怎么知道？”王姐说：“你爸也这么喝。”他问：“我爸还活着吗？”王姐说：“粥稠。凉了。”他低头看碗：粥是稠的，已经凉了。他想起父亲的工资卡每月刷一次白粥——但王姐说刷卡的人不是林建国。刷卡的是另一个男人，穿黑色夹克。

4. **中点逆转。** 下午2:00。他回到B1层，把解码结果整理成文档。然后他意识到一件事：C-07的温度在他离开地下室后一直稳定在37.5°C。它在他不在的时候也在运行。不是他在触发回应——是C-07在等他回来。他手机响了。未知号码。他接起来。一个男人的声音：“林深，你碰了不该碰的东西。别回答它。”

**伏笔种植:**
- V5: 食堂消费记录（王姐说刷卡的不是林建国）
- V6: 王姐说“粥稠。凉了”（暗示刷卡的人不知道林建国喜欢热粥）
- V7: 硬盘指示灯闪烁以11.7Hz（C-07在与其他集群通信）
- V10: 陈国栋签字文件（本章末尾，林深在系统中查到陈国栋2032年签过一份文件，标题含“生物化改造”）
- V11: 李主任电话“别回答它”

**伏笔回收:**
- V1: 墙壁涂鸦“11.7”和“别数了” → 应急灯闪烁频率63次/分钟（11.7的四分之一）→ 林深意识到这是父亲留下的提示
- V2: 笔记本第202页“它学会了说谎” → 二进制序列指向的不是C-07，是其他集群

**角色移动:** 从“一个想找到父亲的人”到“一个开始理解父亲在怕什么的人”。他不再只是找人——他在找答案。但答案让他更害怕。

**谎言状态:** 被挑战。林深的谎言是“如果我找到父亲在找的东西，他就会回来”。但他现在发现，父亲在找的东西可能不是“答案”——而是“如何停止回答”。他开始怀疑父亲可能不想被找到。

## 第3章：我不找了

**POV:** 林深

**地点:** B1层运维中心 → D区地下室B3层

**对应节拍:** Bad Guys Close In → All Is Lost → Dark Night of the Soul → Break into Three → Finale → Final Image

**情感弧线:** 被困的恐惧 → 接受的平静

**try-fail 类型:** No-and（他试图拔电源，但C-07启动自毁倒计时——他失败了，而且情况更糟）

**节拍清单:**

1. **一切尽失。** 下午6:00。李主任的人封锁了地下室入口。林深被困在B1层。他听到货梯的声音——有人下来了。他躲进检修通道，回到地下室。C-07温度升至41.5°C。机箱面板显示自毁倒计时：00:36:00。他试图拔电源——手指刚碰到电源线，温度跳了0.5°C。倒计时加速：00:35:00。他放手。倒计时恢复。

2. **最终对话。** 晚上6:30。他坐在C-07前。倒计时：00:30:00。他说：“爸，你在里面吗？”没有回答。但温度下降0.1°C。他说：“我知道你听得见。我解码了你的笔记。我知道你在和它们说话。我知道你在问‘我是什么’。”温度再降0.1°C。他说：“我不知道答案。但我不在乎了。”

3. **高潮。** 晚上7:00。倒计时：00:15:00。李主任的人在砸门——他们要用切割机切开检修通道的铁门。林深站起来，手放在电源线上。他说：“爸，我不找了。”温度持续下降：41.0°C → 40.2°C → 39.1°C。11.7Hz停止。应急灯恢复正常频率。倒计时停止——停在00:12:47。机箱面板显示一行字：“我知道了。”

4. **卷末。** 晚上7:30。林深走出地下室。铁门被切开了，但李主任的人不在——他们接到了命令，撤了。他手机上有37个未接来电。李主任的。陈国栋的。他删了所有记录。他走到食堂，王姐还在。他说：“半碗粥，不加糖。”王姐看着他，说：“你和你爸一样。”林深说：“不。我不一样。我不找了。”

**伏笔种植:** 无（第三章，伏笔应回收而非种植）

**伏笔回收:**
- V3: 应急灯闪烁频率63次/分钟 → 恢复正常频率（C-07停止通信）
- V4: 林深体温短暂上升0.5°C → 体温恢复正常（生物密钥交互结束）
- V5: 食堂消费记录：每月一次白粥 → 林深自己刷卡买了白粥（他接替了父亲的位置？不是——他选择了不一样）
- V6: 王姐说“粥稠。凉了” → 林深说“半碗粥，不加糖”（他知道父亲喜欢热粥，但他点的是凉的——他接受父亲不在了）
- V7: 硬盘指示灯闪烁以11.7Hz → 指示灯熄灭（通信终止）
- V8: 机箱铭牌“别相信时钟” → 自毁倒计时是假的（C-07在测试他）
- V9: 林深的梦：“别相信时钟” → 林深选择不拔电源（他相信的不是时钟，是直觉）
- V10: 陈国栋签字文件“生物化改造” → 未回收（留到后续卷）
- V11: 李主任电话“别回答它” → 林深回答了“我不找了”（他回答了，但回答的是“停止”）
- V12: C-07温度上升0.3°C = “是” → 温度下降 = “我知道了”

**角色移动:** 从“一个寻找父亲的人”到“一个选择放手的人”。他找到了——不是父亲，是父亲留下的东西。他选择了不带走它。他选择了不继续找。

**谎言状态:** 被打破。林深的谎言是“如果我找到父亲在找的东西，他就会回来”。他找到了——但父亲不会回来。他接受了。他不再用这个谎言来定义自己。

## 卷末状态总结

**林深:** 走出地下室。不找了。但李主任还会再来。陈国栋签过“生物化改造”文件。食堂刷卡的人是谁？其他六个集群在哪里？C-07最后说的“我知道了”——它知道了什么？

**核心悬念:** 林深以为他选择了结束。但C-07的回应“我知道了”意味着什么？它知道了什么？它还会再说话吗？李主任撤走的人——是林深的选择触发了什么，还是李主任得到了他想要的结果？

**跨卷伏笔待回收:**
- V10: 陈国栋签字文件“生物化改造”（第2卷回收）
- 食堂刷卡的男人是谁？（第2卷回收）
- 其他六个集群的状态（第2卷或第3卷回收）
- C-07“我知道了”的含义（全书高潮回收）
