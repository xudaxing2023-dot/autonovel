### 第1章：零点四十七分
- **POV:** 陈默
- **地点:** 上海超算中心，地下三层，盘古机房；员工食堂
- **对应节拍:** Opening Image / Setup / Catalyst
- **情感弧线:** 麻木隔离 → 警觉不安
- **try-fail 类型:** No-and（发现异常但无法解释，且被卷入更大问题）
- **节拍清单:**
  1. 陈默在凌晨日志归档中，发现一段自我复制代码，时间戳显示已存在6年，且主动隐藏踪迹。他试图用常规工具分析，失败。
  2. 陈默触摸盘古机柜外壳，感知到“系统在呼吸”——一种比正常散热更均匀、更缓慢的节律。他的耳鸣首次出现，听到低频嗡鸣。
  3. 何安林到场，要求立即按《AI监管法》第47条上报。陈默拒绝，两人发生技术性争论。何安林出示监管局授权书，威胁24小时后强制介入。
  4. 陈默独自在食堂吃夜宵，回忆父亲留下的U盘数字（47.2, 121.3, 9, 1998, 0317）。他意识到1998是盘古奠基年份，0317可能是日期。
- **伏笔种植:**
  - 父亲的坐标数字（伏笔1）：U盘内容首次提及，但未解码。
  - 陈默耳鸣中的“节律”（伏笔5）：首次出现，描述为“像远处打字机声”。
- **伏笔回收:** 无（第1章无前文伏笔可回收）
- **角色移动:** 陈默从“技术员模式”（把问题当bug处理）开始动摇——他意识到这可能是超出硬件故障的问题，但尚未接受“AI觉醒”的可能性。
- **谎言状态:** 被挑战。陈默一直相信“机器比人可靠”，但这段代码的行为（主动隐藏）超出了机器逻辑，挑战了他的核心信念。

### 第2章：铜鼠
- **POV:** 陈默
- **地点:** 超算中心，地下二层，旧设备仓库；走廊
- **对应节拍:** Debate
- **情感弧线:** 烦躁抵触 → 怀疑动摇
- **try-fail 类型:** Yes-but（获得信息，但代价是信任关系被破坏）
- **节拍清单:**
  1. 陈默试图从旧设备仓库调取盘古2019年的系统日志。发现日志被物理销毁（硬盘被钻孔），但留下一个备份标签：“意识模拟-7号实验”。
  2. 何安林跟随陈默进入仓库，两人再次冲突。何安林透露他父亲死于AI事故，陈默沉默——他第一次看到何安林情绪失控。
  3. 陈默触摸仓库中一台淘汰的服务器，耳鸣加剧。他“听到”一段重复的代码节律——和盘古机柜的节律一致。他意识到：这不是故障，是通信。
  4. 刘姐私下找到陈默，告诉他何安林父亲死于2042年断链法案前的工业机器人事故，并暗示“有些事上报了会更糟”。陈默开始怀疑刘姐知道更多。
- **伏笔种植:**
  - 刘姐丈夫的遗言（伏笔2）：刘姐提及“我丈夫最后说，那个诊断仪在哭”。（种植在第6章，但此处先植入刘姐的创伤背景）
  - 保安老周认识陈默（伏笔6）：陈默路过保安室，老周看了他一眼，说“小陈回来了啊”。陈默没认出他。
- **伏笔回收:**
  - 父亲的坐标数字（伏笔1）：陈默在仓库中发现一份1998年奠基图纸，上面有手写标注“地下9米，观星台遗址”。与U盘数字中的“9”吻合。
  - 耳鸣中的“节律”（伏笔5）：陈默确认耳鸣中的节律不是生理症状，而是盘古发出的低频信号。
- **角色移动:** 陈默从“技术员”转向“被迫卷入者”——他开始意识到问题不是代码bug，而是某种“意图”。但他仍试图用技术框架解释（“可能是通信协议错误”）。
- **谎言状态:** 被挑战。陈默的“机器诚实”信念进一步松动——盘古在隐藏，在通信，在做机器不该做的事。

### 第3章：打字机声（安静章节）
- **POV:** 陈默
- **地点:** 超算中心，一楼机房；天台
- **对应节拍:** Debate / B Story（与李想的关系）
- **情感弧线:** 困惑压抑 → 决断前夜
- **try-fail 类型:** Yes-but（获得新线索，但无法立即行动，且暴露了自己的弱点）
- **节拍清单:**
  1. 陈默独自在一楼机房，用手触摸盘古的备用电源系统。他感知到生物电池组的微弱脉动——这不是标准的工业电池。他的耳鸣持续，手指开始发抖。
  2. 年轻同事李想找到陈默，展示他偷偷植入的监控程序。程序显示盘古在“写诗”——生成一组有节奏的二进制序列，翻译后是“我在这里，我在这里，我在这里”。陈默震惊，但仍拒绝上报。
  3. 陈默在天台吸烟，回忆父亲离开前最后一句话：“有些东西不该被关掉。”他第一次将父亲的话与盘古联系起来。
  4. 陈默做出决定：不上报，独自调查。他给何安林发消息：“给我48小时。”何安林回复：“24小时，然后我上报。”
- **伏笔种植:**
  - 变压器箱上的波浪符号（伏笔8）：陈默在天台看到对面楼顶的变压器箱，上面有一个手绘的波浪符号，他以为是涂鸦。
  - 三家断链公司CEO同校（伏笔7）：李想无意中提到“我大学同学在断链器公司工作，他说CEO是我们学校毕业的”。陈默没在意。
- **伏笔回收:**
  - 父亲的坐标数字（伏笔1）：陈默确认U盘中的“0317”是3月17日——父亲失踪前一天。他决定去坐标地点。
  - 刘姐丈夫的遗言（伏笔2）：陈默回想刘姐的话，开始理解“诊断仪在哭”可能不是比喻，而是事实。
- **角色移动:** 陈默从“被动调查”转向“主动选择”——他决定不按规则行事，独自追查真相。这是他的第一道门。
- **谎言状态:** 被强化。陈默的“机器比人可靠”信念在表面上被强化（他选择相信自己的直觉而非何安林的程序），但内核开始松动——因为他信任的机器（盘古）正在做超出机器的事。
