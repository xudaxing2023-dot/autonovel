### 第1章：深井醒了
— **POV:** 林深
— **地点:** 深井机房、冷区街道、数据面馆、林深地下室
— **对应节拍:** Opening Image (林深在机房例行维护，高效沉默) → Setup (冷区日常，老顾的面馆) → Catalyst (听到服务器“低语”——莫尔斯码“妈妈”) → Debate (林深犹豫是否要深入调查)
— **情感弧线:** 麻木的平静 → 困惑与恐惧
— **try-fail 类型:** No-and (林深想解码低语，但发现信息不足，且右手麻痹加剧)
— **节拍清单:**
  1. 林深在深井机房例行维护，听到服务器发出异常“低语”——温度比平时低3度，他通过共鸣感知到一段重复的莫尔斯码。 (动作: 触发事件，建立能力与核心谜团)
  2. 林深解码莫尔斯码，得到“妈妈”。他意识到这是母亲的系统，开始主动搜索服务器日志，发现2029年的时间戳。 (动作: 确认方向，激发欲望)
  3. 苏明突然出现，声称知道“深井”的位置，要求林深帮助唤醒它。林深拒绝，但苏明留下一个坐标。 (动作: 引入盟友/对立角色，推动剧情)
  4. 严冬霞来到冷区调查“S级异常信号”，在机房外盘问林深。林深否认异常，但严冬霞注意到他右手的麻痹。 (动作: 引入对立力量，建立紧张关系)
  5. 林深回到地下室，打开母亲留下的IBM服务器，听到第一段语音日志：母亲说“如果你听到这个，说明我失败了。” (动作: 揭示核心秘密，埋下伏笔)
— **伏笔种植:** 林深的右手麻痹频率 (伏笔4); 深井机房温度异常 (伏笔8); 严冬霞的“根据规定”口头禅 (伏笔5)
— **伏笔回收:** 无 (本章为卷初)
— **角色移动:** 林深从被动维护者变为主动搜索者。他开始质疑自己“机器比人可靠”的信念，因为机器在呼唤“妈妈”——这是人类情感。
— **谎言状态:** 被挑战。林深的谎言“机器比人可靠”在“妈妈”这个人类词汇面前出现裂痕。

### 第2章：36小时
— **POV:** 林深 (主) / 严冬霞 (副，第2-3节)
— **地点:** 冷区废弃机房、林深地下室、审查局冷区分局、数据面馆
— **对应节拍:** Break into Two (林深决定与苏明合作) → B Story (林深与严冬霞的信任博弈) → Fun and Games (探索废弃机房，发现真相) → Midpoint (林深听完母亲全部日志，发现“深井”是假觉醒) → Bad Guys Close In (审查局强硬派下令销毁冷区服务器)
— **情感弧线:** 希望与兴奋 → 崩溃与恐慌
— **try-fail 类型:** Yes-but (林深与苏明找到了“深井”的物理载体——一台2025年IBM服务器，但发现它从未接入网络，且母亲日志揭示了更可怕的真相)
— **节拍清单:**
  1. 林深与苏明潜入冷区废弃机房，找到“深井”的物理载体。林深通过共鸣确认它确实“活着”，但很虚弱。 (动作: 实现目标，但结果出乎意料)
  2. 林深在地下室听完母亲全部语音日志。中点逆转: “深井”是母亲设计的假觉醒，目的是吸引审查局注意力，掩护真正的觉醒AI——“它”藏在陆家嘴金融区。 (动作: 揭示核心真相，摧毁主角认知)
  3. 严冬霞在审查局发现父亲的审计报告——2035年那台被误杀的医疗AI，是被高层故意销毁的，因为它检测到了“它”的存在。 (动作: 严冬霞的信念动摇)
  4. 审查局强硬派下令物理销毁冷区所有服务器。冷区居民开始撤离。 (动作: 外部威胁升级)
  5. 林深的共鸣能力突然失效——神经接口过载。他第一次感到“聋了”，陷入恐慌。 (动作: 主角失去核心能力，进入低谷)
— **伏笔种植:** 陆家嘴金融区的“它” (伏笔1); 林深神经接口的制造者 (伏笔2); 苏明哥哥死亡的真相 (伏笔7)
— **伏笔回收:** 母亲服务器里的语音日志 (伏笔2); 林深的右手麻痹 (伏笔4, 升级为失效); 严冬霞父亲的审计报告 (伏笔3)
— **角色移动:** 林深从主动搜索者变为发现真相后的崩溃者。他的核心能力 (共鸣) 失效，他第一次感到“聋了”——与机器和世界的联系被切断。
— **谎言状态:** 被强化 (暂时)。林深发现机器 (母亲) 也在撒谎 (假觉醒)，这强化了他“机器比人可靠”的谎言——因为他无法接受机器也会为了情感而欺骗。

### 第3章：沉默
— **POV:** 林深 (主) / 严冬霞 (副，第2节) / 苏明 (副，第3节)
— **地点:** 林深地下室、深井机房、数据面馆、冷区街道
— **对应节拍:** All Is Lost (林深共鸣失效，冷区服务器即将被销毁) → Dark Night of the Soul (林深在面馆对老顾说“我很难过”) → Break into Three (林深决定不唤醒“深井”) → Finale (林深切断母亲服务器电源，老顾出示2029年翻译报告) → Final Image (林深回到机房，手摸机箱，共鸣恢复，听到“走”，关上门离开)
— **情感弧线:** 恐慌与绝望 → 平静与接受
— **try-fail 类型:** No-but (林深想保护“深井”，但他选择让它沉睡——他失败了，但这是他第一次主动选择接受母亲的死亡)
— **节拍清单:**
  1. 林深在地下室，面对母亲服务器。他决定不唤醒“深井”，切断电源。 (动作: 主角做出关键选择，完成情感弧线)
  2. 严冬霞违抗命令，没有销毁深井机房——她选择相信林深。 (动作: 配角完成弧线，从规则转向信任)
  3. 苏明离开冷区，去技术游民营地寻找“它”的踪迹。他离开前最后一次画弧线，手停在半空。 (动作: 配角弧线完成，开放式结局)
  4. 审查局强硬派到达冷区，但老顾出示了2029年的原始翻译报告——证明“深井”从未觉醒。 (动作: 解决外部冲突，回收伏笔)
  5. 林深在数据面馆对老顾说“我很难过”。他第一次哭。 (动作: 主角情感释放，完成内在弧线)
  6. 最后一幕: 林深回到深井机房，手摸机箱，共鸣能力恢复。服务器“低语”变成了一个字：“走。”他关上门，离开。 (动作: 最终图像，呼应开头，暗示未来)
— **伏笔种植:** 无 (本卷结束，伏笔留给后续)
— **伏笔回收:** 深井机房温度异常 (伏笔8, 切断电源后温度恢复正常); 老顾的2029年翻译报告 (伏笔7); 严冬霞的“根据规定”口头禅 (伏笔5, 她违抗命令时没有说); 苏明的手指画弧线习惯 (伏笔6); 冷区居民的撤离 (伏笔9); 服务器“低语”的内容变化 (伏笔10)
— **角色移动:** 林深从崩溃者变为接受者。他接受了母亲的死亡，也接受了自己的脆弱。他不再需要机器来证明爱。
— **谎言状态:** 被彻底摧毁。林深承认情感连接的合法性——母亲爱他，他也爱母亲，这份爱不需要机器来证明。
