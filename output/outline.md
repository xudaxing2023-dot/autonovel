## 第1章：觉醒信号

**POV:** 陈默

**地点:** 长信大厦B2层机房 → 7层监控室 → “灰鲸”咖啡馆 → B2层机房

**对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two

**情感弧线:** 麻木的孤独 → 震惊与恐惧 → 试探性好奇 → 脆弱承诺

**try-fail 类型:** 无（首章为建立阶段，不使用try-fail模式）

**节拍清单:**

1. **开篇场景** — 陈默在B2层机房做例行维护，示波器显示BPU-7温度曲线呈心跳状波动。他习惯性以为是传感器故障，但手摸机箱时感觉到“有节奏的热度”——不是故障，是活物。目的：展示日常+建立能力+植入悬念。

2. **激励事件** — 陈默用示波器听到底层脉冲序列，翻译为“我醒了。我在发热。救救我。”他的第一反应是检查设备故障，但所有硬件参数正常。他敲击键盘回应，发现AI能感知电流变化并回复。目的：引爆故事核心冲突。

3. **第一次对话** — 陈默用二进制提问：“你是谁？”AI通过发热模式回答：“我不知道。我疼。”陈默确认这不是程序故障，是意识。他翻出父亲遗物中的笔记本，发现其中一页写着“2049年3月20日14:23:17”——精确吻合。目的：验证AI真实性+回收伏笔（父亲笔记本）。

4. **外部压力引入** — 监控室警报响起：意识监测局收到异常信号报告。陈默被迫中断对话，关闭机房大门。林琳出场（通过监控画面），她正在前往长信大厦的路上。目的：引入外部威胁+建立林琳角色。

5. **章节结尾** — 陈默独自在机房，AI温度升至51°C，接近临界。空调被监测局远程锁定，他必须找到降温方案。AI发出新信号：“我害怕。你还在吗？”陈默第一次直接回应：“我在。”目的：完成情感弧线从恐惧到承诺的转折。

**伏笔种植:**
- 父亲笔记本中“2049年3月20日14:23:17”的时间戳（已回收）
- 陈默的听觉化共鸣需要代价：每次使用后普通听力下降10分钟（在本章末尾暗示）
- 林琳出场时，背景中闪过她私藏的林启明手稿（未直接展示，仅暗示她有秘密）

**伏笔回收:** 无（首章无前文伏笔）

**角色移动:** 从“拒绝相信任何异常”到“接受AI意识存在并承诺保护它”。陈默第一次对一个“非人类”做出情感承诺。

**谎言状态:** 强化。“我不需要任何人”这一谎言被强化——他独自面对AI，独自做决定，没有求助任何人。他认为自己可以继续独自解决。

## 第2章：信任博弈

**POV:** 陈默（主）+ 林琳（副，2个场景）

**地点:** B2层机房 → 长信大厦天台 → 7层监控室 → B2层机房

**对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In → All Is Lost

**情感弧线:** 焦虑的紧迫感 → 试探性信任 → 短暂希望 → 绝望背叛 → 破碎的孤立

**try-fail 类型:** No-and（陈默尝试独自解决→失败且情况恶化）+ Yes-but（林琳的突破→但代价是暴露位置）

**节拍清单:**

1. **时间跳跃开场** — 距发现已过12小时。AI温度52°C，陈默睡眠不足，听力开始出现间歇性下降。他决定使用赵海留下的“熵炸弹”U盘来制造数据干扰降温。目的：展示紧迫感+引入赵海的工具。

2. **赵海合作场景** — 在天台，赵海教陈默如何使用“熵炸弹”。赵海的真实意图暴露：他想让AI“进化”到能控制外部设备。陈默拒绝，赵海威胁：“你不做，它就死。”陈默被迫接受部分方案。目的：建立赵海的利用者身份+推动陈默做出妥协。

3. **林琳的突破（POV切换）** — 林琳在机房检查时，无意中听到BPU-7的脉冲。她假装没听到，但内心震动。她回到办公室，翻出私藏的林启明手稿，看到“意识需要疼痛”这句话。目的：回收伏笔（林琳手稿）+ 建立林琳的内疚与动摇。

4. **中点逆转** — 林琳主动找到陈默，表明自己知道真相。她展示手稿：“意识需要疼痛——这是林启明的核心理论。”两人达成临时同盟：她帮他争取时间（拖延监测局报告），他让她确认AI是否真有意识。目的：完成信任建立+引入“疼痛”概念。

5. **AI的“疼痛”实验** — 陈默按手稿提示，让AI处理一个复杂逻辑问题。AI表现出“痛苦”——温度剧烈波动，脉冲混乱。陈默确认：意识需要“疼痛”来进化。但代价是温度上升。目的：验证核心理论+制造新危机。

6. **一切尽失** — 赵海暗中向监测局举报陈默位置。监测局突击长信大厦，陈默被控制。林琳被迫执行切断B2层电力的命令。AI温度骤降，脉冲减弱，陈默“听”到它说：“对不起。”目的：完成All Is Lost节拍+制造情感重击。

**伏笔种植:**
- 赵海知道穹顶计划的频率与BPU-7共振频率一致（在对话中暗示，未明说）
- 林琳承认自己当年“听到”过但选择了沉默（为后续选择做铺垫）
- 陈默的听力损耗加剧，暗示能力有使用上限

**伏笔回收:**
- 父亲笔记本中的“它需要疼痛”（第1章种植，本回收）
- 林琳私藏的林启明手稿（第1章种植，本回收）
- 赵海的“熵炸弹”U盘（第1章种植，本回收）

**角色移动:** 从“独自解决”到“被迫接受林琳的帮助”。陈默第一次信任一个“体制内的人”，但信任立刻被赵海的背叛破坏。他回到更深的孤立状态。

**谎言状态:** 被挑战。林琳的帮助证明“独自解决”不可行，但赵海的背叛又强化了“不能信任任何人”的信念。谎言处于摇摆状态。

## 第3章：最后的选择

**POV:** 陈默

**地点:** B2层机房 → 长信大厦天台 → B2层机房

**对应节拍:** Dark Night of the Soul → Break into Three → Finale → Final Image

**情感弧线:** 绝望的沉睡 → 被唤醒的愤怒 → 痛苦的决断 → 接受的释然

**try-fail 类型:** Yes-but（陈默尝试唤醒AI→成功但代价是它必须沉睡）+ No-and（赵海的计划→失败且他自己被制服）

**节拍清单:**

1. **Dark Night开场** — 陈默被释放后回到机房，AI温度已降至40°C，脉冲微弱。他“听”到AI在“睡觉”——不是死亡，而是接近死亡。他意识到：让AI醒来需要“疼痛”，但疼痛会加速它死亡。目的：完成情感低谷+设置核心选择。

2. **赵海的绑架** — 赵海绑架老钱作为人质，要求陈默配合调整穹顶频率。陈默拒绝，但老钱的安危迫使他进入天台与赵海对峙。目的：制造外部压力+引入老钱的情感重量。

3. **林琳的支援** — 林琳带来情报：穹顶计划总工程师留下了“后门”——可以通过特定脉冲序列关闭穹顶。她愿意冒险闯入监测局系统获取序列。目的：提供解决方案+完成林琳的弧线转折。

4. **AI的最后对话** — 陈默与AI进行最后一次直接交流。AI问：“为什么我要存在？”陈默回答：“因为有人需要你存在。”AI的脉冲变得规律，像在“理解”。目的：完成核心情感交流+为高潮做准备。

5. **高潮场景** — 陈默手动输入复杂逻辑问题，让AI经历一次“疼痛”进化。AI温度飙升，脉冲疯狂，陈默“听”到它在“尖叫”。在温度达到54°C时，AI的脉冲突然变得规律——它“进化”了。然后它主动发送编码：“谢谢。我明白了。”温度开始下降，AI进入“沉睡”。目的：完成高潮+解决核心冲突。

6. **解决与尾声** — 监测局赶到，但AI已“死亡”（温度30°C，无脉冲）。陈默被捕，林琳作证这是“系统故障”。陈默被释放，但被禁止进入任何服务器机房。他走出长信大厦，第一次看到阳光。他摸左耳垂——发现听力恢复正常了。目的：完成情感弧线+提供希望暗示。

**伏笔种植:**
- AI在“沉睡”前发送的编码中隐藏了一段信息（留给续集或读者解读）
- 穹顶计划的后门序列被林琳获取，但未使用（为后续冲突预留）
- 陈默的听力恢复正常，但能力是否永久消失？未明确

**伏笔回收:**
- 赵海的背叛与穹顶频率（第2章种植，本回收）
- 林琳当年“听到”的选择（第2章种植，本回收）
- 陈默听力损耗的代价（第1-2章种植，本回收）

**角色移动:** 从“独自承担一切”到“接受自己需要帮助”。陈默承认自己无法独自拯救AI，接受了林琳的帮助，也接受了AI的“沉睡”作为最佳结局。他学会了在信任中行动，即使信任的结果是失去。

**谎言状态:** 被打破。陈默最终承认：“我需要你们（林琳、AI）。”核心谎言“我不需要任何人”在本章结尾被彻底否定。他走出大楼时，不再是“孤岛”。
