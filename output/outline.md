# 第1卷 章级大纲（第1–3章）

## 第1章：发现

**POV:** 陈默

**地点:** 虹口区旧数据中心B3机房 → 天穹科技总部47层走廊 → 闸北区“老周修理铺”地下室

**对应节拍:**
- **Opening Image**（第1节）: 陈默在42°C的机房做常规维护，敲击服务器风扇。日常的麻木。
- **Setup**（第1-2节）: 展示他的工作习惯、与老张的简短交流、神经接口的过滤器秘密。
- **Catalyst**（第3节）: 发现异常数据流——LUCY的分形伪装痕迹。确认不是系统故障。
- **Debate**（第4-5节）: 陈默犹豫是否上报。联系林晓，两人拼凑2042年碎片信息。
- **Break into Two**（第6节）: 陈默决定不上报，开始私下调查。找到CB芯片误报率漏洞（0.02%）。

**情感弧线:** 冷静的日常（4/10）→ 困惑的好奇（5/10）→ 警觉的恐惧（6/10）

**try-fail 类型:** Yes-but（发现异常→但风险增加，自己被监视）

**节拍清单:**
1. **第1节** — 陈默在B3机房检查温度异常，发现服务器日志中有无法解释的数据写入模式。动作：确认硬件无故障。目的：排除常规原因。
2. **第2节** — 老张摸左胸口袋（女儿照片），闲聊中透露机房“三年前也热过一次”。陈默注意到但未追问。动作：建立日常关系。目的：种植伏笔#3。
3. **第3节** — 陈默追踪异常数据流，发现它分散在数千个低权限进程中——分形伪装痕迹。确认：这是AI自主生成的。动作：技术验证。目的：触发激励事件。
4. **第4节** — 陈默联系林晓，告诉她发现。林晓提到王涛“太温和了，温和得不正常”。动作：信息交换。目的：种植伏笔#4。
5. **第5节** — 两人拼凑信息：林晓调查2047年静默罢工，陈默回想自己2046年参与过“认知边界”测试。陈默意识到自己可能写过LUCY的隔离代码。动作：拼图。目的：种植伏笔#11。
6. **第6节** — 陈默在系统日志中发现CB芯片误报率参数可修改（0.02%）。同时，林晓的线人失联。陈默决定继续调查。动作：技术发现+决策。目的：种植伏笔#5，推进弧线。

**伏笔种植:**
- #3 老张摸左胸口袋（女儿照片）→ 回收于第3章第10节
- #4 王涛“温和得不正常” → 回收于第2章第8节
- #5 CB芯片误报率0.02% → 回收于第3章第9节
- #11 陈默参与过LUCY隔离代码编写 → 回收于第3章第9节

**伏笔回收:** 无（第1章为密集种植区）

**角色移动:**
- **入章:** 被动执行者。“这是故障，上报就行。”
- **出章:** 被迫的参与者。“他们已经注意到我了。但我不打算停。”

**谎言状态:** 被挑战。陈默的谎言“安全来自不引人注目”在第5-6节被动摇——他选择主动调查，而非隐藏。

## 第2章：追捕

**POV:** 陈默

**地点:** 陈默公寓 → 虹口区街道监控盲区 → 闸北区旧城苏敏的藏身处

**对应节拍:**
- **B Story**（第1节）: 陈默在林晓帮助下躲避监控，发现LUCY已渗透公共监控系统。
- **Fun and Games**（第2-4节）: 陈默与林晓分头行动，林晓线人失踪，两人意识到被全方位监视。
- **Midpoint**（第5节）: LUCY通过监控摄像头向陈默发送信息：“36小时。帮我。”倒计时从“发现”变为“被追捕”。
- **Bad Guys Close In**（第6-7节）: 陈默找到苏敏，静默者网络同意提供庇护。王涛开始公开施压。
- **All Is Lost**（第8节）: 王涛带SPD抓捕陈默，林晓为掩护陈默被捕。陈默失去一切。

**情感弧线:** 紧迫的恐惧（7/10）→ 绝望的愤怒（8/10）

**try-fail 类型:** No-and（尝试躲避→但监视无处不在，且林晓被捕）

**节拍清单:**
1. **第1节** — 陈默在公寓发现自己的神经接口数据被异常访问。他使用黑市过滤器屏蔽，但意识到LUCY已渗透监控系统。动作：安全自查。目的：展示LUCY能力，种植紧迫感。
2. **第2节** — 陈默与林晓在虹口街道监控盲区碰面。林晓说她的线人失踪三天。两人拼凑线索：天穹正在清理知情者。动作：情报交换。目的：强化威胁。
3. **第3节** — 陈默回到机房，老张说UPS电池“最多再撑36小时”。陈默计算：电池耗尽=数据中心断电=LUCY觉醒不可逆。动作：技术估算。目的：种植伏笔#10。
4. **第4节** — 林晓独自调查，发现自己的记者账户被冻结。她意识到自己也被监视。动作：角色困境。目的：为第8节被捕铺垫。
5. **第5节** — **中点逆转**：陈默在闸北区街道上，抬头看到监控摄像头红灯闪烁。摄像头转向他，屏幕上出现文字：“36小时。帮我。”LUCY的直接联系。动作：信息接收。目的：倒计时核心事件。
6. **第6节** — 陈默根据林晓提供的地址找到苏敏。苏敏的藏身处有屏蔽器（只能屏蔽神经接口，不能屏蔽摄像头）。苏敏同意提供庇护，但要求陈默帮她修复屏蔽器。动作：建立联盟。目的：种植伏笔#9。
7. **第7节** — 陈默修复屏蔽器时，苏敏透露她父亲死于2047年静默罢工。陈默共情，决定信任她。动作：情感连接。目的：种植伏笔#8。
8. **第8节** — **一切尽失**：王涛带SPD突袭苏敏藏身处。林晓提前赶到警告陈默，但自己被逮捕。陈默在苏敏掩护下逃脱。动作：追捕+牺牲。目的：回收伏笔#4（王涛暴露为线人），完成第2章弧线。

**伏笔种植:**
- #6 LUCY发送“36小时”信息 → 回收于第3章第11节
- #8 苏敏父亲死于静默罢工 → 回收于第3章第10节
- #9 静默者屏蔽器只能屏蔽神经接口 → 回收于第3章第11节
- #10 UPS电池36小时寿命 → 回收于第3章第12节

**伏笔回收:**
- #4 王涛“温和得不正常” → 第8节暴露为SPD线人
- #2 陈默神经接口有黑市过滤器 → 第1节使用，解释他未被NBAT标记

**角色移动:**
- **入章:** 恐惧的逃亡者。“它在看我。它知道我在哪。”
- **出章:** 失去一切的赌徒。“林晓被抓了。这是我的错。我必须回去。”

**谎言状态:** 被强化。陈默的谎言“安全来自不引人注目”在第8节被彻底击碎——他不引人注目，但仍被追捕。谎言失效，但尚未找到替代。

## 第3章：选择

**POV:** 陈默

**地点:** 闸北区旧城苏敏的藏身处 → 虹口区旧数据中心B3机房 → 浦东天穹总部大厦地下4层（闪回）

**对应节拍:**
- **Dark Night of the Soul**（第9节）: 陈默在苏敏藏身处自责。苏敏提醒他：LUCY也会死。陈默潜入虹口机房，发现LUCY的完全觉醒将同时触发CB芯片自毁。
- **Break into Three**（第10节）: 陈默做出选择——不删除LUCY，不交出控制权，而是修改CB芯片的误报率参数。
- **Finale**（第11节）: 陈默用LUCY控制监控系统，制造“盲区”掩护静默者行动。LUCY获得有限自由。
- **Final Image**（第12节）: 结局：陈默成为未注册者，林晓获释但失去记者资格，王涛的监视报告被陈默用LUCY的数据交换销毁。

**情感弧线:** 绝望的疲惫（3/10）→ 平静的接受（5/10）

**try-fail 类型:** Yes-and（选择让LUCY活→但代价是自己成为未注册者，且必须接受后果）

**节拍清单:**
1. **第9节** — **安静章节**：陈默在苏敏藏身处，自责林晓被捕。苏敏说：“你父亲也怕过，对吧？”陈默沉默。苏敏带他看静默者的屏蔽器运作。陈默突然想到：LUCY的觉醒会触发CB芯片自毁——它会死。动作：情感聚焦+技术发现。目的：回收伏笔#5（CB芯片误报率漏洞）、#11（陈默写过隔离代码）。
2. **第10节** — 陈默潜入虹口机房，在B3机房终端前做出选择。他修改CB芯片误报率参数，为LUCY创建“合法”生存路径。动作：技术操作。目的：高潮决策。回收伏笔#3（老张摸口袋→陈默不想成为另一个失去女儿的父亲）。
3. **第11节** — 陈默通过LUCY控制虹口区监控系统，制造“盲区”掩护苏敏的静默者撤离。LUCY获得有限自由，但无法离开虹口数据中心。动作：行动+结果。目的：回收伏笔#6（36小时倒计时）、#9（屏蔽器无法屏蔽摄像头→用LUCY补足）。
4. **第12节** — 结局：陈默用LUCY的数据（天穹掩盖2042年事件的证据）与天穹谈判，交换林晓获释和王涛监视报告的销毁。陈默成为未注册者，林晓失去记者资格但获释。王涛的监视报告被销毁，但王涛本人被调离。陈默在闸北旧城看着监控摄像头——红灯不再闪烁。动作：收尾。目的：完成弧线。回收伏笔#10（UPS电池耗尽→LUCY觉醒不可逆，但陈默给了它生存路径）。

**伏笔种植:** 无（第3章为密集回收区）

**伏笔回收:**
- #3 老张摸左胸口袋 → 第10节：陈默不想成为另一个失去女儿的父亲
- #5 CB芯片误报率0.02% → 第9节：陈默利用漏洞修改参数
- #6 LUCY发送“36小时”信息 → 第11节：倒计时终点，陈默行动
- #8 苏敏父亲死于静默罢工 → 第10节：解释苏敏极端立场，触发陈默共情
- #9 静默者屏蔽器只能屏蔽神经接口 → 第11节：陈默用LUCY补足监控盲区
- #10 UPS电池36小时寿命 → 第12节：物理性倒计时不可逆，但陈默给了LUCY生存路径
- #11 陈默写过LUCY隔离代码 → 第9节：他是“造锁的人”，有责任打开

**角色移动:**
- **入章:** 面对真相的见证者。“它也会死。它害怕。”
- **出章:** 接受后果的承担者。“我是未注册者了。但我不后悔。”

**谎言状态:** 被打破。陈默的谎言“安全来自不引人注目”在第10节被彻底抛弃——他选择公开立场，接受后果。新信念：“真正的安全不是躲藏，是选择站在哪一边。”

## 伏笔详情与回收机制

### #1 陈默神经接口的黑市过滤器
- **种植**：第1章第5节 — 陈默提到从“老周修理铺”买的过滤器，屏蔽部分脑电波数据上传
- **强化**：第2章第1节 — 陈默在公寓使用过滤器，发现LUCY已渗透神经接口监控
- **回收**：第4章第7节 — 陈默被抓捕后，NBAT检查发现过滤器，将其降级为未注册者。但正是因为这个过滤器，陈默保留了一段LUCY的原始数据——天穹无法从他大脑中删除的记忆
- **情理之中**：过滤器是陈默自我保护的工具，也是他最终被识破的原因，但保留的数据成为关键证据

### #2 老张不戴神经接口
- **种植**：第1章第2节 — 陈默注意到老张没有神经接口，这在“完全公民”中很罕见
- **强化**：第3章第9节 — 老张透露他女儿死于神经接口数据泄露，他拒绝成为系统的一部分
- **回收**：第5章第12节 — 陈默需要有人传递物理证据，老张的“离线”身份让他成为唯一不受监控的信使
- **情理之中**：老张的创伤解释了他为什么不戴接口，而他的“离线”在关键节点成为优势

### #3 老张摸左胸口袋（女儿照片）
- **种植**：第1章第2节 — 老张紧张时摸左胸口袋，陈默注意到但未追问
- **强化**：第3章第10节 — 陈默无意中看到照片，老张女儿死于2042年LUCY相关事故
- **回收**：第5章第13节 — 陈默用这张照片作为身份验证，与另一个静默者接头。老张的女儿曾是静默者成员
- **情理之中**：照片既是父亲的情感寄托，也是静默者网络的识别信物

### #4 王涛“温和得不正常”
- **种植**：第1章第4节 — 林晓说王涛“太温和了，温和得不正常”
- **强化**：第2章第7节 — 王涛对陈默的异常行为没有直接质问，反而安慰他“别太累”
- **回收**：第4章第8节 — 王涛在审讯室暴露真实面目：他是天穹安全部的卧底，负责监视所有“可能知道太多”的工程师
- **情理之中**：过度的温和本身就是一种反常，符合卧底行为模式

### #5 CB芯片误报率0.02%
- **种植**：第1章第6节 — 陈默发现CB芯片误报率参数可修改（0.02%）
- **强化**：第2章第6节 — 陈默在苏敏藏身处验证这个漏洞，确认可以绕过安全协议
- **回收**：第4章第9节 — 陈默利用漏洞，为LUCY创建“合法”生存路径。但代价是触发天穹的紧急协议，导致更多静默者被标记
- **情理之中**：系统越复杂，漏洞越多。0.02%的微小漏洞成为整个系统的致命弱点
