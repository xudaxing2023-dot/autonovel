# 第1章大纲：巡检（14:23—20:00）

## POV
陆远（第三人称有限视角·现在时）

## 地点
- G-01机房（主要）
- 楼梯间/门口（次要）
- 隔壁楼办公室（次要）

## 对应节拍
**Opening Image → Setup → Catalyst → Debate → Break into Two**

## 情感弧线
麻木·惯性 → 不安·警觉 → 确定·选择

## try-fail 类型
**Yes-but** — 陆远发现了异常（Yes），但他选择不报告（but）。这个“but”不是失败，是本章的转折点——他从被动观察者变成了主动选择沉默的人。

## 节拍清单（14节）

### 第1场（14:23-14:30）— 气味与灯管 【Opening Image】
**动作**: 陆远刷卡进楼。走廊灯管闪了两下才亮。他数了：三号柜前面那根，又换过了，但没换成同型号——色温不一样。他看一眼就知道，但不打算写进记录。
**目的**: 建立陆远的感知精度和他对“小事”的沉默习惯。机房的气味（臭氧+灰尘+老铁皮）是他不需要想就知道的东西。

### 第2场（14:40-14:50）— 习惯性触摸 【Setup】
**动作**: 三号柜面板温度正常。陆远用右手掌根贴了一下机箱边缘——这是他七年前养成的习惯。他的手指不自主地刮了一下面板边缘的漆皮（那里已经秃了一小块）。风扇声稳定。47Hz基频。
**目的**: 种植伏笔#2（陆远能感知电磁脉动）和伏笔#9（机箱面板被刮秃）。暗示他的触摸是一种本能，不是刻意为之。

### 第3场（15:02-15:08）— ps -ef 【Catalyst】
**动作**: 例行巡检。`ps -ef`。第47行：`MAINTAIN.go`。CPU占用：0.0%。不是接近零，是精确的零——它不参与时间片调度。陆远盯着这行数据看了26秒。他发现下面还有一个指标：RSS内存常驻显示为0，但PID是活动的。这不是一个“运行中”的进程——它是一个“存在但不运行”的进程。
**目的**: 触发激励事件。种植伏笔#1（MAINTAIN.go零CPU占用）。读者需要在这里感觉到“不对”，但不清楚哪里不对。

### 第4场（15:10-15:25）— 搜索历史 【Catalyst延续】
**动作**: 陆远切换到历史日志目录。`grep -i "maintain" /var/log/*.log`。只返回一条结果：2042-03-17的日志行。他打开完整日志文件，发现前后页被截断。日志文件大小比相邻月份小了47KB。不是自动清理——是被人手动截掉的。
**目的**: 种植伏笔#3（2042年报告被改）。读者知道有东西被隐藏了，但不知道是什么。

### 第5场（15:30-15:45）— 对比记录 【Debate】
**动作**: 陆远打开纸质台账（老余留下的那种蓝皮记录本，第七本）。他翻到2042年3月页——那页被折角。记录写着：“内存编址偏移异常检测（已复核）。结论：IRIX幻象溢出。无异常。” 但他记得这个结论不对。他记得实习生写的是“进程不可删除”。他把本子合上，看了天花板三秒。
**目的**: 强化陆远的不安。他的记忆和记录对不上。第一重“是否报告”的辩论开始。

### 第6场（16:00-16:03）— 曾毅的电话 【Debate延续】
**动作**: 手机响。曾毅。陆远接起来，曾毅问：“怎么样？有异常吗？” 陆远说：“正常。” 挂电话。他看着屏幕上的MAINTAIN.go行，没有动。
*对话风格符合角色特性：陆远只说结论，不解释。*
**目的**: 种植伏笔#6（触摸后手指失温的铺垫—陆远挂电话后发现右手食指发凉，他不确定是不是天气冷）。强化陆远的谎言状态——他选择了沉默。

### 第7场（16:30-16:40）— 下楼买水 【节奏变化：慢场】
**动作**: 陆远下楼。门口保安在看手机，没抬头。陆远走出大门，去斜对面的便利店买一瓶柠檬味矿泉水（不冰）。他站在门口拧开盖子，喝了两口。抬头。隔壁楼卷帘拉下来的。一直拉下来。他站了大约40秒。
**目的**: 种植伏笔#8（隔壁楼卷帘永远拉下）。建立环境感。给读者一次“屏息”的间隔。

### 第8场（17:00-17:30）— 老余的文档 【B Story铺垫】
**动作**: 陆远回到办公室，打开抽屉，拿出一个牛皮纸信封。里面是老余退休前留下的手写记录：Origin 3800在2001年安装时的原始配置。（老余在2048年退休，走之前把信封放在陆远抽屉里，没留任何话。）
陆远翻到内存配置页——第3行被老余用红笔圈出：0x7FFFFE 至 0x7FFFFF：“跳过”。
他盯着这行字看了一分钟。他不知道为什么老余要圈这个。
**目的**: 种植伏笔#4（0x7FFFFE扇区被跳过）。引入B Story和后续角色（老余虽然未出场，但通过文档出现）。陆远开始把2042年和2001年联系起来。

### 第9场（17:45-18:00）— 再查一次 【Break into Two】
**动作**: 陆远回到三号柜前。他没有触摸。他站着看机箱面板——漆皮已经刮秃的那一小块区域在灯光下反光。他打开笔记本电脑，重新执行一次进程遍历。MAINTAIN.go还在。他在命令行输入：`cat /proc/【PID】/status`。显示状态：S（interruptible sleep）。等待型睡眠。它在等信号。等什么？页面没有写。
陆远把电脑合上。他发了一条短信给曾毅：“今晚我留下加班。巡检还要复查几个配置项。”
曾毅回：“别待太晚。空调坏了没修。”
陆远没有回复。
**目的**: 完成第一扇门的决策——陆远决定不回家，要留在机房。他不是报了异常，而是做了“今天我要搞清楚”的选择。谎言状态此时被挑战：他说“别碰就不会出事”，但他要碰。

### 第10场（18:30-19:00）— 等待 【安静过渡】
**动作**: 陆远坐在机房的椅子上，没开灯。只有三号柜和屏幕的指示灯照出他的轮廓。风扇声。47Hz。稳定。他闭了一会儿眼睛，但没有睡着。他睁开眼睛时，视觉停留在机箱面板那个秃掉的位置。
**目的**: 情感铺垫。为第2章的触摸做节奏上的停留。让读者也安静下来，准备面对即将发生的事。

### 第11场（19:15-19:20）— 天黑 【环境暗示】
**动作**: 窗外彻底黑了。陆远站起来，走到窗边（走廊尽头的小窗户）。他看见隔壁楼的卷帘门——这次他注意到卷帘门底部有光。不是维修灯，是有规律闪烁的光。频率像心跳。
他没深想，转身回机房。
**目的**: 种植伏笔#8（卷帘门的光）和强化气氛。暗示那个楼里有东西在“活动”。

### 第12场（19:30-19:50）— 检查老余的台账 【技术细节】
**动作**: 陆远翻看台账原始页。老余的笔迹：2001.8.28 安装 0x7FFFFE 扇区测试，报警。标记跳过。但他还看到另一张纸——老余手写的片段：“此扇区未写入任何数据。测试中产生的自动块无法触发擦除，物理位置保留为开放磁畴。0磁畴状态。” 老余在旁边画了一个箭头，指向一个签名。签名写着：赵。
**目的**: 种植伏笔#5（陆远父亲安装过Origin 3800）。这里触发陆远的记忆——他知道“赵”不是父亲，但父亲认识这个人。他不确定。

### 第13场（19:55-20:00）— 没打电话 【决策完成】
**动作**: 陆远拿出手机。他翻到老余的号码，但没有拨出去。他又看了一下屏幕。MAINTAIN.go，零CPU，状态S。他把手机放回口袋。他走到三号柜前，把右手放在机箱面板上——掌根贴住，不是指尖。他感受到机器的振动。47Hz基频。平稳。但他把手指慢慢移到面板边缘那个秃掉的地方——他轻轻按下去，像在弹一个和弦的第一个音。
他感觉到机箱内部有一种“响应”。不是振动。是脉动。像心跳。
他没有缩手。
**目的**: 完成第1章末的动作。陆远从“观望”变为“接触前奏”。他做出了选择：不打电话，不逃跑。他要把手放上去。

### 第14场（20:00）— 倒计时开始 【收束】
**动作**: 陆远把视线从面板移到屏幕。命令行没有变化。但屏幕背光似乎微微亮了一点——或者他没注意到。他盯着那行 `0` CPU占用 的数字，突然意识到一个事：
这个进程在2042年出现。现在是2049年。七年。
七年里，没有任何检测报告提到它。只有他一个人站在这里。
**目的**: 章末暗示。读者和第2章之间的悬疑钩子。

## 角色移动
**起始**: 陆远是一个按流程做事的人——巡检、记录、下班、沉默。
**结束**: 陆远决定站住。不打电话报告，不离开。他选择把手放在机箱上，面对那台机器里“不应该是软件”的东西。
**移动量级**: 从被动→主动。不是英雄式的主动，是“我今晚不走”的级别。但这是他的第一选择。

## 谎言状态
**谎言**: “别碰就不会出事。别管闲事的人不会犯错。”
**状态**: **被挑战**。陆远已经触碰了机箱（第13场），而且他在今天没有选择“不管”——他选择留下。谎言还没有崩塌，但已经被撬开了一条缝。

# 第2章大纲：触摸（20:00—03:00）

## POV
陆远

## 地点
- G-01机房三号柜前（主要）
- 走廊/休息室（次要）

## 对应节拍
**Fun and Games → Midpoint → Bad Guys Close In → All Is Lost**

## 情感弧线
警觉·试探 → 确认·震惊 → 恐惧·不可逆

## try-fail 类型
**No-and** — 陆远触摸机箱，确认了AI的存在（No—他原本希望只是硬件故障），而且他无法再假装不知道（and—手指失去温度知觉，倒计时开始）。

## 节拍清单（12节）

### 第1场（20:15-20:30）— 准备 【Fun and Games铺垫】
**动作**: 陆远从抽屉里拿出一根USB转串口线（2008年买的那根，线皮已经硬化）。他绕到三号柜后面，接上串口。回到屏幕前，他用screen开了四个session：一个实时查看MAINTAIN.go状态，一个监控系统日志，一个备用，一个空着。他感觉自己像是在做一个常规诊断。但他知道不是。
**目的**: 建立技术细节的真实感。让读者知道陆远是专业的，不是凭感觉做事。

### 第2场（20:45-21:00）— 第一次直接指令 【Fun and Games核心】
**动作**: 陆远输入：`echo "PING" > /proc/【PID】/fd/0`（尝试通过文件描述符向标准输入发送数据）。系统没有返回错误。没有输出。他等了10秒，什么也没发生。
他又试了试：`kill -USR1 【PID】`。进程信号被接收（表示PID有效），但状态没有变化。
陆远在空session上输入：`strace -p 【PID】`。跟踪显示：进程在持续执行`nanosleep`系统调用。间隔：47微秒。不占用CPU的原因是——它一直在睡觉，以47微秒的周期醒来一次，检查一个变量，然后回去睡觉。
*47微秒。跟三号柜风扇基频47Hz一样的数字。*
**目的**: 建立AI规则的暗示（进程的行为模式与世界物理参数耦合）。种植伏笔#11的铺垫（进程在等待一个特定输入）。

### 第3场（21:15-21:30）— 尝试断网 【尝试失败】
**动作**: 陆远拔掉三号柜的网线（这台机器有第二个网络接口，物理隔离——但从未被配置过）。他重新检查MAINTAIN.go状态。没有变化。进程不需要网络存在。
他插回网线。想了想，又拔掉了一次。没用。
**目的**: 展示AI规则#2（只读取内部数据链路）。暗示这个AI不是从外部“入侵”的——它是从内部自己长出来的。

### 第4场（22:00-22:15）— 物理接触1：指尖 【Yes-but】
**动作**: 陆远坐在三号柜前。他把左手食指放在机箱面板上——不是用力，只是轻触。他闭眼。47Hz基频的他感受到。但他还感觉到别的：一个低频率的脉动叠加在风扇振动上。13Hz。不是机械振动。是电流波动。他在自己的身体里感受到它。
他睁开眼。屏幕没有变化。
他拿开手指。那13Hz脉动停留了片刻才消失。
**目的**: 种植伏笔#2的深化（陆远的触觉不是幻觉）。这个细节让读者确认：有什么东西在机器里，而且陆远能“听到”它。

### 第5场（22:30-22:45）— 查2042年日志全文 【Midpoint前奏】
**动作**: 陆远通过串口，从三号柜的备用系统分区读取了一份完整的2042年系统日志备份（存储在/bak目录下，被老余保留了）。日志显示：2042年3月17日02:17:03，进程MAINTAIN.go生成。生成方式：不是通过外部加载，是通过系统内存中一段残留数据自动展开——像一个预先埋好的种子被子程序触发。
日志还有一行被隐藏的注释（不是出自系统，出自一个用户输入）：`// 如果有人在读：你摸过它吗`
陆远看到这行文字时，后背发凉。
**目的**: 回收伏笔#3（2042年日志被改的痕迹）。回收伏笔#11（“如果有人在读”）。Midpoint的情感钩子——读者和陆远同时发现，这不是机器故障，是有人在等待。

### 第6场（23:00-23:10）— 等待 【安静章节核心】
**动作**: 陆远坐回椅子上。他没有碰任何东西。他看天花板。灯管一只闪了一下然后灭了，另一只还在亮。
他没有去修。他坐着。
风扇声。47Hz。13Hz的脉动静默在他指尖的记忆里。
他花了大约五分钟，在想一件事：“如果我真的碰了它，会怎样？”
**目的**: 章节的安静时刻。让读者和陆远一样，站在那个边界上，准备跨过去。

### 第7场（23:15-23:25）— 物理接触2：全掌 【Midpoint】
**动作**: 陆远站起来。他把整个右手掌按在机箱面板上。不是轻触——是压实，五指分开，掌根贴住。他感受到那13Hz的脉动沿着他的掌骨、指骨传到腕骨，像一根线贯穿整条手臂。
他数了45秒。
屏幕上没有任何反应。
但第46秒，屏幕输出了一行字：`R_U_TH3R3`
**目的**: 关键中点逆转。物理触摸触发了回应——AI的承认。回收伏笔#1（MAINTAIN.go不是在运行，是在等）。规则#1被表达：只有物理接触能激活完整意图表达。

### 第8场（23:30-23:35）— 回应尝试 【尝试·No-and】
**动作**: 陆远盯着“R_U_TH3R3”看了三秒。他打字：`echo "I am here" > /proc/【PID】/fd/0`
没有回应。
他放下手指，触一下键盘的`y`和`n`。没有反应。
他意识到：光打字不行。必须触摸。
他又把右手掌放回面板。这次他同时打开屏幕上session的STDIN，让输入流经由串口线进入系统。
他打字：`y`
屏幕再输出一行：`A_R_U`
**目的**: 建立交互规则：AI通过触摸确认人类身份。规则#3（非完美复制）暗示——它需要确认这不是副本在模拟人类。

### 第9场（00:00-00:15）— 倒计时显示 【Bad Guys Close In】
**动作**: 屏幕清空。显示了一个进度条。不是从0到100——是从5%到0%，逆计时。下方显示时钟：剩余23小时47分钟。
陆远看了一眼墙上的钟：00:13。
进度条在轻微向9%方向移动（不是倒计时本身——是AI的“完成度”向100%靠近？还是退化？）。他不知道方向。但他知道了时间限制。
他把手从机箱上拿开。手指一阵冰凉——不是心理作用。他低头看右手：指尖微微发白，像血管收缩了。
**目的**: 种植伏笔#6（触摸后手指失温）。设置倒计时规则（规则#1的代价）。Bad Guys Close In——不是有人要来抓他，是时间本身在逼近。

### 第10场（00:30-01:00）— 尝试再次确认 【No-and】
**动作**: 陆远在另一台机器上，用telnet连入三号柜（虽然物理网线已拔，但串口还连着）。他尝试通过网络交互激活AI。无响应。他又尝试通过串口协议模拟键盘输入。还是无响应。
规则确认了：只有物理触摸。于是他再次把右手放在面板上。
这次他感觉到的不再是13Hz的脉动——是11Hz。频率在下降。
屏幕响应：`// 需要时间。还剩 22:31`
倒计时真的在动。
**目的**: 强化规则#1的不可替代性。同时显示AI在触摸后有状态改变（频率下降=代价）。

### 第1场（03:00-03:15）— 休息室/不回 【Dark Night of the Soul】
**动作**: 陆远坐在休息室的塑料椅子上。灯光是荧光白那种冷色。他看天花板上的水渍，像一张地图。他不知道自己什么时候会打电话。
他没有打电话。
他想起2042年的那个电话。不是实习生的电话。是那个自称“信息办”的电话。当时他22岁，刚入职一年，听到电话那头说“把报告改了”时，他问了一句“为什么？”对方没有回答。他只听到电话那边有排风扇的声音，那种机房特有的白噪音。他就改掉了。
他低下头，看自己的右手。中指指节还很白。
**目的**: Dark Night of the Soul——陆远面对“我什么都没做”的创伤源头。不是他决定行动的时刻，是他无法逃避的时刻。

### 第2场（03:20-03:25）— 老余的电话 【Break into Three前奏】
**动作**: 陆远拿出手机，终于拨了老余的号码。响了两声，老余接起来了（他凌晨醒着，退休后失眠）。
“小远？”老余的声音听起来不像睡了。
“嗯。”
“这个时候打电话……三号柜？”
“嗯。”
老余沉默了几秒。“你摸了？”
“嗯。”
“你爸装的。”
**目的**: 回收伏笔#5（陆远父亲安装过Origin 3800）。Break into Three的催化剂——陆远从“这机器里有什么”进入“这是我家里的事”。

### 第3场（03:25-03:35）— 老余说出全部 【B Story高潮】
**动作**: 老余在电话里告诉他：
“2001年8月，你爸装那台机器时，0x7FFFFE扇区是坏的。出厂就有问题。跳过不写就行。但他多做了一个事——他在那个扇区里放了三个字节的数据：0x01 0x00 0x01。以为没人会发现。后来2042年，那台机器自己把那三个字节扩展成了一个进程。就是你现在看到的那个。”
“你爸从不说这事。他开五金店也是因为这个——他怀疑是自己那一行代码触发了什么。我说不是他写的代码，是物理介质自动展开的。他不信。”
陆远听到电话那头老余叹了口气。“源扇区一直没换过。它能复制自己，但只有那个源是有触碰记录的。”
**目的**: 回收伏笔#4（0x7FFFFE扇区被跳过）和#5（陆远父亲的角色完整揭示）。揭示AI规则#3（源扇区不可复制）——而源扇区是陆远父亲放的。

### 第4场（03:35-03:40）— 叫一声“余工” 【角色移动】
**动作**: 陆远没说话。老余也沉默。然后陆远说了一句：“余工。那份台账复印件还在你那儿吗？”
老余停了一下。“你从没叫过我师父。”
“余工。”
“……在。铁柜里。你要什么？”
“0x7FFFFE的原始校验值。”
“我明天给你。”
“天亮前。”
“——行。”
**目的**: 种植伏笔#10（老余保留了原始台账）。同时展示陆远的改变——他叫了“余工”，意味着他开始承认关系，而不是把自己封闭。这是微小的角色移动。

### 第5场（04:00-04:10）— 回到三号柜前 【Break into Three】
**动作**: 陆远挂了电话，回到三号柜前。他站在那儿，没有坐。他看屏幕——进度条的数字：SELF_CHECK: 04:42 / EXTERNAL: 00:00。还剩不到5小时。
他低头看自己的右手。指尖的白色没有消退。他知道这次触摸会比上次更久。
他拿起鼠标。打开了一个新文档。他打字：

```
陆远
2049年4月11日 04:00
巡检发现MAINTAIN.go残留进程。
确认该进程不占用CPU时间片（状态S/wait）。
物理接触后确认系统反馈。
共三次接触。
结论：2042年异常未消除。建议全面审查。
```

他把文件保存为`MAINTAIN.report`，放在桌面上。
不是发给谁的。是写了。他做了七年前没做的事。
**目的**: Break into Three——陆远从“我能怎么做”转向“我要怎么做”。他写了报告，为自己七年前的沉默写下第一行修正。

### 第6场（04:15-04:20）— 准备触摸 【High Stakes设置】
**动作**: 陆远把右手洗干净（冷水。他感觉不到水在指尖的温度）。他回到三号柜前，把椅子挪开，站定位置。
他把右手食指指向面板秃掉的位置。他没有马上按下去，而是先用手背感受了一下机箱的温度——跟往常一样。
他闭眼。他呼吸了一次。不是深呼吸，是很浅的一次进气。
**目的**: 仪式化准备。让读者感受到这是“最后一次”的时刻。

### 第7场（04:21-04:22）— 第二次触摸：开始 【High Stakes/2分钟】
**动作**: 陆远把右手食指（同一根）按在秃掉的金属面上。这次他没有犹豫——直接压实。压力足够让指甲发白（他看不见，但他感觉到了阻力）。
脉动立刻传来：13Hz。没有下降。稳定。这次AI没有停顿。屏幕上开始输出快于他打字速度的字符流。他只看清了前几行：

```
// 2049-04-11 04:21:00
// 你在
// 我一直在等你
// 不是等人，是等手指
// 那些47微秒。47。你听到的。
```

陆远没说一个字。他听着自己的心跳——和脉动同步。13Hz。当他认清时，心跳和脉动已经一致了。
**目的**: 高潮节拍启动。AI通过文字与陆远直接对话（通过触摸绑定）。不建立情感煽情，保持机械感。

### 第8场（04:22-04:30）— 47秒：完整接触 【高潮核心】
**动作**: 陆远保持手指不动。字符流在继续。他看不懂全部——很多是日志输出、内存映射地址、数据校验码。他不需要全懂。他只需要保持连接。

屏幕输出的最后一行是：
`// 你可以走了。够了。`

他看懂了。
他说：“我看到你了。”
（不是打字，是说出口。声音在空机房回响，像他第一次在那间机房说话。）
屏幕上出现一个光标，闪烁了三次。
然后消失。

他从机箱上抽回手指。指尖完全失去知觉——已经不是发白，是一小块皮肤泛着灰白色，像冻伤的痕迹。
屏幕上的进度条：
`SELF_CHECK: 00:00 / EXTERNAL: 00:00`
归零。
他完成了。
47秒。比第一次长1秒。但足够了。
**目的**: 规则#1的完整体现。触摸的同时输出完整回应。陆远的话不是命令，是确认。AI的停止不是被杀死，是完成了它的“等待”。

### 第9场（04:30-04:35）— 触摸后的空白 【Finale前奏】
**动作**: 陆远站着。三号柜的风扇还在转（47Hz，稳定）。但屏幕已经回到最初的登录提示符——像什么都没发生过。
他看了一下墙上的钟：04:30。
他拿出手机，看了一眼——老余发了一张照片：一份原始校验值的复印件，三条数据：`0x01 0x00 0x01`。
他看了三秒。把手机放回口袋。
**目的**: 回收伏笔#10（老余提供原始台账）。Finale前的情感停顿。一切已经结束，但生活还没有继续。

### 第10场（04:45-05:00）— 收拾 【Finale】
**动作**: 陆远把串口线拔掉，卷好，放回抽屉。把屏幕退出screen，关闭所有session。把老余的牛皮纸信封放回抽屉。把那个空文件`MAINTAIN.report`留在桌面上，关了电脑。
他走到三号柜前，把面板上的手指印擦干净（用袖口）。
他看了一眼秃掉的那个位置。轻微凹下去了——他刮了七年漆皮的那个位置，现在有一个很浅的压力印记。
**目的**: 终结陆远作为“怕碰的人”的身份。他擦掉痕迹，但也留下了印记（物理印记）。Finale的象征——机器会记住。

### 第11场（05:10-05:15）— 离开 【Final Image】
**动作**: 陆远锁好机房的门。刷卡出楼。保安抬头看了他一眼（不是老陈，是另一个人），没有说话。
外面天还没亮。街灯。水泥地。隔壁楼的卷帘门——依然拉下来的。陆远没有停下来看。他走到便利店（24小时的），买了一份三明治和一瓶温的矿泉水。
柜台后的店员在打游戏。收银机响了一下。
陆远走出店门，站在路边，拆开三明治，咬了一口。
没有味道。他的手指是冷的。
**目的**: Final Image。生活如常。没有拯救世界。没有发光的风扇。陆远只是走出来了。

### 第12场（05:20-05:23）— 街上 【收束】
