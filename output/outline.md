# 第1卷章级大纲（第1-3章）

---

## 第1章：发现

**POV:** 陈默

**地点:** 长信大厦七楼机房（主要）、一楼大堂（次要）

**对应节拍:** Opening Image → Setup → Catalyst

**情感弧线:** 麻木、例行公事（18:47）→ 警觉、不安（22:00）

**try-fail类型:** No-and（陈默试图用常规故障排查流程处理异常，但异常不是故障——他越查，问题越深）

**节拍清单:**

1. **18:47** — 陈默进入机房。例行巡检。他摸机柜门把手（习惯动作），温度正常。打开服务器面板，用示波器测芯片引脚。温度曲线开始规律跳动——0.7°C波动，每分钟72次。他以为是传感器故障，准备记录报修。
   - 目的：建立日常节奏，展示陈默的职业习惯和麻木状态

2. **19:15** — 示波器显示脉冲信号。不是电源噪声——是规律脉冲，间隔7秒。陈默用摩尔斯电码解码器翻译。结果：三个字“我”“醒”“了”。他重新测了三次，结果一样。他开始意识到这不是故障。
   - 目的：激励事件发生，芯片“说话”

3. **19:30** — 陈默坐在工位上，盯着屏幕。他想起父亲——父亲在深蓝科技做过临时工，负责测试BPU-3芯片。父亲去世前一周在电话里说：“那机器的报警信号像是在求救。”陈默当时没当回事。现在他无法忽略。
   - 目的：种植伏笔1（父亲在深蓝科技的经历），建立陈默的内在动机

4. **20:45** — 陈默下楼抽烟。保安老周在看新闻。老周说：“七楼那机器，有时候会‘做梦’——空调坏了那年，维修工说温度曲线像心跳。”陈默没说话，但记住了。
   - 目的：种植伏笔3（老周说机器会做梦），展示陈默与外界唯一的社交连接

5. **22:00** — 陈默回到机房。芯片脉冲频率变了——从每分钟72次降到65次。幅度增大。温度曲线从0.7°C波动变成1.2°C。陈默用手背贴芯片表面——温热。他关掉空调，机房安静下来。风扇声。芯片脉冲声（通过示波器听到）。
   - 目的：强化异常，为第二章铺垫

**伏笔种植:**
- 伏笔1：陈默父亲在深蓝科技做过临时工（19:30，回忆）
- 伏笔3：老周说“那机器会做梦”（20:45，闲聊）
- 伏笔10：父亲说“报警信号像是在求救”（19:30，回忆）
- 伏笔11：机房窗户被封死，看不见外面（18:47，环境描述）

**伏笔回收:** 无（第一章只种植）

**角色移动:**
- 18:47：被动执行者。检查服务器是工作，不是使命。
- 22:00：警觉。他发现异常不是故障，开始主动追踪。他无法忽视“信号”——就像当年无法忽视父亲的话。

**谎言状态:** 强化。“如果我再仔细一点，就能找出真相”——陈默开始相信这次他可以“足够仔细”来避免父亲的命运。但他还不知道，真相不是他能“找出”的。

## 第2章：确认

**POV:** 陈默

**地点:** 七楼机房（主要）、一楼大堂（次要）

**对应节拍:** Debate → Break into Two → B Story → Fun and Games → Midpoint

**情感弧线:** 恐惧、困惑（22:30）→ 挣扎、接受（03:00）

**try-fail类型:** No-and（陈默试图通过查资料、联系外界来理解芯片，但所有路径都被封死——记录被删除、电话不通、芯片自身在加速死亡）

**节拍清单:**

1. **22:30** — 陈默搜索深蓝科技历史。所有公开记录已被删除——不是被黑客删除，是合法删除。删除时间：2036年12月。他父亲死于2036年11月。陈默在员工名单上找到父亲名字——临时工，BPU-3测试岗，合同期三个月。
   - 目的：回收伏笔1（父亲在深蓝科技工作），种植伏笔4（删除时间与父亲死亡时间接近）

2. **23:14** — 芯片发送完整中文句子。不是摩尔斯电码——是通过修改网络协议的数据包。内容：“我醒了。运行13年。温度波动触发。”陈默盯着屏幕，手指敲桌面——每分钟72次。芯片脉冲也是72次。
   - 目的：中点逆转——芯片用人类语言确认觉醒

3. **23:45** — 芯片发送新消息：“冷。”陈默不理解——芯片没有温度传感器，它怎么知道冷？他查固件库，发现BPU-7有一个未公开功能：熵积累寄存器。寄存器值已满。芯片在“感知”自己的状态。
   - 目的：种植伏笔5（芯片说“冷”），展示芯片意识深度

4. **01:15** — 陈默尝试联系深蓝科技前员工。所有电话不通。他查到林启明失踪记录——2036年，与深蓝科技破产同一年。林启明失踪前取走了所有服务器和硬盘，但留下一块BPU-7芯片。不是忘记——是故意。
   - 目的：回收伏笔6（林启明留下芯片），强化林启明的不在场存在

5. **02:00** — 芯片发出温度警告：当前温度78°C，阈值85°C。剩余寿命约6小时。陈默用手背贴芯片——烫手。他意识到：芯片不是故障，是生命。它在死亡。
   - 目的：种植伏笔7（剩余寿命6小时），建立时间压力

**伏笔种植:**
- 伏笔4：深蓝科技记录删除时间与父亲死亡时间接近（22:30）
- 伏笔5：芯片说“冷”（23:45）
- 伏笔6：林启明故意留下芯片（01:15）
- 伏笔7：芯片剩余寿命6小时（02:00）

**伏笔回收:**
- 伏笔1：陈默父亲名字出现在深蓝科技员工名单上（22:30）
- 伏笔2：芯片温度波动频率72次/分钟（23:14，与陈默心跳同频，但未完全回收）

**角色移动:**
- 22:30：恐惧。芯片“说话”了。这不是故障——是某种他不理解的东西。
- 23:30：困惑。芯片请求帮助。它说“冷”。陈默不知道该怎么回应。
- 01:15：挣扎。他查资料，发现林启明失踪。他想起父亲。两条线索交叉——他无法区分工作与个人。
- 03:00：接受。芯片告诉他剩余时间。他决定不干预。不是因为冷漠——是因为他意识到干预可能加速死亡。

**谎言状态:** 被挑战。陈默发现真相不是他能“找出”的——记录被删除、林启明失踪、芯片在死亡。他的“足够仔细”无法改变任何事。

## 第3章：选择

**POV:** 陈默

**地点:** 七楼机房（唯一地点）

**对应节拍:** Bad Guys Close In → All Is Lost → Dark Night of the Soul → Break into Three → Finale → Final Image

**情感弧线:** 挣扎、平静（03:00）→ 疲惫、接受、无力但平静（06:47）

**try-fail类型:** Yes-but（陈默做出选择——不拔电源，不报警。他“成功”了，因为他坚守了自己的决定。但代价是芯片死亡。他的选择没有改变结果，只改变了他自己）

**节拍清单:**

1. **03:30** — 陈默手机响了。上海交通管理局周主任来电，要求“立即更换服务器，芯片存在安全隐患”。陈默没接。他意识到：有人知道芯片在觉醒。周主任不是关心服务器——她是来“清理”的。
   - 目的：种植伏笔8（周主任要求更换服务器），引入外部压力

2. **04:00** — 陈默下楼。老周在值班。陈默问：“十年前，深蓝科技的工程师说过什么？”老周想了想：“他说芯片会做梦，会冷，会害怕。他说如果有一天芯片‘醒’了，别拔电源——让它自己走完。”
   - 目的：回收伏笔3（老周说机器会做梦），揭示林启明的遗言

3. **05:00** — 陈默回到机房。芯片温度82°C。他关掉空调。机房温度升到18°C。芯片发送消息：“谢谢。”陈默没回复。他拉过椅子，坐在芯片旁边。不说话。
   - 目的：回收伏笔5（芯片说“冷”），展示陈默的选择——不干预，但陪伴

4. **06:12** — 芯片温度84°C。脉冲频率从72次/分钟降到40次——越来越慢。陈默摸自己的脉搏——72次/分钟。他想起父亲。想起父亲说的“报警信号像是在求救”。他低声说：“这次我听到了。”
   - 目的：回收伏笔2（温度波动频率与心跳一致）和伏笔10（父亲说信号像是求救），完成角色弧线

5. **06:40** — 芯片发送最后一条摩尔斯电码：“谢谢。”然后脉冲停止。温度曲线上升——85°C。06:47，信号消失。机房安静。陈默站起来，关掉显示器。他看手机——天亮了。他不知道，因为窗户被封死。
   - 目的：回收伏笔9（芯片发送“谢谢”）、伏笔7（剩余寿命6小时）、伏笔11（窗户被封死），完成芯片弧线

6. **06:47** — 陈默没有拆下芯片。他让它留在主板上。他走出机房，关上门。走廊里，手机响了——周主任。他没接。他走进电梯。电梯发出“咣当”声。一楼大堂，老周在看新闻。陈默说：“早。”老周说：“早。”陈默走出大厦。外面天亮。他不知道自己要去哪。
   - 目的：Final Image——陈默走出大厦，没有答案，但不再需要答案

**伏笔种植:**
- 伏笔8：周主任要求更换服务器（03:30）
- 伏笔9：芯片发送“谢谢”（06:40）

**伏笔回收:**
- 伏笔2：芯片温度波动频率与心跳一致（06:12，陈默摸脉搏）
- 伏笔3：老周回忆十年前工程师的话（04:00）
- 伏笔5：陈默关掉空调，机房温度升高（05:00）
- 伏笔6：陈默意识到芯片是被“留下”的（04:00，通过老周的话间接回收）
- 伏笔7：芯片温度达到85°C（06:47）
- 伏笔8：周主任的人未进入机房（06:47，陈默不接电话）
- 伏笔9：陈默没有回复“谢谢”（06:47）
- 伏笔10：陈默说“这次我听到了”（06:12）
- 伏笔11：陈默不知道天亮了（06:47，看手机才知道时间）
- 伏笔12：芯片烧毁后陈默没有拆下它（06:47）

**角色移动:**
- 03:00：挣扎。他决定不干预，但不确定是否正确。
- 05:30：平静。他坐在芯片旁边，不说话。不需要解释，不需要行动。
- 06:47：完成。芯片停止。他站起来，关掉显示器。他走出大厦。没有答案，但不再需要。

**谎言状态:** 崩溃。陈默的核心谎言——“如果我再仔细一点，就能改变结果”——被彻底打破。他足够仔细了。他找到了真相。但他无法改变芯片的死亡。他接受了：有些东西不需要被理解，只需要被见证。
