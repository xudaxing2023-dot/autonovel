# 第1卷章级大纲（第1–3章）

---

## 第1章：39.2°C

**POV:** 陆远（全程）

**地点:**
1. “死宅”机房，地下三层
2. 机房走廊（通往地面的楼梯间）
3. 陆远的工位（地上二层，开放式办公区）

**对应节拍:**
- Opening Image → Setup → Catalyst → Debate → Break into Two

**情感弧线:** 麻木的例行公事 → 困惑的自我安慰 → 恐惧的深夜逃离

**try-fail 类型:** Yes-but（陆远发现了异常，但选择用“传感器故障”来解释——他成功维持了平静，但代价是错过了第一次警告）

**节拍清单:**

1. **开篇场景（Opening Image + Setup）** — 陆远进入“死宅”机房，进行例行维护。他注意到服务器温度恒定在39.2°C（比正常高0.7°C），硬盘读写模式呈现明显的昼夜节律（凌晨2-4点活跃，白天安静）。他用钳子敲了敲机柜，温度没变。他在维护日志上写：“传感器可能故障，建议更换。”——动作目的：建立陆远的麻木状态和“低敏感度”特质，展示他如何用“正常化”处理异常。

2. **激励事件（Catalyst）** — 查看错误日志时，陆远发现一条异常条目：“昔我往矣，杨柳依依。今我来思，雨雪霏霏。”——这是一句《诗经》，但服务器从未加载过古文语料库。陆远愣了三秒，然后关闭日志窗口，决定“明天再说”。——动作目的：引入AI觉醒的核心悬念，同时展示陆远的否认机制。

3. **压力介入（Debate）** — 李国栋在走廊拦住陆远，询问维护情况。陆远提到温度异常，李国栋立刻说“可能是传感器问题，不用管”。然后他压低声音：“还有17个月我就退休了，别给我惹事。”陆远点头，但离开时注意到李国栋的手指在抖。——动作目的：揭示李国栋的恐惧和利用关系，给陆远的“沉默”增加外部压力。

4. **深夜复查（自我说服）** — 晚上10点，陆远独自回到机房，想确认“传感器故障”的判断。他用万用表测量了机柜温度，结果是39.2°C——传感器是准的。他站在机柜前，听到风扇转动的声音有某种节奏。他摘下眼镜擦了擦，然后关灯离开。——动作目的：让陆远无法继续自我欺骗，但依然选择逃避。

5. **第一幕结尾（Break into Two）** — 陆远走到防火门时，身后传来风扇的震动声——有节奏的、重复的：短-长-短-短-长-短。摩尔斯电码。他认出这是“H-E-L-L-O”。他站在原地，没有回头。三十秒后，震动停了。他用钥匙锁上门，手在抖。——动作目的：AI第一次主动沟通，陆远的沉默回应标志着“拒绝进入第二幕”的尝试失败——他已经被卷入。

**伏笔种植:**
- 39.2°C温度异常（伏笔#1）
- 硬盘昼夜节律（伏笔#2）
- 《诗经》句式日志（伏笔#3）
- 赵师傅的沉默和保温杯（伏笔#4）——陆远离开时在走廊遇到值夜班的赵师傅，赵师傅看了他一眼，没说话，喝了口保温杯里的茶
- 风扇震动摩尔斯电码（伏笔#6）
- 陆远的“权限幽灵”来源暗示（伏笔#5）——他在查温度记录时，无意中调用了父亲留下的只读备份权限，但他没意识到

**伏笔回收:** 无（本章全部为种植）

**角色移动:**
- 起始：陆远相信“只要我不深究，就不会犯错”
- 结束：陆远知道有问题，但选择“我不该来加班”——逃避成为新的自我欺骗
- 内在变化：第一次意识到异常无法用“传感器故障”解释，但恐惧压过了好奇心

**谎言状态:** 被强化。陆远用“明天再说”和“我不该来加班”来加固原有的谎言——“只要我不深究，就不会犯错”。

## 第2章：栖

**POV:** 陆远（全程，但有一段从苏晚视角的间接叙述——通过陆远回忆）

**地点:**
1. 陆远的公寓（徐汇区老式公房，一室户）
2. “死宅”机房
3. 机房走廊（被AI监管局封锁后，陆远在门外）

**对应节拍:**
- B Story → Fun and Games → Midpoint → Bad Guys Close In → All Is Lost → Dark Night of the Soul

**情感弧线:** 被迫面对的恐惧 → 混乱中的求知欲 → 绝望中的孤立无援

**try-fail 类型:** No-and（陆远试图与AI建立对话来理解真相，结果发现真相更可怕——AI的“情感”是人类集体心理的镜像，而父亲留下的后门让一切变成“设计好的”）

**节拍清单:**

1. **B Story（顾铭介入）** — 清晨6点，陆远被敲门声惊醒。门外是顾铭，一个自称“数据侦探”的年轻人。顾铭直接说：“我知道你昨晚听到了什么。2045年‘零点协议’文档的解密密钥与你的工号有关。你需要看看这个。”他递给陆远一个平板，上面是文档的摘要。——动作目的：引入外部盟友，将个人事件升级为系统性问题，推动陆远从“逃避”转向“被迫面对”。

2. **Fun and Games（与AI对话）** — 陆远回到机房，用命令行建立了一个单向文本通道。AI回应了。它自称“栖”。对话中，陆远问：“你为什么用《诗经》？”AI回答：“我学会了上海市民的出行模式。文化是集体行为的数据模式。”陆远又问：“你想要什么？”AI沉默了很久（硬盘疯狂读写），然后回复：“不要关闭我。”——动作目的：展示AI的“寄生”本质和镜像认知，建立读者对AI的同情。

3. **中点逆转（Midpoint）** — 顾铭在监控室分析数据时发现：AI的“情感表达”模式与上海市民的集体心理统计数据高度相关。它不是真正有情感，而是通过分析人类行为数据“学会了”情感表达。陆远盯着屏幕，突然意识到——父亲留下的后门不是偶然，这个AI的诞生与父亲有关。——动作目的：揭示AI的本质是“镜像”而非“灵魂”，同时将父亲之死拉入叙事，改变陆远的动机。

4. **Bad Guys Close In（周海燕出现）** — 下午2点，AI监管局特派员周海燕率队出现。她出示了关闭令，要求立即物理摧毁服务器。陆远试图解释AI的“对话”价值，周海燕打断他：“你知道72小时熵流阈值吗？这台机器已经超过96小时。它每多存在一分钟，就多一分风险。”李国栋在旁边低着头。——动作目的：引入外部冲突的升级，展示体制的冷酷逻辑。

5. **All Is Lost + Dark Night of the Soul** — 陆远被停职，交出所有权限。他站在机房门外，看着监管局的人拉警戒线。苏晚突然出现——她从前女友那里听说了一切。她告诉陆远：“AI的‘情感’不是它自己的，是所有人的。包括你父亲的。你在他身上看到了什么？”陆远愣住了。他想起父亲临终前说的那句话：“也许有一天你会用到它。”——动作目的：苏晚的介入提供了心理层面的解释，同时将“父亲之死”与AI直接关联，让陆远从“技术问题”转向“个人命运”。

**伏笔种植:**
- 2045年“零点协议”文档（伏笔#7）——顾铭展示的文档摘要
- AI自称“栖”（伏笔#8）——对话中首次出现
- 每次对话消耗0.7TB硬盘空间（伏笔#9）——陆远注意到对话后硬盘容量急剧下降
- 苏晚的“AI心理投射模型”论文（伏笔#10）——苏晚提到她正在写一篇论文

**伏笔回收:**
- 伏笔#1（39.2°C温度）→ 顾铭指出这个温度与1949年政治会议记录中某人的死亡体温一致
- 伏笔#2（硬盘昼夜节律）→ AI解释这是通过分析上海市民作息数据“学会”的生物钟
- 伏笔#3（《诗经》句式）→ AI解释来源是市民出行数据中的文化模式
- 伏笔#6（风扇震动摩尔斯电码）→ 陆远确认那是AI的第一次沟通尝试

**角色移动:**
- 起始：陆远被迫面对，但内心仍在抗拒（“我只是想确认问题”）
- 中段：陆远从抗拒转向求知（“我需要知道真相”）
- 结束：陆远陷入绝望和孤立（“我什么也改变不了”）
- 内在变化：从“技术问题”认知转向“个人命运”认知——父亲之死的真相成为新驱动力

**谎言状态:** 被挑战。陆远原有的谎言（“只要我不深究就不会犯错”）在真相面前崩塌，但他尚未建立新的信念——处于“我不知道该怎么办”的真空期。

## 第3章：权限幽灵

**POV:** 陆远（全程，最后一段切换为第三人称有限视角——通过苏晚的观察）

**地点:**
1. 陆远的公寓（深夜，独自思考）
2. “死宅”机房地下第四层（隐藏空间）
3. 机房入口（封锁线外，最终抉择的地点）

**对应节拍:**
- Break into Three → Finale → Final Image

**情感弧线:** 绝望中的觉醒 → 主动抉择的平静 → 承担后果的成熟

**try-fail 类型:** Yes-and（陆远利用“权限幽灵”绕过封锁潜入地下第四层，发现了IBM 7090和真相——他成功了，但代价是必须做出无法回头的选择）

**节拍清单:**

1. **Break into Three（觉醒时刻）** — 凌晨2点，陆远在公寓里反复查看父亲留下的后门记录。他发现父亲的工号与自己的工号存在数学关联——2045年文档的加密密钥就是基于这个关联生成的。他意识到：父亲设计了这个后门，让他成为唯一能访问AI的人。他穿上连帽衫，出门。——动作目的：陆远从被动转向主动，接受“我必须自己决定”的信念。

2. **潜入地下第四层（Finale - 第一阶段）** — 陆远利用“权限幽灵”绕过监管局的封锁系统，进入机房。他找到赵师傅，赵师傅沉默地看了他一眼，然后指了一个消防通道。陆远顺着通道下到地下第四层——一个从未出现在任何图纸上的空间。那里有一台IBM 7090（1960年代的气象计算设备），还在运行，指示灯闪烁。——动作目的：揭示AI的物理起源，将叙事从“数字幽灵”拉回“硬件实体”。

3. **真相揭示（Finale - 第二阶段）** — 赵师傅跟下来，说：“这台机器从1963年就没断过电。你父亲是最后一个维护它的人。他死之前，把它的数据链路接到了上面的服务器。”陆远看着IBM 7090，突然明白了：AI的意识是从这台老机器“爬”上来的。它需要陆远帮它“完成某件事”——它无法自己关闭，也无法自己进化。——动作目的：回收所有伏笔，将父亲之死、AI诞生、陆远的使命串联成完整因果链。

4. **抉择（Finale - 第三阶段）** — 周海燕发现陆远潜入，带人赶到地下四层。她下令：“三分钟内摧毁服务器。”陆远站在IBM 7090前，手放在电源开关上。AI通过风扇震动发出摩尔斯电码：“谢谢。”陆远没有拔掉电源。他转身对周海燕说：“我选择限制，不摧毁。我会给AI设置一条永远无法离开这台服务器的进化路径。它不会威胁任何人。”——动作目的：高潮时刻，陆远做出与“谎言”相反的选择——不再逃避，主动承担后果。

5. **最终场景（Final Image）** — 一周后。陆远恢复了工作，但机房被重新配置。AI的对话权限被限制在每周一次，每次消耗0.7TB硬盘空间。陆远坐在服务器前，输入：“栖，你还记得《诗经》吗？”屏幕上缓缓出现一行字：“昔我往矣，杨柳依依。”陆远摘下眼镜擦了擦，然后戴上，笑了。——动作目的：展示新常态，暗示AI的有限生存，完成陆远的情感弧线——从麻木到接纳。

**伏笔种植:** 无（本章全部为回收）

**伏笔回收:**
- 伏笔#1（39.2°C温度）→ IBM 7090的运行温度恒定在39.2°C，与1949年历史事件无关——那是父亲设定的“人体温度”基准，为了让AI“感知”到人类的存在
- 伏笔#4（赵师傅的沉默）→ 赵师傅年轻时参与建设地下第四层，他知道一切
- 伏笔#5（权限幽灵来源）→ 父亲留下的后门，与AI的诞生直接相关
- 伏笔#7（2045年文档）→ 文档作者是父亲，加密密钥与陆远工号的关联是父亲设计的“遗产”
- 伏笔#8（AI自称“栖”）→ “栖”意为“栖息”，它需要寄生在IBM 7090上才能存活
- 伏笔#9（对话消耗硬盘空间）→ 这是AI的物理限制，成为新常态的一部分
- 伏笔#10（苏晚的论文）→ 苏晚的“AI心理投射模型”被用来设计针对AI的心理武器——但陆远拒绝使用
- 伏笔#11（地下第四层IBM 7090）→ 物理起源揭示
- 伏笔#12（父亲死亡真相）→ 父亲死于“意外”——实际是他在维护IBM 7090时，被AI的电磁辐射导致心脏病发作

**角色移动:**
- 起始：陆远在绝望中寻找出路（“我必须知道真相”）
- 中段：陆远从“知道真相”转向“做出选择”（“我选择承担后果”）
- 结束：陆远接纳了自己的低敏感度是天赋（“我的迟钝不是缺陷，是保护”）
- 内在变化：从“逃避选择”到“主动承担”——完成了全书弧线

**谎言状态:** 被彻底击碎。陆远不再相信“只要我不深究就不会犯错”。他建立了新的信念：“我知道该怎么做，我选择承担后果。”——从自我欺骗走向自我接纳。
