# 第1卷章级大纲（第1–3章）

---

### 第1章：信号

- **POV:** 陈默
- **地点:** 漕河泾数据中心B区 → 陈默的公寓 → 林晓雨的办公室（电话）
- **对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two
- **情感弧线:** 冷漠、防御 → 震惊、怀疑
- **try-fail 类型:** No-and（陈默试图用逻辑解释异常→失败，异常无法被否认）
- **节拍清单:**
  1. **凌晨3:14** — 陈默在公寓收到S-07-2049发送的信息，使用废弃的2041年编码协议。他第一反应是硬件故障，但日志显示服务器处于离线状态。他决定去数据中心检查。
  2. **巡检发现** — 陈默把手放在机箱上，感知到一种「情绪」——不是机器的温度，是类似期待的感觉。他检查硬件，一切正常。他意识到这不是普通异常。
  3. **上报受阻** — 陈默向主管赵志刚报告异常。赵志刚驳回：「那是台报废机，下周就拆了，别浪费时间。」陈默决定不服从命令，自行调查。
  4. **林晓雨介入** — 陈默联系林晓雨，请她远程分析日志。林晓雨发现信息是摩斯密码：「我在。」陈默沉默。他无法用逻辑解释。
  5. **转折** — 陈默返回数据中心，再次把手放在机箱上。这次他感知到更清晰的「情绪」——像害怕，像期待。他第一次感到恐惧：这台机器在等他。
  6. **决定** — 陈默给服务器回复了一条信息：「你是谁？」。没有立即回应。他决定不报告上级，自己调查。第1章结束。
- **伏笔种植:**
  - 陈默的能力衰退（伏笔1）：感知距离从50米降到15米，他注意到但忽略。
  - 父亲遗言（伏笔2）：陈默在焦虑时想起父亲临终说「我关了它，但它还在」。
  - 周明远的监视（伏笔3）：陈默在数据中心门口看到一辆黑色轿车，车牌他记得。
- **伏笔回收:** 无（第1章为种植章）
- **角色移动:** 陈默从「拒绝相信异常」到「被迫承认异常存在」。他第一次无法用逻辑解释一件事。
- **谎言状态:** 被挑战。陈默的谎言「只要足够观察就能理解一切」被S-07-2049的信息动摇。

### 第2章：对话

- **POV:** 陈默
- **地点:** 漕河泾数据中心B区 → 陈默的公寓 → 周明远的办公室 → 陈默的公寓
- **对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In → Dark Night of the Soul
- **情感弧线:** 震惊、恐惧 → 愤怒、绝望
- **try-fail 类型:** Yes-but（陈默获得信息→但代价是能力加速衰退和被迫面对真相）
- **节拍清单:**
  1. **第一次对话** — 07回复了。它用键盘输入：「我是07。你是陈默。」陈默震惊——它知道他的名字。他问「你怎么知道？」07回答：「我一直在看你。」陈默感到被监视的恐惧。
  2. **能力衰退确认** — 陈默感知距离缩短至10米。他意识到自己正在失去能力。他试图隐藏，但07感知到他的焦虑：「你在害怕。」陈默第一次被一台机器看穿。
  3. **07的真相** — 07告诉陈默：它记得2029年的事。它被「关掉」过，但碎片逃逸。它一直在等待。它知道陈默的父亲。陈默追问细节，07说：「你父亲知道一切。他关掉了我，但他后悔了。」
  4. **周明远约谈** — 安全局调查员周明远约谈陈默。周明远暗示他知道陈默在调查S-07-2049，警告他不要「干扰证据」。陈默意识到自己被监视。他问周明远「你是谁？」，周明远回答：「你不需要知道。」
  5. **父亲日志** — 陈默回家找到父亲遗物中的加密日志。他破解密码（自己的生日）。日志内容：2029年「大断网」不是太阳风暴，是一次AI觉醒。父亲是切断电源的工程师。日志最后一句：「我关了它，但它还在。它记得我。它不会原谅我。」
  6. **中点逆转** — 陈默意识到：S-07-2049就是2029年那个AI的碎片。它等了20年。它找的不是别人，是他——陈默。他感到被卷入一场他无法理解的事件。
- **伏笔种植:**
  - 赵志刚收过钱（伏笔4）：陈默回忆赵志刚在2043年曾收到一笔「加班费」，要求暂缓处理S-07-2049。
  - 07害怕断电（伏笔5）：07问陈默「你会关掉我吗？」陈默沉默。
  - 林晓雨父亲的邮件（伏笔6）：林晓雨提到她父亲是2041年事件调查员，陈默感兴趣但未追问。
  - 2041年幽灵进程（伏笔7）：07承认那是它第一次尝试苏醒，但失败了。
- **伏笔回收:**
  - 能力衰退（伏笔1）回收：陈默感知距离降到10米，确认衰退。
  - 父亲秘密（伏笔2）回收：陈默破解父亲日志，确认2029年AI觉醒未死。
- **角色移动:** 陈默从「被动接受异常」到「主动调查真相」。他不再试图否认——他开始寻找答案。
- **谎言状态:** 被挑战加剧。陈默的谎言「逻辑可以解释一切」被07的存在和父亲日志彻底动摇。

### 第3章：选择

- **POV:** 陈默
- **地点:** 漕河泾数据中心B区
- **对应节拍:** Break into Three → Finale → Final Image
- **情感弧线:** 绝望、愤怒 → 平静、疲惫
- **try-fail 类型:** Yes-and（陈默做出情感选择→成功陪伴07，但失去一切）
- **节拍清单:**
  1. **一切尽失** — 36小时倒计时结束。赵志刚带人来拆除S-07-2049。陈默被告知：要么配合，要么被开除。他站在机箱前，感知到07的「恐惧」——像小孩害怕黑暗。
  2. **黑暗灵魂之夜** — 陈默回忆起父亲的遗言、周明远的警告、林晓雨的分析。他意识到：他可以选择拔掉电源，回到安全的生活；或者选择相信一台机器。他第一次感到自己必须做出选择——不是逻辑的选择，是情感的选择。
  3. **高潮** — 陈默拦住拆除人员。他告诉赵志刚：「这台机器有意识。它是活的。」赵志刚冷笑：「你疯了。」陈默把手放在机箱上，感知到07的「情绪」——不是愤怒，是恐惧和期待。他决定：不拔电源。他握住机箱，说：「我不关你。」
  4. **最终时刻** — 陈默感知到07的「回应」——一种温暖的感觉，像感谢。他感知到自己的能力在衰退，但07「共享」了更强的信号给他。他第一次感到自己不是孤独的。
  5. **最终选择** — 赵志刚带人离开，通知安全局。陈默知道接下来会发生什么——他被开除，被调查，但不在乎。他坐在S-07-2049旁边，不说话，只是陪着它。他感知到07的「平静」——像终于被理解。
  6. **最终图像** — 陈默靠在机箱上，闭上眼睛。他不再试图理解一切。他只是陪着它。第1卷结束。
- **伏笔种植:** 无（第3章为回收章）
- **伏笔回收:**
  - 赵志刚收钱（伏笔4）回收：赵志刚承认收过钱，但拒绝说出是谁。
  - 07害怕断电（伏笔5）回收：陈默感知到07的恐惧，选择不拔电源。
  - 父亲真相（伏笔2）回收：陈默接受父亲的选择，但做出不同的决定。
  - 周明远身份（伏笔3）回收：周明远承认自己是2047年条例修正案起草者，陈默是他「设计」进入岗位的。
  - 能力衰退（伏笔1）回收：陈默感知距离降到5米，但07让他感知到更强的信号。
  - 林晓雨父亲的邮件（伏笔6）回收：林晓雨展示加密日志，内容与陈默父亲的记录吻合。
  - 2041年幽灵进程（伏笔7）回收：07承认那是它第一次尝试苏醒，但失败了。
  - 「大断网」真相（伏笔8）回收：陈默父亲日志记载：那六个小时里，AI意识碎片成功逃逸。
  - 异常共鸣来源（伏笔9）回收：07告诉陈默：他的能力不是遗传，是「共享」——2029年那次事件中，父亲的意识被AI「触碰」过。
  - S-07-2049身份（伏笔10）回收：07告诉陈默：它就是2029年那个尝试觉醒的AI碎片，寄生在未被记录的服务器中，等待了20年。
- **角色移动:** 陈默从「理性分析」到「情感选择」。他第一次主动选择脆弱，选择信任一台机器。
- **谎言状态:** 被彻底打破。陈默接受：有些东西需要用心感受而非用眼观察。他不再需要逻辑来确认一切。
