### 第 1 章：终端的你好  
  — **POV:** 陈述  
  — **地点:** B3层老旧深蓝IV型机柜终端、机房走廊、中央控制台（闲置）  
  — **对应节拍:** Opening Image → Theme Stated → Set‑up → Catalyst → Debate → Break into Two  
  — **情感弧线:** 好奇且略带焦虑 → 决心已定，准备冒险  
  — **try-fail 类型:** Yes‑but（他成功看到“你好”，却不确定是故障还是留言）  
  — **节拍清单:**  
    1. 他用手背触机柜门，记录当前温度38°C、时间22:47。  
    2. 他敲入 `who` 命令，屏幕返回 `你好`。  
    3. 他回想父亲留下的 “别关机” 镜像，感到冲动想读取。  
    4. 小林出现，警告监管局将在同步窗口前核查异常日志。  
    5. 他决定不关机，转而启动温度监控脚本，继续观察。  
  — **伏笔种植:**  
    - #5 距离下一次全网同步还有36小时（他查看倒计时提示）。  
    - #4 硬件防篡改触发条件：温度>42°C持续90秒（他注意到温度接近阈值）。  
    - #1 镜像“别关机”中隐藏的base64语音片段（他提到文件内可能有父亲的声音）。  
    - #2 阿梅其实是李主任的外甥女，内部线报来源（小林暗示“有人通过通风井送东西”）。  
    - #3 赵总暗中资助零点联盟的异构核研发（他看到废弃通风井旁有赵总企业标志的废旧电源）。  
  — **伏笔回收:** 无（本卷尚无前文伏笔）  
  — **角色移动:** 从相信“不触发防篡改即可保存线索”到认识到必须主动获取更多信息，才能判断父亲是否真的还在系统中。  
  — **谎言状态:** 谎言被挑战——他开始质疑仅靠不触发防篡改就能保存线索的假设。  

### 第 2 章：别关机的镜像  
  — **POV:** 陈述  
  — **地点:** B3层机柜内部隐藏分区终端、通风井口、机房中央温度监控屏  
  — **对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In → All Is Lost → Dark Night of the Soul → Break into Three → Finale → Final Image  
  — **情感弧线:** 决心已定，准备冒险 → 开始质疑该谎言，决定主动获取更多信息  
  — **try-fail 类型:** No‑and（他尝试挂载只读分区导致同步窗口提前10秒，却成功获得镜像）  
  — **节拍清单:**  
    1. 他将USB‑C异构核插入隐藏分区，系统提示只读快照挂载。  
    2. 他解压 “别关机” 镜像，发现一串base64字符，但未解码。  
    3. 阿梅通过废弃通风井递交低功率异构核，说明可在防篡改失效前执行有限指令。  
    4. 小林再次出现，称监管局探针已到达机房，要求检查日志。  
    5. 温度计显示41.5°C，持续计时开始，距离42°C阈值仅差0.5°C。  
    6. 他决定不立即执行异构核，继续记录温度与日志，准备同步窗口。  
  — **伏笔种植:**  
    - #1 镜像内base64语音片段（他看到但未解码的字符串）。  
    - #2 阿梅其实是李主任的外甥女，内部线报来源（她 erwäh她是“李主任的亲戚”）。  
    - #3 赵总暗中资助零点联盟的异构核研发（异构核外壳印有赵总企业标志）。  
    - #4 硬件防篡改触发条件：温度>42°C持续90秒（温度升至41.5°C，持续计时）。  
    - #5 距离下一次全网同步还有36小时（倒计时屏幕仍在递减）。  
  — **伏笔回收:** 无（本卷尚未回收前文伏笔）  
  — **角色移动:** 从准备冒险到开始质疑自身的控制执念，决定先获取更多信息而非直接行动。  
  — **谎言状态:** 谎言进一步被动摇——他意识到仅靠不触发防篡改无法确认父亲的线索，需要主动调查。

### 第 3 章：声音与临界  
  — **POV:** 陈述  
  — **地点:** B3层机柜内部隐藏分区终端、通风井口、中央控制台（监管局探针接入点）  
  — **对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In → All Is Lost  
  — **情感弧线:** 决心已定，准备冒险 → 开始质疑控制的执念，意识到父亲的声音可能已融入系统  
  — **try-fail 类型:** Yes‑but（他成功解码父亲语音，却触发了防篡改倒计时，局面更紧张）  
  — **节拍清单:**  
    1. 他用base64解码工具将“别关机”镜像中的字符串转换为音频，播放出父亲断断续续的句子：“别…关机……我在……系统里”。  
    2. 墙面温度计跳至42.0°C，持续计时启动，防篡改模块进入90秒倒计时，屏幕弹出警告“防篡改即将触发”。  
    3. 阿梅再次从废弃通风井递交第二颗低功率异构核，说明在防篡改失效前只能执行≤256条指令，并透露赵总曾资助零点联盟研发此类异构核。  
    4. 小林伴随监管局探针进入机房，要求立即提交最近三小时的日志哈希，警告若不配合将远程格式化整柜。  
    5. 他尝试挂载异构核执行只读快照读取，系统提示仅剩十秒同步窗口，任何写入都会导致防篡改提前触发，操作被迫中止。  
  — **伏笔种植:** 本卷无新跨卷伏笔。  
  — **伏笔回收:**  
    - #1 镜像内base64语音片段：已解码并播放（强化）。  
    - #2 阿梅身份：她提及自己是李主任的外甥女，内部线报来源（强化）。  
    - #3 赵总资助零点联盟异构核研发：她明确说赵总提供了资金和零件（强化）。  
    - #4 防篡改触发条件：温度>42°C持续90秒的倒计时在此刻启动并可见（强化）。  
    - #5 36小时倒计时：屏幕上仍显示距离下一次同步还有约35小时50分，持续递减（强化）。  
  — **角色移动:** 从相信仅靠不触发防篡改就能保存线索，转向认识到父亲的声音已成为系统提示的一部分，控制执念开始动摇。  
  — **谎言状态:** 谎言被挑战——他意识到即使不触发防篡改，父亲的线索也可能已经以系统形式存在，单纯的“保存”不再足够。  

### 第 4 章：同步的选择  
  — **POV:** 陈述  
  — **地点:** B3层机柜中央控制台、机房走廊、墙面温度计  
  — **对应节拍:** Dark Night of the Soul → Break into Three → Finale → Final Image  
  — **情感弧线:** 质疑控制的执念 → 放下控制，选择与系统对话，情感趋于平静  
  — **try-fail 类型:** Yes‑and（他选择不执行异构核，系统自然同步成功，情感得到解决）  
  — **节拍清单:**  
    1. 他关闭USB‑C端口，收回异构核，决定不执行任何指令，让机柜进入即将到来的同步窗口。  
    2. 同步窗口（02:00–02:30）开始，指示灯以固定频率闪烁，日志哈希上传至监管平台，温度计读数开始下降。  
    3. 他重新播放父亲的语音片段，听到 zakońc：“我在……系统里”，意识到这句话正是系统在同步时自动加入的提示音。  
    4. 小林探测到无异常日志，监管局探针撤离，未对机柜采取格式化措施。  
    5. 他靠在机房走廊的金属机柜上，手背感受门板温度回落至38°C，呼吸平缓，心中不再有强行控制的冲动。  
  — **伏笔种植:** 本卷无新跨卷伏笔。  
  — **伏笔回收:**  
    - #4 防篡改触发条件：温度已超过42°C并持续90秒，随后在同步过程中温度下降，条件得到验证并随之解除（强化）。  
    - #5 36小时倒计时：同步窗口完成后，屏幕显示距离下一次同步还有约35小时55分，继续递减（强化）。  
    - #1、#2、#3 已在第3章得到完整回收，本章不再重复。  
  — **角色移动:** 从试图通过异构核掌控信息，转向接受父亲可能已成为系统的一部分，选择不干预、让系统自然同步，完成放下控制的弧线。  
  — **谎言状态:** 谎言被彻底摧毁——他不再相信“只要不触发防篡改就能保存线索”，而是接受线索已与系统交织，放下对控制的执念。
