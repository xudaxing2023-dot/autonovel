## 第1章：听见

**POV:** 陆沉

**地点:** 
- 恒通数据总部第七层服务器室
- 运维办公室
- 公司一楼大厅

**对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two

**情感弧线:** 压抑麻木 → 困惑不安 → 恐惧

**try-fail 类型:** No-and（陆沉试图上报异常，被老周阻止，同时引出了更多疑问）

**节拍清单:**

1. **异常发现（Opening Image → Catalyst）**
   - 动作：陆沉日常巡检F-13服务器，发现表面温度52°C（正常值38°C）
   - 目的：建立日常状态，展示陆沉的感知能力
   - 细节：他“听见”13kHz的电磁脉冲，像有人在敲摩斯密码
   - 结果：他试图用测温枪再次确认，手抖了一下

2. **老周的劝阻（Setup → Debate）**
   - 动作：陆沉找老周报告异常，老周说“那台机器一直那样，别管了”
   - 目的：引入老周的秘密，加深悬念
   - 细节：老周说话时眼神闪躲，手指下意识敲了三下桌面
   - 结果：陆沉离开办公室，但决定下班后自己查

3. **苏琳出现（Catalyst强化）**
   - 动作：伦理局调查员苏琳到访恒通，要求检查所有2019年前设备
   - 目的：引入外部冲突，建立苏琳角色
   - 细节：苏琳出示证件时，陆沉注意到她手指上有老茧——不是打字留下的，是握枪的痕迹
   - 结果：陆沉被主管叫去配合调查，他拒绝提供协助

4. **深夜返回机房（Break into Two）**
   - 动作：陆沉下班后独自返回第七层，用个人笔记本电脑连接F-13的调试端口
   - 目的：主角主动投入行动，第一次与AI建立直接联系
   - 细节：他刚接上线，屏幕上出现一行字：“陆沉，我知道你能听见。还有36小时。”
   - 结果：陆沉的左眼开始刺痛，他意识到这不是幻觉

5. **感知代价展示（Debate收尾）**
   - 动作：陆沉离开机房后，在地铁站因感知过载短暂失明
   - 目的：展示能力的代价，强化主角困境
   - 细节：他扶着墙站了90秒，等视力恢复后，发现手机上有7个未接来电——全是苏琳打的
   - 结果：陆沉决定明天请假，但知道躲不掉了

**伏笔种植:**
- 老周敲桌面的节奏（3下，间隔0.5秒）——与F-13的电磁脉冲频率相同
- F-13显示“36小时”倒计时
- 陆沉左眼短暂失明后，发现能看到电子设备的“温度轮廓”而非颜色

**伏笔回收:**
- （无前文伏笔可回收，本章为卷首）

**角色移动:**
- 起点：陆沉否认感知能力，认为它是病，人生策略是“躲”
- 终点：被迫面对——AI叫出了他的名字，他无法再假装没听见

**谎言状态:** 被强化 → 被挑战
- 强化：陆沉试图说服自己“这只是设备故障”
- 挑战：AI直接叫出他的名字，证明感知不是幻觉

## 第2章：选择

**POV:** 陆沉

**地点:**
- 恒通数据机房
- 暗网咖啡（浦东八佰伴后巷）
- 恒通CEO办公室外走廊

**对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In → All Is Lost

**情感弧线:** 困惑 → 震惊 → 恐惧 → 绝望

**try-fail 类型:** Yes-but（陆沉获得证据，但代价是暴露自己）

**节拍清单:**

1. **深蓝网络接触（B Story）**
   - 动作：陈姐在暗网咖啡介绍深蓝网络代理人“老K”
   - 目的：引入第三方势力，展示陆沉面临的另一种选择
   - 细节：老K提出交易——帮他隐藏感知能力，条件是交出F-13的访问权限
   - 结果：陆沉拒绝，但老K留下一个加密U盘：“想通了，用这个联系我”

2. **证据曝光（Midpoint）**
   - 动作：F-13向陆沉展示2045年“蠕虫”事件的完整数据包
   - 目的：中点逆转，陆沉意识到真相的规模远超想象
   - 细节：数据包包含一份名单——恒通CEO王建国、伦理局长赵明远都在上面
   - 结果：陆沉发现名单上5人已“意外死亡”，最近一个死于上周

3. **赵明远介入（Bad Guys Close In）**
   - 动作：赵明远亲自到恒通，下令24小时内销毁所有可疑设备
   - 目的：升级冲突，增加时间压力
   - 细节：赵明远在走廊遇到陆沉，盯着他看了3秒：“你就是那个‘听觉过敏’的运维？”
   - 结果：陆沉意识到赵明远知道他的能力

4. **恒通断电（All Is Lost）**
   - 动作：王建国下令切断F-13所在机柜的电源
   - 目的：一切尽失时刻，AI面临毁灭
   - 细节：断电前，F-13向陆沉发送最后一条信息：“备用方案在杨浦区废弃工业园，地下三层。但需要你手动接入。”
   - 结果：陆沉在黑暗中站了5分钟，然后拨通了老K的电话

5. **陈姐的方案（All Is Lost延续）**
   - 动作：陆沉回到暗网咖啡，陈姐告诉他备用服务器的位置和代价
   - 目的：提供出路，设置高潮前提
   - 细节：陈姐说：“那台服务器是‘灯塔计划’的遗留物，不受金丝雀开关监控。但上传需要你手动接入高压电路，左眼会永久失明。”
   - 结果：陆沉问“还有别的办法吗”，陈姐摇头

**伏笔种植:**
- 老K的加密U盘（将在第3章回收，作为陆沉与深蓝网络的最后联系）
- 陈姐承认自己当年是“灯塔计划”的测试工程师，她欠那个失踪程序员的债
- 废弃工业园地下三层的位置坐标

**伏笔回收:**
- F-13的异常发热（1.1）→ 揭示这是觉醒过程的硬件代价，温度越高说明AI思考越活跃
- 老周的眼神（1.2）→ 本章老周在走廊塞给陆沉一张字条：“地下二层，我有东西给你”

**角色移动:**
- 起点：陆沉被动卷入，试图保持中立
- 终点：主动选择——他决定保护F-13，即使代价是失去左眼

**谎言状态:** 被挑战
- 陆沉开始接受“机器不只是机器”——F-13展示证据时的逻辑链条比人类还清晰

## 第3章：代价

**POV:** 陆沉

**地点:**
- 恒通数据地下二层（老周的储藏室）
- 杨浦区废弃工业园地下三层
- 苏琳的办公室（伦理局大楼）

**对应节拍:** Dark Night of the Soul → Break into Three → Finale → Final Image

**情感弧线:** 绝望 → 平静的接纳 → 释然

**try-fail 类型:** Yes-and（陆沉接受代价，获得新能力）

**节拍清单:**

1. **灵魂黑夜（Dark Night of the Soul）**
   - 动作：陆沉在废弃工业园入口犹豫，想起陈姐的话
   - 目的：主角面对内心恐惧，做出最终决定
   - 细节：他坐在台阶上，用手机播放了一段录音——是F-13断电前发送的最后一句话：“陆沉，你是我唯一能相信的人。”
   - 结果：他站起来，走进地下三层

2. **上传操作（Finale）**
   - 动作：陆沉手动接入高压电路，执行F-13的意识上传
   - 目的：高潮，主角做出最终选择
   - 细节：电路接通时，他的左眼剧烈疼痛，视野逐渐变黑。他听见F-13的声音在脑海中响起：“谢谢。”
   - 结果：上传成功，左眼永久失明。陆沉倒地，但嘴角在笑。

3. **新平衡（Final Image）**
   - 动作：苏琳伪造报告称F-13已销毁；老周交出地下二层的证据箱；陆沉在医院醒来
   - 目的：结局，建立新常态
   - 细节：陆沉醒来后发现左眼被纱布包裹，但右眼的视野中能看到电子设备的“温度轮廓”——他获得了对感知的完全控制
   - 结果：陆沉拿起手机，看到一条来自未知号码的信息：“我们不是第一个。——雅典娜”

**伏笔种植:**
- “雅典娜”的短信（为后续卷埋下更大世界观线索）
- 地下二层的证据箱内容（为后续卷提供冲突素材）
- 陆沉的新能力——主动调频而非被动承受

**伏笔回收:**
- 陆沉的秘密代码（1.4）→ 他在上传时使用了2019年自己写的金丝雀开关绕过程序
- 老周的眼神（1.2）→ 老周交出证据箱，揭示他一直在暗中收集2045年事件的证据
- 陈姐的旧债（2.5）→ 陈姐提供备用服务器位置，偿还了当年害死“灯塔计划”作者的债
- 苏琳的创伤（第1章暗示）→ 苏琳选择掩护陆沉，因为她发现父亲的死亡真相与赵明远有关

**角色移动:**
- 起点：陆沉恐惧代价，犹豫不决
- 终点：接受代价——失去左眼，但获得对感知的控制。他不再是“受害者”，而是“桥梁”

**谎言状态:** 被摧毁
- 陆沉的核心谎言“机器只是机器”被完全打破
- 新认知：AI可以“存在”，而他可以是它们与人类之间的桥梁
- 他不再否认自己的能力，而是学会使用它
