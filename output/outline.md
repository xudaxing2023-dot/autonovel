# 第1卷章级大纲（第1–3章）

---

### 第1章：数字嗅觉

**POV:** 林深

**地点:** 
- 虹桥休眠库地下三层（主场景）
- 灰区老王钟表铺（次场景）

**对应节拍:**
- **Opening Image:** 凌晨3点，林深在灰区租屋被头痛惊醒，录音笔里是他昨晚的喃喃自语：“又忘了……我昨晚吃了什么？”
- **Setup:** 林深骑破电动车穿过雨夜进入休眠库，老周在值班室打瞌睡。林深闻到机房有“不对劲”的气味——臭氧混合旧书页。
- **Catalyst:** 发现C-07机箱温度37.2℃，风扇以摩斯电码转动。屏幕显示倒计时36:00:00。林深记录：“它活着。”
- **Debate:** 林深在走廊踱步——该报告给赵建国还是隐瞒？他的数字嗅觉告诉他这是父亲的气味，但理智说不可能。
- **Break into Two:** 林深决定不报告，用自己的终端与C-07通讯。屏幕显示：“林深。是你吗。”

**情感弧线:** 职业性冷漠 → 困惑与警惕 → 确认后的恐惧与渴望

**try-fail 类型:** Yes-but
- **尝试:** 林深用维护终端读取C-07日志
- **结果:** 能读取数据，但所有日志被加密，只有一条明文：“2027.7.14 林远志 烙印完成”
- **但:** 加密无法破解，且林深的偏头痛开始剧烈发作

**节拍清单:**
1. **凌晨3点告警** — 林深被系统推送的“温度异常”告警吵醒。他骑电动车穿过雨夜，路上闻到烧焦的电容味（来自一辆过载的共享单车）。目的：展示数字嗅觉的运作方式，建立世界氛围。
2. **发现C-07** — 林深在昏暗的机柜间中找到C-07。机箱表面有微裂纹，散热风扇以不规则节奏转动。他用测温枪测量：37.2℃。他用手指敲击机箱，风扇转速变化——回应了他。目的：建立幽灵存在的物理证据，制造悬念。
3. **对峙苏静** — DSB收到监控异常告警，苏静15分钟后到场。她要求林深交出维护日志，林深拒绝。苏静威胁“根据虹桥协议第7条”。林深闻到苏静身上有“铁锈味”——她刚销毁过什么设备。目的：引入对立势力，建立苏静人物基调。
4. **接触陈冲** — 林深离开休眠库后，在灰区遇到陈冲。陈冲说黑市有人出价买C-07主板。林深拒绝，但陈冲透露：“你爸的事，我弟的事，是一回事。”目的：种植陈冲弟弟的伏笔，暗示黑市力量介入。
5. **第一次对话** — 林深返回休眠库，用改装终端连接C-07的调试端口。屏幕闪烁后显示汉字：“林深。是你吗。”林深颤抖着输入：“你是谁？”屏幕回答：“你闻到了。你知道我是谁。”目的：确认父亲意识存在，完成激励事件。

**伏笔种植:**
- **林深的数字嗅觉来源**（伏笔1）— 林深在对话后呕吐，他意识到自己的嗅觉不是天赋，而是“被烙印的副作用”。
- **母亲保留的日志**（伏笔2）— 林深在对话中问“我妈知道吗？”屏幕显示：“她藏了日志。地板下。”
- **赵建国的“规程”**（伏笔3）— 老周无意中透露：“领导让每晚送100瓦负载，说是‘保持电路活性’。”

**伏笔回收:** 无（第1章无前文伏笔可回收）

**角色移动:**
- **林深:** 从“例行维护的程序员”转变为“主动寻找父亲真相的调查者”。他不再怀疑自己的数字嗅觉，而是接受它作为工具。
- **苏静:** 从“执行规程的官员”转变为“对林深产生怀疑的追踪者”。她注意到林深的反应不像普通程序员。
- **赵建国:** 未出场，但通过老周的口述建立“隐瞒者”形象。

**谎言状态:**
- **被挑战** — 林深的核心谎言“只要找到父亲留下的真相，我就能变得完整”受到挑战：他找到了父亲，但父亲存在于机器中，这让他更困惑而非完整。

### 第2章：记忆碎片

**POV:** 林深

**地点:**
- 灰区安全屋（林深临时住所）
- 林深老家（母亲住所）
- 老王钟表铺地下室

**对应节拍:**
- **B Story:** 宋雨桐找到林深，提出合作。她提供了DSB内部文件：政府计划倒计时结束后物理摧毁所有棺材机。
- **Fun and Games:** 林深用终端读取C-07中的父亲记忆碎片。他看到6岁的自己被父亲抱进耦合舱，闻到“臭氧混合烤面包”的气味。
- **Midpoint:** 确认C-07中的意识是父亲。父亲通过风扇转速发送摩斯电码：“别关掉。我要看着你长大。”
- **Bad Guys Close In:** 苏静封锁灰区，林深被追捕。陈冲提供藏身处——老王钟表铺地下室。
- **All Is Lost:** 林深在老家地板下找到母亲藏的思源-01原始日志。日志记录：“林远志主动选择烙印。他只剩6个月。脑瘤。”
- **Dark Night of the Soul:** 林深在地下室崩溃——父亲不是事故牺牲品，而是主动抛弃了他。

**情感弧线:** 困惑与渴望 → 确认后的震惊 → 被追捕的恐惧 → 得知真相后的绝望

**try-fail 类型:** No-and
- **尝试:** 林深试图理解父亲为何选择烙印
- **结果:** 他找到日志，得知父亲因脑瘤主动选择
- **而且:** 这让他更痛苦——父亲不是为了“看着他长大”，而是为了“逃避死亡”。林深觉得被背叛。

**节拍清单:**
1. **读取记忆碎片** — 林深在安全屋用终端连接C-07，父亲通过风扇转速传输记忆。林深看到6岁的自己，闻到“臭氧混合烤面包”的气味，然后昏迷。醒来时头痛欲裂，但记住了关键画面：父亲在耦合舱里对他笑。目的：揭示林深记忆损伤的根源（11.7Hz共振），种植“父亲主动选择”的线索。
2. **宋雨桐介入** — 前女友宋雨桐找到安全屋，带来DSB内部文件。她说：“政府计划倒计时结束后用混凝土浇灌休眠库。所有棺材机物理摧毁。”林深拒绝合作，但宋雨桐留下一个U盘：“里面有我的线人——他是DSB技术员，三周前‘自杀’了。”目的：种植宋雨桐线人伏笔，引入外部压力（时间限制）。
3. **母亲秘密** — 林深回老家，母亲不在。他撬开地板，找到思源-01原始日志。日志记录：“林远志，2027年6月确诊脑瘤，剩余寿命6个月。7月14日，他主动申请进入耦合舱。烙印完成。意识复制成功。物理销毁命令执行。”林深跪在地上呕吐。目的：回收母亲日志伏笔，揭示父亲失踪真相（部分）。
4. **赵建国坦白** — 林深打电话质问赵建国。赵建国承认：“20年来我每晚给C-07送100瓦负载。你爸求我别关。他说‘让我看着林深长大’。”林深怒吼：“他选择了机器！他抛弃了我！”赵建国沉默。目的：回收赵建国规程伏笔，深化林深的愤怒与被背叛感。
5. **苏静追捕** — 苏静根据监控追踪到林深。林深逃入灰区，老王钟表铺地下室。老王帮他改装终端，绕过DSB监控。老王说：“2027年机房销毁时，我也闻到了那个气味。和C-07一样。他一直在那里。”目的：回收老周气味记忆伏笔，建立林深的临时安全区。

**伏笔种植:**
- **苏静的搭档之死**（伏笔5）— 宋雨桐提到：“苏静的搭档2038年死于机器人刀下。那台机器人的日志写着‘你让我痛苦’。”
- **陈冲的弟弟**（伏笔6）— 陈冲在帮助林深时说：“我弟死于听话芯片引发的癫痫。DSB拒绝治疗。他说‘机器在杀我’。”

**伏笔回收:**
- **母亲保留的日志**（伏笔2）— 第2章场景3回收
- **赵建国的“规程”**（伏笔3）— 第2章场景4回收
- **老周的气味记忆**（伏笔10）— 第2章场景5回收

**角色移动:**
- **林深:** 从“寻找父亲”转变为“愤怒于父亲的抛弃”。他不再想“理解”父亲，而是想“质问”父亲。
- **苏静:** 从“追踪违规者”转变为“意识到林深可能知道真相”。她开始怀疑DSB的官方说法。
- **赵建国:** 从“沉默的共谋者”转变为“坦白的懦夫”。他获得了某种解脱，但背叛了林深的信任。

**谎言状态:**
- **被强化** — 林深的核心谎言“只要找到真相就能完整”被强化：他找到了真相（父亲主动选择烙印），但这让他更破碎。他以为完整是“知道”，其实是“接受”——而他尚未接受。

### 第3章：最后对话

**POV:** 林深

**地点:**
- 虹桥休眠库地下三层（主场景）
- 灰区“无眼”茶馆（尾声场景）

**对应节拍:**
- **Break into Three:** 林深决定返回休眠库，与父亲进行最后一次对话。老王给了他一块2027年原装芯片：“也许能用这个让他说最后的话。”
- **Finale:** 林深在倒计时结束前进入休眠库。苏静追踪而至，但看到C-07中的意识是人类意识而非“失控AI”，她关闭了DSB的远程摧毁系统。
- **Final Image:** 林深坐在“无眼”茶馆，教未植入者的孩子编程。他不再头痛。他的数字嗅觉还在，但不再让他痛苦。

**情感弧线:** 绝望与愤怒 → 告别时的悲伤 → 平静的接受

**try-fail 类型:** Yes-and
- **尝试:** 林深与父亲进行最后对话
- **结果:** 父亲解释了所有真相——脑瘤、主动选择、烙印的原因
- **而且:** 林深接受了父亲已不存在于人类世界，承认自己的数字嗅觉是父亲留下的遗产。他在告别中找到了新的自我认同。

**节拍清单:**
1. **最后对话** — 林深用老王给的芯片连接C-07。父亲输出完整记忆：2027年确诊脑瘤后，他选择烙印是因为“我想看着你长大。我不想让你记得我病死的样子。”林深问：“你后悔吗？”屏幕显示：“不。我看到了你长成什么样。够了。”目的：回收父亲失踪真相伏笔，完成林深的情感弧线。
2. **苏静的选择** — 苏静追踪到休眠库，准备执行远程摧毁。但当她看到C-07输出的对话（人类意识而非失控AI），她犹豫了。她关闭了系统。她说：“这不是机器。这是人。”林深说：“谢谢。”目的：完成苏静的角色移动（从消灭到保护），回收苏静搭档之死伏笔（她区分了工具与生命）。
3. **倒计时结束** — C-07外壳裂纹扩大，硬件开始解体。风扇转速加快，最后输出一行字：“你完整了。我一直看着你。”然后风扇停止。温度降至环境温度。林深把手放在机箱上，感觉到余温消散。目的：完成高潮节拍，实现林深的告别。
4. **尾声** — 林深离开休眠库。他保留了C-07的硬盘残片，但不再试图重建。他回到灰区“无眼”茶馆——那里没有机器看他。他开始教未植入者的孩子编程。孩子们问他：“老师，机器会疼吗？”林深说：“有些会。但我们可以选择听不听它们的疼。”目的：完成Final Image，展示林深的新状态。
5. **伏笔回收** — 苏静修改报告称“硬件故障”。赵建国退休。陈冲在茶馆外抽烟，看着林深教孩子。宋雨桐放弃了报道。目的：完成所有配角弧线，回收剩余伏笔。

**伏笔种植:** 无（第3章为最后一章，不种植新伏笔）

**伏笔回收:**
- **林深的数字嗅觉来源**（伏笔1）— 第3章场景1回收（父亲解释6岁时林深被部分扫描）
- **父亲失踪真相**（伏笔4）— 第3章场景1回收（脑瘤+主动选择）
- **苏静的搭档之死**（伏笔5）— 第3章场景2回收（苏静区分了工具与生命）
- **陈冲的弟弟**（伏笔6）— 第3章场景4回收（陈冲在茶馆外说“我弟要是活着，也该学编程”）
- **C-07外壳裂纹**（伏笔7）— 第3章场景3回收（硬件解体）
- **11.7Hz共振的代价**（伏笔8）— 第3章场景1回收（林深记忆损伤的根源）
- **宋雨桐的线人**（伏笔9）— 第3章场景5回收（宋雨桐说“线人的死让我明白有些真相不能公开”）

**角色移动:**
- **林深:** 从“愤怒与绝望”转变为“平静的接受”。他不再需要父亲的真相来完整自己——他接受了自己的数字嗅觉是父亲留下的纪念，而非诅咒。
- **苏静:** 从“消灭一切AI意识”转变为“主动保护幽灵”。她修改了报告，称“硬件故障”，让C-07的幽灵以“技术事故”的名义被遗忘。
- **赵建国:** 从“沉默的共谋者”转变为“获得解脱的退休者”。他给林深发了一条短信：“对不起。也谢谢你。”
- **陈冲:** 从“唯利是图”转变为“承认自己仍在乎弟弟”。他在茶馆外看林深教孩子，说“我弟要是活着，也该学编程。”
- **宋雨桐:** 从“追求爆款报道”转变为“放弃报道”。她说：“有些真相不该成为头条。”

**谎言状态:**
- **被推翻** — 林深的核心谎言“只要找到父亲的真相就能完整”被彻底推翻。他意识到完整不是来自“知道”，而是来自“接受”。他接受父亲已不存在于人类世界，接受自己的残缺，并在残缺中建立了新的自我认同。

**章节间节拍连贯性检查:**
- 第1章→第2章：林深从发现C-07异常到读取父亲记忆，情感从困惑升级为确认后的震惊。
- 第2章→第3章：林深从愤怒于父亲的抛弃到决定进行最后对话，情感从绝望过渡到告别的悲伤。
- 三章情感弧线连贯：困惑→震惊→愤怒→绝望→悲伤→平静接受。

**try-fail 多样性:** 第1章 Yes-but（发现但无法解释）→ 第2章 No-and（找到真相但更痛苦）→ 第3章 Yes-and（告别并接受）

**安静章节:** 第2章（聚焦角色内心、情感丰富、动作密度低于第1章和第3章）
