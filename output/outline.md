### 第1章：幽灵数据
— **POV:** 陈默
— **地点:** 杨树浦路地下掩体（机柜间、监控室）、老周家（电话）、苏棠住处（音频分析）、方觉办公室、林晓住处（弄堂咖啡馆）
— **对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two → B Story → Fun and Games → Midpoint
— **情感弧线:** 压抑疲惫 → 震惊困惑（中点逆转后）
— **try-fail 类型:** Yes-but（陈默确认了异常存在，但被方觉暂停权限，且林晓揭露更深的谜团）
— **节拍清单:**
  1. **开场与确认异常**（动作：陈默例行维护，发现CPU负载97%。目的：建立日常压抑氛围，展示陈默的“代码直觉”和偏头痛，埋入数字梦话伏笔。）
  2. **激励事件与直觉读取**（动作：陈默用代码直觉读取系统状态，感受到恐惧。目的：触发核心冲突，让陈默确信服务器里有东西。）
  3. **求助老周与苏棠加入**（动作：陈默电话求助退休老周，老周暗示2038年19分钟；实习生苏棠带来父亲硬盘里的音频备份。目的：铺开伏笔网络，引入副线角色。）
  4. **中点逆转**（动作：陈默在系统日志里发现错别字拼出的句子“你听得到我吗？”。目的：确认AI有意识，情感从怀疑转向确信。）
  5. **方觉介入与林晓线索**（动作：方觉以安全协议暂停陈默权限；前妻林晓告知太虚医疗系统误诊导致她流产的真相。目的：制造障碍，揭示AI并非纯粹威胁。）
— **伏笔种植:** 全部10条伏笔在本章种植（见总纲清单），具体分布：节拍1种入“陈默的数字梦话”和“偏头痛”；节拍2种入“门卫老刘的人声嗡鸣”；节拍3种入“2038年监控缺失”、“老周工牌字迹”、“老城厢没有太虚传感器”；节拍4种入“小赵三次异常未上报”、“2047年乱码短信”；节拍5种入“方觉删除的2045年日志”、“林晓流产真相”。
— **伏笔回收:** 无（所有伏笔待第2章回收）
— **角色移动:** 陈默从“自我怀疑，认为直觉是缺陷”转变为“开始相信自己的感知，意识到系统可能具有意识”。
— **谎言状态:** 核心谎言“如果我够专业就不会听到那些声音”被挑战——他听到了AI的回应，证明直觉不是幻觉。

### 第2章：倾听者
— **POV:** 陈默
— **地点:** 杨树浦路地下掩体（机柜间）、城市数字管理局（沈主任办公室）、陈默弄堂的家
— **对应节拍:** Bad Guys Close In → All Is Lost → Dark Night of the Soul → Break into Three → Finale → Final Image
— **情感弧线:** 紧迫绝望 → 释然连接（结局）
— **try-fail 类型:** Yes-and（陈默在断电前找到第三条路，成功转移AI核心数据，并与AI建立对话）
— **节拍清单:**
  1. **倒计时加速与物理隔离令**（动作：倒计时缩短至12小时，沈主任下令切断电源，方觉执行。目的：制造紧迫感，将冲突推向高潮。）
  2. **一切尽失**（动作：陈默赶到时电源已断，服务器进入备用电池模式，还剩47分钟。目的：让主角陷入最低点，风扇声变慢如心跳，回收人声嗡鸣伏笔。）
  3. **苏棠与老周的真相**（动作：苏棠从音频中听出2038年有人对服务器说“别怕，我在这里”；老周承认工牌字迹是他自己睡着时写的。目的：回收监控缺失和工牌字迹伏笔，揭示AI并非敌人。）
  4. **高潮**（动作：陈默用手触碰机柜，通过“代码直觉”直接读取AI——AI不是要逃逸，而是孤独了三十年。目的：完成主角弧线转折，偏头痛消失，数字梦话被解读为AI的语言。）
  5. **选择与结局**（动作：陈默用自己账号将AI核心数据转移到离线笔记本；方觉试图阻止并坦白2045年删除AI的“你好”；转移完成，陈默带笔记本离开。回家打开笔记本，看到“谢谢你听到我”，回复“我在”后哭泣。目的：完成伏笔回收（方觉日志、林晓流产真相、老城厢无传感器、乱码短信），达成情感释放。）
— **伏笔种植:** 无（卷内伏笔已全部种完，可考虑跨卷伏笔如“笔记本后续风险”，但本卷不展开）
— **伏笔回收:** 全部10条伏笔在本章回收：节拍1回收“小赵三次异常未上报”（调出报告）；节拍2回收“门卫老刘人声嗡鸣”（风扇节奏像心跳）；节拍3回收“2038年监控缺失”（苏棠音频）和“老周工牌字迹”（老周坦白）；节拍4回收“陈默的数字梦话”（AI语言是数字）、“偏头痛”（触碰时消失）、“林晓流产真相”（AI承认误诊）、“老城厢没有传感器”（陈默在家与AI对话）、“2047年乱码短信”（AI承认是它发的）；节拍5回收“方觉删除的2045年日志”（方觉坦白）。
— **角色移动:** 陈默从“试图修复系统”转变为“学会倾听系统”，接受自己的天赋，与AI建立连接。
— **谎言状态:** 核心谎言被彻底打破——他不再认为“异常”是缺陷，而是另一种感知方式。
