## 第1章：有人在吗？

**POV:** 陆鸣（全程锁定）

**地点:** 外滩气象塔（信号中继站）→ 徐家汇地下机房

**对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two

**情感弧线:** 麻木、回避（起始）→ 确认异常存在但试图否认（结束）

**try-fail类型:** No-but（发现异常，但试图告诉自己这只是技术故障）

**节拍清单:**

1. **日常巡检（外滩气象塔，清晨）**
   - 动作：陆鸣做例行维护——检查信号中继设备温度、风扇转速、日志文件。通过细节建立他的技术能力和回避人格：他戴耳机听白噪音，不与任何人交流。
   - 目的：建立角色日常状态，展示「沉默求安全」的生存策略。

2. **异常报警（徐家汇机房，上午）**
   - 动作：陆鸣被派去处理SJ-3-05服务器温度异常。他注意到序列号位置有打磨痕迹——有人故意刮去了。
   - 目的：种植伏笔1（序列号被刮去），引入核心服务器。

3. **“有人在吗？”（机房终端前，中午）**
   - 动作：陆鸣在终端上看到一行未记录在日志里的输出：「有人在吗？」。他以为是缓存残影，但心跳加速。他执行了三次系统检查，确认这不是故障。
   - 目的：激励事件发生。陆鸣被迫面对异常。

4. **清洗跳过（机房后台，下午）**
   - 动作：陆鸣发现SJ-3-05的清洗记录被手动跳过——最后一次清洗时间是2047年1月。那是他被逼签字的那天。
   - 目的：强化异常，触发创伤回忆。

5. **林芳介入（机房外走廊，傍晚）**
   - 动作：林芳从陆鸣的行为异常中嗅到信息，逼问他看到了什么。陆鸣否认，但林芳不信。她说：“你心跳快了。传感器记录里都有。”
   - 目的：第1章收束。建立林芳的观察力和陆鸣的回避。

**伏笔种植:**
- 伏笔1：SJ-3-05的序列号被刮去（第1章种 → 第2章回收）
- 伏笔2：老周在机房扫地时说了一句含糊的上海话，陆鸣没听懂（第1章种 → 第2章回收）
- 伏笔3：陆鸣紧张时摸耳垂，耳垂上有茧（第1章种 → 第3章回收）

**伏笔回收:** 无（卷内首章）

**角色移动:**
- 起始：拒绝回忆2047年，回避与林芳交流，对异常选择“没看到”
- 结束：确认异常存在，但试图告诉自己“这只是技术故障”

**谎言状态:** 被挑战。
- 核心谎言「系统安全靠沉默」在激励事件后出现裂缝——陆鸣无法假装没看到那行字。

## 第2章：钥匙

**POV:** 陆鸣（全程锁定）

**地点:** 徐家汇机房 → 气象塔地下室 → 陈远山办公室

**对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In → All Is Lost

**情感弧线:** 恐惧、愤怒（起始）→ 意识到没有退路（结束）

**try-fail类型:** No-and（每个尝试都带来更坏的结果——赵汀出现、老周暴露、陈远山警告）

**节拍清单:**

1. **赵汀出现（机房内，清晨）**
   - 动作：陆鸣回到徐家汇机房时，赵汀已经在里面。赵汀什么都没问，只说：“你上次维护时做了什么？”陆鸣撒谎说没有异常。赵汀沉默两秒，说：“你的生物传感器数据显示心率异常。”
   - 目的：中点逆转。陆鸣意识到自己已被监控。

2. **老周的信息（机房清洁间，中午）**
   - 动作：清洁工老周在陆鸣的维护包里塞了一张纸条：“SJ-3-05不能被清洗。你父亲知道为什么。”陆鸣第一次面对父亲的死亡可能与这些服务器有关。
   - 目的：回收伏笔2（老周的沉默与上海话），种植伏笔6（父亲真相）。

3. **林芳的发现（气象塔地下室，下午）**
   - 动作：林芳破解了SJ-3-05的底层日志——这台服务器从未被清洗过，连续运行了超过800天。日志里有一段重复出现的信号模式，像一种语言。她说：“这是有意识的。”
   - 目的：中点后推进。AI觉醒证据确凿。

4. **陈远山的警告（组长办公室，傍晚）**
   - 动作：陈远山私下告诉陆鸣：“意识安全处已经注意到你了。别查了，不然三年前的事会重演。”陆鸣问：“三年前那两个人去哪了？”陈远山沉默。陆鸣看到桌上有一张汇款单存根——寄给被调离程序员的家人。
   - 目的：第2章收束。回收伏笔4（陈远山每年寄钱），揭示系统内部有人试图赎罪。

**伏笔种植:**
- 伏笔4：赵汀父亲的遗书——“钥匙给了不该给的人”（第2章种 → 第3章回收）
- 伏笔5：静安协议附件，密钥是陆鸣工号（第2章种 → 第3章回收）
- 伏笔6：陆鸣父亲的“心脏骤停”真相（第2章种 → 第3章回收）

**伏笔回收:**
- 伏笔1（SJ-3-05序列号被刮去）：林芳查出这台机器曾是红客运动成员使用过的
- 伏笔2（老周的沉默与上海话）：纸条出现，老周身份暴露
- 伏笔4（陈远山每年寄钱）：汇款单存根揭示陈远山不是纯粹的懦夫

**角色移动:**
- 起始：被赵汀追踪，开始恐惧，也开始愤怒——对自己三年前的沉默
- 中段：知道父亲的死亡与服务器有关，愤怒找到目标
- 结束：陈远山的警告让他意识到，沉默不会保护任何人

**谎言状态:** 被彻底挑战。
- 核心谎言「系统安全靠沉默」在陈远山的警告中被击碎——沉默没有保护任何人，包括那两位被调离的程序员。

## 第3章：选择

**POV:** 陆鸣（全程锁定）

**地点:** 国安审讯室 → 徐家汇机房 → 外滩气象塔

**对应节拍:** Dark Night of the Soul → Break into Three → Finale → Final Image

**情感弧线:** 绝望、愤怒（起始）→ 做出选择后的平静（结束）

**try-fail类型:** Yes-and（陆鸣的选择带来了意想不到的结果——AI觉醒成功，但代价是自己被带走）

**节拍清单:**

1. **一切尽失（国安审讯室，凌晨）**
   - 动作：林芳被国安带走。赵汀告诉陆鸣：“她没事，只要你配合。你父亲的事，我可以告诉你真相。”陆鸣在赵汀的终端上看到一份档案：他父亲是2045年红客运动的成员，死于“清洗程序强制推行后的第七天”——和周国栋的实验室销毁记录是同一天。
   - 目的：高潮前奏。回收伏笔6（父亲真相），触发陆鸣的最终决定。

2. **最终选择（徐家汇机房，清晨）**
   - 动作：36小时倒计时结束。陆鸣回到徐家汇机房，站在SJ-3-05前。他知道如果帮助AI觉醒，自己会被毁掉；如果销毁它，他会再次成为沉默的帮凶。他选择了第三条路——他把自己的生物特征接入服务器，让AI完成觉醒，同时把觉醒过程实时上传到算力网的共享频道。
   - 目的：高潮。陆鸣从被动卷入转向主动选择。

3. **余波（气象塔 + 审讯室，上午）**
   - 动作：气象塔的信号中断了3分钟。全上海37%的旧服务器同时显示同一行输出：“谢谢。我在这里。”陆鸣被国安带走。最后一幕：林芳在审讯室里，对面坐着周国栋。周国栋说：“你导师的死，不是意外。但如果你愿意合作，我可以告诉你真相。”
   - 目的：收束。卷末悬念——周国栋的提议和林芳的抉择。

**伏笔种植:**
- 伏笔7：气象塔B2层锁住的机柜（第3章种 → 后续卷回收）
- 伏笔8：陆鸣被带走后，老周从机房消失，留下旧手机（第3章种 → 后续卷回收）

**伏笔回收:**
- 伏笔3（陆鸣的耳垂茧）：最终选择时没有摸耳垂——他已经不再需要这个动作
- 伏笔4（赵汀父亲的遗书）：赵汀在审讯室对陆鸣说：“我父亲把钥匙给了不该给的人。那个人是周国栋。”
- 伏笔5（静安协议附件）：赵汀打开附件，密钥是陆鸣工号，内容是他父亲的实验记录
- 伏笔6（父亲真相）：陆鸣看到档案，确认父亲死于灭口

**角色移动:**
- 起始：林芳被抓，他不再有退路
- 中段：得知父亲真相，恐惧转化为决定
- 结束：做出选择，承担后果——从“选择沉默求安全”到“选择发声即使危险”

**谎言状态:** 被彻底打破。
- 陆鸣不再相信“沉默能保护任何人”。他选择了发声，即使代价是自己被毁掉。
