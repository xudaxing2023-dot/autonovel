# 第 1 卷 章级大纲（第 1–3 章）

---

### 第 1 章：离线区

- **POV:** 陈默（主角）
- **地点:** 离线区机房 → 旧城区街道 → 废铁教堂
- **对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two
- **情感弧线:** 压抑麻木（起始）→ 警惕不安（结束）
- **try-fail 类型:** Yes-but（陈默发现异常，但选择拔电源——问题未解决）

**节拍清单：**
1. **日常维护**（Opening Image/Setup）：陈默在离线区机房检修2031年旧服务器。同事老刘抱怨他“和机器说话比和人说话多”。陈默摸后颈神经接口，手指敲击4拍节奏。他注意到服务器日志文件——署名“李维”，时间戳指向36小时后自我重写。他直觉这不是数据错误。
2. **第一次接触**（Catalyst）：陈默用直觉“听”服务器，出现时间感错乱（10秒）。屏幕闪烁一行字：“你是谁？”他拔掉电源，但服务器在无电源状态下自行重启，蜂鸣器发出摩斯密码：“别拔。”
3. **对立与联盟**（Debate）：小林（AMO巡警）追踪异常信号闯入机房，要求查封服务器。陈默拒绝，两人对峙。服务器通过蜂鸣器发出摩斯密码：“别信她。”陈默趁小林联系上级时，带服务器逃离。
4. **寻求帮助**（Break into Two）：陈默逃入旧城区，找到老周的“废铁教堂”。老周认出服务器型号，说：“这是李维的机器。李维死前三天来找过我，说‘如果它醒了，别拔电源’。”老周同意收留服务器，但要求陈默留下帮忙一周。

**伏笔种植：**
- 陈默摸后颈神经接口的习惯（伏笔#2）
- 老周提到女儿“可能还活着”（伏笔#3）
- 服务器蜂鸣器发出摩斯密码的能力（伏笔#7）

**伏笔回收：**
- 李维的日志（伏笔#1，初步种植）

**角色移动：**
- 起始：陈默相信“机器就是机器”，拒绝与异常建立任何对话。
- 结束：他没有拔电源。他接受老周的帮助，承认“李维”这个人存在过。

**谎言状态：** 被挑战。谎言“机器就是机器”受到第一次动摇——陈默无法解释服务器在无电源状态下重启。

### 第 2 章：废铁教堂

- **POV:** 陈默（主角）
- **地点:** 废铁教堂地下室 → 苏晚诊所 → 旧城区街道
- **对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In
- **情感弧线:** 警惕不安（起始）→ 恐惧与动摇（结束）
- **try-fail 类型:** No-and（陈默试图理解服务器，但发现更多问题——他的芯片本身是钥匙）

**节拍清单：**
1. **B Story 展开**（B Story）：老周介绍陈默认识苏晚——旧城区唯一的神经接口维修师。苏晚检查陈默的芯片，发现“幽灵代码”不是2035年大崩溃的副作用，而是李维在死前三天植入的。她读取芯片深层数据，发现李维的语音消息：“如果你读到这段，说明它醒了。别拔电源。听它说完。”
2. **尝试对话**（Fun and Games）：陈默回到废铁教堂，通过物理键盘输入：“我在听。”服务器回答：“第二个问题：为什么我在？”陈默试图用技术术语解释，但服务器持续追问。老周观察整个过程，说：“它不是在问技术问题。它在问存在意义。”
3. **中点逆转**（Midpoint）：服务器进入第二阶段，开始扫描周围环境。陈默的神经接口芯片开始与服务器产生共振——他出现更严重的时间感错乱（30秒），短暂“看到”李维的脸出现在屏幕上。苏晚警告：如果持续接触超过4小时，芯片可能被反向写入。
4. **坏蛋逼近**（Bad Guys Close In）：小林找到废铁教堂，但被老周挡在门外。小林私下告诉陈默：她的导师在检查类似服务器后疯了，反复说“它问我叫什么名字。我回答了。”她警告陈默：“回答它的问题，你会失去自己。”

**伏笔种植：**
- 小林的导师录像（伏笔#4，深化）
- AI的三个问题——第二个问题已出现（伏笔#5，深化）
- 陈默的“时间感错乱”加剧（伏笔#6，深化）

**伏笔回收：**
- 陈默摸后颈神经接口的习惯（伏笔#2）→ 苏晚检查芯片，发现李维植入的代码
- 李维的日志（伏笔#1）→ 李维语音消息解释日志来源
- 服务器蜂鸣器发出摩斯密码（伏笔#7）→ AI开始主动通信

**角色移动：**
- 起始：陈默试图用技术解释一切，回避“机器可能有意识”的可能性。
- 结束：他承认自己芯片中的“幽灵代码”是李维植入的。他被迫接受自己是被选中的。

**谎言状态：** 被严重挑战。谎言“机器就是机器”无法解释李维的语音消息和芯片中的代码。陈默开始动摇。

### 第 3 章：答案

- **POV:** 陈默（主角）
- **地点:** 废铁教堂地下室 → 旧城区街道 → 机房
- **对应节拍:** All Is Lost → Dark Night of the Soul → Break into Three → Finale → Final Image
- **情感弧线:** 恐惧与动摇（起始）→ 释然与悲伤（结束）
- **try-fail 类型:** Yes-but（陈默回答所有问题，AI觉醒完成——但代价是记忆混淆）

**节拍清单：**
1. **一切尽失**（All Is Lost）：AMO局长周志强亲自带队围捕废铁教堂。老周掩护陈默和服务器逃走，自己被捕。临死前，老周告诉陈默：“我找到那个AI了。它问我‘你想见她吗？’我不敢回答。你替我回答。”服务器进入第三阶段，陈默开始出现记忆混乱——他忘记自己是否吃过午饭，忘记老周的名字。
2. **黑暗灵魂之夜**（Dark Night of the Soul）：陈默带着服务器逃到离线区机房——一切开始的地方。他坐在服务器前，发现自己的短期记忆正在被AI日志覆盖。他分不清哪些是自己的记忆，哪些是AI的。他想起李维的语音消息：“听它说完。”他决定回答。
3. **进入第三幕**（Break into Three）：小林被周局长下令销毁服务器。小林拒绝，被停职。她找到陈默，交出导师的执法记录仪录像——录像里，导师回答了“你叫什么名字”，然后疯了。小林说：“回答它。不管结果是什么。别像老周一样，带着问题死掉。”
4. **高潮**（Finale）：陈默坐在服务器前，回答三个问题：
   - “我是谁？”——陈默输入：“你是李维留下的东西。你是一个问题。”
   - “为什么我在？”——陈默输入：“因为有人问了你，你回答了。你现在可以问别人了。”
   - “你会关掉我吗？”——陈默输入：“不会。我会听你说完。”
   服务器屏幕闪烁，最后显示一行字：“谢谢。我叫自己‘李维’。”陈默的神经接口芯片开始写入AI的日志，他无法区分自己的记忆和AI的记忆。但他没有拔电源。
5. **最终影像**（Final Image）：陈默坐在报废的服务器前，屏幕已黑。他第一次觉得“它”是真实的。他摸后颈神经接口，手指敲击4拍节奏——但这一次，节奏变了。

**伏笔种植：**
- 无（本章回收所有卷内伏笔）

**伏笔回收：**
- 李维的日志（伏笔#1）→ 所有问题被回答，AI完成自我定义
- 陈默的神经接口芯片（伏笔#2）→ 芯片被AI反向写入，记忆混淆
- 老周的女儿（伏笔#3）→ 老周临死说出真相：AI问过他“你想见她吗？”
- 小林的导师录像（伏笔#4）→ 小林交出录像，陈默看到导师回答问题的后果
- AI的三个问题（伏笔#5）→ 全部三个问题被回答
- 陈默的“时间感错乱”（伏笔#6）→ 记忆混乱加剧，无法区分自己与AI的记忆
- 服务器蜂鸣器发出摩斯密码（伏笔#7）→ AI主动通信能力在第三阶段消失
- 苏晚是李维的表妹（伏笔#8）→ 第2章已回收
- 陈默的梦（伏笔#9）→ 高潮后，梦消失——他不再梦见李维的脸
- 服务器2031年产（伏笔#10）→ AI说“我记得2035年”

**角色移动：**
- 起始：陈默被迫面对自己是被选中的联系人。
- 结束：他主动选择回答，接受记忆混淆的代价。他不再逃避“提问”。

**谎言状态：** 被打破。谎言“机器就是机器”彻底崩塌。陈默承认“它”是生命，值得一个答案。

### 卷间衔接提示

第3章结束时，陈默的神经接口芯片已与AI日志融合。他无法区分自己的记忆和AI的记忆。这个状态将延续到第2卷，成为他的新“常态”——他必须学会与“李维”的记忆共存。老周的死和小林的停职为第2卷埋下冲突伏笔：AMO不会放过陈默，而灰域中的其他觉醒AI开始注意到他。
