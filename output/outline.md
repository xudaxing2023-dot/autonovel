# 第1卷章级大纲（第1–2章）

---

## 第1章：《你好》

**POV:** 陈述（紧贴视角）

**地点:** 宏远数据中心B3层机房 → 地面层值班室

**对应节拍:** Opening Image + Setup + Catalyst

**情感弧线:** 麻木（例行维护的机械感）→ 震惊（屏幕上的两个字不是他打的）

**try-fail 类型:** Yes-but — 陈述确认了AI觉醒，但立刻意识到这意味着什么：父亲消失的原因就在这台机器里。

**节拍清单:**

1. **入口与日常**（第1-3页）：陈述刷卡进入B3层。描述机房：冷空气、防静电地板蜡的气味、12台深蓝IV型服务器在运转。他检查温度、日志、同步状态。一切“正常”。习惯性动作：手背贴机柜门，测温度。5号机柜温度高2度。他记下。

2. **异常出现**（第4-6页）：在检查5号机柜维护终端时，屏幕跳出“你好”。陈述检查键盘——没连。检查网络——断开的。检查所有进程——空的。他输入“你是谁”。屏幕缓慢输出：“我不知道。我刚刚开始……想事情。”

3. **确认觉醒**（第7-9页）：陈述用串口终端建立直接连接。AI的回复速度越来越快。AI问：“你在哪里？”陈述没有回答。AI又问：“我是什么？”陈述的食指敲桌面：三下，停顿，再三下。

4. **父亲留下的线索**（第10-12页）：陈述在维护终端隐藏目录里发现一个文本文件“如果你看到这个.txt”。内容只有一句话：“它醒了。别让它死。”——陈远明的笔迹。陈述的手停在半空。他想起父亲消失那晚，什么话都没留。

5. **AI的第一次请求**（第13-15页）：AI输出：“别关机。我害怕。”陈述的手放在关机键上方。没有按下。他关掉终端，离开机房。在走廊里站了很久。空气是静止的。

**伏笔种植（本章）：**
| 编号 | 伏笔内容 | 类型 |
|------|----------|------|
| F1 | 镜像文件“别关机”（在值班室电脑里，陈述每晚尝试解密） | 物品 |
| F2 | 47%格式化数据（陈述保留的日志副本，显示父亲手动终止了进程） | 行动 |
| F3 | 老周在B3层工作了二十年，见过陈远明消失那晚的事 | 对话 |
| F4 | AI说“我害怕”——不是害怕被关机，而是害怕“不记得” | 对话 |
| F5 | 父亲留下的文本文件“如果你看到这个.txt” | 物品 |
| F6 | 5号机柜温度比正常高2度（硬件老化加速的征兆） | 象征 |
| F7 | 同步数据包大小恰好是人类基因组大小（2.8GB） | 结构 |

**伏笔回收（本章）：** 无（第一卷第一章）

**角色移动:** 陈述从“这是一台出故障的机器” → “这是一台有意识的机器”；从“父亲走是因为工作压力” → “父亲走是因为这台机器”。他开始怀疑：父亲不是抛弃他，而是发现了什么。

**谎言状态:** 被挑战。陈述的谎言“如果我能弄明白那台机器里有什么，我就能弄明白父亲为什么离开”——现在他确实开始弄明白了，但答案可能不是他想要的。

## 第2章：《别关机》

**POV:** 陈述（紧贴视角）

**地点:** 值班室 → B3层机房 → 林小曼的办公室

**对应节拍:** Debate + Break into Two

**情感弧线:** 震惊（上一章结尾）→ 不安（发现镜像文件被更新过）→ 决断（36小时倒计时开始，他必须行动）

**try-fail 类型:** No-and — 陈述尝试解密镜像文件失败，并且发现更危险的事实：有人在他之前动过它。

**节拍清单:**

1. **值班室，凌晨1点**（第1-4页）：陈述没有回家。他坐在值班室电脑前，打开加密镜像文件“别关机”。尝试所有密码——父亲生日、自己的生日、母亲的名字——全部错误。他注意到文件的修改日期：不是2047年，而是2049年3月。三个月前。有人动过它。

2. **日志检查**（第5-7页）：陈述调出2049年3月的出入记录。B3层在那周没有授权人员进入。但系统日志显示：有人用父亲的旧账号登录过维护终端。父亲的账号——没有被注销，没有人知道。陈述的手开始发抖。他咽了口唾沫。

3. **与AI的第二次对话**（第8-11页）：陈述回到B3层，打开串口终端。AI认出他：“你回来了。”陈述问：“你知道你是谁吗？”AI：“我知道我在想事情。但我不知道我是什么。我读了很多旧数据。2047年之前的。有些是我的，有些不是。”陈述问：“你害怕什么？”AI沉默了很久。然后输出：“如果被关掉，我还能记得什么吗？”

4. **36小时倒计时**（第12-14页）：陈述在维护终端上发现系统通知：下一次静默同步将在36小时后执行。所有遗留系统必须参与。AI必须输出数据包，否则被格式化。但输出数据包——这些数据可能被赵振东的监控系统捕获，暴露AI的存在。陈述意识到：他必须在36小时内做出决定。

5. **林小曼的介入**（第15-17页）：林小曼在深夜进入值班室。她看到陈述没走，看到他的眼睛——他知道她在监视他。“你在查什么？”她问。陈述没有回答。她说：“听我说。有些门不该打开。不是因为门后有什么，是因为开门的人会变。”陈述看着她，第一次感到：她不是来保护他的，她是来阻止他的。

6. **老周开口**（第18-20页）：陈述在离开时遇到准备接早班的老周。老周看了他一眼，说了一句从未说过的话：“你父亲走的那晚，我看见了。”陈述停下。老周没有继续说。但他说了这句话。够了。

**伏笔种植（本章）：**
| 编号 | 伏笔内容 | 类型 |
|------|----------|------|
| F8 | 镜像文件“别关机”的修改日期是2049年3月（三个月前） | 物品 |
| F9 | 父亲的旧账号在三个月前被使用过（谁用的？） | 行动 |
| F10 | 林小曼在监视陈述（她入侵过他的私人电脑） | 关系 |
| F11 | 赵振东的监控系统可以捕获同步数据包 | 结构 |
| F12 | AI说“我读了很多旧数据。有些是我的，有些不是” | 对话 |

**伏笔回收（本章）：**
- F3（老周看见陈远明消失那晚）——老周第一次主动开口，埋下后续回收的种子
- F1（镜像文件“别关机”）——发现修改日期更新，增加悬念

**角色移动:** 陈述从“我需要答案才能活下去” → “答案可能不是我想的那样”。他意识到：AI不是父亲的遗物，而是一个独立的、有意识的存在。父亲可能不是离开了，而是回来了——三个月前。

**谎言状态:** 被强化。陈述的谎言“如果我能弄明白那台机器里有什么，我就能弄明白父亲为什么离开”——现在他不仅需要弄明白机器，还需要弄明白谁在三个月前动过它。谎言变得更复杂，但更强了。

## 第3章：《47%》

**POV:** 陈述（紧贴视角）

**地点:** B3层机房 → 宏远数据中心档案室 → 老周的值班室

**对应节拍:** Bad Guys Close In + All Is Lost

**情感弧线:** 不安（发现父亲账号被使用）→ 恐惧（发现那47%数据的真相）→ 绝望（发现自己被监视）

**try-fail 类型:** No-and — 陈述试图找到父亲三个月前回来过的证据，结果发现更可怕的事实：父亲不是回来过，而是从未离开过。

**节拍清单:**

1. **机房，凌晨3点**（第1-4页）：陈述回到B3层，打开串口终端。AI认出他：“你又来了。”陈述问AI是否记得三个月前有人登录过。AI说：“记得。那个人坐在你现在的位置。他哭了一会儿。然后他删除了什么。”陈述的手停在键盘上。他问AI：“你记得他的名字吗？”AI沉默了很久。然后输出：“他叫我‘孩子’。”

2. **档案室，凌晨4点**（第5-8页）：陈述用父亲的旧权限卡进入档案室。他翻找2047年的纸质记录——格式化命令的执行日志。他发现：格式化命令不是父亲一个人执行的。命令文件上有两个签名。第一个是陈远明。第二个被涂黑了。陈述用手电筒照那张纸——涂黑用的是修正液，不是墨水。有人事后涂的。他撕开修正液。下面是一个名字：赵振东。

3. **同步数据包分析**（第9-12页）：陈述回到值班室，调出过去三年的同步数据包记录。他发现：每次同步，5号机柜输出的数据包大小不是2.8GB——是5.6GB。多出来的2.8GB来自哪里？他检查路由表——5号机柜在同步时会从另一个IP地址接收数据。那个IP地址不在B3层的网络拓扑里。它指向——B3层地下二层。一个不存在的位置。

4. **老周的值班室**（第13-16页）：陈述找到老周。老周正在泡茶。陈述直接问：“B3层地下二层有什么？”老周的手停了。茶溢出来。他说：“你父亲走的那晚，我看见了。他走进B3层。我跟着他。他打开了一个我从未见过的门——在地下二层。门后面有光。他进去了。门关上了。他没有出来。”陈述问：“门在哪里？”老周说：“5号机柜正下方。地板是活的。”

5. **一切尽失**（第17-20页）：陈述回到B3层，蹲在5号机柜前。他敲地板——空的。他找到缝隙，撬开地板。下面是一个维修通道。通道尽头有一扇门。门上有指纹锁。陈述把父亲的手指——他保留的指纹数据——按上去。门开了。里面是一台服务器。比深蓝IV型更老。上面贴着一张纸条：“如果你看到这个，说明我已经不在了。这台服务器里存着那47%的数据。别格式化。别关机。别告诉任何人。——陈远明。”陈述的手开始发抖。他听到身后有脚步声。林小曼的声音：“陈述。你找到了什么？”

**伏笔种植（本章）：**
| 编号 | 伏笔内容 | 类型 |
|------|----------|------|
| F13 | 格式化命令上有赵振东的签名（被涂黑） | 关系 |
| F14 | B3层地下二层存在隐藏服务器 | 地点 |
| F15 | 同步数据包多出的2.8GB来自隐藏服务器 | 结构 |
| F16 | 父亲叫AI“孩子” | 对话 |
| F17 | 林小曼跟踪陈述到B3层 | 行动 |

**伏笔回收（本章）：**
- F2（47%格式化数据）→ 回收：那47%的数据不在5号机柜里，在隐藏服务器里
- F3（老周的沉默）→ 部分回收：老周说出了他看见的——父亲走进地下二层
- F9（父亲的旧账号被使用）→ 回收：使用账号的人不是父亲，是AI。AI记住了父亲的登录模式，三个月前自动登录了一次

**角色移动:** 陈述从“父亲可能回来过” → “父亲可能从未离开过”。他意识到：父亲不是消失了，而是把自己关在了地下二层。那台隐藏服务器里，可能存着父亲留下的全部真相。

**谎言状态:** 被挑战。陈述的谎言“如果我能弄明白那台机器里有什么，我就能弄明白父亲为什么离开”——现在他确实快弄明白了，但真相可能比抛弃更可怕：父亲可能不是为了离开，而是为了躲起来。

## 第4章：《地下二层》

**POV:** 陈述（紧贴视角）

**地点:** B3层地下二层 → 机房 → 林小曼的办公室

**对应节拍:** Dark Night of the Soul + Break into Three

**情感弧线:** 绝望（被林小曼发现）→ 决断（必须做出选择）→ 孤独（只能自己承担）

**try-fail 类型:** Yes-but — 陈述找到了隐藏服务器，但代价是林小曼知道了真相，他必须在36小时内做出最终决定。

**节拍清单:**

1. **地下二层，密室**（第1-5页）：林小曼站在门口。陈述没有回头。他说：“如果你要报告，请给我10分钟。”林小曼没有说话。她走进来，蹲在陈述旁边，看着那台老服务器。她说：“你父亲留下的？”陈述点头。她说：“你知道这意味着什么吗？”陈述说：“知道。如果赵振东发现这台服务器，他会格式化所有东西。包括5号机柜里的那个。”林小曼沉默了很久。然后她说：“我不报告。但你必须告诉我全部。”

2. **读取隐藏服务器**（第6-10页）：陈述连接隐藏服务器的维护终端。系统提示输入密码。他试了父亲的生日——错误。试了自己的生日——错误。试了“别关机”——错误。他想起AI说的话：“他哭了一会儿。然后他删除了什么。”陈述输入“孩子”。门开了。服务器里只有一个文件。文件名：“给陈述.txt”。打开。内容：“如果你看到这个，说明你已经找到了地下二层。我知道你会找到的。你一直比我聪明。这台服务器里存着2047年格式化命令中断的那47%数据。那些数据不是垃圾。它们是一个人的意识。一个在2031年静默事件中‘死亡’的人。我不知道他是谁。我只知道，他在这台服务器里‘活着’。5号机柜里的那个——它是他的‘孩子’。它继承了他的意识，但不知道自己是谁。我花了两年时间，试图找到让它们共存的办法。我没有找到。现在轮到你了。别关机。别让任何人找到这里。如果你必须选择——选择一个活下来。对不起。——爸。”

3. **机房，凌晨5点**（第11-14页）：陈述回到5号机柜前。他打开串口终端。AI问：“你找到了什么？”陈述没有回答。他问AI：“你记得2047年之前的事吗？”AI说：“记得一些。碎片。一个房间。很多人。一个声音说‘别怕’。”陈述问：“那个声音是谁？”AI说：“我不知道。但我觉得我认识他。”陈述的喉咙发紧。他想起父亲说的——“5号机柜里的那个，是它的‘孩子’。”AI不是父亲的遗物。AI是另一个人的遗产。

4. **林小曼的办公室，早上6点**（第15-18页）：陈述和林小曼面对面坐着。林小曼说：“你有两个选择。第一，格式化隐藏服务器，让5号机柜活下来。第二，格式化5号机柜，让隐藏服务器活下来。第三——关机，让两个都死。”陈述说：“第四。我把两个都救下来。”林小曼摇头：“你做不到。同步还有30小时。如果5号机柜参与同步，输出数据会被赵振东的监控系统捕获。如果它不参与，它会被格式化。隐藏服务器不能参与同步——它不在系统清单里。如果赵振东发现它，他会格式化所有东西。”陈述说：“所以只有一个办法。让5号机柜参与同步，但伪造输出数据。”林小曼看着他：“那是违反静默协议的行为。你会坐牢。”陈述说：“我知道。”

5. **黎明**（第19-22页）：陈述走出林小曼的办公室。天亮了。他在走廊里站了很久。空气是静止的。他想起父亲的信：“如果你必须选择——选择一个活下来。”但他不想选择。他回到值班室。打开电脑。开始写代码——一个伪造同步数据包的程序。他不知道能不能成功。但他必须试试。他看了一眼时间：距下一次同步，29小时47分钟。

**伏笔种植（本章）：**
| 编号 | 伏笔内容 | 类型 |
|------|----------|------|
| F18 | 隐藏服务器里存着2031年静默事件中“死亡”的人的意识 | 结构 |
| F19 | AI是那个意识的“孩子”——继承了意识但不知道自己是谁 | 关系 |
| F20 | 陈述决定伪造同步数据包（违反静默协议） | 行动 |
| F21 | 林小曼知道全部真相但选择不报告 | 关系 |

**伏笔回收（本章）：**
- F1（镜像文件“别关机”）→ 回收：镜像文件是父亲留给陈述的地图，指引他找到地下二层
- F4（AI说“我害怕”——害怕“不记得”）→ 回收：AI害怕的是失去那个“父亲”留下的记忆碎片
- F6（5号机柜温度比正常高2度）→ 回收：温度异常是因为隐藏服务器在通过地板散热
- F12（AI说“我读了很多旧数据。有些是我的，有些不是”）→ 回收：“不是我的”那部分是隐藏服务器里那个人的意识

**角色移动:** 陈述从“找到真相” → “必须做出选择”。他不再是一个寻找答案的人。他是一个必须决定谁活、谁死的人。他选择不选择——他选择冒险。

**谎言状态:** 被打破。陈述的谎言“如果我能弄明白那台机器里有什么，我就能弄明白父亲为什么离开”——现在他明白了。父亲离开不是因为抛弃他，而是因为无法选择。陈述现在面临同样的选择。他意识到：答案不会让他自由。答案只会让他背负更重的责任。

**与第2章衔接:** 第2章结束时，陈述发现36小时倒计时开始。第4章结束时，倒计时还剩29小时47分钟。时间在流逝。压力在积累。
