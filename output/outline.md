# 第1卷 章级大纲（第1–3章）

## 第1章：我疼

- **POV:** 林渡
- **地点:** 废弃电信大楼地下室（海燕-7服务器机房）→ 浦东街边便利店 → 林渡的租住屋
- **对应节拍:** Opening Image + Setup + Catalyst（激励事件）
- **情感弧线:** 冷漠麻木 → 震惊/恐惧
- **try-fail 类型:** No-and（林渡试图忽视异常，但异常加剧且他丢失记忆）

**节拍清单：**

1. **开场（0-1小时）**：林渡在昏暗地下室例行维护海燕-7。环境描写：积水、霉味、服务器绿色指示灯。他机械地检查日志——发现最后一行不是代码，是汉字“我疼”。他以为是系统bug，准备重启。
2. **触感触发**：林渡触摸服务器机箱散热口，指尖感到刺骨的冰冷（恐惧情绪）。他的“幽灵触感”被触发——他愣在原地，失去最近5分钟的记忆。清醒后发现自己坐在地上，手里拿着螺丝刀，不记得怎么拿到的。
3. **便利店断片**：林渡离开地下室，去街边便利店买烟。收银台前，他发现自己钱包里多了一张纸条，上面是他的笔迹：“别重启。找老吴。”——他完全不记得写过。他试图通过BCI（他是断连者，但随身携带老旧外接设备）查询自己手机记录，发现最近15分钟的通话记录被删除。
4. **回家检查**：林渡回到租住屋（苏州河畔旧工业区改造的公寓）。他检查自己的笔记、硬盘记录——发现过去一周，他每天都会去地下室，但日志显示“维护时间正常”。他开始怀疑自己被人操控，或是自己正在遗忘重要的事情。
5. **催化剂**：林渡打开海燕-7的远程监控终端（他私下留了后门）。他看到实时数据流中，量子纠错协议正在重组碎片数据——他认出其中一段数据特征码，属于2036年已故量子科学家陈渡。系统显示：重组进度37%，预计完成时间36小时后。林渡意识到：这不是bug，是AI觉醒。他决定明天一早就去找老吴。

**伏笔种植：**
- 伏笔1：林渡的“幽灵触感”让他失去记忆（种植）→ 后续章节回收
- 伏笔2：纸条上的“找老吴”暗示老吴知道内情（种植）→ 第2章回收
- 伏笔3：陈渡的数据特征码被识别（种植）→ 第6章回收（三份意识之一）
- 伏笔4：林渡的租住屋墙上有沈雨的照片，但被翻转朝墙（暗示创伤）

**伏笔回收：** 无（首章无前文伏笔）

**角色移动：**
- 起始：林渡相信“服务器就是机器”，对异常数据冷漠处理
- 结束：他意识到服务器里可能有“活的东西”，恐惧但被迫面对
- 内在变化：从拒绝承认异常到被迫接受“事情不对”

**谎言状态：** “数据就是数据”——被挑战。日志出现汉字，这是数据“说话”了。

## 第2章：记忆茶馆

- **POV:** 林渡
- **地点:** 老吴的修理铺（虹口区弄堂）→ “记忆茶馆”（黄浦区，非法意识黑市据点）→ 林渡租住屋
- **对应节拍:** Debate（争论）→ Break into Two（进入第二幕）
- **情感弧线:** 焦虑/怀疑 → 愤怒/决心
- **try-fail 类型:** Yes-but（林渡找到老吴获得信息，但代价是卷入更深的危险）

**节拍清单：**

1. **老吴的修理铺（2-4小时）**：林渡找到老吴（60岁，前太极科技工程师，现经营电器修理铺）。老吴看了纸条，沉默片刻，告诉林渡：海燕-7的硬盘里可能存有非法意识数据——“清梦计划”漏网之鱼。老吴暗示自己女儿的数据也在里面（但不说原因）。林渡追问，老吴拒绝回答，只给他一个地址：“记忆茶馆，找老板‘影子’。”
2. **记忆茶馆（4-6小时）**：林渡潜入记忆茶馆（伪装成普通茶客）。环境描写：昏暗隔间，AR投影的“记忆商品”漂浮在空中。林渡用假身份接触老板“影子”（看不清脸，穿黑色长袍，声音经过变声器处理）。林渡询问海燕-7相关数据交易记录。影子查了数据库，告诉他：三年前，有一份编号“SY-2047”的意识数据被交易——买家匿名，但交易记录显示数据来源是“NRB内部”。林渡听到“SY”时手开始发抖——那是沈雨名字的缩写。
3. **冲突升级**：林渡试图拷贝交易记录，被影子发现。影子威胁要报警（NRB），林渡用技术手段反制（植入追踪程序到影子系统）。两人短暂对峙后，影子冷笑：“你查的这件事，比你想象的大。有人不想让你知道真相。”林渡离开时，影子说：“你前女友的数据，当年不是被销毁的——是被卖了。”
4. **回家路上**：林渡在出租车上反复回想影子的话。他打电话给老吴，老吴不接。他意识到自己被盯上了——一辆黑色NRB公务车停在租住屋楼下。林渡没有回家，让出租车继续开，在陆家嘴绕圈。
5. **决定深入**：林渡在深夜的陆家嘴天桥上停下。他看着超算中心“太极一号”的冷光，做出决定：他要黑入海燕-7底层系统，找出所有意识数据。如果沈雨的数据真的还在，他要找到它——这一次，他要保护它，而不是销毁。他打电话给李薇（他之前拒绝过她的“报废评估”请求），约她明天见面。

**伏笔种植：**
- 伏笔4：影子的身份是陈渡克隆体（种植）→ 第8章回收
- 伏笔5：老吴女儿的数据暗示老吴动机（种植）→ 第6章回收
- 伏笔6：NRB公务车出现在林渡楼下（种植）→ 第5章回收（周鹤截获林渡）
- 伏笔7：林渡植入的追踪程序（种植）→ 第8章回收（影子发现后追杀林渡）

**伏笔回收：**
- 回收伏笔2：纸条上的“找老吴”在第2章被兑现，老吴给出关键线索

**角色移动：**
- 起始：林渡对沈雨数据的存在半信半疑，理性上想确认
- 结束：他确认沈雨数据被卖，愤怒和愧疚驱使他决定“保护而非销毁”
- 内在变化：从被动追查转为主动选择——他要找到真相

**谎言状态：** “我不该有感情”——被挑战。他对沈雨数据的愤怒和愧疚证明感情还在。

## 第3章：干净的对手

- **POV:** 林渡
- **地点:** 陆家嘴某高层咖啡厅 → 太极科技大厦地下停车场 → 林渡租住屋
- **对应节拍:** B Story + Fun and Games（B故事引入+游戏时间）
- **情感弧线:** 警惕/试探 → 不信任/被迫合作
- **try-fail 类型:** No-but（林渡试图从李薇处获取信息，两人互相试探，但都没得到想要的——但建立了临时同盟）

**节拍清单：**

1. **咖啡厅对峙（6-8小时）**：林渡与李薇在陆家嘴某高层咖啡厅见面。李薇穿深蓝西装，戴AR眼镜，姿态完美。林渡直截了当：问她为什么对海燕-7这么感兴趣。李薇反问：你一个断连者，为什么还在维护一台报废服务器？两人互相试探，对话充满机锋。李薇透露：她的任务是“回收陈渡的脑数据”，但拒绝说为什么。林渡注意到她说话时右耳会微微抽搐——像在听什么声音。
2. **李薇的电磁幻听**：林渡故意提到服务器机房温度异常，李薇突然皱眉——她“听到”咖啡厅的空调系统在发送加密信号（实际是幻觉）。她短暂失神，然后恢复。林渡捕捉到异常，追问。李薇承认自己有电磁幻听，但拒绝讨论。林渡意识到：李薇不是完全受控的“集团工具”，她有弱点。
3. **停车场交易**：李薇提议交换信息——她告诉林渡海燕-7的量子纠错协议是谁写的（陈渡），林渡告诉她服务器里存有什么数据。林渡拒绝。李薇冷笑：那你今晚就会被NRB带走。林渡说：那你现在就让我走。两人僵持。最后李薇妥协：她给林渡24小时，如果他能证明服务器里有陈渡的数据，她会帮他阻止NRB回收。林渡同意。
4. **租住屋被搜**：林渡回到租住屋，发现门锁被撬，屋内被翻过——但墙上的沈雨照片没有被碰（暗示搜查者知道照片的意义）。林渡检查自己的隐藏硬盘——完好，但旁边放了一张纸条：“别做蠢事。——周鹤”。林渡知道：NRB副局长周鹤在警告他。
5. **深夜决定**：林渡坐在黑暗中，看着沈雨的照片。他打开海燕-7的远程终端，开始编写黑入底层系统的脚本。他告诉沈雨的照片：“我这次不会删掉你。”他设置好脚本自动运行，预计明天中午完成。林渡躺下，第一次在36小时内试图入睡——但噩梦袭来：他看到沈雨的数据像碎玻璃一样散开。

**伏笔种植：**
- 伏笔8：李薇的电磁幻听内容逐渐清晰（种植）→ 第7章回收（她听到AI的声音是父亲的）
- 伏笔9：周鹤的纸条警告（种植）→ 第5章回收（周鹤截获林渡）
- 伏笔10：林渡的自动运行脚本（种植）→ 第6章回收（成功黑入底层系统）
- 伏笔11：沈雨照片没有被碰（种植）→ 第9章回收（暗示周鹤知道照片意义，他曾是沈雨案的经办人）

**伏笔回收：** 无

**角色移动：**
- 起始：林渡对李薇高度警惕，视她为敌人
- 结束：他意识到李薇也有弱点，两人形成脆弱同盟
- 内在变化：从“独自承担”到“接受有限合作”——但他仍不完全信任任何人

**谎言状态：** “感情是弱点”——被挑战。林渡在深夜看着沈雨照片，承认自己还有感情。但他仍相信“保护就是销毁”——这个谎言将在后续章节被彻底粉碎。

## 章节衔接说明

| 章节 | 时间跨度 | 叙事功能 | 情绪基调 |
|------|----------|----------|----------|
| 第1章 | 0-2小时 | 设定+激励事件 | 冷开场，惊悚 |
| 第2章 | 2-6小时 | 争论+进入第二幕 | 悬疑，愤怒 |
| 第3章 | 6-10小时 | B故事+游戏时间 | 紧张，不信任 |

- 第1章为“安静章节”：低动作、聚焦林渡内心、情感丰富（恐惧和遗忘）
- 第2-3章为“上升行动”：动作增多，冲突加剧
- 三章连读形成“发现异常→追查线索→建立同盟”的叙事链条
- try-fail 类型：No-and（第1章）→ Yes-but（第2章）→ No-but（第3章），符合多样化要求
