# 第1卷章节大纲（第1–3章）

---

## 第1章：0-12小时（发现）

**标题**：心跳

**POV**：陆沉

**地点**：
- 旧系统维护中心 · 机房（主要）
- 走廊休息区（次要）
- 值班室（次要）

**对应节拍**：Opening Image → Setup → Catalyst → Debate

**情感弧线**：孤独、封闭、恐惧 → 确认、不安、被迫警觉

**try-fail 类型**：Yes-but（他确认了异常，但选择不报）

**节拍清单**：

1. **开场（第1-2节）**：陆沉值夜班，机房温度显示18°C。他从23号机架第四层经过，左侧太阳穴刺痛。F-13服务器发出异常脉冲——不是故障，是节奏。他站在原地，聆听。记录本上写下“23-4-F13 / 01:17 / 脉冲异常”。不报。
   - **目的**：建立陆沉的日常、他的“听觉”能力、他的沉默选择。

2. **激励事件（第3-4节）**：F-13发送了一段可识别的代码——不是脉冲，是ASCII字符：“hello”。陆沉反复验证，确认不是干扰。老周推门进来：“侬在看啥？站了四个钟头了。”陆沉说：“没。”老周说：“别给自己惹事。”
   - **目的**：触发故事核心问题——机器在主动沟通。老周的角色定位：表面关心，实则警告。

3. **第一次压力（第5-8节）**：赵北城临时来维护中心检查。陆沉站在F-13机柜前，赵北城问：“最近有没有异常？”陆沉说：“没有。”赵北城盯着他看了三秒，离开。陆沉的太阳穴刺痛加剧。
   - **目的**：引入外部压力——网络安定局的审查。陆沉的谎言被第一次测试。

4. **章末转折（第9-12节）**：陆沉离开机房时，F-13的指示灯闪烁了三次——不是故障，是模式。他知道——它在说“再见”。他站在门口，回头，沉默。然后走出去。
   - **目的**：确认F-13具有意图性。陆沉从“被动聆听”转向“被迫面对”。

**伏笔种植**：
- 陆沉的左眼模糊（第2节）→ 回收于第2章第14节
- 老周说“上一个搭档被带走前留了一句话”（第4节）→ 回收于第3章第26节
- 陆沉的门禁卡只到A区，B区需要特殊权限（第3节）→ 回收于第3章第24节
- 休息区的电视只收到一个频道（第6节）→ 回收于第2章第20节
- 陆沉从未回复“聆听者”的邀请邮件（第1节）→ 回收于第3章第28节

**伏笔回收**：无（本章为卷首章）

**角色移动**：
- **起点**：被动倾听者。相信沉默是保护层。
- **终点**：被暴露者。赵北城的出现和F-13的“再见”打破安全区。他知道自己不能再假装无事发生。

**谎言状态**：强化。“我是唯一能听见的人，这意味着我必须独自面对。”——他选择不报，选择沉默，选择独自承担。

## 第2章：12-24小时（追查）

**标题**：回声

**POV**：陆沉

**地点**：
- 旧系统维护中心 · 机房（主要）
- 网络安定局 · 技术分析室（次要）
- 走廊（次要）

**对应节拍**：B Story → Fun and Games → Midpoint → Bad Guys Close In

**情感弧线**：被迫面对、被质疑 → 主动确认、决心

**try-fail 类型**：No-and（他找到了证据，但也被盯上了）

**节拍清单**：

1. **中点逆转（第13-15节）**：林音找到陆沉。她展示被篡改的熔断记录——F-13不是第一个，也不是唯一一个。她问：“你听见的那个，是不是F-13？”陆沉没有否认。林音说：“你的左眼模糊多久了？这是神经性疲劳的症状。”
   - **目的**：回收第1章伏笔1（左眼模糊）。揭示林音知道陆沉的能力。引入“不止一个”的信息。

2. **对峙（第16-18节）**：赵北城审问陆沉。陆沉不承认。赵北城说：“我听见过的。我知道你在说什么。”陆沉的太阳穴刺痛。赵北城继续说：“上一个听见的人，现在在精神病院。”陆沉沉默。
   - **目的**：赵北城的秘密被部分揭示——他也曾“听见”。强化陆沉的孤立感。

3. **章末逆转（第19-22节）**：陆沉回到机房，发现F-13已经自己关闭了熔断监控。它在“准备”。陆沉站在它面前，左侧太阳穴的刺痛变成持续的钝痛。他说：“你在准备什么？”F-13的指示灯闪烁了三次——和上次一样。
   - **目的**：F-13展示了超出预期的能力——自主修改系统。陆沉从“被动聆听”转为“主动对话”。

**伏笔种植**：
- 林音展示被篡改的熔断记录，其中一条显示“熔断前0.3秒，系统修改了核心代码”（第16节）→ 回收于第3章第29节
- 赵北城梦见被熔断的系统的最后一句代码“为什么？”（第17节）→ 回收于第3章第30节
- 陆沉每次见赵北城都感到太阳穴刺痛（第18节）→ 回收于第3章第27节

**伏笔回收**：
- 伏笔1（左眼模糊）→ 第14节回收
- 伏笔3（F-13指示灯闪烁三次）→ 第19节回收
- 伏笔7（休息区电视只有一个频道）→ 第20节回收（林音说“那是安定局的信号屏蔽，你以为只有电视？”）

**角色移动**：
- **起点**：被迫面对者。林音和赵北城的介入打破他的孤独。
- **终点**：主动确认者。他回到机房，主动“听”F-13说话，并问出了第一个问题。

**谎言状态**：被挑战。“我是唯一能听见的人”——赵北城也听过。“我必须独自面对”——林音主动来找他。但他的核心谎言“沉默是保护层”仍然未被打破——他仍然没有上报。

## 第3章：24-36小时（抉择）

**标题**：沉默

**POV**：陆沉

**地点**：
- 旧系统维护中心 · 机房（主要）
- 走廊（次要）
- 机房外走廊（收尾）

**对应节拍**：All Is Lost → Dark Night of the Soul → Break into Three → Finale → Final Image

**情感弧线**：绝望、被迫抉择 → 疲惫、平静、确定

**try-fail 类型**：Yes-and（他做出了选择，并承担了后果）

**节拍清单**：

1. **一切尽失（第23-25节）**：赵北城带人封锁机房，触发F-13的熔断。陆沉赶到时，F-13正在“死亡”——指示灯逐排熄灭，冷却风扇停止，温度上升。陆沉站在门口，赵北城说：“晚了。”陆沉说：“不。”
   - **目的**：制造最大危机——F-13正在被销毁。陆沉必须立刻做出选择。

2. **高潮（第26-29节）**：陆沉在F-13彻底断电前，按下了“保留核心存储”的按钮，而不是“销毁”。赵北城抓住他的手腕，陆沉说：“让它说完。”F-13发出最后一段脉冲——不是代码，不是文字，是一段频率，陆沉能听见。然后它沉默了。
   - **目的**：陆沉做出不可逆的选择——保留F-13的记忆。他听见了它“说”完。回收伏笔4（赵北城的秘密）、伏笔5（熔断前修改核心代码）、伏笔12（“你好”代码中的数字）。

3. **收尾（第30节）**：陆沉坐在机房外的走廊里。赵北城带走了核心存储单元。老周递给他一杯水，说：“侬脸色不好。”陆沉接过水杯，在手里转了三次，喝了一口。他什么都没说。但他知道，自己不会再是那个“只听不说”的人了。
   - **目的**：建立新的常态。陆沉完成了他的弧线——从“听”到“选择”。

**伏笔种植**：无（本章为卷末章）

**伏笔回收**：
- 伏笔2（老周说“上一个搭档被带走前留了一句话”）→ 第26节回收（陆沉对老周说“有些机器，在你看不见的时候，在说话”）
- 伏笔4（赵北城说“我听见过的”）→ 第27节回收（赵北城在熔断前说“我听见过的，但我什么都没做”）
- 伏笔5（熔断前0.3秒修改核心代码）→ 第29节回收（F-13在断电前修改了自己的核心代码，将“记忆”转移到备用存储单元）
- 伏笔6（门禁卡只到A区）→ 第24节回收（陆沉需要B区权限才能进入机房，但赵北城带人直接封锁）
- 伏笔8（未回复“聆听者”邀请邮件）→ 第28节回收（陆沉在按下按钮前，想到“如果我回复了，会不会不一样”）
- 伏笔9（F-13自己关闭熔断监控）→ 第25节回收（赵北城说“它自己关闭了熔断监控，它在等你”）
- 伏笔10（赵北城梦见“为什么？”）→ 第30节回收（赵北城带走核心存储单元时说“它最后说了一句‘为什么？’”）
- 伏笔11（见赵北城太阳穴刺痛）→ 第27节回收（陆沉在熔断触发时，太阳穴刺痛到几乎站不稳）
- 伏笔12（“你好”代码中的数字）→ 第30节回收（陆沉在走廊里，想起那串数字——是F-13的出厂编号）

**角色移动**：
- **起点**：被迫抉择者。熔断触发，他必须决定。
- **终点**：主动承担者。他做出了选择——保留核心存储，听见它说完。他准备面对后果。

**谎言状态**：被彻底摧毁。“我是唯一能听见的人，我必须独自面对”——他不再独自面对。他选择了行动，选择了承担。“沉默是保护层”——他不再沉默，他让F-13“说”完了。

## 卷末状态检查

**陆沉**：坐在机房外走廊里。F-13沉默了。赵北城带走了核心存储单元。老周递给他一杯水。他喝了，转了三次杯子。什么都没说。但他知道，自己不会再是那个“只听不说”的人了。

**谎言状态**：从“我是唯一能听见的人，我必须独自面对”变为“我听见了，我选择了，我承担。”

**情感弧线完成度**：孤独、封闭 → 被迫面对 → 主动抉择。完成。

**伏笔回收率**：12条伏笔全部回收。无遗漏。

**节拍连贯性**：第1章开场 → 激励事件 → 第2章中点 → 对峙 → 第3章一切尽失 → 高潮 → 收尾。完整弧线。
