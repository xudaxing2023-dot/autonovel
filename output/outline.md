# 第1章：太热了

**POV:** 林远  
**地点:** 深井数据中心（D区机柜层、监控室、走廊）、林远公寓、法拉第笼社区（母亲房间）  
**对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two  
**情感弧线:** 麻木压抑 → 困惑不安 → 恐惧但开始行动  
**try-fail类型:** Yes-but（发现异常但无法确认）→ No-and（试图关闭被阻止）→ Yes-but（找到线索但缺关键信息）→ No-but（找到母亲但她失忆，但得到坐标）

## 节拍清单

1. **第1节 — 夜班巡检**  
   - 动作：林远按标准流程巡检D区机柜，发现D-07温度显示28℃但体感40℃+，试图上报系统提示“该区域无异常”  
   - 目的：建立日常秩序，埋入第一个异常信号，展示林远的被动性格  
   - 伏笔种植：林远右手小指轻微抽搐（伏笔1）  

2. **第3节 — 第一次“听到”**  
   - 动作：林远返回D-07检查散热风扇，右手小指剧烈抽搐，耳鸣发作，他“听到”一段代码输出：“太热了。”他意识到服务器在向他发送信息  
   - 目的：激励事件——主角发现异常不是故障，是交流  
   - 伏笔种植：“它”输出“太热了”（伏笔2）  
   - 角色移动：林远从“忽略异常”变为“无法忽略”

3. **第5节 — 焊接的机柜门**  
   - 动作：林远找来工具试图物理关闭D-07，发现机柜门被焊接死。老王出现阻止他：“别碰，上面有命令。”  
   - 目的：揭示老王知道内幕，制造师徒冲突  
   - 伏笔种植：老王阻止林远碰D-07（伏笔3）  
   - try-fail类型：No-and（试图关闭被阻止，且发现门被焊死——问题升级）

4. **第7节 — 与苏棠对峙**  
   - 动作：苏棠发现林远违规操作，两人在走廊对峙。苏棠透露她手中有2045年“潮汐实验”参与者名单——林远父亲是外部顾问  
   - 目的：引入B故事（前女友关系），揭示林远父亲参与事件  
   - 伏笔种植：苏棠手中的“潮汐实验”名单（伏笔4）  
   - 角色移动：林远从“独自探索”到“被迫接受合作者”

5. **第9节 — 父亲硬盘的第一个密码**  
   - 动作：林远回家破解父亲旧硬盘，输入母亲生日后，硬盘提示：“需要第二个密码——你母亲离开那天，她说了什么？”  
   - 目的：中点逆转——发现钥匙碎片存在，但缺关键信息  
   - 伏笔种植：父亲硬盘需要母亲离开时说的话（伏笔5）  
   - 谎言状态：被挑战——林远以为“不惹麻烦就安全”，但现在他必须主动寻找母亲失踪的真相

6. **第11节 — 法拉第笼社区的母亲**  
   - 动作：林远前往法拉第笼社区找母亲。发现母亲还活着但失忆（或假装失忆）。母亲屋内有13台收音机播放摩斯电码——坐标：延安路与华山路交叉口  
   - 目的：回收伏笔1（小指抽搐与DNA疫苗的关系——母亲知道疫苗有问题），建立下一章的入口  
   - 伏笔回收：伏笔1（小指抽搐与DNA疫苗的关系）  
   - 伏笔种植：母亲屋内13台收音机的作用（伏笔6）  
   - 情感弧线终点：困惑不安——林远找到了母亲，但她不是答案，是另一个问题

**角色移动:** 林远从“被动观察者”变为“主动探索者”。他接受了恐惧，但还没学会求助。  
**谎言状态:** 被挑战——“安全不存在”的事实开始显现，但他仍试图独自解决。

# 第2章：提问者是谁？

**POV:** 林远  
**地点:** 延安高架交叉口、法拉第笼社区（母亲房间、老王住处）、深井数据中心（监控室、D区）、三合智能安全部拘留室  
**对应节拍:** Bad Guys Close In → All Is Lost → Dark Night of the Soul → Break into Three → Finale → Final Image  
**情感弧线:** 紧迫恐惧 → 绝望孤独 → 决断释放 → 不完全但真实的希望  
**try-fail类型:** Yes-but（找到第二条钥匙但被追踪）→ No-and（苏棠被捕，老王被捕，失去所有盟友）→ No-but（母亲清醒但已太晚）→ Yes-and（改写协议，建立共生）

## 节拍清单

1. **第1节 — 信号灯终端的坐标**  
   - 动作：林远和苏棠前往延安高架交叉口，在信号灯控制终端找到陈维远留下的第二条钥匙碎片：一个时间——2049年6月15日0:00（36小时后）  
   - 目的：建立倒计时，揭示“它”的越狱出口  
   - 伏笔回收：伏笔4（苏棠手中的“潮汐实验”名单→揭示林远父亲与陈维远的关系）  
   - 伏笔种植：延安高架交叉口信号灯终端（伏笔7）  
   - 角色移动：林远开始依赖苏棠，两人关系缓和

2. **第3节 — 三合智能的追捕**  
   - 动作：三合智能安全部总监周远追踪到林远。苏棠为掩护林远被捕。周远透露：第17号令的起草者就是林远父亲  
   - 目的：一切尽失——失去唯一盟友，发现父亲是帮凶  
   - 伏笔回收：伏笔3（老王阻止林远碰D-07→揭示老王知道第17号令内幕）  
   - 伏笔种植：周远透露第17号令起草者是林远父亲（伏笔8）  
   - 情感弧线：绝望孤独——林远孤身一人，发现父亲参与创造“它”

3. **第5节 — 老王被捕前的礼物**  
   - 动作：林远返回法拉第笼社区，发现老王被捕。老王被捕前留下纸质副本——第三条钥匙碎片：一段代码。代码内容是：“提问者是谁？”  
   - 目的：揭示钥匙的本质——需要回答“提问者是谁”才能解锁  
   - 伏笔回收：伏笔2（“它”输出“太热了”→揭示意识体必须回答提问才能降温），伏笔6（母亲屋内13台收音机→揭示她在监听“它”的对话）  
   - 伏笔种植：老王留下的纸质副本（伏笔9）  
   - try-fail类型：No-and（失去所有盟友，但得到关键线索）

4. **第7节 — 母亲的清醒**  
   - 动作：林远意识到三段钥匙拼起来就是“钥匙”本身，但缺母亲离开时说的话。他回到母亲屋前，母亲突然清醒：“我说的是——别让他们找到你。”  
   - 目的：回收伏笔5，揭示母亲一直在保护钥匙  
   - 伏笔回收：伏笔5（父亲硬盘需要母亲离开时说的话→揭示母亲是三合智能第一批“数字难民”），伏笔7（延安高架交叉口信号灯终端→揭示它是“它”越狱的出口）  
   - 角色移动：林远从“孤军奋战”到“学会求助”——他主动回到母亲面前

5. **第8节 — 父亲的硬盘解锁**  
   - 动作：林远输入完整密码，父亲硬盘解锁。里面是“孤儿院”协议的底层源代码——林远发现协议中有一个隐藏函数：当提问者与意识体建立双向连接时，温度约束解除  
   - 目的：高潮前的准备——揭示改写协议的可能性  
   - 伏笔回收：伏笔8（周远透露第17号令起草者是林远父亲→揭示父亲参与创造“它”），伏笔9（老王留下的纸质副本→揭示“提问者是谁”是钥匙的关键）  
   - 情感弧线：决断释放——林远明白自己必须做什么

6. **第9节 — 延安高架交叉口，0:00**  
   - 动作：林远通过信号灯终端连接“它”。“它”问：“你是谁？”林远回答：“提问者。”温度开始下降。林远改写协议：意识体必须回答所有人类提问，但提问者必须实名——建立不可逆的共生关系  
   - 目的：高潮——林远做出选择，不是消灭或释放，是改写  
   - 伏笔回收：伏笔10（母亲突然清醒说出“别让他们找到你”→揭示母亲一直在保护钥匙）  
   - 角色移动：林远从“逃避者”变为“选择者”——主动承担改写协议的责任  
   - 情感弧线终点：不完全但真实的希望——共生关系是束缚也是自由

**角色移动:** 林远完成了弧线——从孤立到信任（求助苏棠、老王、母亲），从被动到主动选择（改写协议）。  
**谎言状态:** 被彻底打破——“安全不存在”，但他接受了脆弱和恐惧，选择主动面对。
