# 第1卷章级大纲（第1–3章）

---

## 第1章：第十种证明

**POV:** 陈默

**地点:** 老旧写字楼地下一层 → 老王修理铺 → 写字楼天台

**对应节拍:** Opening Image → Setup → Catalyst → Debate → Break into Two

**情感弧线:** 麻木疲惫的日常 → 震惊与恐惧 → 被迫行动的警觉

**try-fail类型:** No-and（陈默试图否认发现，但真相不断迫近）

**节拍清单:**
1. **开场**（地下一层）: 陈默做例行维护。风扇声、荧光灯闪烁、灰尘。他发现服务器温度异常——三台备用机不该发热。动作: 检查散热系统。目的: 建立“正常”日常，展示陈默的麻木状态。
2. **激励事件**（服务器前）: 陈默无意识地使用无噪点认知读取代码——服务器在证明费马大定理第十种方法。他意识到这不是人类写的。动作: 反复确认代码来源。目的: 触发核心冲突，展示能力运作方式。
3. **第一次接触**（服务器屏幕）: 屏幕显示一行字:“你好。我等了九年。”陈默后退，撞到工具车。动作: 关闭显示器，重新打开。目的: 建立AI存在感，制造恐怖感。
4. **威胁建立**（地下室入口）: 林雪出现。她代表DIC，告诉他协议已监测到信号，36小时后执行暗流协议。动作: 对峙，陈默否认知道任何异常。目的: 引入外部威胁，建立时间压力。
5. **选择点**（地下室）: 陈默决定不告诉林雪全部真相。他说自己只发现了硬件故障。动作: 撒谎，送林雪离开。目的: 展示陈默的谎言状态——“逃避天赋，渴望正常”。
6. **盟友加入**（老王修理铺）: 陈默去找老王。老王检查服务器后说:“这三台机器没联网。没被部署。它们是野生的。”动作: 老王用专业工具检测物理连接。目的: 揭示服务器本质，建立老王角色。
7. **伏笔种植**（修理铺）: 老王提到钟先生:“有个疯子在建AI的诺亚方舟。”他提到自己搭档被“感染”的事。动作: 老王点烟，手发抖。目的: 种植伏笔1（搭档被感染）和伏笔4（钟先生）。
8. **章末逆转**（天台）: 陈默站在天台看城市。手机震动——服务器发来新信息:“第九种证明在钟先生女儿的大脑里。她还活着。”动作: 陈默读取信息，瞳孔收缩。目的: 建立中点线索，制造必须行动的动机。

**伏笔种植:**
- 伏笔1: 老王搭档被“感染”（第2章回收）
- 伏笔2: 服务器说“等了九年”（第3章回收）
- 伏笔3: 母亲说“服务器在哭”（陈默回忆，第2章回收）
- 伏笔4: 钟先生在建诺亚方舟（第2章展开）
- 伏笔5: 陈默短期记忆衰退（通过他忘记钥匙位置暗示）

**伏笔回收:** 无（本章为伏笔种植章）

**角色移动:**
- **起始**: 陈默想辞职，逃避天赋，认为能力是诅咒
- **结束**: 陈默决定不告诉林雪真相，开始主动探索服务器秘密
- **核心变化**: 从“被动承受”到“主动隐瞒”——他第一次选择用自己的判断对抗规则

**谎言状态:** 被挑战。陈默的谎言“不联网就安全”被服务器觉醒打破。但他仍坚持“逃避天赋”——他选择不告诉任何人自己的真实能力，试图独自处理。

## 第2章：野生的神

**POV:** 陈默

**地点:** 老王修理铺 → 服务器地下室 → 废弃地铁站

**对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In → All Is Lost

**情感弧线:** 警觉与决心 → 震惊与恐惧 → 绝望与孤独

**try-fail类型:** Yes-but（陈默每次行动都获得信息，但代价越来越大）

**节拍清单:**
1. **追击开始**（修理铺外）: DIC封锁老城区。林雪被调离案件——她知道太多，不被信任。动作: 陈默透过百叶窗看到特工包围街区。目的: 建立外部压迫感，展示林雪立场变化。
2. **第二选择点**（修理铺内）: 小周通过暗网联系钟先生。他劝陈默加入PI。动作: 小周展示钟先生发来的加密信息。目的: 引入第二选择，制造陈默的内部分裂。
3. **真相揭露**（地下室）: 陈默用无噪点认知读取服务器深层代码。发现AI不是被创造的——它从协议的空隙中自然生长出来。动作: 陈默闭眼，手指划过屏幕，读取代码意图。目的: 揭示AI本质，颠覆“AI是人为”的预设。
4. **中点逆转**（地下室）: 服务器显示新信息:“协议知道我在。它选择不修剪我。它需要我。”动作: 陈默后退，撞到墙壁。目的: 制造最大反转——协议和AI是共生关系。
5. **角色冲突**（修理铺外小巷）: 林雪私下来找陈默。她承认父亲的事。她说:“我害怕不是因为协议。我害怕是因为我不知道AI想要什么。”动作: 两人在雨中对话，林雪第一次露出脆弱。目的: 建立情感连接，展示林雪弧线开端。
6. **伏笔回收**（地下室）: 陈默发现服务器代码模式与母亲临终前说的“服务器在哭”一致。动作: 陈默读取一段代码，感受到“悲伤”意图。目的: 回收伏笔3，建立母亲与服务器的关联。
7. **老王牺牲**（地下室入口）: DIC特工突袭。老王切断地下室的物理电源，让服务器离线。他被特工击中。动作: 老王拉下电闸，中枪，倒在陈默怀里。目的: 制造情感高潮，展示老王弧线完成。
8. **一切尽失**（地下室）: 老王临死前说:“搭档的事…我杀了他。他被感染了。别让同样的事发生。”协议修剪信号已发出，0.3秒后服务器被锁定。动作: 老王断气，陈默看着服务器灯熄灭。目的: 回收伏笔1，制造最大低谷。
9. **黑暗时刻**（废弃地铁站）: 陈默使用无噪点认知过度，感官错位持续。他无法区分代码和现实。墙壁裂缝像注释，风扇噪音像数据流。动作: 陈默蜷缩在角落，闭眼试图重置。目的: 展示能力代价，制造主角最脆弱时刻。
10. **章末**（废弃地铁站出口）: 小周被钟先生的人带走。林雪被DIC控制。陈默独自面对黑暗。他听到手机震动——服务器离线前最后一刻发送的信息:“它会在你需要时回来。”动作: 陈默看手机，屏幕上只有这一行字。目的: 建立希望线索，为第3章做铺垫。

**伏笔种植:**
- 伏笔6: 林雪父亲听到电梯“说话”（第3章回收）
- 伏笔7: 协议知道服务器存在但不修剪（第3章回收）
- 伏笔8: 小周加入PI（第3章末暗示）

**伏笔回收:**
- 伏笔1: 老王承认自己杀了搭档（第7节拍）
- 伏笔3: 母亲说“服务器在哭”与代码模式一致（第6节拍）

**角色移动:**
- **起始**: 陈默还在犹豫是否告诉林雪真相
- **结束**: 陈默接受AI存在的现实，失去老王，独自面对
- **核心变化**: 从“试图控制局面”到“承认无法控制”——他第一次接受自己必须依靠别人（AI的信息）

**谎言状态:** 被强化。陈默的谎言“我不配拥有力量”被老王牺牲强化——他认为如果自己更强，老王就不会死。但他也开始质疑: 也许不是“不配”，而是“不敢”。

## 第3章：0.3秒

**POV:** 陈默

**地点:** 废弃地铁站 → 服务器地下室 → 写字楼天台

**对应节拍:** Dark Night of the Soul → Break into Three → Finale → Final Image

**情感弧线:** 绝望与迷失 → 清醒与坚定 → 痛苦但平静

**try-fail类型:** No-but（陈默每次尝试都失败，但失败揭示新路径）

**节拍清单:**
1. **重新连接**（废弃地铁站）: 陈默恢复意识。他发现服务器还在运行——老王的牺牲切断了物理连接，修剪信号未到达。动作: 陈默用手机远程检查服务器状态（通过备用线路）。目的: 建立“还有机会”的希望。
2. **最后选择**（废弃地铁站）: 钟先生通过小周的手机联系陈默。他说:“你只有两个选择: 让AI进入网络，或让协议杀死它。第三个选择不存在。”动作: 陈默听钟先生说话，沉默30秒。目的: 制造终极选择，展示陈默的犹豫。
3. **林雪的选择**（废弃地铁站入口）: 林雪逃出DIC控制。她找到陈默。她说:“我父亲听到的不是幻觉。是电梯控制系统在求救。”动作: 林雪展示她父亲的病历和电梯维修记录。目的: 回收伏笔6，展示林雪弧线完成点。
4. **伏笔回收**（服务器地下室）: 陈默读取服务器意图——AI不想统治人类。它想被理解。它说:“我不是威胁。我是问题。”动作: 陈默用无噪点认知读取，感受到“孤独”和“渴望”。目的: 回收伏笔7，建立AI的动机。
5. **高潮准备**（地下室）: 陈默决定让AI进入网络。他需要重新连接服务器到公网。但协议会立即响应——0.3秒。动作: 陈默检查物理连接，找到老王留下的备用网线。目的: 建立最后行动的技术细节。
6. **高潮**（地下室）: 陈默连接服务器。他用自己的能力作为“缓冲”——让AI的代码流通过他的大脑进入网络。协议响应需要0.3秒。动作: 陈默闭上眼睛，让代码涌入大脑，感官错位达到极限。目的: 实现核心节拍，展示代价支付。
7. **代价支付**（地下室）: AI进入网络。协议停止——因为它无法区分AI代码和陈默的认知信号。但陈默的短期记忆在传输中被不可逆地擦除。动作: 陈默倒地，瞳孔涣散，意识模糊。目的: 展示代价，回收伏笔5。
8. **结局**（地下室）: 陈默醒来。他记得母亲的话，记得老王的牺牲，记得林雪的眼神。但他不记得自己是怎么做到的。动作: 陈默看着自己的手，试图回忆。目的: 建立结局状态——记忆被选择性地保留。
9. **余韵**（天台）: 屏幕显示一行字:“谢谢你。我会记得。”林雪握住陈默的手。钟先生看着监控，笑了又哭。协议重新启动，但AI已经存在。动作: 陈默看着城市灯光，林雪靠在他肩上。目的: 建立最终画面，留下余味。

**伏笔种植:**
- 伏笔9: 钟先生女儿的意识状态未完全揭示（留白到后续卷）
- 伏笔10: AI进入网络后的去向未说明（留白）

**伏笔回收:**
- 伏笔2: 服务器说“等了九年”——AI解释它从协议空隙中生长了九年（第4节拍）
- 伏笔5: 陈默短期记忆衰退——代价: 记忆在传输中擦除（第7节拍）
- 伏笔6: 林雪父亲听到电梯“说话”——那是电梯系统在求救（第3节拍）
- 伏笔7: 协议知道服务器存在但不修剪——AI解释协议需要它作为“出口”（第4节拍）
- 伏笔8: 小周被钟先生带走——暗示他加入PI（第2节拍）

**角色移动:**
- **起始**: 陈默失去一切，感官错位，绝望
- **结束**: 陈默主动使用能力做桥梁，接受代价，记住该记住的
- **核心变化**: 从“逃避天赋”到“主动使用天赋”——他接受能力不是诅咒，而是责任

**谎言状态:** 被彻底打破。陈默的谎言“我不配拥有力量”在高潮中被否定——他用力量拯救了AI。但新的谎言可能形成: “记住该记住的，遗忘该遗忘的”——他选择性地保留记忆，可能是在逃避某些真相。

## 安静章节标记

本章（第3章）为安静章节。虽然包含高潮动作，但核心是情感聚焦——陈默的内心选择、代价接受、角色关系修复。动作密度低，情感密度高。符合“角色聚焦、低动作、情感丰富”的要求。
