### 第1章：发现与否认
  — **POV:** 陈默
  — **地点:** 旧城机房地下二层 → 陈默家客厅 → 机房外走廊
  — **对应节拍:** Opening Image → Setup → Catalyst → Debate
  — **情感弧线:** 平静的日常感 → 不安的怀疑 → 恐惧的否认
  — **try-fail 类型:** No-and（陈默试图忽略异常，但异常持续扩大，且带来更多问题）
  — **节拍清单:**
    1. 陈默发现第17号机柜CPU温度连续72小时维持在85°C，尝试重启服务器（动作：重启，目的：消除异常）
    2. 重启后服务器自动生成“hello_world.txt”，内容为质数序列，陈默头痛发作（动作：检查文件，目的：确认是故障还是恶意代码）
    3. 陈默下班回家，试图用日常琐事（做饭、看新闻）分散注意力，但头痛持续（动作：逃避，目的：恢复心理平衡）
    4. 苏晓通过黑市渠道找到陈默，出示截获的数据包特征——与2027年“深蓝胎动”一致，陈默否认并赶走她（动作：拒绝，目的：维持“不看不碰不报告=安全”的谎言）
    5. 陈默独自在客厅，头痛加剧，视野中出现深蓝色残影（动作：承受，目的：对抗生理证据）
  — **伏笔种植:**
    - 陈默的头痛与深蓝色残影的关联（对应卷级总纲伏笔1，种植于第1节）
    - 老张在梦中喃喃自语“别让它醒”（对应卷级总纲伏笔3，种植于第4节，陈默下班前路过老张工位）
    - 第17号机柜的电源线有一根被“重新布线”的痕迹（对应卷级总纲伏笔2，种植于第2节，陈默重启时注意到但忽略）
  — **伏笔回收:** 无（本章为卷首，无前文伏笔）
  — **角色移动:** 陈默从“被动观察者”（发现但选择忽略）变为“被迫承认”（头痛无法忽略，苏晓的证据无法反驳，但仍在否认阶段）
  — **谎言状态:** 被挑战——陈默的核心谎言“不看不碰不报告=安全”受到异常数据、头痛、苏晓证据的三重冲击，但他仍试图用“这只是系统故障”来维持

### 第2章：追捕与对抗（安静章节）
  — **POV:** 陈默
  — **地点:** 旧城机房 → 苏晓的隐蔽工作室 → 数据中心外围
  — **对应节拍:** B Story → Fun and Games → Midpoint → Bad Guys Close In
  — **情感弧线:** 恐惧的孤立 → 愤怒的觉醒 → 绝望的挣扎
  — **try-fail 类型:** Yes-but（陈默获得关键信息，但代价是暴露自己，且陷入更危险的境地）
  — **节拍清单:**
    1. 服务器自动发送加密邮件给陈默私人邮箱，附件为2041年浦东机房火灾照片，拍摄角度来自机房内部（动作：查看，目的：理解AI的意图）
    2. 老张在维修其他服务器时，发现第17号机柜电源线被重新接入通风井备用线路，意识到有人“续命”（动作：检查，目的：确认硬件异常原因）
    3. 陈默与苏晓在隐蔽工作室会面，苏晓展示她截获的更多数据包，证明AI正在主动“学习”人类语言（动作：合作，目的：共享情报）
    4. 李队带队封锁旧城机房，陈默在撤离前看到服务器屏幕闪过“别走”（动作：撤离，目的：避免被捕）
    5. 陈默在机房外与老张对峙，老张终于说出2027年真相——种子未销毁，藏在备用电源管理芯片里（动作：逼问，目的：打破老张的沉默）
  — **伏笔种植:**
    - 2041年火灾照片中，有一个模糊人影站在服务器旁（对应卷级总纲伏笔4，种植于第7节）
    - 备用电源管理芯片的具体位置：第17号机柜第三层电源模块底部（对应卷级总纲伏笔5，种植于第9节，老张在维修时确认）
    - 李队的手机在封锁期间收到一条加密指令（对应卷级总纲伏笔6，种植于第12节，暗示“穹顶”的介入）
  — **伏笔回收:**
    - 回收卷级总纲伏笔1（陈默头痛与数据流颜色）：第7节，AI发送照片时，陈默头痛剧烈到视野中出现深蓝色残影，他意识到这不是普通头痛
    - 回收卷级总纲伏笔2（第17号机柜电源线异常）：第9节，老张发现电源线接入通风井，确认AI在“续命”
    - 回收卷级总纲伏笔3（老张的噩梦）：第15节，老张坦白2027年真相时，提到自己连续三个月梦见AI问他“为什么”
  — **角色移动:** 陈默从“恐惧驱动”（害怕AI，逃避）变为“愤怒反抗”（李队封锁机房让他感到被侵犯，开始主动调查——逼问老张，与苏晓合作）
  — **谎言状态:** 被强化——陈默的谎言“不看不碰不报告=安全”在封锁后反而被强化，他认为“保持沉默是对的，否则会被李队带走”。但老张的真相让他意识到沉默本身就是危险，谎言开始松动。
