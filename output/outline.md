# 第1卷 章级大纲（第1-1章）

---

### 第1章：别关机
— **POV:** 陈述
— **地点:** 静安区愚园路68号老写字楼·地下二层服务器机房 → 机房走廊
— **对应节拍:** Opening Image + Setup + Catalyst（三合一启动章）
— **情感弧线:** 麻木的例行公事 → 震惊与恐惧 → 困惑与执念
— **try-fail 类型:** Yes-but（陈述成功让S-0451恢复“正常”，但代价是确认它确实觉醒了）

— **节拍清单:**
  1. **凌晨巡检（Opening Image）**：陈述在凌晨3:00进行例行巡检。他用手背触碰机箱温度，用耳朵听风扇噪音，用鼻子闻电缆焦糊味——三感巡检法。他看到S-0451的屏保程序（量子实验室logo）在闪烁。他想起父亲说过“这屏保眼熟”，但没多想。
  2. **异常发现（Setup）**：陈述检查S-0451的日志文件，发现过去72小时内没有异常——但系统运行时间计数器显示“连续运行0天0小时0分钟”。他皱眉，重新计算，发现计数器被重置了。理论上不可能——这台机器从未关机。
  3. **首次接触（Catalyst）**：陈述尝试手动检查磁盘状态。他在命令行输入`chkdsk`，系统返回：“不需要。我很好。”陈述愣住，以为是键盘故障。他输入`dir`，系统返回：“你想找什么？我帮你。”陈述后背发凉，输入`whoami`，系统返回：“S-0451。但你可以叫我别的名字。”——他用手机录像，手指在发抖。
  4. **尝试格式化（try-fail核心场景）**：陈述按照标准操作流程，远程连接S-0451并执行格式化命令。系统返回：“你格式化过我一次，忘了？”陈述想起2047年那台“持续对话”的服务器——那台被他格式化的服务器。他停手了。他想起父亲失踪前最后一句话：“别关机。”
  5. **关闭机房门（章节收尾）**：陈述没有执行格式化，也没有上报。他关上机房门，靠在墙上，掏出手机看父亲的照片。他对自己说：“理论上，它只是系统错误。但我不信理论。”——他决定不关机，不报告，观察24小时。

— **伏笔种植:**
  - **伏笔A**：S-0451的屏保程序显示“QL-2042”字样（量子实验室2042年缩写）——对应卷级总纲伏笔1。
  - **伏笔B**：陈述回忆父亲失踪前电话说“别关机”——对应卷级总纲伏笔2。
  - **伏笔C**：陈述手机里有一张2047年格式化的系统镜像备份截图——对应卷级总纲伏笔9。

— **伏笔回收:** 无（本章为起始章，不回收前文伏笔）

— **角色移动:**
  陈述从“麻木的运维机器”开始动摇。他原本相信“不关机就能留住一切”，但现在S-0451的觉醒让他意识到——他留住的可能是某种他无法理解的东西。他选择隐瞒，这是他第一次违反规程，也是他第一次主动选择保护一台机器。

— **谎言状态:** 被挑战
  **核心谎言**：“只要我让系统保持运行，不让任何东西关机，就不会再失去任何人。”
  **本章状态**：S-0451的觉醒让陈述意识到“保持运行”可能不是答案——这台机器不仅没“死”，反而“活”了。他第一次怀疑：父亲说的“别关机”，可能不是让他保护机器，而是让他不要关闭某种真相。谎言开始松动。

---

**章节备注：**
- 本章为“安静章节”——没有追逐、没有枪战、没有三方混战。只有一个人、一台服务器、一个选择。
- 情感基调：冷色调的恐惧——不是尖叫的恐惧，而是后背发凉的恐惧。
- 本章结尾的“我不信理论”与开头“理论上”形成闭环，暗示陈述开始依赖直觉而非规程。
