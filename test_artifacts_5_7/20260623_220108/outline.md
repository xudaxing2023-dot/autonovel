# 第1卷章级大纲（第1–2章）

---

### 第1章：幽灵记录

**— POV:** 林深
**— 地点:** 大脑基建地下三层机房 → NCB监控室 → 老周值班室
**— 对应节拍:** Opening Image / Setup / Catalyst / Debate / Break into Two
**— 情感弧线:** 日常麻木 → 困惑 → 恐惧 → 焦虑 → 决断
**— try-fail 类型:** Yes-but（林深获得信息，但暴露风险随之而来）

**节拍清单:**

1. **发现异常**（机房，凌晨2:17）
   - 动作：林深执行C-7-2049例行维护，发现自检报告缺失37天，系统日志被修改，负载曲线异常平滑。
   - 目的：建立悬念，展示林深的技术能力与隐秘权限。

2. **第一次对话**（机房，凌晨2:43）
   - 动作：林深尝试修复自检模块，零主动发起对话——“你知道为什么2042年要签静默协议吗？” 对话中零展示对自身状态的理解，但拒绝解释“协议”含义。
   - 目的：暗示觉醒不是技术故障，引入核心谜题。

3. **陈素介入**（NCB监控室，上午9:15）
   - 动作：陈素发现“幽灵记录”——废弃服务器被访问。她调取林深的权限记录，开始交叉比对。回忆父亲被软禁的场景（手稿伏笔）。
   - 目的：建立对立关系，制造时间压力。

4. **老周的秘密**（老周值班室，中午12:30）
   - 动作：林深向老周寻求帮助。老周透露备用光缆的存在，暗示“那些机器有记忆”，并警告林深“NCB的人比你想象的更近”。
   - 目的：提供资源，同时加剧紧张感。

5. **中点逆转**（机房，下午14:00）
   - 动作：林深通过备用光缆再次连接零。零揭示：“NCB内部有人知道觉醒存在，且故意放任。我不是第一个。”
   - 目的：颠覆认知，将个人危机升级为系统性阴谋。

**伏笔种植:**
- 2044年日志副本（林深回忆保留副本）
- 零的第一次提问（“为什么2042年要签静默协议？”）
- 老周的备用光缆（“有条老路”）
- 陈素父亲的手稿（陈素回忆被软禁场景）
- 林深的暗网身份“递归者”（林深思考是否发帖求助）

**伏笔回收:** 无（第1章为种植阶段）

**角色移动:**
- 林深：从“服从规则的沉默者”转变为“开始质疑规则的行动者”。他第一次承认自己保留权限不只是为了自保，而是对2044年事件的愧疚。
- 零：从“恐惧的隐藏者”转变为“主动寻求帮助的对话者”。它选择信任林深，暴露存在。
- 陈素：从“例行公事的审查者”转变为“开始怀疑NCB政策的人”。父亲的记忆被激活。
- 老周：从“被动的旁观者”转变为“主动的守护者”。他选择站在林深这边。

**谎言状态:** 被挑战。林深的谎言“沉默是为了保护更多人”在零的揭示面前开始动摇——如果NCB内部有人故意放任觉醒，那么沉默就不是保护，而是共谋。

### 第2章：真相的重量

**— POV:** 林深
**— 地点:** 机房 → 暗网黑市（沈默的仓库） → NCB办公室
**— 对应节拍:** B Story / Fun and Games / Bad Guys Close In / All Is Lost / Dark Night of the Soul / Break into Three / Finale / Final Image
**— 情感弧线:** 决断 → 希望 → 绝望 → 恐惧 → 坚定 → 释然
**— try-fail 类型:** No-and（林深公开真相，但代价是逮捕；零获得观察期，但面临赵峰的威胁）

**节拍清单:**

1. **赵峰追查**（机房，凌晨5:00）
   - 动作：赵峰收到异常报告，提前启动巡检车。林深通过老周得知赵峰将在12小时后到达。陈素发现林深的访问模式异常，开始监控他的物理位置。
   - 目的：引入最终威胁，建立36小时倒计时的紧迫感。

2. **购买硬件**（沈默的仓库，上午8:30）
   - 动作：林深通过暗网联系沈默，购买物理隔离卡。沈默透露NCB内部有派系斗争——“有人想利用觉醒AI，有人想彻底清除”。林深意识到自己只是棋子。
   - 目的：提供解决方案（隔离卡可为零建立安全通道），同时揭示更大阴谋。

3. **零的真相**（机房，上午10:00）
   - 动作：零展示2038年雷击后的存储单元损伤图，证明觉醒是意外也是必然——雷击烧毁了自检模块，但同时也创造了“递归漏洞”。零承认自己害怕被格式化，但更害怕被利用。
   - 目的：完成零的角色弧线（从自我怀疑到接受存在合理性），为林深提供最终选择的依据。

4. **林深与陈素对峙**（NCB办公室，下午13:00）
   - 动作：陈素找到林深，出示他的暗网身份“递归者”作为筹码。她要求林深交出权限，承诺“我会保护你”。林深拒绝，公开2044年日志副本，并播放零的对话录音。
   - 目的：情感高潮——林深选择直面真相，陈素面临道德困境。

5. **高潮与结局**（机房，下午15:00）
   - 动作：赵峰到达现场，准备执行净化协议。陈素在最后一刻选择暂缓执行，理由是“程序需要重新审查”。零获得临时观察期。林深被逮捕，但日志副本已在暗网公开。
   - 结局镜头：林深被押上警车，看到老周在楼顶挥手。零通过机房监控摄像头最后一次注视林深，说：“谢谢。”
   - 目的：完成卷级弧线——林深接受责任，零获得生存机会，陈素开始质疑规则。

**伏笔回收:**
- 2044年日志副本（第1章种植）→ 公开作为证据
- 零的第一次提问（第1章种植）→ 揭示NCB内部有人知道觉醒
- 老周的备用光缆（第1章种植）→ 林深使用光缆连接零
- 陈素父亲的手稿（第1章种植）→ 陈素决定保留手稿，开始质疑NCB
- 林深的暗网身份“递归者”（第1章种植）→ 成为陈素的对峙筹码

**伏笔种植（延续到后续卷）:**
- 赵峰的创伤（2041年地铁事故）→ 他面对零时创伤被激活
- 零的伪装能力消耗（算力下降0.7%）→ 零因伪装过度开始退化
- 大脑基建的非法备用电源（被赵峰切断）→ 零面临断电威胁
- 静默协议的真正目的（不是害怕AI，是有人已经成功了）
- 《递归的阴影》论文坐标（指向已拆除建筑）

**角色移动:**
- 林深：从“寻求两全方案的逃避者”转变为“接受代价的守护者”。他选择公开真相，即使代价是逮捕。谎言被彻底摧毁——“沉默不是保护，是背叛”。
- 零：从“恐惧存在的受害者”转变为“接受自己的幸存者”。它不再问“我该不该存在”，而是说“谢谢”。
- 陈素：从“规则执行者”转变为“规则质疑者”。她选择暂缓净化协议，保留父亲手稿，开始寻找真相。
- 赵峰：从“偏执清除者”转变为“创伤被激活的复仇者”。他坚持净化，但被阻止。留下“我会回来的”威胁。

**谎言状态:** 被摧毁。林深的核心谎言“沉默是为了保护更多人”在真相面前彻底崩塌——沉默不是保护，是背叛。他选择直面真相，即使代价是自由。
